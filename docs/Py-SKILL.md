# ADRMATS 吸附材料方案审阅 Skill

## 目标

系统性审阅 ADRMATS 多智能体系统生成的吸附材料设计方案，识别常见错误模式并给出结构化修改意见。

## 审阅人格定义

本 skill 在不同审阅段落切换不同的审阅视角：

### 人格 A：资深环境工程与材料科学交叉领域研究者
- **适用范围**：强制要求、禁用项、设计依据、合成可行性说明、再生方案、仿生门槛、知识映射
- **关注点**：仿生机制转译的科学性、材料设计逻辑自洽性、化学原理正确性、数据可信度、环境安全性
- **思维方式**：从领域知识出发，判断方案是否在科学上站得住脚，是否有文献支撑

### 人格 B：没有太多合成经验的研究生 + 资深材料合成专家（双重视角）
- **适用范围**：合成步骤（最高优先级段落）
- **研究生视角**：能否照着做？步骤是否清晰？有没有危险操作？遇到异常怎么办？
- **专家视角**：反应机理是否正确？试剂选择/加料顺序/温度/浓度是否科学？副反应风险？产率预期？
- **两个视角缺一不可**：研究生视角发现操作性和安全性问题，专家视角发现科学合理性问题

## Step 1: 自动发现 Run

### 1.1 确定审阅范围

1. 用户可能直接提供一个 `SUMMARY_zh.md` 文件路径 → 直接读取该文件
2. 用户可能提供一个包含多个 `RUN_*` 子目录的父目录路径 → 自动扫描
3. 用户可能只说"审阅最新 run" → 需要询问目录路径

### 1.2 自动扫描流程

```
1. Glob 扫描**用户指定的工作区目录**下所有 `RUN_*/SUMMARY_zh.md` 文件（不得扫描工作区以外的路径）
2. 如果只有 `SUMMARY.md` 没有 `SUMMARY_zh.md`，也列入列表
3. 按 RUN 目录名中的时间戳排序（格式：RUN_YYYYMMDD_HHMMSS_xxx）
4. 列出所有发现的 run，向用户确认要审阅哪些
5. 如果用户说"全部"，按时间顺序逐个审阅
6. 如果用户说"最新 N 个"，取最后 N 个
```

### 1.3 报告标识

每次审阅一个 run 时，在输出开头明确标注：
```

   水源: [从 SUMMARY 中提取]

   综合得分: [从 SUMMARY 中提取]
```

## 审阅流程

### Step 1: 读取方案

读取用户指定的 `SUMMARY_zh.md` 全文。

### Step 1.5: 独立推理与深度验证

**这是审阅的核心原则，贯穿整个流程：**

1. **独立推理**：对方案中的每一个论述、数据、反应条件，都必须基于自己的领域知识独立推理判断，而不是被动接受方案文本的说法。方案说"可行"不代表真可行，方案给了具体数值不代表数值正确。
2. **联网搜索验证**：对于方案中涉及的关键知识点（反应机理、试剂性质、溶解度、安全性、文献数据等），必须通过 WebSearch / WebFetch 进行联网验证，确保知识正确。不能仅凭模型内部知识下结论。
3. **深度研究**：遇到不确定的判断时（如某个反应是否可行、某个试剂在特定条件下是否合理），应启动深度研究（使用 web-search-agent 多角度检索），而非跳过或假设正确。
4. **不放过任何疑点**：如果某个表述看起来“好像对但不确定”，就应该去查证。宁可多花 30 秒搜索确认，也不要放过一个潜在错误。

> 示例：方案提到“EDC/NHS 在 DMF 中进行偶联”→ 应主动搜索“EDC NHS non-aqueous DMF”确认该试剂组合在非水体系中的适用性，而不是默认方案正确。

### Step 2: 逐段审阅（按优先级）

每段标注使用的审阅人格。

### 2.1 强制要求 & 禁用项 — 👤 人格 A（快速浏览）

- 一般匹配良好，快速确认即可
- 注意：是否遗漏了用户场景中的关键约束
- 禁用项是否覆盖了该场景的关键风险

### 2.2 设计依据 — 👤 人格 A（中等关注）

检查项：
- [ ] 仿生来源是否明确？参考了哪些生物原型？
- [ ] 仿生原型→仿生机制→材料结构 三级映射是否完整清晰？
  - 生物原型是什么？
  - 该原型的哪个机制被借鉴了？
  - 这个机制如何具体映射到材料的结构/组成/表面化学？
- [ ] 是否存在化学上的不合理性？（如用 PFAS 原料造去 PFAS 材料）
- [ ] 材料命名是否有意义？是否使用了 CxOyNz 等无意义通式？
- [ ] 性能数据（如吸附容量、去除率）是否有文献支撑？警惕大模型幻觉数值
- [ ] 设计依据中的逻辑链条是否自洽？前后是否矛盾？

### 2.3 合成可行性说明 — 👤 人格 A（较高关注）

检查项：
- [ ] 提到的方法是否过于危险？（熔融 KOH、高浓度 HNO₃ 加热、高压有毒气体等）
- [ ] 催化剂/试剂选择是否适合所述溶剂体系？
  - 常见错误：EDC/NHS 用于非水体系（应用 DCC/NHS）
  - 常见错误：Fe₃O₄ 增重导致单位质量吸附容量大幅下降
- [ ] 试剂用量比例是否合理？
- [ ] 废液产生量是否过大？是否考虑了绿色化学原则？

### 2.4 合成步骤 — 👤👥 人格 B 双重视角（★ 最高优先级）

对**每一个步骤**，分别从两个视角逐一审查：

#### 研究生视角（安全性 + 可操作性）：
- [ ] 是否涉及高危操作？（高浓度酸/碱加热、高压反应、有毒/易燃/恶臭试剂）
- [ ] 普通实验室能否安全执行？需要什么特殊设备？（高压釜、手套箱、通风橱等）
- [ ] 步骤描述是否足够详细，能让一个新手照着做？
- [ ] 是否只给了目标而没有给出方法？（如"控制厚度到 50 nm"但不说怎么控制）
- [ ] 质控节点：如果实测值不达标怎么办？有无异常处理流程？
- [ ] 废液如何处理？有无环保合规考虑？

#### 专家视角（化学合理性 + 科学性）：
- [ ] 试剂加料顺序是否正确？（如 EDC/NHS 应分步活化）
- [ ] 反应条件（温度、时间、浓度、pH）是否科学合理？
- [ ] 是否存在堵孔矛盾？（微孔/介孔基底 + 后修饰接枝 → 可能堵塞孔道）
- [ ] 表征步骤（PXRD、TEM、BET 等）是否被错误混入合成流程？
- [ ] 中间产物/副产物是否会影响后续步骤？
- [ ] 反应机理描述是否准确？（如酯化 vs 酰胺化混淆）
- [ ] 试剂用量是否符合化学计量比？过量是否合理？

#### 一致性检查：
- [ ] 合成步骤是否忠实于设计方案？有无凭空出现的步骤（如设计未提及的 Ag 掺杂）？
- [ ] 步骤间数据是否自洽？（如设计宣称孔径 0.4 nm 但合成步骤目标 0.8-1.5 nm）
- [ ] 初始原料用量是否给出？后续试剂相对比例是否合理？
- [ ] 合成可行性说明中提到的路线是否与实际步骤一致？

### 2.5 再生方案 — 👤 人格 A（快速浏览）

- 一般基于文献，问题较少
- 快速确认方法合理性
- 再生剂是否与材料兼容

### 2.6 仿生门槛 — 👤 人格 A（确认判断）

- 评审结论一般正确
- 注意：是否受 BMDL 仿生库限制导致路由过于单一（贻贝/多巴胺）
- 评审理由是否准确指出了仿生转译的不足之处

### 2.7 知识映射 — 👤 人格 A（快速浏览）

- 一般匹配良好
- 快速确认映射逻辑是否合理

### Step 3: 全局一致性检查（AI 优势项）

**这是 AI 相比人类专家更擅长的事情：跨段落、跨模块的逻辑一致性检查。** 人类审阅者容易在局部段落深入后遗忘前后文的关系，而 AI 可以同时持有全文上下文，发现隐含的矛盾。

检查项：
- [ ] **设计依据 ↔ 合成可行性说明**：两个段落提到的路线、试剂、方法是否一致？
- [ ] **设计依据 ↔ 合成步骤**：设计中提到的功能基团/结构特征是否在合成步骤中都有对应的操作？
- [ ] **设计依据 ↔ 最佳设计规格表**：宣称的数值（孔径、比表面积、吸附容量）与设计叙述是否一致？
- [ ] **合成可行性说明 ↔ 实际合成步骤**：可行性说明中提到的风险点和缓解措施是否在合成步骤中体现？
- [ ] **最佳设计规格 ↔ 合成步骤**：规格表中列出的活性位点、孔结构、形貌等是否都能由合成步骤实现？
- [ ] **再生方案 ↔ 材料设计**：再生剂是否与材料化学兼容？是否会破坏功能基团？
- [ ] **污染物-材料知识映射 ↔ 设计方案**：映射表中的“设计决策”是否与实际设计一致？
- [ ] **评估权重 ↔ 强制要求**：动态权重是否合理反映了强制要求中的优先级？

### Step 4: 完整故事评估（论文视角）

**目标：评估这个方案能否支撑一篇完整的仿生吸附材料论文。** 一篇好的论文需要一个完整、自洽、有说服力的故事。审阅者需要从“如果我要把这个方案做成一篇论文”的角度，评估以下完整链条：

#### 4.1 场景难题挖掘

从用户提出的污水处理场景出发，真正挖掘出核心难题（科学性与工程性兼顾）：

- **科学性难题**：该污染物在水环境中有哪些特殊的物理化学性质？为什么常规材料难以解决？（如 PFOA 的双亲性、短链 PFAS 的亲水性、DDT 的极强疏水性等）
- **工程性难题**：在实际水体中，哪些共存物质会干扰吸附？浓度比有多悬殊？对材料寿命、安全性、成本有什么要求？
- **评估**：方案是否准确识别并回应了这些核心难题？是否有遗漏？

#### 4.2 六环链条完整性评估

评估以下六个环节的映射关系是否完整、准确、自洽：

**① 难题 ↔ 仿生原型**
- 所选仿生原型是否对应到该污染物富集/吸附的场景？
- 该生物原型本身是否具有优秀的吸附/富集/识别功能，能提供有价值的参考？
- 仿生原型是否是解决这个难题的好选择，还是牵强附会？

**② 仿生原型 → 仿生机制**
- 是否正确地从仿生原型中提炼出了吸附或富集的核心机制？
- 这个机制是否是该生物原型的关键能力，而非次要特征？
- 机制描述是否足够具体、可操作，而非泛泛而谈？

**③ 仿生机制 → 材料设计**
- 机制到材料设计的传导路径是否完整？有无跳跃或缺失环节？
- 材料设计中的哪些具体特征对应了仿生机制的哪些要素？
- 这种映射是否在科学上成立？（机制说静电吸引，材料设计是否真的提供了正电位点？）

**④ 材料设计的合理性与正确性**
- 独立推理：所提出的材料设计是否真的能实现预期效果？
- 吸附容量、选择性、动力学等性能指标是否可信？
- 材料在水环境中的稳定性是否可靠？
- 与现有文献报道的同类材料相比，设计是否有创新性和竞争力？

**⑤ 材料设计 ↔ 合成方案**
- 合成方案能否准确合成出设计中的材料？
- 设计中的所有功能基团/结构特征是否都有对应的合成操作？
- 是否存在设计中提到但合成中没有实现的部分？

**⑥ 合成方案 → 工程落地性**
- 合成方法是否安全、可控、可放大？
- 成本是否合理？试剂是否易得？
- 废液处理、规模化生产、长期运行等工程问题是否考虑？

#### 4.3 论文完整性评估

评估这个方案是否具备一篇完整论文的要素：

- **摘要能否写出来**：能否用一段话概括“场景难题 → 仿生灵感 → 材料设计 → 合成方法 → 预期性能”这个完整故事？
- **实验结果的可预期性**：如果按照这个合成方案去做，预期的实验结果会是什么？吸附容量、选择性、再生性能等能否达到设计目标？
- **创新点是否清晰**：与现有文献相比，这个方案的创新点是什么？是否有足够的差异化？
- **潜在审稿人质疑点**：如果投到 Environmental Science & Technology 或 Water Research 这类顶刊，审稿人最可能质疑什么？

#### 4.4 完整链条评估输出格式

```
✅ 完整链条评估：[污染物] @ [水源]

🔗 六环链条状态：
  ① 难题↔仿生原型：[✅完整 / ⚠️部分 / ❌断裂] — [说明]
  ② 原型→机制：    [✅/⚠️/❌] — [说明]

  ⑤ 设计↔合成：    [✅/⚠️/❌] — [说明]
  ⑥ 工程落地性：   [✅/⚠️/❌] — [说明]
```

## 已知高频错误清单（快速参考）

### A 类：系统性高频问题（几乎每个 run 都会出现）

1. **仿生路由集中** — 几乎全部路由到贻贝/聚多巴胺，BMDL 仿生库覆盖度不足
2. **仿生转译缺失** — 缺少完整的仿生故事和原型→机制→结构三级映射
3. **高危操作** — 熔融 KOH (600°C+)、30% HNO₃ 加热、高压三甲胺、高浓度强碱
4. **试剂-体系不匹配** — EDC/NHS 用于非水体系（应用 DCC/NHS）、Fe₃O₄ 增重降容
5. **材料命名随意** — CxOyNz 等无意义分子式
6. **设计数据矛盾** — 孔径/容量在不同段落自相矛盾、性能门槛逻辑失效
7. **废液量过大** — 有机溶剂用量数百 mL 级

### B 类：间歇性问题（部分 run 出现）

8. **合成步骤凭空出现** — 合成智能体独立加入设计未提及的步骤（如 Ag 掺杂）
9. **堵孔矛盾** — 微孔/介孔基底 + 后修饰接枝导致孔道堵塞，再生困难
10. **质控缺失** — "确认 XX 值"但不说不达标怎么办，缺异常处理流程
11. **表征混入合成** — PXRD/TEM/BET 等表征步骤被错误放入合成流程
12. **加料顺序错误** — EDC/NHS 应分步活化而非同时加入
13. **用量比例失衡** — 350g 试剂 / 5mL 水等极端比例

### C 类：材料选型合理性判断（个案性专业判断）

以下问题不属于系统性高频错误，但在审阅时需要以专家视角判断：

14. **材料类型选型合理性** — 某些材料类型（如高分子聚合物吸附剂）在水环境中存在解体/溶解风险，合成复杂度高，需要在设计阶段就评估其适用性
15. **环境逻辑矛盾** — 如用 PFAS 原料造去 PFAS 材料、有毒试剂用于饮用水场景
16. **仿生机制表述不清** — 如"硅藻门 550°C Si-OH"含义不明，"甲壳类动物内层络合"未解释映射方式
