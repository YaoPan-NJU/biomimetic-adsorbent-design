## 1. 质询原文（要点）

BPA 与结构类似物 BPF、BPS、BPAF 共存，这里面需要关心：其他同系干扰物的环境检出频率如何？风险（PNEC）如何？

- 如果其他同系物和 BPA 一起高频出现，但风险不如 BPA 高，无选择性的吸附剂会浪费大量本可以吸附 BPA 的位点——那么这种选择性是有价值的。
- 如果反过来，环境中根本没有这些污染物，那去做选择性，岂不是虚空索敌？
- 如果这些同系物的毒性比双酚 A 还要高，那没有必要对它们做选择性（应当一并去除）。
- 真正有用的选择性，应该是对无关的 DOM、盐之类的基质背景。

这是科学问题上所有人都需要形成的判断共识。

## 2. 判据（规范文本）

任何方案声称"对目标物 T 相对竞争物 C 有选择性"之前，必须先回答 **C 是谁、值不值得对它有选择性**：

### 2.1 基质背景选择性是底线必需

DOM、无机盐（竞争阴离子/阳离子）、无关微污染物永远以巨大过量存在并竞争位点。对基质背景的选择性是"真正有用的选择性"，一切方案必须以此为第一设计目标与第一验证对象。

### 2.2 对结构同系物/类似物的选择性须先建立两条证据

- **(a) 共现证据**：该同系物在目标水体（本项目默认为市政二级出水）中的检出频率与浓度范围，须给出可核验来源；
- **(b) 风险对比**：该同系物的风险（PNEC、毒性 endpoint、监管地位）相对目标物的高低，须给出可核验来源。

### 2.3 决策矩阵

| 共现情况 | 风险对比 | 结论 |
|---|---|---|
| 高频共现 | 同系物风险 < 目标物 | 对它们的选择性**有价值**（位点不被低风险同系物浪费） |
| 基本不出现 | 任何 | 对它们做选择性是**虚空索敌**，不得作为设计目标；只保留基质选择性 |
| 高频共现 | 同系物风险 ≥ 目标物 | 对它们做选择性**适得其反**，应类级共去除；选择性努力转向基质背景 |
| 共现证据缺失 | 任何 | 选择性主张**挂起**：补证据，或降级为机制探针并如实标注 |

### 2.4 对竞争实验设计的推论

竞争实验的竞争物集合必须按**环境真实浓度比例**配置；不得用等摩尔同系物鸡尾酒夸大罕见同系物的权重。等摩尔混合物只可作为机制探针实验，且须与"环境比例混合物"实验分开报告、分开下结论。

### 2.5 与既有评审维度的关系

fresh_1000 创新清单 D 维（选择性策略创新）原要求"竞争物谱全部为结构近似物"——本判据**补充而非取消**该要求：结构近似物仍是机制可证伪性的必要探针，但**选择性主张的环境价值**必须另按 2.2/2.3 举证。二者分开陈述：机制探针（结构近似物，等摩尔可）与环境价值主张（按 2.3 决策矩阵）。

## 3. 适用范围

所有分支（main/Qwen/Ultimate/dsreview/kimi-k3）的全部在议、通过、暂停方案；后续新设计必须在场景节（痛点 1）内直接回答 2.2 两条证据；评审者对缺失者按 2.3 第四行处理。

## 5. 整改要求（按方案）

1. **BPA20-01 / S14（最优先，U-019 下一轮讨论的前置项）：**
   - 补 BPF/BPS/BPAF 在市政二级出水的检出频率与浓度（可核验来源），并补 PNEC/毒性/监管对比；
   - 按 2.3 决策矩阵重写场景节：若同系物低频或缺证，四元竞争降级为机制探针，选择性环境价值主张改写为"对 DOM/盐基质背景的选择性 + 对真实检出的双酚类级共捕"；
   - 竞争实验增设"环境比例混合物"臂，等摩尔四元只作机制探针臂；
   - S2 硬门（α*(BPA/BPAF) 逆 logKow）保留为机制探针判据，但其"环境必要性"表述以补证结果为条件。
2. **DCP20-01：** 补 2,4-/2,5-/3,5-DCP 检出与风险证据；缺证则位置异构体选择性降级为机制探针，环境价值主张改写为抗 DOM 屏障 + 基质选择性。
3. **GX50-01：** 场景节明示竞争 PFAS 均为高风险受监管物、按判据应类级共捕；GenX 专属增量改标为"监测/机制需求"，不作环境必要性主张（方案已停，整改以存档批注形式记录）。
4. **S27、S32、S34：** 各自竞争物对按 2.3 第四行标注"环境价值待证"，补共现/风险证据或把头部选择性判据改标机制探针。
5. **S31：** 补氯酚同族物共现与 PCP/TeCP 风险对比；缺证则 snug-fit 选择性降级为主客体机制研究。
6. **S51：** 记录方向性错误（风险同级应共捕），不整改（已停）。
7. **SC-P02：** 补强四成员检出频率引文（UCMR 3/5、NPDWR、EPA HA），把"四成员均为受监管物 → 类级共捕"的判据符合性显式写入场景节。
8. **SPEC/评审规约：** fresh_1000 创新清单 D 维与 DESIGN_BRIEF 类文档增补 2.5 条口径（结构近似物为机制探针，环境价值另证）。
