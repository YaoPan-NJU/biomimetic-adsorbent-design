# 仿生方案可视化解释提示词包规约

状态：`main` 约束性规约，2026-08-02 生效。适用于供潘尧审阅的独立方案包。图像用于帮助跨学科专家检查生物原型、功能抽象、材料映射和合成逻辑，不是科学证据、结构表征或性能结果。

## 1. 触发条件与交付边界

每个作为独立方案交付的 `concept_valid`、`E1_ready` 或 `E2_ready` 材料实现，在提交潘尧审阅前必须附一套可直接交给 ImageGen 的提示词包。大型候选表中的一行、`lead_only` 线索、常规对照和已否决实现不强制逐条生成；当其中任何一项被单独提交为方案时，本规则立即生效。

提示词包在独立设计、首次攻击和 Reviewer 裁决冻结后生成。设计者和攻击者不得先看图再补造机制。图像生成结果不得进入证据台账，不得改变 Gate A/B/C、E1/E2、分数或谱系状态。

历史方案不批量改写。本规约生效时仍待 owner 审阅的正式 E1 方案优先回填；后续方案与其设计包同步产出。

## 2. 图的固定叙事骨架

默认使用横向三栏，并允许在 C 栏加入小型合成流程嵌图：

1. **A 生物证据：** 只画来源已支持的生物结构、界面、分配、屏障或运输过程。必须写清目标物是否被直接测试。没有坐标或直接显微证据时使用示意图，不能伪造成原子级结构或真实显微图。
2. **B 功能抽象：** 只写不依赖材料名称的 TR 转译原则，区分必要功能、支持功能和未知项。不得把蛋白折叠或生物组分直接搬入材料。
3. **C 候选人工材料：** 画确切 ME 材料实现、候选人工识别单元、关键空间组织、最小 SR 合成流程和最有判别力的因果对照。整栏必须标注“Proposed design, not experimentally validated”或同义的准确状态。

三栏不能呈现为同等证实程度。A 栏是证据，B 栏是有来源边界的抽象，C 栏是待实验推翻或支持的工程假说。

## 3. 可视化主张分级

提示词包必须逐项填写可视化主张账本，每个将被画出的对象只允许以下身份：

| 类别 | 含义 | 推荐视觉语言 |
|---|---|---|
| `OBSERVED` | 来源直接支持且定位已核验的事实 | 黑色或深灰实线；标证据 ID |
| `ABSTRACTED` | 从证据抽象出的可转译功能，不是直接观察对象 | 蓝色轮廓、箭头或半透明功能区 |
| `PROPOSED` | 人工材料、相互作用、空间组织、合成结果或性能假说 | 橙色虚线、问号、红色未验证横幅 |
| `UNKNOWN_OMITTED` | 证据不足、未实现或有意不画的关系 | 不绘制；必要时以空白或“not established”说明 |

任何 `PROPOSED` 关系不得使用与 `OBSERVED` 相同的黑色接触线。图例必须解释上述差别。

## 4. 每套提示词包的必备组成

一套完整文件包含：

1. **版本锁：** `scheme_id`、材料实现、释放状态、来源文件、来源文件 SHA-256、仓库基准提交、提示词版本和生成日期。
2. **可视化主张账本：** 图中对象、分级、来源证据、允许画法、禁止外推。
3. **参考资产清单：** 哪些 PDB 渲染、化学结构、谱图或材料截面必须先由受控工具生成，哪些只是可选风格参考。
4. **ImageGen 主提示词：** 采用一致字段顺序，至少包含 use case、audience、primary request、scene、subject、style、composition、verbatim text、constraints 和 avoid。
5. **成图复核清单：** 逐项核对文字、分子连接、几何、证据等级、材料组成、合成顺序、状态横幅和新增主张。
6. **定向修正提示词：** 只改错误区域并重申其余不变，避免每次重写整张图导致内容漂移。

模板位于 `templates/VISUAL_EXPLANATION_PROMPT_PACKAGE_TEMPLATE.md`。

## 5. 精确结构和化学式的处理

ImageGen 不是分子建模、晶体结构或化学绘图软件。仅凭文字写“依据某 PDB”不能保证残基坐标、配体构象或接触方向正确。以下对象若是论证关键，必须先制作并附上经核对的参考资产，再把 ImageGen 用于版式整合：

- PDB 中的残基位置、配体构象、距离和氢键方向；
- 单体、候选人工识别单元、模板和目标物的精确二维结构；
- 数值图、谱图、真实显微结构或材料截面；
- 壳层厚度、孔径和局部位点距离等定量几何。

没有资产时采用安全降级：画功能示意、分子轮廓或标注方框，不显示原子级连接、残基坐标或定量尺度。提示词不得要求模型“自行查找”PDB、文献或数据库。

## 6. 文字与版式控制

- 图内只允许使用提示词包列出的逐字文本，不允许模型补写新结论。
- 标题、状态横幅和三至六个核心标签优先；详细解释可放图注，不把整段报告塞入图中。
- 罕见缩写、材料代码和化学名称必须逐字核对。成图中任何拼写错误都视为 QC 失败。
- 采用白底、克制配色、清楚留白和可打印字号。箭头表达推导方向，不能表达尚未证实的因果强度。
- 图像中若显示合成流程，只画已冻结的关键顺序、空间变量和 QC 停止点，不画未冻结条件，也不暗示产品已成功制得。

## 7. 成图后的强制复核

至少由当前设计资料复核以下八项：

1. A 栏是否只包含来源支持的对象，且直接目标与类似物没有互换；
2. B 栏是否仍是不依赖材料名称的 TR，而不是对 C 栏的倒推说明；
3. C 栏是否显著标明候选、未实验验证和当前释放状态；
4. 分子连接、官能团、材料组分、模板和合成顺序是否与设计文件一致；
5. 未验证接触是否全部使用假说视觉语言；
6. 是否新增了选择性、容量、抗污、再生、水稳定、尺度或孔几何主张；
7. 删除体、错配体或空间随机体是否被画成真正的因果检查，而不是装饰；
8. 图中文字是否逐字正确、无乱码、无多余标签。

任一项失败时，图像状态为 `rendered_unreviewed`，不得用于 owner 裁决、汇报或论文。修正后重新检查；只有 `visual_qc_passed` 的图可以进入正式沟通材料。

## 8. 版本失效规则

出现以下任一变化，旧提示词和旧图自动标为 `stale`：

- SP、BP、TR、ME 或 SR 任一模块发生实质修改；
- 释放状态、关键停止线或候选人工识别单元改变；
- 新证据推翻图中的直接接触、空间关系或功能边界；
- 来源设计文件 SHA-256 与提示词包记录不一致。

修订时保留旧文件用于审计，新建版本并说明变化。不得只改图片、不更新提示词和主张账本。

## 9. 对潘尧提供示例的吸收与修正

ERRγ–BPA–P1-MAPy 示例保留了四个优点：证据、抽象和人工假说分栏；候选栏明确写未验证；未建立的相互作用用问号和不同线型；底部图例解释证据等级。

该示例也显示出需要流程修正的风险：文字提示不能保证 PDB 几何准确；ImageGen 可能画错 P1-MAPy 连接；密集图中文字可能失真；概念性多孔网络容易被误读为已经形成预组织位点。以后通过参考资产清单、主张账本、短文本白名单和成图 QC 处理这些风险。该历史示例只作为工作流参考，不恢复其后来已被修订的科学方案。
