# GLOBAL_SPEC — fresh_1000 千方案马拉松全局设计规范

> 版本：v1.0 | 日期：2026-07-29 | 状态：生效

---

## 1. 目的与范围

本文件整合分散于 `SOUL.md`、`SPEC.md`、`BIOMIMETIC_DESIGN_FRAMEWORK.md`、`INNOVATION_CHECKLIST.md`、`research_contract.yaml`、`PROTOCOL.md` 中的方法论规则，形成 **统一硬约束层**。

- **定位**：千方案马拉松（20 种污染物 × 50 槽 = 1000 方案）的全局设计规范，所有分类 Spec 与污染物执行 Spec 均继承本文件。
- **效力**：本文件中的规则为 **不可降级** 的硬约束；分类 Spec 可追加更严要求，不可放宽。
- **适用范围**：fresh_1000 全部 20 种污染物的 Phase A（简报+角度地图）与 Phase B（方案槽设计-攻击-裁决）。

## 2. 核心要素

### G1. 科学因果链模板

> 来源：`SOUL.md` Scientific spine + `SPEC.md` 单方案闭环标准第 1 条 + `BIOMIMETIC_DESIGN_FRAMEWORK.md` 第四节

每个方案必须建立以下贯通因果链（非并列清单）：

```
污染物难去除的根因
  → 该根因恰是传统合成方法原理上做不到的
    → 某生物原型在进化中解决了该根因
      → 提取可转译的设计原理（非直接复制蛋白结构）
        → 人工材料实现（识别单元 + 载体架构）
          → 可证伪实验（含因果对照）
            → 论文主张
```

**模板格式**（每个方案必填）：

| 环节 | 内容要求 |
|------|---------|
| 科学问题 | 该污染物难去除的本征原因（非"浓度低"，须指出选择性/传质/热力学瓶颈） |
| 工程难题 | 传统方法原理上做不到的具体能力（如"在 mM 硫酸根背景下选择性识别 ng/L 级四面体磺酸根"） |
| 生物原型 | 自然界进化解决该难题的具体原型（须通过"自然界进化解决方案"判据） |
| 设计原理 | 从原型提取的可转译机制（如"疏水腔 + 极性锚定 + 空间预组织"） |
| 材料实现 | 人工材料中实现该原理的具体特征（非蛋白、非折叠肽） |
| 可证伪实验 | 成功/失败判据，含因果对照与竞争物谱 |

**判据**：若无法写成上述贯通链，则方案不成立。痛点须从仿生能力 **倒推**，而非先有方案再凑痛点。

### G2. 仿生对应矩阵标准

> 来源：`SOUL.md` + `BIOMIMETIC_DESIGN_FRAMEWORK.md` 第三节 + `research_contract.yaml` hard_correspondence

**至少 1 条硬对应**（方案须包含），每条约六列完整：

| 列 | 说明 |
|----|------|
| 生物特征 | 原型的关键结构/机制特征 |
| 来源支持 | 文献证据（DOI/URL、标题、年份、定位、证据层级、核验状态） |
| 材料实现 | 人工材料中对应的具体特征 |
| 预期功能 | 该对应预期实现的选择性/传质/再生功能 |
| 测量 | 验证该功能的实验方法与指标 |
| 因果对照 | 隔离该特征贡献的对照实验（缺失则因果链不闭合） |

**规则**：
- 动态对应 **可选**；若声称须独立满足同一六列标准。
- 动态对应不得将蛋白、折叠肽、铰链或响应单元强行引入材料。
- 形态相似、熟悉的生物衍生聚合物或通用官能团 **不构成** 有效对应。
- 仿生对应须通过"自然界进化解决方案"判据：原型在自然界中自然存在，且进化出来解决类似问题。SELEX 适配体、噬菌体展示肽、合成生物学改造分子 **不构成** 仿生原型。

### G3. 创新性五维检查

> 来源：`INNOVATION_CHECKLIST.md`

每个方案进入正式评分前 **必须逐项通过** 以下五维检查：

| 维度 | 核心要求 |
|------|---------|
| **A. 机制创新** | 选择性机制超越普通疏水分配/静电吸附/尺寸筛分；提出可被因果对照推翻的新识别原理 |
| **B. 材料架构创新** | 超越载体替换或孔径调参；引入新空间组织方式（预组织位点、受限腔体、梯度结构） |
| **C. 仿生转译创新** | 超越官能团类比；提取不可由常规化学直觉得到的设计原则 |
| **D. 选择性策略创新** | 选择性不可由单一物化参数（logKow/电荷/分子量/链长/pKa）单调解释；须 ≥2 个正交识别维度协同 |
| **E. 先例区分** | 完成系统先例检索；与最近先例的区别可被实验量化；增量贡献足以支撑独立发表 |

**判定规则**：
- A-E 中 **至少一个维度** 须展示明确的、可被实验验证的创新性。
- 纯载体替换、参数优化、已发表平台的简单复用 **不算创新**。
- 未通过创新性检查的方案 **不得进入正式评分**。

### G4. 评分量表与通过标准

> 来源：`research_contract.yaml` final_scoring + `SOUL.md` Acceptance

**六维评分量表**（总分 100）：

| 维度 | 满分 | 说明 |
|------|------|------|
| 因果闭环 (Causal closure) | 20 | 科学问题→工程难题→生物原型→设计原理→材料实现→实验验证的贯通性 |
| 选择性吸附机制 (Selective adsorption mechanism) | 25 | 选择性来源的正交性、竞争物谱覆盖、因果对照完整性 |
| 人工材料可转译性 (Artificial material translatability) | 20 | 仿生转译是否超越官能团类比、材料复杂度是否可控 |
| 原创性 (Originality) | 15 | 机制/材料/策略的创新程度，先例区分 |
| 实验可证伪与对照 (Experimental falsifiability and controls) | 10 | 成功/失败判据、因果对照、基质效应、再生/泄漏/稳定性 |
| 证据完整性 (Evidence integrity) | 10 | 证据层级标注、文献核验状态、事实/推断/假设分层 |

**通过线**：**≥ 85/100**，且：
- 未决 critical 问题 = 0
- 未决 high 问题 = 0
- 创新性检查清单通过
- 含至少 1 条硬功能对应（实现于人工材料）
- 提供可信的台架合成 SOP
- 每个核心主张均映射到测量与因果对照

**任何轮次不降低评分门槛。**

### G5. 证据规则

> 来源：`SOUL.md` Evidence rules

| 规则 | 说明 |
|------|------|
| **禁止编造** | 不得编造引用、引文、参数、生物机制、合成条件或性能预测 |
| **摘要不足** | 仅阅读摘要、关键词重叠、有 DOI 但未检视证据 → **不得标 verified** |
| **分层标注** | 每条证据须区分：事实 (fact) / 来源支持的线索 (source-backed lead) / 推断 (inference) / 设计假设 (design hypothesis) |
| **硬主张须直接支撑** | 核心主张须有经全文检视的直接证据；缺失支撑是知识空白，不是推断确定性的许可 |
| **数据库文本非独立验证** | 数据库条目文本不视为独立验证的风险证据 |
| **证据记录格式** | 每条证据含：DOI/URL、标题、年份、支持的主张、定位（图表/页节）、证据层级、核验状态 |

### G6. 材料复杂度约束

> 来源：`BIOMIMETIC_DESIGN_FRAMEWORK.md` 第六节 + `SOUL.md`

**材料体系优先级**：

| 优先级 | 体系 | 说明 |
|--------|------|------|
| 优先 (primary) | 活性炭/工程多孔碳 | 成本最低、水稳定性好、工程化成熟 |
| 二级 (secondary) | 多孔聚合物 (HCP/PAF)、COF、MIP | 结构明确、孔径可控 |
| 避免 (avoid) | MOF、蛋白质/抗体、二维材料 | 成本高、水稳定性差、难以规模化 |

**硬约束**：
- 默认交付物为 **可制造的人工吸附剂**。
- 蛋白、表达构建体、折叠肽、蛋白衍生生物杂合体 **须潘尧明确重开 scope**，不得默认进入。
- 不要求复制蛋白质精确三维结构；提取 **设计原理**，用可合成材料实现。
- 载体选择 **材料类别中性**，须计入惰性质量。

**报告口径**（所有方案统一）：
- 总干复合体 mg 目标物/g
- packed-bed mg 目标物/mL
- 可及位点密度 (mmol/g)
- 空白载体贡献（匹配条件下）
- 受体质量分数与位点利用率

**拒绝规则**：若惰性载体质量代价未被选择性、基质耐受性、再生性、稳定性或床层性能补偿，则拒绝该载体方案。

### G7. 浓度场景分析模板

> 来源：`BIOMIMETIC_DESIGN_FRAMEWORK.md` 第五节

每个方案 **必须包含** 完整的浓度场景分析：

**至少 5 个场景**：

| 场景 | 浓度范围 | 典型值 | 来源 (DOI/作者年份) | 是否主目标 |
|------|---------|--------|---------------------|-----------|
| 点源高浓度（工业废水） | mg/L 级 | — | — | 通常否 |
| 点源中浓度（医院/养殖废水） | µg/L 级 | — | — | 可选验证 |
| 市政进水 | µg/L 级 | — | — | 通常否 |
| **市政二级出水** | **ng/L - µg/L** | — | — | **通常主目标** |
| 受纳水体（地表水） | ng/L 级 | — | — | 可选外部验证 |

**要求**：
- 每场景含浓度范围 + 典型值 + 来源 + 主目标标注
- 主目标场景至少 3 篇文献数据
- 明确列出实验浓度点（低/中/高）及选择理由
- 实验浓度须匹配主目标场景，避免过高（与真实场景无关）或过低（接近检测限）

### G8. 迭代与终止策略

> 来源：`SPEC.md` 迭代政策 + 耗尽条款

**单槽迭代**：
1. 每个方案槽执行 **2 轮** 设计-攻击-裁决
2. 未通过则带问题台账 **换角度推倒重建**
3. 单个槽至多 **3 次重建**（即最多 5 轮总计）
4. 重建仍不通过 → **终止该槽** 并记录原因

**推进策略**（广度优先）：
- 每污染物 **至少 1 个通过方案** 后即推进到下一污染物
- 20 污染物全部访问一轮后，再回溯补充额外角度与槽位
- 每污染物上限 **50 槽**

**耗尽条款**：
- 若机制可区分角度全部用尽且重建仍无法通过 → 如实记录实际通过数 N（可 < 50）
- 附角度耗尽清单与终止原因汇总
- **诚实的 N < 50 优于凑数的 50**（此条款是"禁止凑数"指令的执行形式）

### G9. 水质场景与竞争物谱规范

> 来源：`SPEC.md` 水质场景与证据规则 + `SOUL.md` Research boundaries

| 实验类型 | 水质要求 | 说明 |
|---------|---------|------|
| 机制与因果对照实验 | **超纯水/去离子水** | 隔离目标物-识别单元本征相互作用 |
| 选择性验证 | 含 **真实竞争物**（结构近似物 + 不同类物质） | 竞争物谱须包含结构近似物，而非仅不同类物质 |
| 基质耐受性 | **二级出水或相应真实基质** | 含 DOM/ NOM 分组分干扰 |
| 工程性能 | 再生、泄漏、稳定性、床层 | 在真实基质中验证 |

**水质场景按污染物论证**：市政二级出水、工业废水、地表水、饮用水源、地下水。简报给出真实浓度区间与暴露场景。

**G9.1 选择性价值判据（2026-08-05 潘尧质询 Q1 增订，约束性）**：竞争物谱中的结构近似物承担机制可证伪探针功能，但选择性主张的环境价值必须另行举证——方案须给出 (a) 各结构近似物在目标水体（默认市政二级出水）的检出频率与浓度范围、(b) 其风险（PNEC/毒性/监管地位）相对目标物的高低。决策矩阵：高频共现且风险低于目标物，选择性有价值；环境中基本不出现，属虚空索敌，不得作设计目标；风险不低于目标物，应类级共捕，选择性努力转向基质背景；证据缺失，主张挂起或降级为机制探针并如实标注。对 DOM/盐基质背景的选择性是底线必需。竞争实验按环境真实浓度比例配置；等摩尔同系物混合物只作机制探针臂，须与环境比例实验分开报告。规范文本：`docs/SELECTIVITY_VALUE_CRITERION_2026-08-05.md`。

### G10. 角色隔离与门禁

> 来源：`PROTOCOL.md` + `SPEC.md` 角色与流程

**角色输入边界**：

| 角色 | 可读取 | 不得读取 | 唯一输出 |
|------|--------|---------|---------|
| 设计者 | 入围污染物、证据边界、科学问题与工程难题定义 | 其他角色隐藏推理、后续攻击意见 | 方案文件 |
| 攻击者 | 当前方案、证据台账、攻击清单、创新性检查清单 | 设计者隐藏推理、未来修订稿 | 攻击报告 |
| 裁决者 | 当前方案、证据台账、攻击意见、评分表、创新性检查结果 | 完整历史链和角色身份 | 裁决报告 + 评分 |
| 监督者 | 全部状态文件、证据控制 | — | Git 提交、门禁裁决、状态更新 |

**门禁链**（千方案简化版）：

| 门禁 | 内容 |
|------|------|
| Phase A 完成 | 简报 + 角度地图入库，预筛完成 |
| 方案槽启动 | 角度定义锁定，证据边界冻结 |
| 设计-攻击-裁决 | 串行执行，每槽独立工作流 |
| 通过/终止 | 评分 ≥ 85 + 0 critical/high + 创新性通过 → 通过；否则终止或重建 |

**失败行为**：
- 证据不支持 → 降级主张、补证或否决，**禁止编造补齐**
- 低于 85 分或仍有 critical/high → 修订或淘汰，**不降低门槛**
- 创新性检查未通过 → **不得进入正式评分**

## 3. 快速预筛机制（Phase A+ 阶段）

在 Phase A（简报+角度地图）完成后、Phase B（方案槽设计）启动前，对每个候选角度执行三道快速预筛。

> **性质声明**：预筛结果为 **"建议"性质**——设计者可声明覆盖理由后继续推进。预筛不否决角度，仅标记风险。

### 3.1 TFG — 热力学可行性门 (Thermodynamic Feasibility Gate)

**三组分检查**：

| 组分 | 检查内容 |
|------|---------|
| (a) 目标物-识别位点结合自由能 | 上限估算：识别机制在目标工况下能否提供足够结合能 |
| (b) 竞争物相对结合自由能 | 主要竞争物（结构近似物 + 高浓度基体组分）的相对亲和力 |
| (c) ng/L 工况所需 Kd 对应的最低结合亲和力 | 由目标浓度与竞争物浓度计算所需选择性因子与绝对 Kd |

**筛除判据**：
- (a) < 1.5 × (b)：目标物结合能不足以在竞争物过量背景下维持选择性
- (c) 超出化学合理范围 > 100 kJ/mol：所需亲和力在化学上不可实现

**历史反例**：GenX A01 = 36 分——中性氢键氧阴离子洞对 GenX 离域羧酸根 + 强水合永久阴离子本质不可行（疏水机制近乎失效 logKow ~0.5-1.5，中性脲供体已知强结合硫酸根 = 选择性负债）。

### 3.2 PADS — 先例密度评估 (Prior Art Density Score)

**评分规则**：

| 先例类型 | 每篇扣分 | 说明 |
|---------|---------|------|
| 直接先例 | -15 | 同一污染物 + 同一识别机制/材料平台 |
| 方向先例 | -5 | 同一污染物 + 相近机制方向 |
| 平台先例 | -3 | 同一材料平台用于其他污染物 |

**起始分 100**，逐项扣减。

**筛除判据**：PADS > 50 → 标记为 **先例饱和**，需换角度或声明增量区分策略。

**历史反例**：PFOA 10 槽中 9 槽终止（先例饱和：Zr-MOF/PAF/COF/胍基阳离子等 2019-2026 多平台占据）。

### 3.3 ODC — 正交维度检查 (Orthogonal Dimension Check)

**正交维度要求**：
- 选择性须由 **≥ 2 个正交维度** 支撑（如几何识别 + 静电互补、尺寸匹配 + 氢键阵列等）
- 若选择性可退化为 **单参数单调函数**（pKa / logKow / 链长 / 分子大小）→ **不通过**

**检查方法**：
1. 列出方案依赖的所有选择性来源
2. 检验各来源之间是否正交（改变一个不影响另一个）
3. 若仅一个独立维度 → 标记为单参数退化

**历史反例**：DCP26 3 槽全终止——区域选择性退化为 pKa 单调（A01 区域位阻选择性因子先验 < 2；A03 咪唑鎓 pH 门控本质为单参数 pKa 单调利用）。

每个角度在 Phase A+ 阶段填写以下模板：


## 4. 角度预分类体系

基于预筛结果，将每个污染物的候选角度分为四类：

| 等级 | 条件 | 执行优先级 |
|------|------|-----------|
| **S 级 (Strong)** | 几何/拓扑识别轴明确 + 正交维度 ≥ 2 + 先例密度低 (PADS ≤ 20) | 优先执行 |
| **A 级 (Adequate)** | 可行识别机制 + 先例密度中等 (20 < PADS ≤ 40) 或正交维度 = 2 | 次优先 |
| **B 级 (Borderline)** | 热力学可行但选择性轴单薄或先例密集 (40 < PADS ≤ 50) | 仅 S/A 级失败后尝试 |
| **X 级 (Excluded)** | TFG 不通过 或 PADS > 50 | 不进入 Phase B，记录为结构性不可行 |

**执行规则**：
- 优先执行 S 级角度；S 级用尽后执行 A 级
- B 级仅在 S/A 级均终止后尝试
- X 级角度记录为角度耗尽清单条目，不开启方案槽
- 设计者可覆盖预筛分类（如声明新的正交维度或增量区分策略），但须在记录中注明覆盖理由

## 5. 三级 Spec 层级结构

```
GLOBAL_SPEC.md（本文件）
  └── 分类 Spec（5 组，按化学类别分组）
       └── 污染物执行 Spec（20 份，每种污染物一份）
```

| 层级 | 文件 | 内容 |
|------|------|------|
| **全局 Spec** | `GLOBAL_SPEC.md` | G1-G10 核心要素 + 预筛机制 + 质量监控；不可降级 |
| **分类 Spec** | `categories/<组名>_SPEC.md` | 组内共性规则（如 PFAS 组的链长/头基识别轴约束、卤代酚组的 pH 门控约束）；可追加更严要求 |
| **污染物执行 Spec** | `<slug>/BRIEF.md` + `DESIGN_SPACE.md` | 污染物特异参数（浓度场景、竞争物谱、角度地图、已知陷阱）；继承全局 + 分类 Spec |

**继承规则**：
- 下级 Spec **继承** 上级全部硬约束
- 下级 Spec **可追加** 更严要求，**不可放宽** 上级要求
- 冲突时以 **上级为准**

## 附录 A：失败模式参考库

基于 22 次尝试中 16 次终止（73% 终止率）归纳的四类核心失败模式：

### FM1. 先例饱和 (Prior Art Saturation)

**定义**：目标污染物 + 识别机制/材料平台的组合已被大量先例占据，增量贡献不足以支撑独立发表。

**历史案例**：
- PFOA A01（胍基杯[5]芳烃 2019、季铵 PAF-1 2022 先例覆盖）
- PFOA A03（COF 胍基识别，2019-2025 六篇以上先例覆盖，原创性上限 78-80）
- PFOA A05（Zr-MOF 先例饱和：Fe-MOF-808/PCN-999/Zr-PTA 等多平台占据）
- PFOA A09（两性离子刷，ACS ES&T Water 2026 先例覆盖）

**规避策略**：Phase A+ 执行 PADS 评估；直接先例 ≥ 4 篇时标记为先例饱和，换角度或声明可量化增量区分。

### FM2. 单参数单调陷阱 (Single-Parameter Monotonic Trap)

**定义**：选择性机制退化为单一物化参数（pKa / logKow / 链长 / 分子大小）的单调函数，不满足创新性 D 维（正交维度 ≥ 2）要求。

**历史案例**：
- DCP26 A01（区域位阻识别，选择性因子先验 < 2，退化为位置异构体疏水差异单调）
- DCP26 A03（咪唑鎓 pH 门控，本质为单参数 pKa 单调利用）
- PFBS A05（铁载体笼捕获，选择性轴退化为单参数链腔疏水沿链长单调）
- BPA A02（柔性 POP 脲/Hamilton 酚氧识别，α ≥ 3 旗舰被疏水单调解释）

**规避策略**：Phase A+ 执行 ODC 检查；方案须明确 ≥ 2 个正交选择性维度，且各维度独立贡献可量化。

### FM3. 中性氢键对强水合阴离子不可行 (Neutral H-bond Feasibility Gap)

**定义**：中性氢键供体（脲/硫脲/squaramide/氧阴离子洞）对强水合永久阴离子（磺酸根/羧酸根在高水合状态下）的选择性结合在水相中本质弱，绝对亲和力主要由疏水基线决定，头基差分识别不可靠。

**历史案例**：
- GenX A01 = 36 分（中性氢键氧阴离子洞对 GenX 离域羧酸根 + 强水合阴离子四重缺陷）
- PFHxS A01（四面体磺酸头中性氢键笼，头基维中性氢键对强水合磺酸头水相本质弱，69→70→81→70）
- PFOA A02（氧阴离子洞判 decorative，原则通用非蛋白特异）

**规避策略**：Phase A+ 执行 TFG 检查；对永久阴离子污染物，中性氢键方案须有额外正交维度（如几何反差、疏水协同），不得单独依赖氢键阵列。

### FM4. 框架内拮抗天花板 (In-Framework Antagonism Ceiling)

**定义**：方案内部存在不可调和的机制拮抗（如捕获 vs 抗污、亲和力 vs 选择性、稳定性 vs 再生），多轮迭代无法突破天花板。

**历史案例**：
- PFOA A09（两性离子刷：致密水化层同时为抗污机制与捕获屏障，四轮持续未解，天花板 77）
- PFOA A07（hSA 层级树脂：底线-容量解耦在 ng/L 工况按构造不可满足，天花板 83-84）
- PFOA A10（反应性 LDH：结合-活化耦合同位点机制内禀张力，82/78 均 < 85）
- BPA A03（异丙叉几何标尺 COF：BPA/BPF O-O 距离重叠 + 二面角标尺降为构象熵间接通道）

**规避策略**：设计阶段识别潜在拮抗对；若捕获-抗污/亲和力-选择性拮抗为架构内禀，应在角度选择阶段规避。

### 共性特征

1. **正交多维度**：所有通过方案均有 ≥ 2 个正交选择性维度（几何 + 静电、尺寸 + 氢键、电子 + 拓扑等）

3. **诚实标注**：所有通过方案均诚实标注仿生强度、不确定性、低先验预测
4. **因果对照完整**：每个核心主张均映射到测量与因果对照
5. **增量可量化**：与最近先例的区别可被实验量化（非"首次报道"式空泛声称）
6. **迭代闭合能力**：7/8 经 3-5 轮迭代达线，每轮有实质议题闭合而非文字修饰
