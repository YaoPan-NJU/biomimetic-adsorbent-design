> 版本：v1.0 | 日期：2026-07-29 | 状态：生效

## 1. 组概述

### 1.1 成员

| 成员 | 全称 | 分子式 | MW | pKa | logKow | 关键结构特征 |
|------|------|--------|-----|-----|--------|-------------|
| **BPA** | 双酚 A | C₁₅H₁₆O₂ | 228 | ~9.6–10.2 | ~3.3–3.4 | 双酚头基 + 异丙叉桥（偕二甲基） |
| **NP** | 壬基酚 | C₁₅H₂₄O | 220 | ~10.2 | ~4.5–5.2 | 酚羟基 + C9 支链壬基尾（α-四级碳） |
| **DCP26** | 2,6-二氯苯酚 | C₆H₄Cl₂O | 163 | ~6.64 | ~3.06 | 2,6-位双邻位氯取代酚 |
| **PCP** | 五氯苯酚 | C₆HCl₅O | 266 | ~4.75 | ~5.1 | 全氯代酚（五氯），近圆形氯鞘轮廓 |

### 1.2 选择性难题共性

1. **酚羟基锚定**：四种污染物均含酚羟基（氢键供体 + 受体双重身份），是组内共有锚定把手
2. **取代基几何/拓扑识别**：BPA 的异丙叉桥、NP 的 C9 支链尾（α-四级碳拓扑）、DCP26 的 2,6-双邻位氯取代模式、PCP 的全氯环轮廓——取代基几何是组内区分的核心维度
3. **pH 形态切换**：pKa 跨度 4.75–10.2，覆盖中性分子（BPA、NP 在环境 pH）到酚盐阴离子（DCP26 部分解离、PCP 完全解离），pH 形态切换为组内共有的设计杠杆
4. **类内近似物竞争**：BPA 类似物（BPF/BPS/BPAF）、NP 近似物（OP/NP1EO/NP2EO）、氯酚同族物（2,4-DCP/2,4,6-TCP/TeCP）构成组内最尖锐的选择性挑战
5. **中性分子与阴离子共存**：BPA/NP 为中性分子（静电无效），DCP26/PCP 在中性 pH 下部分/完全解离为酚盐阴离子——组内跨越两种电荷形态，识别机制须分别适配

### 1.3 组内差异

B 组从双酚（两个酚羟基 + 桥连碳）到烷基酚（单酚 + 长链烷基）到氯酚（酚羟基 + 氯代模式），差异覆盖：

- **锚定模式**：BPA 双酚羟基双锚 vs NP/DCP26/PCP 单酚羟基单锚
- **识别维度**：BPA 桥连区体积/极性 → NP α-碳拓扑形状 → DCP26 区域位阻/氯取代对称性 → PCP 全氯鞘轮廓/σ 空穴五点图案
- **pKa 梯度**：10.2 (NP) → 9.6 (BPA) → 6.64 (DCP26) → 4.75 (PCP)，决定环境 pH 下电荷形态
- **疏水性梯度**：DCP26 (3.06) < BPA (3.3) < NP (4.5–5.2) ≈ PCP (5.1)

| **OAT/OCT**（有机阴离子/阳离子转运体） | 转运蛋白 | DCP26, PCP | 中（OAT1/3 转运氯酚先例存在） | 酚盐阴离子头基识别，但静电非特异风险高 |

### 2.2 原型使用约束

- **毒性受体排除**：ERRγ/ER 系列为毒性受体，框架示例 2 禁作方案主干，仅作 approach-3 个案补充
- **TTR 毒理受体警示**：TTR 结合 PCP 属 T4 脱靶模拟（甲状腺内分泌干扰），不构成自然界对 PCP 污染的进化解决方案，仿生强度标「仿生启发」，不得写成「自然界为 PCP 准备了结合蛋白」
- **微生物限制**：禁止活污泥与完整微生物作处理材料；ipso 途径仅提取几何拓扑读取规则，化学反应部分（ipso 羟化与 1,2-C,O 迁移）明确排除
- **降解途径限制**：还原脱卤酶、漆酶等降解酶系仅转译识别原理，以降解途径作主干属思路三禁止

## 3. 角度定义模板

### 3.1 通用角度描述模板

每个 B 组角度定义须包含以下字段：

```
## AXX [角度名称]

- 原型家族：[仿生原型名称与来源]
- 识别机制轴：
  - 酚羟基锚定维：[酚羟基氢键锚 / 酚盐头基锚 / 酚氧负离子中性氢键锚]
  - 取代基几何/拓扑维：[桥连区体积 / 烷基尾拓扑 / 氯取代对称性 / 全氯鞘轮廓]
  - 正交维度（如适用）：[卤键 σ 空穴 / 疏水腔尺寸 / 静电互补 / 电子效应]
- 材料平台候选：[COF / HCP/POP / β-CD 聚合物 / 超交联树脂 / 有机笼 / 分级孔碳]
- 选择性签名：[非单调分离因子序列 / 逆 logKow 梯度 / 几何残差 / 对称性反差]
- 已知陷阱注入：[从第 5 节陷阱库中选取适用条目]
- 先例风险：[low / medium / high]
```

### 3.2 识别机制轴说明

B 组角度须在以下四个识别机制轴中至少覆盖两个正交维度：

1. **酚羟基锚定轴**：
   - 中性分子（BPA/NP）：氢键供体 + 受体双重身份的酚 OH，可与吡啶 N、羰基 O 等形成氢键配准
   - 酚盐阴离子（DCP26/PCP 在中性 pH）：酚氧负离子须以中性预组织氢键供体（仿 SBP 原理）或几何匹配头基锚捕获，避免静电非特异

2. **取代基几何/拓扑轴**：
   - BPA：异丙叉桥体积（偕二甲基）+ 酚-酚间距 ~1 nm + C2 对称性
   - NP：α-碳分支拓扑（α-四级碳紧凑分支丛 vs 线性伸展链）
   - DCP26：2,6-位双邻位氯的对称空间轮廓（C2v 对称 vs 2,4-位 Cs 不对称）
   - PCP：近圆形全氯鞘轮廓 + 五点 σ 空穴图案

3. **卤键 σ 空穴轴**（DCP26/PCP 适用）：
   - C-Cl 键 σ 空穴作为卤键供体与定向路易斯碱受体作用
   - 正交性来自几何图案（对称性、点位排布），非强度（强度随氯数单调，落入陷阱 T1）
   - 水相 σ 空穴显著衰减，须前置 DFT/MD 水相能量预算

4. **疏水腔尺寸轴**：
   - 标定自由体积的疏水腔产生非单调体积阈值（窗口选择性）
   - 须证明选择性不可由 logKow 单调解释

## 4. 标准竞争物谱

### 4.1 同类酚（结构近似物，最高威胁）

| 目标物 | 最危险竞争物 | 浓度量级 | 威胁机制 |
|--------|------------|---------|---------|
| BPA | BPF（亚甲基桥）、BPS（砜桥）、BPAF（六氟异丙叉桥）、TBBPA（四溴双酚 A） | ng/L–µg/L | 双酚类共享酚羟基锚，桥连区差异是核心区分维度 |
| NP | OP（辛基酚，C8 vs C9）、NP1EO/NP2EO（乙氧基前体）、4-n-NP（线性异构体） | ng/L–µg/L | 烷基酚共享酚羟基头基，尾链长度/分支差异是区分维度 |
| DCP26 | 2,4-DCP（区域异构体）、2,4,6-TCP（三氯酚）、4-CP（单氯酚） | ng/L–µg/L | 氯酚同族物共享酚羟基 + 氯取代，区域异构体区分是核心难题 |
| PCP | 2,3,4,6-TeCP（四氯酚）、2,4,6-TCP（三氯酚）、2,4-DCP（二氯酚） | ng/L–µg/L | 氯酚连续梯度，随氯数 pKa/logKow 单调变化 |

| 竞争物 | 威胁等级 | 说明 |
|--------|---------|------|

| Ca²⁺, Mg²⁺ | 低 | 硬度离子对酚羟基氢键的间接干扰 |

## 5. 已知陷阱库

### 5.1 FM2-B：单参数单调陷阱（酚类特化版）

**描述**：酚类选择性退化为单一物化参数（pKa / logKow / 氯数）的单调函数，不满足创新性 D 维（正交维度 ≥ 2）要求。

**历史案例**：
- **DCP26 A01**（区域位阻识别，75 分终止）：2,6-DCP vs 2,4-DCP 区域选择性退化为位置异构体疏水差异单调，选择性因子先验 < 2
- **DCP26 A03**（咪唑鎓 pH 门控，68 分终止）：本质为单参数 pKa 单调利用——pH 6.64 的形态切换是单维开关，三条独立终止依据（D 维判负 + 先例家族覆盖 + µg/L 低浓工况不相容）
- **PCP A01**（TTR 反向模式 COF，76 分终止）：承重反转型非单调预测（2,4,6-TCP 亲和力 ≥ 2,3,4,6-TeCP）经裁决者独立核算证明几何不可实现——PCP 氯位 {2,3,4,5,6}，TeCP 氯位 {2,3,4,6} 为其真子集，任何 PCP 互补受体图案在锚定位姿下都给 TeCP 四个注册接触、给 TCP 三个接触，接触数读数 PCP5 > TeCP4 > TCP3 严格单调

**规避策略**：
- 酚类方案须明确 ≥ 2 个正交选择性维度（如酚羟基锚定 + 取代基几何/拓扑，或头基锚 + 卤素图案几何）
- 凡选择性随氯数 / logKow / pKa 单调的，D 维判负
- 氯酚区域选择性须证明非单调签名（如对称性识别、图案互补），不得仅依赖位阻或疏水差异

### 5.2 TFM-B：酚类热力学可行性陷阱

**描述**：酚盐阴离子（DCP26/PCP）的中性氢键识别在水相中本质弱于预期，绝对亲和力主要由疏水基线决定，头基差分识别不可靠。

**历史案例**：
- **DCP26 A02**（UGT 头基可及性，76 分终止）：头基可及性识别的结构约束上限 ~80-81 分，架构内禀张力（空腔与水化壳矛盾）
- **PCP A01**（TTR COF，76 分终止）：接触数单调不可突破，承重非单调预测几何不可实现

**规避策略**：
- 对酚盐阴离子方案，中性氢键须有额外正交维度（如几何图案反差、疏水协同），不得单独依赖氢键阵列
- 前置水相能量预算（DFT/MD），无法给出水相能量裕度者首轮判负

### 5.3 FM4-B：框架内拮抗天花板

**描述**：方案内部存在不可调和的机制拮抗（捕获 vs 抗污、亲和力 vs 选择性、结构约束 vs 水相可行性）。

**历史案例**：
- **DCP26 A02**（UGT 头基可及性）：头基受限空腔的结构约束使选择性天花板 ~80-81，多轮迭代无法突破
- **BPA A03**（异丙叉几何标尺 COF）：BPA/BPF O-O 距离重叠 + 二面角标尺降为构象熵间接通道，天花板效应

**规避策略**：
- 设计阶段识别潜在拮抗对
- 若拮抗为架构内禀，应在角度选择阶段规避
- 预设负结果解耦交付（删除变体因果包 + 非单调序列签名）

### 5.4 氯酚区域选择性水相定量选择性先验低

**描述**：氯酚区域异构体（2,6- vs 2,4-位）在水相中的定量选择性因子先验 < 2，区域与构型识别的空腔与水化壳矛盾为架构内禀张力。

**历史案例**：
- **DCP26 三槽全终止**：A01 区域位阻 75 分、A02 UGT 头基可及性 76 分、A03 pH 门控 68 分——三个完全不同机制角度均终止，表明氯酚区域选择性是组内最硬的结构性难题

**规避策略**：
- 新角度须跳出 DCP26 前三槽的机制空间（区域位阻 / 头基可及性 / pH 门控），转向卤键 σ 空穴、全氯环 snug-fit、对称性互补等未探索维度
- 预设低选择性先验，方案价值结构须包含负结果解耦交付
- 诚实的终止优于凑数的重建

### 5.5 酚类同类物区分内禀硬度

**描述**：酚类同类物（双酚类似物、烷基酚异构体、氯酚同族物）在酚羟基锚定后，取代基差异往往仅贡献 2-5 kJ/mol 的结合能差，对应室温下 2-8 倍的选择性因子，是选择性设计的内禀难度下限。

**规避策略**：
- 方案须诚实标注选择性因子预期窗口
- 分离因子 < 1.5 判机制确认失败（参考 NP A01 H1 阈值）
- 须以混合物分离因子而非单溶质容量报告

## 6. 组内各污染物特殊说明

### 6.1 BPA（双酚 A）

**状态**：Phase A 完成，A01 已通过（86 分）。

**通过方案 A01=86（DmpR 锚-门 COF）**：
- 原型：DmpR 型酚效应物传感器（Pseudomonas sp. CF600，PDB 6IY8 全文核验 + 坐标复算）
- 机制：固定酚锚（吡啶 N 氢键受体）+ 桥连区空间门（G0 氢门 / G1 甲基门 / G2 氟门 / G3 极性门），锚门解耦
- 材料：晶态 β-酮烯胺 COF，等网状原位门交换
- 选择性签名：中性水相四元竞争（BPA/BPF/BPS/BPAF）中对 BPA 给出可测且逆 logKow 梯度的分离因子
- 轨迹：r1=71 → r2=82 → r3=83 → r4=84 → r5=86（5 轮迭代，文件级补件闭合）

**成功模式总结**：
1. 自然进化原型（DmpR 转录传感器）+ 双硬对应（H1 固定酚锚 + H2 桥连区空间门）
2. 锚门解耦设计——亲和力由疏水孔壁承担，选择性由锚门空间解耦 + 门身份谱切换承担
3. 逆 logKow 梯度签名通过 D 维（α(BPA/BPAF) > 1 与 logKow 序相反）
4. 诚实低先验标注（P(S2) ≈ 20-30%）+ 完备预注册决策树

**回溯补角方向**：
- A02（脲/硫脲定向多点氢键）：Hamilton 受体对 BPA 水相吸附先例为零，化学风险高但空白区明确
- A03（异丙叉几何标尺 COF）：须避免坍缩为对称双端夹持（已被否，陷阱 T4）
- A04（ERβ 口袋体积阈值窗口）：逆向设计（生物体系仅见单调趋势），可行性本身是科学问题
- A06（pH 形态窗口）：仅作预分级 + 再生轴，须与桥连区识别内核配对

### 6.2 NP（壬基酚）

**状态**：Phase A 完成，A01 已通过（92 分，全计划最高分）。

**通过方案 A01=92（ipso 途径逆向标尺）**：
- 原型：Sphingobium xenophagum Bayram / TTNP3 的 ipso 羟基化途径
- 机制：α-四级碳拓扑形状选择腔——间苯二酚芳烃深腔笼，腔口固定酚羟基氢键锚定位，腔深约等于 α-四级碳紧凑分支丛轴向尺寸且短于线性 C9 链全长
- 选择性签名：对 α-四级碳支链 NP 异构体相对线性 4-n-NP 与 4-tert-OP 的可测分离因子，分离因子与 logKow 不相关（异构体间近简并）
- 轨迹：r1=82 → r2=92（2 轮即通过）

**成功模式总结**：
1. 非蛋白间苯二酚芳烃深腔笼——超越蛋白精确三维结构，提取 α-碳取代拓扑变量在材料侧以几何腔互补重读
2. 「生物留下、材料捕获」逆读标尺——标尺方向与 Bayram 底物偏好同向（均偏好 α-四级碳），「逆读」指应用端反向读取
3. 分离因子不可由 logKow 解释（异构体 logKow 近简并，线性 4-n-NP 的 logKow 通常略高于支链异构体）
4. Lu 2015 摘要级确认：出水残留浓度与立体效应指数正相关 R²=0.76，材料滞留序列与生物立体效应指数-残留相关同向
5. 诚实标注：无 NP 降解酶-底物复合物晶体结构，α-四级碳要求源于稳定碳正离子（电子效应），材料侧为几何统计对应

**后续角度建议**：
- A02（β-CD 主客体 + 腔口二级工程）：须超越通用 CD 包结，腔口增量以异构体分辨分离因子证明
- A10（对位锚定 × α-分支拓扑二维正交）：双维材料分离因子须显著超越单维消融
- A04（C15 链长窗口 + 支链几何排斥狭缝）：零先例，AbAlkB 天然方向为拒绝支链，NP 捕获须反转论证

### 6.3 DCP26（2,6-二氯苯酚）

**状态**：Phase A 完成，前三槽（A01-A03）**全部终止**（硬骨头）。

**终止方案汇总**：

| 槽位 | 角度 | 最终分 | 终止原因 |
|------|------|--------|---------|
| A01 | 区域位阻识别 | 75 | 选择性因子先验 < 2，退化为位置异构体疏水差异单调 |
| A02 | UGT 头基可及性 | 76 | 结构约束上限 ~80-81，架构内禀张力（空腔与水化壳矛盾） |
| A03 | pH 门控（咪唑鎓） | 68 | 三条独立终止依据：(1) D 维判负（单参数 pKa 单调）；(2) 概念被咪唑鎓至酚氧离子对酚吸附先例家族覆盖；(3) µg/L 低浓工况内禀不相容 |

**失败模式分析**：
1. **单参数单调陷阱**：A01 区域位阻和 A03 pH 门控均退化为 pKa / 疏水差异的单调函数
2. **架构内禀天花板**：A02 UGT 头基可及性的结构约束使选择性天花板 ~80-81，多轮迭代无法突破
3. **氯酚区域选择性内禀硬度**：三个完全不同机制角度均终止，表明 2,6-DCP vs 2,4-DCP 的水相定量选择性是组内最尖锐的结构性难题
4. **空腔与水化壳矛盾**：2,6-DCP 酚盐阴离子水化强，识别空腔须克服水化壳竞争，但空腔几何约束又限制了多水化位点的引入

**推荐新角度方向**：
- **卤键 σ 空穴**：2,6-位双 C-Cl 的 σ 空穴作为卤键供体，与定向路易斯碱受体阵列作用；正交性来自 2,6-位对称图案（C2v）vs 2,4-位不对称（Cs），非强度（强度随氯数单调）
- **全氯环 snug-fit 腔**：2,6-位双邻位氯的范德华轮廓（对称双邻位）与 snug-fit 空腔互补；须证明选择性不可由 logKow 解释
- **对称性互补**：2,6-位 C2v 对称双氯 vs 2,4-位 Cs 不对称的对称性识别——对称互补空腔先例极稀疏
- **区域位阻 + 电子效应双维协同**（A11）：2,6-位空间位阻 + 电子 withdrawing 双维正交，须实验验证正交性
- **氯酚羟化酶底物通道**（A12）：底物接近控制的人工孔道版本
- 预设低选择性先验，所有新角度须设负结果解耦交付

### 6.4 PCP（五氯苯酚）

**状态**：Phase A 完成，A01 已终止（76 分），16 个角度待 Phase B。

**终止方案 A01=76（TTR 反向模式 COF）**：
- 承重反转型非单调预测（2,4,6-TCP 亲和力 ≥ 2,3,4,6-TeCP）经裁决者独立核算证明几何不可实现
- PCP 氯位 {2,3,4,5,6}，TeCP 氯位 {2,3,4,6} 为其真子集，接触数读数严格单调
- 轨迹：r1=74 → r2=64 → r3=76 → r4=76（plateau 于 76，重建额度用尽）
- 残余价值：方向张力显式披露与承重预测撤回的诚实修订范式 + 子集结构几何不可实现性核算方法学

**16 个角度优先方向建议**：

| 优先级 | 角度 | 理由 |
|--------|------|------|
| S | A04 全氯环 snug-fit β-CD 聚合物 | 先例风险 low，形状读出与 logKow 单调解耦，PCP 至 β-CD 仅 DFT 计算无实验先例 |
| A | A02 SBP 中性氢键酚氧 POP | 中性氢键阴离子识别原理已在 PFOA A02 通过（85 分），PCP 向酚氧负离子扩展先例为零 |
| A | A03 卤键 σ 空穴五点图案 COF | 正交性来自几何图案非强度，但水相 σ 空穴衰减风险高，须前置 DFT 能量预算 |
| A | A06 双邻位氯图案二维滤器离散笼 | TTR 构效关系（双邻位氯增强结合）的机制转译 |
| A | A07 还原脱卤酶氯位构型识别裂腔 | 区域选择性转译，但氯酚水相定量选择性先验低（DCP26 教训） |
| B | A08 阴离子-π 缺电子孔壁 | 水相阴离子-π 衰减与 π-π 纠缠 |
| B | A10 硫醇介导捕获-脱氯耦合 | 内禀张力（锚定稳定基态抬升脱氯能垒，PFOA A10 同源教训） |
| X | A13 pH 形态切换 | 单参数 pKa 单调，DCP26 A03 同源终止教训 |
| X | A05 FABP 两亲阴离子 | 先例风险 high，阳离子缘 + 疏水协同在氯酚系拥挤 |

**PCP 特殊约束**：
- POP 闭环硬约束：斯德哥尔摩公约附件 A，浓缩液不得回排，须以破坏或安全封存收尾
- 共去除 vs 选择性分离：木材防腐场景中全部氯酚均为去除目标，工程不需要区分；氯酚同族物在机制证据层面是最佳结构近似物竞争谱，不得把共去除容量包装成选择性
- 氧化中间产物毒性：任何氧化角度须以氯代苯醌类中间产物毒性消长为通过判据

## 7. 预筛建议

### 7.1 TFG（热力学可行性门）酚类特别注意事项

1. **酚羟基锚定能量预算**：
   - 中性酚（BPA/NP）：酚 OH···N 氢键水相结合能约 4-10 kJ/mol，须与疏水贡献协同
   - 酚盐阴离子（DCP26/PCP）：中性氢键供体对酚氧负离子的水相结合能显著低于气相，须前置 DFT/MD 水相能量预算
   - 双酚双锚（BPA）：两个酚 OH 提供双倍锚定能，但 BPF/BPS 同样有双酚羟基，锚定维不提供类内选择性

2. **竞争物过量背景**：
   - 腐殖酸（mg/L 级）对 ng/L 级酚类，摩尔比 10⁶-10⁹
   - 氯酚同族物对目标氯酚，摩尔比视水体而定
   - 无机阴离子（mM 级）对酚盐阴离子（µg/L 级），DCP26/PCP 须评估

3. **pH 形态校正**：
   - DCP26（pKa 6.64）和 PCP（pKa 4.75）在中性 pH 下以酚盐为主，须区分中性分子与酚盐阴离子的吸附机制
   - 形态校正离子型 Kd 是氯酚选择性比较的公正基准

### 7.2 PADS（先例密度评估）酚类特别注意事项

1. **BPA 先例密度高**：MIP（39 条）、生物炭（40）、CD 聚合物（20）、石墨烯系（33）等簇均已成熟；新角度须远离饱和平台
2. **NP 先例密度中等**：ipso 途径拓扑识别先例稀疏，但通用 MIP/CD/生物炭先例密集
3. **DCP26 先例密度高**：直接先例已密（J Hazard Mater 2026, Water Res X 2026, Environ Res 2025, Chemosphere 2024）；新角度须量化与最近邻先例距离
4. **PCP 先例密度中等偏高**：碳基吸附最拥挤，COF/POP 平台级空白（零命中），但分析向 MIP 与通用酚盐离子交换已成熟

### 7.3 ODC（正交维度检查）酚类特别注意事项

1. **酚类 D 维核心检验**：选择性不可由以下单参数单调解释：
   - logKow（疏水性随氯数 / 烷基链长单调）
   - pKa（酚羟基酸性随取代基单调）
   - 分子大小 / 氯数（连续梯度）

2. **正交维度组合建议**：
   - BPA：酚羟基锚定 × 桥连区体积/极性（A01 已验证）
   - NP：酚羟基对位锚定 × α-分支拓扑形状（A01 已验证）
   - DCP26：酚氧锚定 × 氯取代对称性 / 卤键图案（待验证）
   - PCP：酚氧头基锚 × 全氯鞘轮廓 / σ 空穴五点图案（待验证）

3. **单参数退化红旗**：
   - 凡选择性随氯数单调 → D 维判负（DCP26 A01/A03, PCP A01 教训）
   - 凡选择性仅由 pH 形态切换承担 → D 维判负（DCP26 A03 教训）
   - 凡选择性仅由 logKow 差异承担 → D 维判负（BPA 居中疏水性硬约束）
