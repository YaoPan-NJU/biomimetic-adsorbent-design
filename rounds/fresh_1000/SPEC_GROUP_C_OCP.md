## 1. 组概述

### 1.2 选择性难题共性

1. **无官能团中性分子**：六种污染物在全 pH 范围内均为中性分子，无解离基团、无氢键供体，静电/氢键/酸碱三类常规识别把手全部不可用
2. **高疏水性**：logKow 3.6–7.0，固液分配强烈，溶解相浓度极低（ng/L–pg/L 级）
3. **形状读出为核心**：桥碳取代差异（DDT –CCl₃ / DDE =CCl₂ / DDD –CHCl₂）、环氧 exo/endo 取向（Dieldrin vs Endrin）、全平伏氯阵列（β-HCH vs 其他 HCH 异构体）、平面性（TCDD vs 非平面 dl-PCB）——均依赖几何/形状互补
4. **立体异构区分**：DDT/DDE/DDD 桥三元组、Dieldrin/Endrin/Aldrin exo/endo 环氧构型、α/β/γ/δ-HCH 氯取向——立体异构体区分是组内最尖锐的选择性问题
5. **颗粒/沉积物主导赋存**：溶解相浓度受溶度积极限约束，主蓄积库为沉积物/土壤/生物相

### 1.3 组内差异

组内差异从三个维度提供正交识别空间：

- **桥碳化学**：DDT 的 –CCl₃ 四面体（含桥 β-氢）→ DDE 的 =CCl₂ 平面（无桥氢）→ DDD 的 –CHCl₂ 四面体
- **笼状骨架修饰**：Dieldrin 的 exo-环氧桥 → Endosulfan 的环状亚硫酸酯桥 → Aldrin 无桥
- **氯构型几何**：β-HCH 全平伏盘状 → TCDD 严格平面芳环 → DDT 系非平面扭转

### 2.2 原型使用约束

1. **毒效靶标排除**：GABA/Rdl（Dieldrin 杀虫靶标）、AhR（TCDD 毒性受体）、AR（DDE 雄激素受体拮抗）按框架 BPA/ERRγ 先例 **禁止作主干仿生原型**，仅可提取识别几何原理作原理级参考
2. **蛋白直接转译排除**：GST、Lipocalin、SCP-2、GABA 受体等的蛋白结构 **不得直接复制**，仅提取设计原理用可合成材料实现
3. **非蛋白原型优先**：矿物表面 Lewis 酸、环糊精主客体、卤键阵列化学等非蛋白原型应占角度地图 ≥ 1/3

**C 组特异约束**：

- **GC1 疏水基线解耦**：任何角度必须明确区分疏水分配基线（logKow 单调层）与识别增量（ΔΔG_geo / ΔΔG_epoxide / ΔΔG_halogen），并以脂质/有机质归一化对照排除普通疏水吸附
- **GC2 立体异构竞争物强制**：角度必须包含至少一种立体异构体或结构近似物作为竞争物（DDT 系桥三元组、Dieldrin/Endrin/Aldrin、HCH 异构体谱、PCDD/F 同系物）
- **GC3 双维度正交硬约束**：因组内所有成员均无静电/氢键/酸碱把手，单一疏水维度按创新性 D 维不得独立构成选择性来源；每个角度须明确 ≥ 2 个正交识别维度
- **GC4 浓度场景匹配**：实验浓度须匹配 ng/L 级主目标场景（Dieldrin 0.1–40 ng/L、DDT/DDE 0.1–5 ng/L、TCDD pg/L 级），mg/L 批次容量不构成选择性证据
- **GC5 再生安全窗口**：含氯笼状/平面分子热处置须避开 PCDD/F 生成温区（Dieldrin 约 823 K、TCDD 250–450 °C de novo 再合成），温和再生路径为硬性要求

### 4.2 竞争物谱使用规则

1. **选择性必须分层证明**：先证第一层（最危险竞争物），再扩展到第二、三层
2. **结构近似物为必须**：仅报告不同类物质（如 NOM）的选择性不构成证据
3. **分离因子报告要求**：必须报告对结构近似物的分离因子 α，不得仅报告总容量或去除率
4. **脂质归一化对照**：所有选择性声称须以脂质/有机质归一化对照排除 logKow 单调解释

## 6. 组内各污染物特殊说明

### 6.1 DDT — Phase A 完成，24 角度

**化学画像要点**：C1 桥 –CCl₃ 四面体（含桥 β-氢，5 个 Cl）是核心识别维度。自然界读取该差异的机制仅两种：脱氯化氢酶（β-消除，要求桥 β-H + –CCl₃ 同时存在）和还原脱氯（DDT→DDD 且 DDE 不反应）。

**角度空间特征**：
- 桥反应性读出族 5（A01、A02、A10、A11、A14）
- 还原介导族 3（A12、A13、A24）
- 桥非共价读出族 6（A04、A05、A07、A08、A09、A22）
- 骨架/谱系识别族 2（A06、A15）
- 受限腔/尺寸族 4（A03、A18、A19、A20）
- 正交乘积族 1（A21）
- 传质/破坏使能族 3（A16、A17、A23）

**历史教训**：
- S20_A04（桥几何形状读出腔）终止：单独形状排阻落入 CT3 机制空洞
- S21_A21（双表位正交预组织）终止：具体失败模式须回溯方案台账

**优先角度建议**：A01（脱氯化氢酶 β-消除双基序反应性识别）与 A05（–CCl₃ 三氯四面体卤键阵列识别）为正交维度最丰富的候选，但 A01 须解决"水相固相攫氢能垒"与"捕获不转化"控制的化学可行性。

### 6.2 DDE — Phase A 完成，15 角度

**化学画像要点**：C1 桥 =CCl₂ 平面（无桥氢，4 个 Cl），识别把手比 DDT 更少。DDE 是 DDT 风化序列的失活产物与终端顽固物。

**角度空间特征**：
- 平面轮廓形状读出族 3（A01、A10、A15）
- 乙烯基卤素相互作用族 1（A02）
- 还原介导族 3（A03、A13、A14）
- 受限分配/界面族 2（A04、A12）
- 印迹族 1（A05）
- EDA 骨架族 1（A06）
- 工程使能族 4（A07 隔氧、A08 预浓缩、A09 门控再生、A11 双正交集成）

**当前状态**：A01 r2=75，结构性脆弱——窗口 0–1 埃 + C 维不通过风险。DDE 苯环扭转角与狭缝最优间距须先经 MD/DFT 核验。

**特殊约束**：
- DDE 无桥 β-氢、无 –CCl₃，DDT 简报可用的桥反应性维度全部不可用
- 选择性声称须诚实收窄为 DDE 对 DDT/DDD 的平面轮廓区分
- 卤键在水中被显著削弱，阵列结合能与水竞争的量化是核心证伪点

### 6.3 Dieldrin — 已通过 A01 = 89 分（exo-环氧双氢键腔）

**成功模式总结**：

1. **核心识别策略**：GABA/Rdl 刚性疏水腔原理（非蛋白复制）+ 方酰胺双 NH 阵列 exo-环氧几何读出
2. **两条硬对应**：
   - HC1：刚性疏水受限腔（SBA-15 介孔硅胶孔壁接枝苯基/甲基疏水层）→ 疏水分选 + 孔内水竞争背景
   - HC2：单一极性接触环氧读出（腔口接枝预合成方酰胺双 NH 双齿供体）→ 几何依赖氢键，方向性限定
3. **关键成功因素**：
   - 立体异构体（exo vs endo）几何识别，非 logKow 单调
   - 诚实标注：A302S 极性插入削弱结合（抗性），原型仅提供架构原理不含增强方向
   - 修正热力学图像：采用实测 logKow（艾氏剂 6.50 > 狄氏剂 5.40 > 异狄氏剂 5.20），疏水本底非近简并
   - 阶段 0 模型化合物水相滴定 go/no-go 门控
   - 供体有无配对实验解耦环氧维贡献
4. **迭代轨迹**：r1=70 → r2=89，每轮有实质议题闭合（H1 热力学勘误、M1 介孔润湿态、M2 合成路线修正、M3 原型方向限定、M5 羰基占据）

**对组内其他污染物的启示**：
- "刚性疏水腔 + 唯一极性把手几何读出"策略可迁移至 Endosulfan（亚硫酸酯桥 S=O 代替环氧氧）
- 方酰胺/硫脲/脲供体强弱序列方法可用于其他弱氢键受体（环氧、亚硫酸酯、醚氧）
- 阶段 0 模型化合物滴定作为 go/no-go 门控应成为组内标准做法
- 诚实标注仿生强度与方向性限定是达到通过线的关键

### 6.4 Endosulfan — 已通过 A01 = 85 分（Lewis 酸介孔水解捕获）

**成功模式总结**：

1. **核心识别策略**：矿物表面 Lewis 酸水解界面（E1 Walse 2002，非蛋白界面原型）+ 介孔氧化物位点密度可控系列 + 亚单层疏水预组织域
2. **两条硬对应**：
   - HC1：Lewis 酸位点配位催化亚硫酸酯桥水解（四重因果阻断 + 位点密度标度回归）
   - HC2：路径方向选择性——水解解毒而非氧化毒化（多途径生物证据收敛 + 双工况硬对照）
3. **关键成功因素**：
   - Phase 0 计算门 GO：所需增强因子 5–49 处于文献金属氧化物催化酯水解增强因子 10²–10⁴ 低端
   - 反单调选择性设计（logKow 更高的近似物被富集但不被破坏，硫丹被选择性移除）
   - 诚实标注 C 维"边界不通过"（同化学平移），D/E 维明确通过支撑总闸
   - r1→r2→r3 三轮迭代每轮有实质议题闭合（62→78→85）
4. **迭代轨迹**：r1=62 → r2=78 → r3=85，关键闭合：r1 ISS-01~04 四条旗舰，r2 medium 全处理 + 先例族补入，r3 Phase 0 计算门 GO + C 维补充 + medium 精确落位

### 6.5 β-HCH — Phase A 完成，21 角度

**化学画像要点**：全平伏六氯构型（D3d 对称）不含反式双直立 H-Cl 对，锁死脱氯化氢与碱性消除两条破坏路径。四异构体同分子式、同分子量、logKow 同处 3.6–4.1，唯一差异在氯原子轴向/平伏排布。

**角度空间特征**：
- CD 包合族 3（A01 交联聚合物、A02 接枝介孔硅、A03 复合膜）
- CD-钴啉双功能族 1（A04）
- MIP 形状读出族 2（A05 形状 MIP、A06 形状+卤键双维 MIP）
- 卤键/σ 孔读出族 2（A07 COF 卤键、A08 N-杂环功能化）
- 还原脱氯族 2（A09 钴啉还原、A10 双功能包合-还原）
- 水解族 1（A11 LinB 转译分子笼）
- 传质增强族 1（A12 CD 包合助剂）
- 其他探索族 9（A13–A21 含各种架构变体）

**历史教训**：
- S29_A01（γ-CD 交联聚合物包合树脂）终止：DFT 包合稳定性不等于水相选择性（CT7-β），水相竞争基质下选择因子不足

**特殊约束**：
- β-HCH 消除被迫经 syn H-C-C-Cl 几何，反应性为四异构体最低
- 选择性须由几何（β 近球全平伏）+ 偶极（β 偶极最小）双正交维度实现
- 竞争物谱须含 α/γ/δ-HCH + 氯苯类（PeCB、HCB）

### 6.6 TCDD — Phase A 完成，14 角度

**化学画像要点**：严格平面刚性三环芳醚，四个氯全处 2,3,7,8 侧位。静电/酸碱/氢键把手全部不可用，可承载选择性的分子特征仅剩严格平面性、侧位氯取代图式与二芳醚骨架三项。主目标场景为 pg/L 级（皮摩尔），Kd 要求 10⁵ L/kg 量级。

**角度空间特征**：
- 氯图式几何读取族 2（A01 卤键 σ-空穴有机笼、A02 四极矩静电 COF 狭缝）
- 平面性形状筛分族 1（A03 高硅分子筛基线）
- 醚氧锚定族 1（A04 虚拟模板 MIP）
- 还原反应性族 2（A05 电化学捕获-脱氯、A06 自由基氧化销毁对照）
- 界面/传质族 2（A07 两亲增溶、A11 扩散-反应梯度）
- 主体侧动态释放族 2（A08 刺激响应、A12 氧化还原切换）
- 其他族 4（A09–A14）

**特殊约束**：
- pg/L 级实验须同位素稀释 HRGC-HRMS 或 ¹³C/¹⁴C 示踪，器壁吸附对照为硬性要求
- 真实 TCDD 水相实验受高等级防护许可约束，须内嵌代用物阶梯
- 过程评价必须以 TEQ 而非母体去除率为判据
- 碳基载体须控类二噁英 PCB 本底与浸出
- AhR 为毒性受体，禁作仿生原型（T6），仅几何约束可用

## 7. 预筛建议

### 7.1 TFG 组特异参数

C 组所有成员为中性非解离分子，无强水合阴离子，因此 GLOBAL_SPEC 中 FM3（中性氢键对强水合阴离子不可行）**不直接适用**。但以下热力学约束须检查：

| 检查项 | C 组适用性 | 说明 |
|--------|-----------|------|
| 目标物-识别位点结合自由能 | 适用 | 弱氢键受体（环氧氧/亚硫酸酯 S=O/醚氧）在水相中的净结合自由能须扣除双侧去溶剂化代价 |
| 竞争物相对结合自由能 | 适用 | 结构近似物（立体异构体）的疏水本底差异极小（ΔlogKow < 0.5），识别增量须 > 1–3 kJ/mol |
| ng/L 工况所需 Kd | 适用 | Dieldrin/DDT/DDE 需 Kd ~10⁴ L/kg；TCDD 需 Kd ~10⁵ L/kg（pg/L 级） |

**C 组 TFG 补充判据**：
- 对弱氢键受体（环氧氧、S=O、醚氧），水相净氢键收益常仅为数个 kJ/mol（Schneider 2009 Angew 综述），须给出可测效应下限
- 疏水本底对立体异构体对的 α_Kow 通常 < 2，识别增量 ΔΔG_geo 须 > 1.0 kJ/mol 方可产生可测分离

### 7.2 PADS 组特异参数

C 组先例密度整体低于 PFAS 组（A 组），但以下方向须注意：

| 方向 | 直接先例 | 方向先例 | 平台先例 | PADS 起始 100 扣减建议 |
|------|---------|---------|---------|---------------------|
| 碳质非特异吸附 | 多 | 多 | 多 | 饱和，不构成独立角度 |
| 还原脱氯（ZVI/Fe-Pd/B12） | 3–5 | 5–8 | 多 | 高饱和（FM1），增量须落选择性 |
| CD 包合 | 0（HCH 特异） | 2–3 | 5+ | 中等，但 DFT ≠ 水相选择性 |
| 设计型水相环氧/桥锚定腔 | 0 | 0 | 0 | **空白**，先例密度极低 |
| 卤键阵列水相吸附设计 | 0 | 1–2（分析 SPME） | 2–3 | 低，水相卤键削弱为核心风险 |
| 超分子主客体-二噁英 | 0 | 0 | 0 | **空白** |

### 7.3 ODC 组特异建议

C 组因无静电/氢键/酸碱把手，正交维度构建是最尖锐的设计挑战。建议的正交维度组合：

| 污染物 | 推荐正交维度组合 | 单参数退化风险 |
|--------|----------------|--------------|
| DDT | 桥反应性 + 形状轮廓；或卤键阵列 + 疏水腔尺寸 | 高（疏水分配 logKow 单调） |
| DDE | 平面轮廓 + 乙烯基卤键图案；或还原电位 + 形状 | 极高（识别把手本征窄） |
| Dieldrin | 环氧几何读出 + 疏水腔受限 ✅ S27 已验证 | 中 |
| Endosulfan | 亚硫酸酯桥反应性 + 笼骨架形状；或硫氧化态 + 桥几何 | 中 |
| β-HCH | 形状互补（全平伏盘状）+ 偶极/四极矩；或 CD 包合 + σ 孔卤键 | 高（四异构体物化参数极近） |
| TCDD | 氯图式卤键 + 平面性形状；或四极矩静电 + 醚氧锚定 | 中（logKow 单调对同系物失效，OCDD logKow 更高但 TEF 低三个数量级） |

### 7.4 角度预分类建议

基于预筛结果，对 C 组各污染物角度提出以下预分类指引：

| 等级 | 条件（继承 GLOBAL_SPEC + C 组补充） | 预期分布 |
|------|-----------------------------------|---------|
| **S 级** | 几何/拓扑识别轴明确 + 正交维度 ≥ 2 + PADS ≤ 20 + 水相净结合自由能效应下限 > 1 kJ/mol | Dieldrin A01 类（已通过）；Endosulfan A01/A02（Lewis 酸/双金属水解） |

| **B 级** | 热力学可行但选择性轴单薄或 PADS ≤ 50 | DDE A04（受限腔单独不过 D 维）；β-HCH A01–A03（CD 包合 DFT 未验证） |

- 材料实现：SBA-15 介孔硅胶孔壁接枝预合成方酰胺双 NH 双齿供体阵列
- 两条硬对应：HC1 刚性疏水受限腔 + HC2 单一极性接触环氧读出

**关键设计决策**：
1. 修正热力学图像（H1 闭合）：采用实测 logKow 排序（艾氏剂 6.50 > 狄氏剂 5.40 > 异狄氏剂 5.20），疏水本底非近简并
2. 核心声称收窄为两层可证伪陈述：异狄氏剂对（ΔΔG_geo ≥ 1.0 kJ/mol，α ≥ 2.4）+ 艾氏剂对（EF ≥ 2.5）
3. 阶段 0 模型化合物水相滴定第一道 go/no-go（go 线 K ≥ 10 M⁻¹）

5. 供体强弱序列（脲 < 硫脲 < 方酰胺）α 响应

**迭代教训**：
- r1=70 → r2=89，关键闭合：H1 热力学勘误（疏水层非近简并）、M1 介孔润湿态（撤销低介电声称）、M2 合成路线（预合成再接枝）、M3 原型方向限定（A302S 削弱非增强）、M5 羰基占据（重定位为机制探针）

### S · Endosulfan A01 · Lewis 酸介孔水解捕获 · 85 分

**核心识别策略**：
- 原型：矿物表面 Lewis 酸水解界面（E1 Walse 2002，非蛋白界面原型，同化学平移）
