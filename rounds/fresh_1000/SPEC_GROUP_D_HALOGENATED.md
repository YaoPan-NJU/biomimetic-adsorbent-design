## 1. 组概述

### 1.1 成员

| 污染物 | 分子式 | MW | logKow | 结构类型 | 关键特征 | Phase A 状态 |
|--------|--------|-----|--------|---------|---------|-------------|
| Chloroform | CHCl₃ | 119 | ~2.0 | 卤代脂肪烃（THM） | 小分子、弱极性、中等挥发、无 π 体系 | 完成，20 角度 |
| HCBD | C₄Cl₆ | 261 | 4.8–4.9 | 全氯代共轭二烯 | 无 C–H、化学惰性、可气提、DNAPL | 完成，13 角度 |
| BDE-209 | C₁₂Br₁₀O | 959 | ~10 | 全溴代二苯醚 | 超大疏水、十个 Br σ 空穴、醚键被屏蔽 | 完成，26 角度 |
| PCB-209 | C₁₂Cl₁₀ | 499 | ~8.2 | 全氯代联苯（扭转构象） | 十 Cl 全取代、四邻位氯强制正交扭转 | 完成，23 角度 |

### 1.2 选择性难题共性

1. **无官能团 / 无结合位点**：四种污染物均无可电离基团、无氢键供体、无金属配位把手；Chloroform 仅有弱 σ 空穴和弱酸性 C–H，HCBD 全 Cl 取代无 C–H，BDE-209 和 PCB-209 仅有卤键 σ 空穴
2. **卤键阵列**：C–Cl / C–Br 键的 σ 空穴构成潜在多位点卤键供体图案，是组内最一致的识别维度
3. **疏水 / 颗粒分配主导**：logKow 2.0–10.0 跨度大，但高卤代成员（BDE-209、PCB-209）溶解相浓度受溶度积极限约束（<100 ng/L），主赋存于颗粒 / 沉积物相
4. **挥发性梯度**：Chloroform（高挥发，Henry 常数 3.67×10⁻³ atm·m³/mol）→ HCBD（可气提）→ BDE-209 / PCB-209（几乎不挥发）
5. **全卤代轮廓识别**：BDE-209 与 PCB-209 为等立体全卤代类似物（仅差醚氧 vs 乙烷桥），区分依赖卤键阵列细节与还原反应性差异

### 1.3 组内差异

组内差异从三个维度提供正交识别空间：

- **分子尺寸跨度**：Chloroform（动力学直径 ~4.5–5 Å，拟四面体）→ HCBD（C4 共轭二烯骨架）→ PCB-209（扭转联苯 ~1.0 nm）→ BDE-209（全溴椭球 ~1.3–1.5 nm），构成从微孔到介孔的多尺度识别需求
- **卤素种与反应性**：Cl（Chloroform、HCBD、PCB-209）vs Br（BDE-209），Br σ 空穴强于 Cl，C–Br 键能低于 C–Cl，还原脱溴速率高于脱氯
- **赋存相态**：Chloroform 以溶解相为主（水溶度 ~8 g/L）→ HCBD 溶解相 + DNAPL 相（水溶度 3.2 mg/L）→ BDE-209 / PCB-209 以颗粒 / 胶体结合态为主（水溶度 <100 ng/L 与 ng/L 级）

**注意**：本组跨度较大（MW 119–959，logKow 2–10），Chloroform 与 BDE-209 在物化性质上差异显著。组内共性主要体现在"无官能团全卤代中性分子"这一识别约束上，而非分子尺寸或疏水性。分类 Spec 须对小组成员分别设定浓度场景与竞争物谱。

### 2.2 原型使用约束

1. **毒效靶标排除**：AhR（TCDD / PCB 毒性受体）、PXR/CAR（毒性信号范畴）按框架 BPA/ERRγ 先例 **禁止作主干仿生原型**，仅可提取识别几何原理作原理级参考
2. **蛋白直接转译排除**：还原脱卤酶、sMMO、LinB/DhaA、Lipocalin 等的蛋白结构 **不得直接复制**，仅提取设计原理用可合成材料实现
3. **非蛋白原型优先**：卤键化学、环糊精主客体、矿物表面、DOM 疏水微域、生物矿化层级等非蛋白原型应占角度地图 ≥ 1/3
4. **反应性角度约束**：还原脱卤（类咕啉 / ZVI / Pd 双金属）属 approach-3 降解性质，仅作个案补充不作主干；若采用须闭合卤素质量平衡

## 3. 角度定义模板

每个角度须按以下模板定义（继承 GLOBAL_SPEC + 组特异补充）：

```yaml
angle_id: A<nn>
pollutant: <slug>
prototype_family: <原型家族名称>
prototype_source_category: <代谢酶|转运蛋白|非蛋白化学|超分子化学|纳米酶|...>
recognition_axis: <识别机制轴描述>
material_architecture_axis: <材料架构轴描述>
hypothesis: <可证伪假设>
prior_art_risk: low | medium | high
orthogonal_dimensions:
  - <维度1>
  - <维度2>
required_competitors:
  - <必须包含的竞争物>
required_controls:
  - <必须包含的因果对照>
group_specific_constraints:
  - <D 组特异约束>
```

**D 组特异约束**：

- **DC1 疏水基线解耦**：任何角度必须明确区分疏水分配基线（logKow 单调层）与识别增量（ΔΔG_halogen / ΔΔG_shape / ΔΔG_reactivity），并以脂质 / 有机质归一化对照排除普通疏水吸附
- **DC2 结构近似物竞争物强制**：角度必须包含至少一种结构近似物作为竞争物（THM4 同族物、氯化溶剂族、PBDE 同系物谱、PCB 同系物谱、BDE-209/PCB-209 等立体对），不得仅用不同类物质
- **DC3 双维度正交硬约束**：因组内所有成员均无或仅有极弱静电 / 氢键 / 酸碱把手，单一疏水维度按创新性 D 维不得独立构成选择性来源；每个角度须明确 ≥ 2 个正交识别维度
- **DC4 浓度场景匹配**：实验浓度须匹配主目标场景（Chloroform µg/L 级饮用水、HCBD µg/L 级工业点源、BDE-209 ng/L 级工业点源颗粒 / 胶体相、PCB-209 pg/L–ng/L 级溶解相），mg/L 批次容量不构成选择性证据
- **DC5 卤素质量平衡**：涉及转化路径的角度须闭合卤素质量平衡（氯 / 溴），以代谢物 / 脱卤产物毒性当量评价净去除
- **DC6 挥发性质量平衡**：Chloroform 与 HCBD 角度须闭合气液相平衡，凡未密封、未做顶空核算的容量 / 选择性数据不可作为证据
- **DC7 相态口径**：BDE-209 与 PCB-209 角度须区分溶解相与颗粒 / 胶体相口径，质量平衡须覆盖颗粒相；忽略相态口径的水相实验浓度与真实场景脱节
- **DC8 平面腔几何不兼容标注**：涉及 PCB-209 的角度须明确标注 AhR 类平面 π 夹持腔与 PCB-209 扭转构象内禀不兼容（T9），任何平面腔设计须重定位为扭转容忍或扭转选择性腔体

## 4. 标准竞争物谱

### 4.1 三层竞争物架构（D 组统一）

| 层级 | 竞争物类别 | 具体物质 | 威胁等级 | 适用成员 |
|------|-----------|---------|---------|---------|
| **第一层：同族卤代物 / 结构近似物** | THM4 同族 | BDCM、DBCM、溴仿（CHBr₃） | 高 | Chloroform |
| | 氯化溶剂族 | HCE（六氯乙烷）、五氯丁二烯、PCE、TCE、CCl₄ | 高 | HCBD |
| | PBDE 同系物谱 | BDE-207/208、BDE-183、BDE-153/154、BDE-99/100、BDE-47 | 极高 | BDE-209 |
| | PCB 同系物谱 | PCB-207/208、PCB-206/207、PCB-194/180/170、PCB-28/52 | 极高 | PCB-209 |
| **第二层：跨类全卤代姊妹物** | 等立体类似物 | PCB-209 ↔ BDE-209（仅差醚氧 vs 乙烷桥） | 极高 | BDE-209, PCB-209 |
| | 跨类卤代芳烃 | DBDPE（十溴二苯乙烷，BDE-209 替代品） | 极高 | BDE-209 |
| | 卤代 DBP 家族 | HAA、HAN、HAM | 中 | Chloroform |
| | 氯苯类 | PeCB、HCB、1,2,4-TCB | 高 | HCBD |
| **第三层：基质竞争** | 天然有机物 | 腐殖酸 / 富里酸（疏水位点抢占） | 高 | 全组 |
| | 颗粒 / 沉积物 | 有机碳、黑碳、DOC、脂质相、微塑料 | 高 | 全组（BDE-209/PCB-209 尤其严重） |
| | 共存卤代物 | 三氯乙烯 / 四氯乙烯（饮用水场景） | 中 | Chloroform |
| | PAH | 芘、苯并[a]芘（污染场地共存） | 中 | PCB-209 |

### 4.2 竞争物谱使用规则

1. **选择性必须分层证明**：先证第一层（最危险竞争物），再扩展到第二、三层
2. **结构近似物为必须**：仅报告不同类物质（如 NOM）的选择性不构成证据
3. **分离因子报告要求**：必须报告对结构近似物的分离因子 α，不得仅报告总容量或去除率
4. **脂质 / 有机质归一化对照**：所有选择性声称须以脂质 / 有机质归一化对照排除 logKow 单调解释

## 5. 已知陷阱库

### 5.1 D 组共性陷阱

| 编号 | 陷阱名称 | 描述 | 规避策略 |
|------|---------|------|---------|
| **DT1** | 疏水分配单调性 | 脂肪 / EPS / 沉积物 / AC 对高 logKow 分子的分配随 logKow 单调，对组内成员（疏水性相近的同系物）无区分力 | 任何"脂质样腔"转译须以有限体积（Langmuir 可饱和）+ 正交维度 + 脂质 / 有机质归一化对照区别于无限有机相分配 |
| **DT2** | 破坏性平台先例饱和 | ZVI / Fe-Pd / B12-corrinoid / 光催化 / 微生物等还原-破坏谱系密集且全部非选择 | 增量须落在 ng/L 工况、同系物 / 结构近似物选择性、真实竞争谱，不得以容量或总降解率替代选择性证据 |
| **DT3** | 卤键水相削弱 | 卤键在水中被显著削弱，阵列结合能与水竞争的量化是核心证伪点 | 卤键角度须给 DFT 能量预算门控与可测效应下限，并与形状 / 疏水维度正交叠加 |
| **DT4** | 挥发性 / 器壁损失伪影 | Chloroform 与 HCBD 的蒸气压与 Henry 常数使吸附实验受顶空损失与器壁吸附污染 | 水相实验须密闭体系并做挥发与器壁吸附质量平衡，否则表观去除是损失而非吸附 |
| **DT5** | 脱卤增毒与母体消失伪去除 | 还原 / 光解 / 生物路径普遍止步低卤代中间产物，产物毒性可能更高 | 须闭合卤素质量平衡，以代谢物毒性当量评价净去除；单一母体消失率不构成去除证据 |
| **DT6** | 共溶剂伪影 | 水相先例几乎全部依赖 THF / 甲醇 / 丙酮助溶加标，共溶剂改变速率与产物谱 | mg/L 级共溶剂批次数据不构成 ng/L 水相证据；设计实验须用被动给体或无载体加标 |
| **DT7** | 氧化还原窗口互斥 | 还原脱卤需低电位电子供体，好氧水体溶解氧使同位点捕获-还原耦合面临失活 | 须以隔氧受限域设计或明确标注厌氧操作条件；可行性须以氧梯度动力学实验证伪 |
| **DT8** | 第三相分配竞争 | BDE-209 / PCB-209 主要赋存于颗粒 / 胶体 / 微塑料 / 脂质相，吸附剂须与这些相竞争 | 任何水相选择性吸附须改写为颗粒 / 胶体界面捕获或预吸附-后销毁两段式 |
| **DT9** | 毒效靶标陷阱 | AhR（平面腔排斥扭转 PCB-209）、PXR/CAR（毒性信号范畴） | 按框架条款禁止作主干仿生原型，仅可提取识别几何原理作原理级参考 |
| **DT10** | 蛋白复制禁令 | 还原脱卤酶、类咕啉辅因子、sMMO 等蛋白结构不得直接复制 | 仅提取设计原理，用可合成材料实现；须潘尧明确重开 scope 方可引入蛋白 |

## 6. 组内各污染物特殊说明

### 6.1 Chloroform — Phase A 完成，20 角度

**化学画像要点**：小分子（MW 119）、弱极性（logKow ~2.0）、中等挥发（Henry 常数 3.67×10⁻³）、全 pH 中性。可用相互作用仅剩三类：三个 Cl 原子上的弱 σ 穴（弱卤键供体）、弱酸性 C–H（弱氢键供体）、拟四面体分子形状互补。主目标场景为出厂水与管网末梢饮用水（µg/L 级），区别于本项目其他污染物的默认市政二级出水。

**选择性难题特殊性**：
- 疏水性有限（logKow ~2.0），单纯疏水分配既无选择性上限又与气提路线竞争
- THM4 同族竞争中溴代物 logKow 更高优先吸附，三氯甲烷在穿透次序中最前
- 壳聚糖改性 AC 对四种 THM 吸附量顺序为 TCM > BDCM > DBCM > TBM，与疏水性顺序相反——提示尺寸 / 孔道可及性而非 logKow 主导

**角度空间特征**：
- 识别类（主干候选）6：A01 α-CD 尺寸匹配腔、A02 Lewis 碱阵列 C–H 氢键、A03 Cl σ 穴卤键阵列、A04 多弱作用协同预组织腔（主干候选）、A05 拟四面体形状筛分、A19 三卤甲基卤素计数签名
- 反应性类 4：A06 类咕啉还原、A07 电化学还原、A08 sMMO 氧化、A09 储库-缓释耦合
- 传质 / 再生 / 界面类 6：A10 Murray 层级传质、A11 挥发性再生、A12 厌氧微环境、A13 膜分配、A14 两性离子抗污、A18 卤键-范德华界面
- 工程耦合 / 边界类 4：A15 捕获-破坏一体、A16 氧化还原门控再生、A17 MIP 腔、A20 二氯卡宾理性设计

**优先角度建议**：A04（单位点内多弱作用协同预组织腔）为最具区分度主干候选，直接满足创新性 D 维；A01（α-CD 尺寸匹配）与 A05（形状筛分）提供几何正交维度。反应性类先例风险高且场景错配（厌氧 vs 好氧饮用水），仅作个案补充。

### 6.2 HCBD — Phase A 完成，13 角度

**化学画像要点**：全氯代 C4 共轭二烯（C₄Cl₆），MW 261，logKow 4.8–4.9，无 C–H 键、化学惰性、可气提（Henry 常数 ~1044 Pa·m³/mol）、DNAPL（密度 1.56–1.68 g/cm³）。可用化学性格仅剩三类：高疏水 + 高极化率、六个乙烯基 C–Cl 卤键 σ 穴、缺电子共轭双键反应性。

**选择性难题特殊性**：
- 主目标场景为工业点源废水及点源影响区地表水（µg/L 级），非市政出水型
- 同族竞争物（TCE/PCE/CCl₄/氯苯类）可过量 100 至 1,000,000 倍
- 水相吸附材料先例为零，识别机制空间全部未被占据

**角度空间特征**：
- 平衡结合类 3：A01 CD 空腔长度 + 卤键、A02 方向性卤键阵列、A03 形状 + 极化率
- 反应性类 2：A04 类咕啉还原、A05 硫醇盐共价缀合
- 动态类 1：A06 PBP 式 pH 门控再生
- 架构 / 工艺补足类 7：A07 核-壳分配、A08 两级串联、A09 生物矿化 FeS 界面、A10 两性离子界面、A11 分级传质、A12 捕获-破坏双功能、A13 表面薄壳动力学

**优先角度建议**：A01（CD 空腔 + 卤键双维）与 A02（方向性卤键阵列）正交维度最丰富；A03（形状 + 极化率）提供非反应性正交维度。反应性角度（A04/A05）先例风险高且属 approach-3，须闭合氯质量平衡。

### 6.3 BDE-209 — Phase A 完成，26 角度

**化学画像要点**：全溴代二苯醚（C₁₂Br₁₀O），MW 959，logKow ~10，水溶度 <100 ng/L。中性、无解离、无氢键供体，醚键氧被邻位溴空间屏蔽。十个溴原子各携 σ 穴（Br σ 穴强于 Cl），为潜在多位点卤键供体。庞大立体轮廓（长轴 ~1.3–1.5 nm）。

**选择性难题特殊性**：
- 水相吸附先例近于空白，去除实为相转移（向污泥 / 颗粒分配）
- 结构最近似竞争者 DBDPE（仅差乙烷桥）与 BDE-209 分子尺寸 / 疏水性极近
- 还原脱溴呈溴数-反应性单调律（高溴优先），但脱溴产物毒性更高
- 溶解相浓度受溶度上限约束，真实水体去除对象为颗粒 / 胶体结合态

**角度空间特征**：
- 反应性捕获 / 读出族 6：A01 类咕啉还原、A02 PceA 双域解耦、A09 级联深度脱溴、A10 隔氧受限域、A11 电化学门控、A24 卤素种还原电位
- 非共价溴阵列读出族 5：A03 σ 穴卤键阵列、A04 溴数梯度 π 酸 EDA、A08 极化率 / 色散匹配、A18 去润湿协同门控、A19 双表位正交预组织
- 桥 / 同系物特异读出族 3：A07 醚氧对乙烷桥判别、A22 C2v 对称轮廓、A25 CD 逐环溴数读出
- 受限腔 / 形状族 3：A05 十溴轮廓受限腔、A06 位阻窗口反转、A20 机制驱动印迹
- 界面 / 传质使能族 4：A12 胞外捕获-催化分工、A13 疏水蛋白界面、A14 膜逆向孔口、A15 海洋雪胶体捕获
- 再生 / 销毁耦合族 4：A16 黄素电子介体、A17 捕获-光催化双功能、A21 颗粒结合态两段式循环、A26 电活性膜
- 受限微环境族 1：A23 肠道受限微反应器

**优先角度建议**：A03（σ 穴卤键阵列）+ A05（十溴轮廓受限腔）+ A07（醚氧对乙烷桥判别）构成三维正交识别核心；A19（双表位正交预组织）为最高创新性候选但复杂度最高。反应性角度（A01/A02/A09）须配隔氧设计并闭合溴质量平衡。

### 6.4 PCB-209 — Phase A 完成，23 角度

**化学画像要点**：全氯代联苯（C₁₂Cl₁₀），MW 499，logKow ~8.2，水溶度推断 ng/L 级。**构型更正**：PCB-209 含四个邻位氯，强制两苯环绕单键取扭转构象（二面角 ~85° 以上），非共平面。该扭转构象正是 PCB-209 无二噁英样活性的结构原因。中性、无 C–H、无氢键、无解离基团。

**选择性难题特殊性**：
- 与 208 个 PCB 同系物仅差氯取代图式，logKow 在同系物序列中单调变化
- PCB-209 单体水相浓度无公开可用数值（pg/L 至亚 ng/L 级推断）
- 四邻氯强制的扭转构象与 AhR 类平面腔内禀不兼容
- 还原脱氯已知生物活性窗口为 Cl₃₋₉，PCB-209 处于窗口之外

**角度空间特征**：
- 扭转 / 形状读出族 3：A01 扭转正交构象形状读出腔（AhR 负面原型反转）、A18 构象熵 / 诱导契合、A20 全氯代 / 零 C–H 轮廓
- 受限腔 / 尺寸族 2：A02 最大体积受限疏水腔、A16 PXR/CAR 大软腔
- 卤键族 1：A03 C–Cl σ 空穴卤键阵列
- 还原捕获-破坏族 6：A04 类咕啉还原、A05 区域选择性级联脱氯、A07 Pd 双金属、A08 黑碳-硫化物界面、A09 醌类电子梭、A10 电化学门控
- 氧化还原窗口 / 光化学族 3：A11 隔氧受限域、A12 疏水富集-光催化、A13 DOM 疏水微域敏化
- 门控再生族 1：A14 pH 门控疏水腔
- 主客体族 1：A15 CD/cavitand 包结
- 谱系 / 色散族 2：A17 π 酸 EDA、A19 十氯重原子极化率
- 氯化度 SAM 族 1：A06 氯化度可调 SAM 磁性纳米
- 传质使能族 2：A21 两亲界面招募层、A22 疏水微域预浓缩
- 正交乘积族 1：A23 多表位正交预组织

**优先角度建议**：A01（扭转轮廓形状读出）+ A03（C–Cl 卤键阵列）构成核心正交二维；A23（多表位正交预组织）为最高创新性候选。还原性角度（A04/A05/A07–A09）普遍为 high 风险且 PCB-209 脱氯活性为零先例，须带 go/no-go 门。

## 7. 预筛建议

### 7.1 TFG 组特异参数

D 组所有成员为中性非解离分子（Chloroform 弱极性小分子、HCBD 全氯代惰性、BDE-209/PCB-209 超疏水巨分子），无强水合阴离子，GLOBAL_SPEC 中 FM3（中性氢键对强水合阴离子不可行）**不直接适用**。但以下热力学约束须检查：

| 检查项 | D 组适用性 | 说明 |
|--------|-----------|------|
| 目标物-识别位点结合自由能 | 适用 | 卤键在水相中显著削弱（Cl σ 穴弱于 Br σ 穴），净结合自由能须扣除双侧去溶剂化代价 |
| 竞争物相对结合自由能 | 适用 | 同系物 / 同族物的疏水本底差异极小（ΔlogKow < 0.5），识别增量须 > 1–3 kJ/mol |
| ng/L 工况所需 Kd | 适用 | BDE-209/PCB-209 需 Kd ~10⁴–10⁵ L/kg（ng/L 级）；Chloroform 需 Kd ~10³ L/kg（µg/L 级） |

**D 组 TFG 补充判据**：
- 对卤键识别（全组），水相净卤键收益常仅为数个 kJ/mol（Schneider 2009 Angew 综述），Cl σ 穴尤其弱（DFT 表明 PCB 的 Cl 卤键不达脱卤能量阈值），须给出可测效应下限
- 对 Chloroform（logKow ~2.0），疏水分配基线低，识别增量须超过水-气分配竞争噪声
- 对 BDE-209/PCB-209（logKow > 8），疏水分配基线极高，有限体积腔须展示相对无限有机相的热力学优势

### 7.2 PADS 组特异参数

D 组先例密度因污染物差异极大：

| 方向 | 直接先例 | 方向先例 | 平台先例 | PADS 起始 100 扣减建议 |
|------|---------|---------|---------|---------------------|
| 碳质非特异吸附 | 多 | 多 | 多 | 饱和，不构成独立角度 |
| 还原脱卤（ZVI/Fe-Pd/B12） | 3–5 | 5–8 | 多 | 高饱和（DT2），增量须落选择性 |
| CD 包合 | 0（卤代物特异） | 2–3 | 5+ | 中等，但水相选择性零先例 |
| 卤键阵列水相吸附设计 | 0 | 1–2（分析 SPME） | 2–3 | 低，水相卤键削弱为核心风险 |
| 水相选择性吸附（BDE-209/PCB-209） | 0 | 0 | 0 | **空白**，先例密度极低 |
| 气提 / 挥发 | 多 | 多 | 多 | 饱和（仅可作再生维度） |
| 形状 / 尺寸匹配腔（水相） | 0 | 0–1 | 1–2 | 低，气相 MOF 先例不可外推水相 |

### 7.3 ODC 组特异建议

D 组因无或仅有极弱静电 / 氢键 / 酸碱把手，正交维度构建是核心设计挑战。建议的正交维度组合：

| 污染物 | 推荐正交维度组合 | 单参数退化风险 |
|--------|----------------|--------------|
| Chloroform | 尺寸匹配腔 + C–H 氢键 / 卤键协同；或多弱作用协同（≥2 类弱作用在预组织腔内） | 高（疏水分配 logKow 单调；单一弱作用在水中低于溶剂竞争噪声） |
| HCBD | 空腔长度 / 形状 + 方向性卤键；或形状 + 极化率 | 高（可用化学性格仅三类，锚点稀疏） |
| BDE-209 | 溴数 σ 穴卤键阵列 + 十溴轮廓形状；或溴数 π 酸梯度 + 位阻窗口；或醚氧桥读出 + 卤键 | 中（溴数依赖反应性 / 卤键提供非单调维度，但疏水分配基线极高） |
| PCB-209 | 扭转轮廓形状 + C–Cl 卤键阵列；或全氯代轮廓 + 扭转形状 + 卤键 | 中（扭转构象为 DDT 不具备的独立维度，但 Cl 卤键内禀弱） |

### 7.4 角度预分类建议

基于预筛结果，对 D 组各污染物角度提出以下预分类指引：

| 等级 | 条件（继承 GLOBAL_SPEC + D 组补充） | 预期分布 |
|------|-----------------------------------|---------|
| **S 级** | 几何 / 拓扑识别轴明确 + 正交维度 ≥ 2 + PADS ≤ 20 + 水相净结合自由能效应下限 > 1 kJ/mol | Chloroform A04（多弱作用协同）；BDE-209 A03+A05 组合（卤键+形状）；PCB-209 A01+A03 组合（扭转+卤键） |
| **A 级** | 可行识别机制 + PADS ≤ 40 或正交维度 = 2 + 阶段 0 go/no-go 可设计 | Chloroform A01/A05；HCBD A01/A02；BDE-209 A07（醚氧判别）；PCB-209 A02/A15 |
| **B 级** | 热力学可行但选择性轴单薄或 PADS ≤ 50 | HCBD A03（形状单独不过 D 维）；BDE-209 A04（EDA 梯度型）；PCB-209 A06（SAM 氯化度偏好） |
| **X 级** | TFG 不通过 或 PADS > 50 或单参数单调退化 | 碳质非特异吸附角度；气提 / 挥发单独角度；BDE-209/PCB-209 单独疏水 / 体积维度；PCB-209 平面 π 夹持腔（T9 不兼容） |
