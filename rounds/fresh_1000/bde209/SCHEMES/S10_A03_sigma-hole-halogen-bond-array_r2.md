### 1.3 设计假设（r2 强化版）

**H1 本征卤键结合层**（r2 强化——回应 W1）：
- **事实**：BDE-209 十个溴原子各携 σ 穴（Br σ 穴强于 Cl）；卤键 C–Br···N/O 在气相/晶体中能量约 8–30 kJ/mol（Schneider 2009）
- **推断**：疏水腔低介环境保护可部分恢复卤键强度
- **假设**：腔内多点卤键（≥3 位点同时作用）净结合自由能贡献 > 5 kJ/mol
- **[r2 新增] 强化策略——受体强度升级阶梯**：
  - r1 以吡啶/硒醚/酰胺羰基为主选受体。r2 新增 **squaramide（方酰胺）** 作为强受体选项。Squaramide 的双 NH 为强卤键受体（β ~0.7–0.9，显著强于吡啶 β ~0.3–0.5），且在超分子化学中已有水相卤键增强案例 [r2-new]（Benz 2017 Chem Eur J, E15 补充；López-Tocón 2021 J Org Chem 10.1021/acs.joc.1c00567，squaramide 水相卤键受体，screened_metadata_crossref）
  - **受体强度阶梯**（r2 扩展）：酰胺羰基（β ~0.2）→ 吡啶（β ~0.3–0.5）→ 硒醚（β ~0.5–0.7）→ squaramide（β ~0.7–0.9）
  - Phase 0 建模门增加受体强度变量：若吡啶 ΔΔG < 2 kJ/mol，自动升级至 squaramide 重算
- **[r2 新增] 强化策略——显式水分子竞争 MD**：
  - r1 Phase 0 仅用隐式溶剂模型（ε = 2, 5, 80）。r2 增加 **显式水分子 MD 模拟**（至少 3 条独立轨迹 × 50 ns），量化疏水腔内残余水分子数与卤键寿命的对应关系
  - 输出：腔内水分子占据数 vs 卤键结合自由能的定量关系曲线；若腔内 >3 个水分子时卤键净收益 < 2 kJ/mol，则须优化腔体疏水性（增加骨架氟化度或缩短孔径）

**H2 非单调签名层**（r2 强化——回应 W2）：
- 继承 r1 假设
- **[r2 新增] 强化策略——DBDPE 内标校准**：
  - DBDPE（十溴二苯乙烷，10 Br σ 穴，logKow ~10.2，与 BDE-209 极近但无醚氧桥）作为**内标校准物**加入竞争谱
  - DBDPE 与 BDE-209 的 logKow 差异 < 0.2（几乎简并），但几何构象不同（乙烷桥扭转柔性 vs 醚氧刚性）
  - 若 α(BDE-209/DBDPE) > 1.5，则为卤键阵列几何读出（非 logKow 单调）的直接证据——因为二者疏水性几乎相同，任何选择性差异必须来自几何/卤键维度
  - DBDPE 加入 LFER 分析作为"疏水性简并对"，约束 logKow 拟合的自由度
- **[r2 新增] 强化策略——双变量 LFER 协议**：
  - r1 仅做 SF vs logKow 残差分析。r2 升级为 **双变量 LFER**：SF = f(logKow, σ穴数量)
  - 若 σ 穴数量的偏回归系数显著（p < 0.05）且独立于 logKow，则卤键维贡献得到统计确认
  - 数据点：BDE-209(10Br)、BDE-183(8Br)、BDE-153(6Br)、BDE-99(4Br)、BDE-47(4Br)、DBDPE(10Br)、PCB-209(10Cl)——7 点双变量回归

### 4.3a [r2 新增] 卤键能量预算强化策略（回应 W1）

**分层能量预算**：

| 层级 | 机制 | 预期贡献 | 不确定性 |
|------|------|---------|---------|
| 基线 | 疏水分配（logKow ~10） | Kd ~10⁴–10⁵ L/kg | 低 |
| 增量 1 | 单价卤键（腔内 ε ~2–5） | 3–8 kJ/mol | 中 |
| 增量 2 | 多点协同（≥3 位点） | 9–24 kJ/mol（设计值） | 高 |
| 增量 3 | squaramide 增强（若启用） | 单价提升至 5–12 kJ/mol | 中-高 |

**Phase 0 门控升级（r2）**：
- go 判据维持 ΔΔG(BDE-209 vs BDE-153) ≥ 2 kJ/mol
- **新增**：若吡啶受体 no-go，自动切换 squaramide 受体重算；若 squaramide 仍 no-go，则角度终止
- **新增**：显式水 MD 验证腔内水分子数 <3 时卤键净收益维持

### 4.3b [r2 新增] logKow 解耦强化协议（回应 W2）

**三层解耦防线**：

1. **DBDPE 内标校准**（新增）：α(BDE-209/DBDPE) > 1.5 为几何/卤键读出的直接证据（二者 logKow 简并）
2. **双变量 LFER**（升级）：SF = f(logKow, σ穴数量)，σ 穴数量偏回归系数须 p < 0.05
3. **甲基化因果对照**（继承 r1 C2）：Lewis 碱甲基化后 SF 回落 >30% 为卤键维贡献的直接因果证据

**解耦逻辑链**：
- 若 DBDPE 内标 α ≈ 1 且 甲基化后 SF 无变化 → 卤键维贡献为零 → D 维判负
- 若 DBDPE 内标 α > 1.5 且 甲基化后 SF 回落 >30% → 卤键维贡献确认 → D 维通过
- 若 DBDPE 内标 α ≈ 1 但 甲基化后 SF 回落 >30% → 矛盾信号 → 须追加实验排查

### 4.5a [r2 新增] 第三相分配量化框架（回应 W6）

**三相分配系数测量协议**：

| 相 | 定量方法 | 报告指标 |
|----|---------|---------|
| 溶解相 | 被动给体（PDMS）+ 水相 LC-MS/MS | Kd_dissolved |
| 颗粒/胶体相 | 土壤胶体稀释体系 + 溶剂萃取 | Kd_particle |
| 吸附剂相 | 吸附剂直接萃取 | Kd_adsorbent |

**竞争判据**：
- 吸附剂须在颗粒/胶体存在下维持 >50% 的溶解相 BDE-209 摄取（否则判第三相竞争压倒识别增量）
- 报告 **第三相竞争因子** FTP = Kd_adsorbent / (Kd_particle × C_particle)，FTP > 1 为吸附剂胜出

**新增对照 C9**：
- 微塑料（PE/PS，1 mg/L）存在下的 SF 对比
- 预期：微塑料对 SF 影响 <20%（因微塑料为无限分配相，无选择性）
