## 4. 材料架构与选择性机制

### 4.1–4.2 继承 r1 + r2

**[r3 具体化] §4.1 骨架选择——β-酮烯胺 COF 优先（回应 W7）**：

r2 识别单元中 Lewis 碱位点选项含 squaramide，但未指定骨架。r3 明确：

**优先骨架：TpPa-1 COF 或其衍生物**

| 性质 | 值 | 来源 |
|------|-----|------|
| 骨架构建化学 | β-酮烯胺键（–C=C–NH–CO–） | TpPa 系列 |
| BET 比表面 | ~800–1500 m²/g | E18 + 文献汇编 |
| 孔径 | ~1.8 nm（TpPa-1） | 文献 |
| 水稳定性 | pH 2–12，7 天 BET 保持 >90% | E18 |
| 后修饰位点 | 骨架 NH 可进一步酰化/硒化 | E20 |
| 合成条件 | 溶剂热，120°C，48–72 h | 标准条件 |

**选择理由**：
1. 水解稳定性远优于亚胺 COF（E18）——BDE-209 实验须在水相中进行，COF 水稳定性为硬约束
2. 孔径 ~1.8 nm 可容纳 BDE-209 分子（长轴 ~1.3–1.5 nm）的部分环进入孔道
3. 骨架 NH 基团提供后修饰锚点（squaramide 化、硒化等）
4. 合成成熟、单体商业可得

### 4.1A [r3 新增] COF 骨架水稳定性加固（回应 W7）

**水稳定性风险评估**：

| COF 类型 | 水解敏感键 | 水稳定性 | 对 BDE-209 方案的适用性 |
|----------|-----------|---------|----------------------|
| 亚胺 COF | C=N | 差（pH >8 水解） | 不适用 |
| β-酮烯胺 COF | C=C–NH–CO | 好（pH 2–12） | **优先** |
| 硼酸酯 COF | B–O | 中等（水敏感） | 不适用 |
| 芳烃 COF（全碳） | 无 | 极好 | 合成困难，后修饰难 |

**TpPa-1 COF 水稳定性实验验证方案**：
1. 合成 TpPa-1 COF → 在 pH 7 去离子水中浸泡 30 天
2. 每 7 天取样：BET、PXRD、FTIR 表征
3. go 判据：30 天后 BET 保持 >80%、PXRD 峰形无明显变化

### 4.4A [r3 新增] 分级孔道传质设计（回应 W4）

BDE-209 为巨分子（MW ~959，长轴 ~1.3–1.5 nm），在纯微孔 COF（d_pore ~1.8 nm）中扩散极慢。r3 引入 **分级孔道设计**：

**双尺度孔道结构**：

| 孔道层级 | 孔径 | 功能 | 设计方法 |
|----------|------|------|---------|
| 介孔传输通道 | ~3–10 nm | 快速传质，缩短颗粒内扩散路径 | 模板法（介孔二氧化硅模板或嵌段共聚物致孔剂） |
| 微孔识别腔 | ~1.5–2.0 nm | 卤键选择性识别位点 | COF 本征微孔 + Lewis 碱功能化 |

**传质增强定量预测**：

1. **纯微孔 COF**：BDE-209 有效扩散系数 D_eff ~10⁻¹²–10⁻¹³ m²/s（基于分子尺寸/孔径比估算）
2. **分级孔道 COF**：介孔通道中 D_eff ~10⁻¹⁰ m²/s（接近体相扩散），微孔中 ~10⁻¹² m²/s
3. **有效颗粒扩散时间**：
   - 纯微孔（颗粒半径 1 µm）：t_diff ~r²/D_eff ~10⁶ s（~10 天）→ 不可接受
   - 分级孔道（介孔通道间距 100 nm）：t_diff ~(100 nm)²/D_eff_medio ~10³ s（~15 min）→ 可接受
4. **合成策略**：
   - 方法 A（硬模板法）：介孔 SiO₂ 模板 + COF 前驱体渗透 → 溶剂热结晶 → HF 蚀刻模板
   - 方法 B（软模板法）：嵌段共聚物（F127/P123）致孔剂 + COF 前驱体共缩合
   - 方法 C（逐级结晶法）：先形成介孔骨架 → 孔壁上外延生长微孔 COF 层

**诚实声明**：分级孔道 COF 的合成复杂度显著高于纯微孔 COF。方法 A/B 的 COF 结晶度可能下降。方法 C 为最优但合成步骤最多。若分级孔道路线失败，可降级为纳米片 COF（厚度 ~10–50 nm，扩散距离缩短至纳米级）。

### 4.5B [r3 新增] 溶解-界面分配定量模型（回应 W5）

BDE-209 水溶度 <100 ng/L，溶解相去除热力学容量极小。r3 将吸附实验设计改写为 **颗粒/胶体界面竞争框架**：

**界面竞争模型**：

1. **实验体系设计**：
   - 溶解相口径：PDMS 被动给体维持 [BDE-209]_dissolved ~10–100 ng/L
   - 颗粒/胶体结合态口径：土壤胶体稀释体系（胶体浓度 10–100 mg/L）
   - 吸附剂投加量：1–10 mg/L
2. **三相分配平衡**：
   - BDE-209 在水-胶体-吸附剂三相间分配
   - Kd_adsorbent >> Kd_colloid → 吸附剂胜出（从胶体相夺取 BDE-209）
   - Kd_adsorbent ≈ Kd_colloid → 吸附剂与胶体竞争，净去除有限
3. **关键判据**：
   - 吸附剂须在胶体存在下维持 >50% 的 BDE-209 摄取（继承 r2 竞争判据）
   - 报告 **界面竞争因子** FIC = Kd_adsorbent / Kd_colloid
   - FIC > 5 → 吸附剂显著胜出
   - FIC 1–5 → 部分竞争
   - FIC < 1 → 吸附剂输于胶体 → 实验意义有限

**诚实声明**：即使 FIC > 5，在真实水体中 BDE-209 主要赋存于颗粒相（沉积物、悬浮颗粒），吸附剂对溶解相的去除贡献有限。本方案的实际应用场景为工业点源废水（含胶体/细颗粒），非一般地表水。

### 7.0A [r3 新增] 力场基准测试协议（回应 W13）

显式水 MD（r2 新增）依赖力场对卤键的描述精度。r3 引入力场基准测试：

**基准测试方案**：

1. **测试体系**：BDE-209 片段模型（单溴苯 + Lewis 碱）的卤键结合能
2. **方法对比**：
   - GAFF2 力场 MD → ΔG_bind(MD)
   - DFT-SAPT（ωB97X-D/aug-cc-pVTZ）→ ΔG_bind(SAPT)
   - 实验参考值（若有）或高精度 CCSD(T)/CBS 参考值
3. **精度判据**：|ΔG_bind(MD) − ΔG_bind(SAPT)| < 2 kJ/mol → 力场可接受
4. **若力场不可接受**：
   - 方案 A：重新拟合卤键相关 LJ 参数（Br···N/O 对）
   - 方案 B：改用极化力场（AMOEBA）
   - 方案 C：以 DFT-SAPT 结果为准，MD 仅作定性参考

**计算量**：~200 核时（基准测试 + 参数优化）

### Step 1 COF 合成与功能化（r3 具体化）

**Step 1A：TpPa-1 COF 骨架合成**：

1. **单体**：
   - 1,3,5-三乙酰基苯（Tp，CAS 631-95-8）
   - 对苯二胺（Pa-1，CAS 106-50-3）
2. **条件**：
   - 溶剂：均三甲苯/1,4-二噁烷（1:1）+ 醋酸（6 M 水溶液，催化剂）
   - 温度：120°C，72 h，溶剂热，N₂ 保护
3. **后处理**：
   - 离心收集 → THF 索氏提取 24 h → 150°C 真空活化 12 h
4. **预期性质**：BET ~800–1200 m²/g，孔径 ~1.8 nm，结晶度（PXRD 峰匹配文献）

**Step 1B：Lewis 碱功能化**：

**路线 1（吡啶功能化，优先）**：
- TpPa-1 COF 骨架 NH 位点 → 2-溴乙酰吡啶接枝（K₂CO₃/DMF，80°C，24 h）
- 预期 N 增量：~2–4 wt%

**路线 2（squaramide 功能化，强受体选项——r3 具体化，回应 W12）**：

1. **前体**：TpPa-1 COF-NH₂（通过过量对苯二胺合成获得末端 NH₂ 功能化 COF）
2. **squaramide 构建**：
   - Step i：COF-NH₂ + 草酸二乙酯（2 equiv）→ 酰胺化中间体
   - 条件：无水乙醇，回流，12 h，N₂ 保护
   - Step ii：环化 → squaramide 环
   - 条件：NaOEt/EtOH，室温，4 h
3. **预期功能化度**：~30–60%（基于 NH₂ 转化率）
4. **表征**：
   - FTIR：squaramide C=O 伸缩 ~1650 cm⁻¹，N–H 伸缩 ~3300 cm⁻¹
   - 固态 ¹³C NMR：squaramide 环碳 ~160–170 ppm
   - 元素分析：N 含量增量 ~2–4 wt%
   - BET：功能化后预期 ~400–800 m²/g（下降因孔道部分填充）

**路线 3（硒醚功能化，备选）**：
- COF-Br（溴功能化 COF）+ Na₂Se → COF-SePh（硒醚化）
- 条件：DMF，80°C，12 h

### 7.1A [r3 新增] 分级孔道 COF 合成方案（回应 W4）

**方法 B（软模板法，优先）**：

1. **致孔剂**：F127 嵌段共聚物（PEO₁₀₆-PPO₇₀-PEO₁₀₆）
2. **COF 前驱体**：Tp + Pa-1 + F127（质量比 10:5:1–10:5:3）

### 7.7A [r3 新增] 具体再生方案（回应 W9）

**再生路线一：竞争性位移洗脱**：

1. **洗脱液**：0.05 M TBA-Br / 甲醇（50:50 v/v）
2. **原理**：Br⁻ 为强卤键受体，竞争性取代 BDE-209 与 Lewis 碱位点的卤键结合
3. **条件**：40°C，5 BV，流速 0.5 mL/min
4. **预期洗脱效率**：~50–70%（单次）

**再生路线二：溶剂梯度洗脱**：

1. **洗脱液梯度**：水 → 甲醇 → 丙酮 → THF
2. **原理**：逐步降低溶剂极性，减弱疏水作用 + 卤键
3. **条件**：每级 3 BV，室温
4. **预期洗脱效率**：~60–80%（全梯度）

**再生路线三：温和碱脉冲**：

1. **洗脱液**：0.01 M NaOH / 甲醇（30:70 v/v）
2. **原理**：碱性条件质子化 Lewis 碱位点，消除卤键
3. **条件**：室温，3 BV
4. **预期洗脱效率**：~70–90%
5. **注意**：须验证 COF 在碱性条件下的稳定性（E18 显示 TpPa COF pH 2–12 稳定）

**再生方案优化**：
- 推荐组合：路线三（碱脉冲）→ 水洗 → 路线一（TBA-Br）→ 甲醇洗
- 预期综合洗脱效率：~80–95%
- 5 循环容量保持预期：≥ 70%
