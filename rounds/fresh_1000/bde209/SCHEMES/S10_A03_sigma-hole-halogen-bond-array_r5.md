## 4. 材料架构与选择性机制（r5 强化）

### 4.1–4.8B 继承 r1–r4

### 4.9c [r5 新增] 低介电微环境工程策略（回应 W1——水相卤键可能太弱）

**问题回顾**：W1 从 r1 到 r4 连续四轮列为 medium。r4 §1.3A 给出了腔内 ε_eff ~2–5 的文献锚定估算，§7.0B 给出了实验快速验证路径，但 ε_eff ~2–5 仍为基于 CB[n] 外推的设计假设，且 ε_eff = 5 时 Br···N 单价 ΔG_XB 仅 ~–5 kJ/mol，10 位点保守场景 ΔG_multi = –75 kJ/mol——虽可接受但裕度不大。

**策略 1：孔口疏水遮蔽降低局部介电常数**

借鉴 PFOA A02 通过方案的孔口预组织策略与 Dieldrin S27 通过方案的疏水腔原理：

1. **孔口疏水环设计**：在 COF 微孔入口引入全氟苯基（C₆F₅）或长链烷基（C₁₂–C₁₈）修饰环
2. **机制**：疏水环排斥水分子进入孔口 → 孔内残留水分子数减少 → 局部 ε_eff 下降
3. **定量预期**：
   - 无遮蔽：ε_eff ~4–5（水相 COF 微孔典型值）
   - 烷基遮蔽：ε_eff ~3–4（参考 C₆F₅ 修饰介孔硅的接触角数据，θ > 110°）
   - 全氟苯基遮蔽：ε_eff ~2.5–3.5（参考全氟化介孔硅的接触角数据，θ > 120°）
4. **对卤键能量的影响**：ε_eff 从 5 降至 3 → Br···N 单价 ΔG_XB 从 ~–5 增至 ~–8 kJ/mol → 10 位点保守 ΔG_multi 从 –75 增至 ~–120 kJ/mol
5. **合成可行性**：全氟苯基修饰可通过 Suzuki 偶联后接枝全氟芳基硼酸实现（已有多篇 COF 后修饰先例，如 Jiang 2019 Nat Chem）

**策略 2：骨架全氟化进一步降低骨架极性**

1. **策略**：将 β-酮烯胺 COF 骨架的 C=O 和 C=N 替换为全氟化类似物（如全氟联苯二甲醛 + 全氟苯胺缩合 → 全氟亚胺 COF）
2. **预期效果**：骨架极性从 ε ~3–4（β-酮烯胺）降至 ε ~2–2.5（全氟芳骨架）
3. **风险**：全氟化 COF 结晶度可能下降、合成难度增加 → 作为备选路线
4. **优先级**：策略 1（孔口遮蔽）为主选，策略 2（骨架全氟化）为备选

**策略 3：低介电微环境的实验验证**

| 验证方法 | 测量内容 | go 线 |
|---------|---------|-------|
| 溶剂化显色探针（Reichardt 染料） | COF 孔内有效介电常数 | ε_eff < 4（有遮蔽）vs > 5（无遮蔽） |
| 水蒸气吸附加高压侵入-挤出 | 孔内疏水程度（水侵入压力） | 遮蔽后水侵入压力 > 50 MPa |
| 荧光探针（Pyrene I₁/I₃ 比值） | 孔内微极性 | I₁/I₃ < 1.2（对应 ε < 4） |

**诚实声明**：孔口疏水遮蔽降低 ε_eff 的定量效果为设计假设，须实验验证。策略 1 的预期 ε_eff ~2.5–3.5 基于介孔硅接触角类比，COF 微孔中的实际效果可能不同。

### 4.9d [r5 新增] 疏水基线解耦的 ITC 直接验证方案（回应 W2——logKow 与卤键纠缠）

**问题回顾**：W2 从 r1 到 r4 连续四轮列为 medium。r4 §4.3b/§4.3c 给出了双变量 LFER 残差分析 + 碳氢骨架对照协议，但这些均为间接推断方法——通过 Kd 系列拟合分离卤键增量，而非直接测量卤键贡献的热力学量。

**策略：等温滴定量热法（ITC）直接测量结合焓/熵分解**

1. **原理**：卤键贡献主要为焓驱动（方向性静电 + 电荷转移），疏水分配主要为熵驱动（去溶剂化释放）。ITC 可直接测量 ΔH 和 ΔS，从而分离两类贡献。
2. **实验设计**：

| 体系 | 测量 | 预期 ΔH | 预期 ΔS | 判决意义 |
|------|------|---------|---------|---------|
| 功能化 COF + BDE-209 | ΔH₁, ΔS₁ | 负值大（卤键 + 疏水） | 正值（疏水贡献） | 总结合热力学 |
| 功能化 COF + DBDPE | ΔH₂, ΔS₂ | 负值中（仅疏水 + 弱卤键） | 正值 | 醚氧贡献缺失的焓差 |
| 空白 COF + BDE-209 | ΔH₃, ΔS₃ | 负值小（仅疏水） | 正值 | 纯疏水基线 |
| 空白 COF + DBDPE | ΔH₄, ΔS₄ | 负值小 | 正值 | 纯疏水基线（碳氢骨架） |

3. **卤键增量直接提取**：
   - ΔΔH_XB = (ΔH₁ – ΔH₂) – (ΔH₃ – ΔH₄)
   - 若 ΔΔH_XB < –5 kJ/mol → 卤键焓贡献显著，超越疏水基线
   - 若 ΔΔH_XB ≈ 0 → 卤键贡献可忽略，退化为疏水基线
4. **go 判据**：ΔΔH_XB < –5 kJ/mol（BDE-209 vs DBDPE 的焓差 > 5 kJ/mol，归因于卤键 + 醚氧）
5. **技术可行性**：BDE-209 水溶度极低（<100 ng/L），ITC 需使用有机溶剂/水混合体系（如 MeOH/H₂O 1:1）或使用被动给体加标方式。若直接 ITC 不可行，降级为竞争 ITC（以已知结合常数的模型化合物为竞争物）。

**诚实声明**：ITC 对 BDE-209 巨分子在水相中的直接测量面临溶度积极限约束。MeOH/H₂O 混合溶剂改变了卤键强度，结果须标注溶剂效应。降级竞争 ITC 的精度较低（±2 kJ/mol）。

### 4.9e [r5 新增] DBDPE 区分的第三维度——缺电子 B 中心化学放大（回应 W11）

**问题回顾**：W11 从 r1 到 r4 连续四轮列为 medium。r4 §4.3d 给出了双维度区分策略（醚氧 Lewis 酸读出 + 卤键图案几何差异），但诚实声明 ΔΔG_total ~2–6 kJ/mol 处于可测边缘，联合后可能仍不足以实现高选择性。

**策略：引入三芳基硼基团作为第三区分维度**

1. **原理**：BDE-209 含醚氧（弱 Lewis 碱，可配位缺电子 B 中心），DBDPE 的乙烷桥无孤对电子 → 无此配位能力。三芳基硼基团（如 BPh₂ 或 BMes₂）为强 Lewis 酸，可选择性结合醚氧。
2. **设计实现**：
   - 在 COF 骨架中引入三芳基硼基团修饰（后合成修饰：将 –B(OH)₂ 接枝于 COF 骨架的醛基位点）
   - 或直接在单体中嵌入三芳基硼基团（如 4-二苯基硼基苯甲醛为 COF 单体组分）
3. **预期增量**：
   - BDE-209 醚氧 → B 中心配位：ΔΔG_B-O ~3–6 kJ/mol（基于芳基硼酸-醚氧配合物文献，Suzuki 偶联中的活化效应）
   - DBDPE 无此贡献 → 第三维度区分增量 ~3–6 kJ/mol
4. **联合三维度区分**：
   - 维度 1（醚氧 Lewis 酸读出）：~1–3 kJ/mol
   - 维度 2（卤键图案几何差异）：~1–3 kJ/mol
   - 维度 3（B 中心-醚氧配位）：~3–6 kJ/mol
   - **总计**：ΔΔG_total(BDE-209 vs DBDPE) ~5–12 kJ/mol → α ~8–130
5. **风险**：
   - 三芳基硼基团水稳定性差（B–C 键水解）→ 须以介孔保护或全氟芳基稳定化
   - B 中心可能同时结合水分子 → 竞争降低有效性
   - 合成复杂度进一步增加

**诚实声明**：三芳基硼-醚氧配位在水相中的有效性为设计假设。B 中心水稳定性为本策略最大风险。若水相不可行，可收窄为"非水相（MeOH/CHCl₃）DBDPE 区分策略"。
