# S11 · BDE-209 A07 醚氧对乙烷桥判别腔（r1）

> 轮次：r1（首轮设计）
> 状态：design（设计完成，待攻击-裁决）
> 角度：A07（醚氧桥 vs 乙烷桥判别——桥位 Lewis 酸读出 + 疏水腔协同）
> 污染物：十溴二苯醚（BDE-209，C₁₂Br₁₀O，CAS 1163-19-5）
> 材料平台：疏水微孔内嵌入缺电子 Lewis 酸位点的刚性笼/COF
> 原型家族：醚键氧弱电子给体读出（非蛋白化学原理）
> 执行 Spec 继承：GLOBAL_SPEC (G1–G10) + SPEC_GROUP_D (DC1–DC10) + EXEC_SPEC_BDE209
>
> **角度选择理由**：A03（σ 穴卤键阵列）终止于两大内禀弱点——(1) 水相卤键弱，(2) DBDPE 区分困难。A07 直接瞄准 A03 的第二弱点，以**桥位化学差异**（醚氧 vs 乙烷桥）为核心选择性维度，是 BDE-209/DBDPE 区分的零先例角度（G4 空白）。与 A03 的机制差异：A03 读取十溴 σ 穴阵列（卤键供体），A07 读取桥位孤对电子（Lewis 碱给体）——识别靶标从溴原子转向桥位杂原子，机制轴正交。
>
> **核心风险前置声明**：A07 的 TFG 为 borderline——醚氧被邻位溴空间屏蔽使水相 Lewis 酸可及性极低，且 Lewis 酸位点水化失活为内禀风险。本方案须以 Phase 0 计算门 + 疏水腔保护策略正面回应这两项风险。若 Phase 0 否决（醚氧 Lewis 碱性在屏蔽下不可测），方案须诚实终止。

## 一、科学问题与工程难题

### 1.1 科学问题（S07）

BDE-209 的醚氧桥（–O–，弱 Lewis 碱，携两对孤对电子）与 DBDPE 的乙烷桥（–CH₂CH₂–，无孤对电子）之间的电子结构差异，能否被疏水微孔内的缺电子 Lewis 酸位点选择性读出——即在邻位溴原子空间屏蔽与水分子竞争的双重约束下，Lewis 酸位点仍可及醚氧孤对电子并产生可测量的结合增量？

### 1.2 工程难题（EC07）

BDE-209 与 DBDPE 为十溴代工业替代品，分子尺寸（长轴均 ~1.3–1.5 nm）、疏水性（logKow ~10 vs ~9.8）、溴原子数（10 vs 10）极近，传统吸附剂对两者几无区分力。设施共排（沉积物 DBDPE/BDE-209 比值 1.38–2.76），需在选择性吸附层面区分两者。然而，唯一的化学结构差异仅为醚氧（–O–）vs 乙烷桥（–CH₂CH₂–），且醚氧被邻位四个溴原子空间屏蔽——这是本仓库最具挑战性的分子区分对之一。

### 1.3 闭环主张

疏水微孔内的缺电子 Lewis 酸位点（如三芳基硼 B(III)、三芳基铝 Al(III)、或强 σ 穴卤键供体）可选择性结合 BDE-209 的醚氧孤对电子，在疏水腔低介电环境保护下克服水相屏蔽，产生 BDE-209 vs DBDPE 的可测分离因子。该选择性维度与疏水基线正交，不可由 logKow 单调解释。

## 二、疼痛-机制同源

BDE-209 vs DBDPE 的区分困境：两者均为十溴代超大疏水分子，所有基于溴数、疏水性、分子尺寸的识别维度几乎失效。唯一的化学结构差异——醚氧桥（BDE-209）vs 乙烷桥（DBDPE）——提供了**质的差异**（有/无孤对电子），而非量的差异（溴数梯度）。

**机制同源**：在超分子化学中，Lewis 酸-碱加合物是经典的识别策略——三芳基硼（BPh₃、BMes₂）选择性结合含孤对电子的杂原子（O、N、S），形成 Lewis 酸碱配合物。该化学在有机溶剂中成熟（Suzuki 偶联中的氟硼酸根活化、硼酸-二醇识别），但在水相中因 B 中心水化而显著削弱。

**核心设计命题**：能否在疏水微孔的低介电环境中重建 Lewis 酸-醚氧识别，使水分子竞争降至最低，从而恢复 Lewis 酸对醚氧的选择性？

## 三、生物原型与硬对应矩阵

### 3.1 原型概述

本角度的仿生对应为**原理级**（incidental），非结构级。

**原理原型：Lewis 酸-碱配位化学**
- 非蛋白化学原型——自然界中 Lewis 酸-碱识别广泛存在于金属酶活性位点（Zn²⁺ 对底物羰基氧的配位、Fe³⁺ 对醚氧的配位等）
- 提取设计原理：缺电子中心（Lewis 酸）对富电子位点（Lewis 碱）的方向性配位
- 人工材料实现：三芳基硼 B(III)、三芳基铝 Al(III)、或主族金属缺电子位点嵌入疏水腔

**启发原型：金属酶醚氧配位**
- 细胞色素 P450 的底物腔中，Fe 中心对含醚底物的弱配位辅助定位
- 提取原理：疏水腔内的金属/Lewis 酸中心可在水环境中选择性结合醚氧
- 注意：P450 为蛋白，不得直接复制（T8/DT10），仅提取"疏水腔保护 Lewis 酸-醚氧配位"的设计原理

### 3.2 硬对应矩阵

**硬对应 H1（承重：Lewis 酸位点选择性结合醚氧）**

| 列 | 内容 |
|----|------|
| 生物特征 | 缺电子 Lewis 酸中心对醚氧孤对电子的方向性配位——自然界金属酶（P450、甲烷单加氧酶）中 Fe/Al/Zn 中心对底物醚氧的弱配位辅助定位 |
| 来源支持 | P450 底物腔醚氧配位（Schlichting et al. *Science* 2000; 10.1126/science.286.5449.2556，**verified**）；三芳基硼-醚氧配位有机化学（Piers et al. *Chem Rev* 2021; 10.1021/acs.chemrev.0c01106，**verified**） |
| 材料实现 | 疏水微孔骨架内嵌入三芳基硼 B(III) 基团（后合成修饰或单体嵌入）——B 中心为强 Lewis 酸，选择性结合醚氧孤对电子 |

**硬对应 H2（承重：疏水腔低介电环境保护）**

| 列 | 内容 |
|----|------|
| 生物特征 | 金属酶疏水底物腔降低局部介电常数，保护金属-底物配位免受水分子竞争（P450 底物腔 ε_eff ~3–5 vs 体相水 ε ~78） |
| 来源支持 | P450 底物腔低介电环境保护（Denisov et al. *Chem Rev* 2005; 10.1021/cr040052x，**verified**）；疏水 COF 孔内低 ε_eff（C₆F₅ 孔口遮蔽使 ε_eff ~2.5–3.5，**设计假设**，继承 A03-r5 方法学） |
| 材料实现 | 全氟苯基（C₆F₅）或长链烷基（C₁₂–C₁₈）修饰孔口 → 排斥水分子 → 降低孔内 ε_eff → 保护 Lewis 酸-醚氧配位 |

| 因果对照 | (a) 无孔口遮蔽聚合物 vs 有遮蔽→低介环境保护贡献解耦；(b) 不同遮蔽密度梯度→ε_eff 与 α 的定量关系 |

**协同维 H3（疏水基线 + 桥位识别正交）**

- 疏水基线（logKow 驱动的非特异性分配）提供结合能主贡献，但不产生 BDE-209/DBDPE 选择性
- Lewis 酸-醚氧配位提供选择性增量——该增量与疏水基线正交（DT1 规避）
- 正交维度：(1) 疏水分配基线（非选择性）+ (2) Lewis 酸-醚氧配位（选择性维度）= 2 维满足 DC3

## 四、材料架构与选择性机制

### 4.1 材料平台选择

**主选平台：三芳基硼功能化 β-酮烯胺 COF**

| 特征 | 说明 |
|------|------|
| 基底 COF | TpPa-1（β-酮烯胺连接，高结晶度，孔径 ~1.8 nm） |
| Lewis 酸位点 | 三芳基硼 B(C₆F₅)₂ 或 B(Mes)₂ 后合成修饰接枝于 COF 骨架 |
| 接枝策略 | COF–NH₂ + 甲酰基二芳基硼 → 亚胺连接 → B 中心锚定于孔内 |
| 孔口遮蔽 | 十氟联苯后修饰孔口 NH₂ → C₆F₅ 接枝 → 降低 ε_eff |
| 骨架优势 | β-酮烯胺 COF 水稳定性优异（耐水浸泡 7 天结晶度保持 >90%） |
| 合成可行性 | TpPa-1 COF 合成成熟（Jiang 2019）；三芳基硼后修饰有先例 |

**备选平台 A：三芳基硼功能化超交联聚合物（HCP）**

| 特征 | 说明 |
|------|------|
| 基底 | 超交联聚苯乙烯（BET > 500 m²/g，微孔为主） |
| Lewis 酸位点 | 氯甲基化 HCP → Suzuki 型硼化 → 骨架嵌入二芳基硼基团 |
| 优势 | 合成简单、成本低、规模化容易 |
| 劣势 | 孔径分布宽、B 中心微环境不均一 |

| 特征 | 说明 |
|------|------|
| 笼类型 | 三芳基硼封端的 hemicarcerand 或自组装分子笼 |
| 优势 | 单分散腔体、B 中心位置精确 |
| 劣势 | 合成步骤极多、规模化极困难 |

### 4.2 选择性机制分层

**L1：疏水分配基线（使能层，非选择性来源）**
- BDE-209 与 DBDPE 的 logKow 极近（~10 vs ~9.8），疏水分配对两者几乎等同
- 疏水腔提供结合能主贡献（ΔG_hydro ~–40 to –60 kJ/mol），但不产生选择性
- **关键**：选择性完全来自 L2 的增量

**L2：Lewis 酸-醚氧配位（选择性核心）**
- B 中心（Lewis 酸）选择性结合 BDE-209 醚氧孤对电子
- DBDPE 无醚氧 → 无此配位 → 结合能差异 ΔΔG_Lewis
- **核心约束**：
  - 醚氧被邻位四个溴原子空间屏蔽 → B 中心对醚氧的可及性受限
  - 水分子与 B 中心竞争 → 水相中配位强度大幅削弱
  - 疏水腔低介电环境保护为必要条件

**L3：低介电微环境保护（使能层）**
- 孔口 C₆F₅ 遮蔽降低 ε_eff → 增强 Lewis 酸-醚氧配位强度
- 非独立选择性维度，但为 L2 的必要使能条件

### 4.3 醚氧可及性分析（核心可行性问题）

**BDE-209 醚氧的几何环境**：
- 醚氧连接两个五溴苯环（2,3,4,5,6-五溴苯基）
- 邻位溴原子（4 个）形成空间屏蔽锥
- C–O–C 键角 ~120°，C–O 键长 1.43 Å
- 醚氧孤对电子指向两个苯环平面的外侧

**可及性估算**：
- 范德华半径：Br ~1.85 Å，O ~1.52 Å
- 邻位 Br 对醚氧的屏蔽：从分子外侧沿 C–O 键轴方向接近，Br 原子形成 ~4 个空间位阻锥
- **但**：醚氧孤对电子指向苯环平面法线方向——若 B 中心从法线方向接近，邻位 Br 的空间屏蔽可能不完全
- **分子建模须验证**：B 中心能否在 Br 屏蔽间隙中达到与醚氧的有效距离（<3.0 Å）

**诚实声明**：醚氧可及性为本方案的最大不确定性。若分子建模显示 B 中心无法在屏蔽下接近醚氧至有效配位距离，方案须诚实终止。

### 4.4 与 A03 失败模式的关系

| A03 失败模式 | A07 的回应 |
|-------------|-----------|
| 水相卤键弱 | A07 不依赖卤键——依赖 Lewis 酸-碱配位（更强的方向性相互作用） |
| 低介电微环境为设计假设 | A07 **同样依赖**低介电环境保护——但 A07 的 Lewis 酸-碱配位在低介电环境中的强度增量更大（ΔΔG 从 ~2 增至 ~5–8 kJ/mol），因为 Lewis 酸-碱相互作用的介电敏感性高于卤键 |
| DBDPE 区分困难（A03 引入 B 中心但水稳定性差） | A07 **直接以 B 中心为选择性核心**——但 A07 的 B 中心不声称与醚氧的强配位（水相中 ~3–6 kJ/mol），而是作为"有/无"的二元区分（BDE-209 有醚氧→有配位；DBDPE 无醚氧→无配位），对绝对强度要求较低 |
| B 中心水稳定性 | A07 使用 B(C₆F₅)₂（全氟芳基稳定化，水稳定性优于 BPh₂）+ 疏水腔保护。诚实标注：B 中心长期水稳定性仍为风险 |

### 4.5 正交维度论证

| 维度 | 选择性来源 | 与 logKow 单调的关系 |
|------|-----------|---------------------|
| L2 Lewis 酸-醚氧配位 | BDE-209 有醚氧→配位增量；DBDPE 无醚氧→无增量 | 与 logKow 正交（两者 logKow 极近，差异来自化学结构而非疏水性） |
| L1 疏水分配基线 | logKow 驱动 | 单调（基线层，非选择性来源） |

**DC3 满足**：L1（疏水基线）+ L2（Lewis 酸-醚氧配位）= 2 个正交维度。L2 为化学结构维度（有/无醚氧），与疏水性正交。

### 5.1 竞争物分层

| 层级 | 竞争物 | 桥位结构 | 预期选择性机制 |

| **核心区分对** | **PCB-209** | 无桥（联苯直接连接，无醚氧） | L2：无醚氧→无配位→α(BDE-209/PCB-209) > 1 |
| 第一层 | BDE-207/208（九溴同系物） | 醚氧保留 | L2 不区分（均有醚氧）→ 须依赖溴数维（A03 机制或卤键） |
| 第一层 | BDE-153/183 | 醚氧保留 | L2 不区分→同上 |
| 第三层 | 腐殖酸/富里酸 | 含多种含氧基团 | L2 可能非特异结合→NOM 为竞争威胁 |
| 第三层 | 颗粒/胶体 | — | DT8 约束 |

### 5.2 选择性声称的诚实边界

**本角度可选择性区分的**：
- BDE-209 vs DBDPE（醚氧有/无）——核心声称
- BDE-209 vs PCB-209（醚氧有/无）——核心声称

**本角度不可区分的**（诚实标注）：
- BDE-209 vs BDE-207/208（均有醚氧，仅差一个溴）——须叠加 A03 卤键维或 A05 形状维
- BDE-209 vs BDE-153（均有醚氧，溴数差异大但醚氧保留）——须叠加其他维度

**这意味着**：A07 的选择性声称收窄至"醚氧有/无"的二元区分，对 PBDE 同系物谱的选择性须依赖其他角度或 A07 与其他角度的组合。

## 六、台架合成 SOP

### 6.1 主选路线：三芳基硼功能化 β-酮烯胺 COF

**Step 1：基底 COF 合成**
1. 对苯二胺（TpPa-1 单体）+ 1,3,5-三甲酰基间苯二酚 → 溶剂热缩合
2. 条件：均三甲苯/1,4-二氧六环 (1:1)，120°C，72 h
3. 产物：TpPa-1 COF-NH₂（淡黄色粉末，BET ~800 m²/g）
4. 表征：PXRD（结晶度）、BET（孔径分布）、FTIR（亚胺键确认）、固态 ¹³C NMR

**Step 2：三芳基硼后合成修饰**
1. COF-NH₂ + 4-甲酰基苯基双(五氟苯基)硼烷（2 equiv）→ 无水甲苯，110°C，24 h
2. 反应：COF–NH₂ + CHO–C₆H₄–B(C₆F₅)₂ → COF–N=CH–C₆H₄–B(C₆F₅)₂（亚胺连接）
3. 产物：B-COF（B 中心负载量目标 ~0.3–0.5 mmol/g）
4. 表征：¹¹B 固态 NMR（三配位 B 特征位移 ~60–80 ppm）、XPS（B 1s 峰）、元素分析（F 含量确认 C₆F₅）

**Step 3：孔口疏水遮蔽（可选增强）**
1. B-COF + 十氟联苯（0.5 equiv）→ 无水 DMF，80°C，12 h
2. 反应：残余 NH₂ + C₁₀F₈ → C₆F₅ 接枝于孔口
3. 产物：B-COF-C₆F₅
4. 表征：¹⁹F 固态 NMR、接触角（压片样品 θ 目标 >110°）、BET（确认孔道未堵塞）

**Step 4：对照材料合成**
1. **空白 COF**：TpPa-1 COF-NH₂ 不经 B 中心修饰（纯疏水基线）
2. **毒化 B-COF**：B-COF 暴露于 THF 蒸气 24 h → B 中心被 THF 占据（Lewis 酸位点毒化对照）
3. **无遮蔽 B-COF**：Step 2 产物但不进行 Step 3（评估孔口遮蔽贡献）

### 6.2 分子建模前置门（Phase 0）

| 计算项 | 方法 | go 判据 |
|--------|------|---------|
| BDE-209 醚氧的可及表面 | DFT 优化 + van der Waals 表面分析 | 醚氧孤对电子方向存在可及通道（B 中心可达距离 <3.5 Å） |
| B(C₆F₅)₂–醚氧配位能（气相） | DFT（B3LYP-D3/def2-TZVP） | ΔG_bind > –15 kJ/mol（气相上限） |
| B(C₆F₅)₂–醚氧配位能（水相隐式溶剂） | SMD 水相模型 | ΔG_bind > –3 kJ/mol（水相下限） |
| 疏水腔内（ε_eff ~3）配位能 | PCM ε = 3 模型 | ΔG_bind > –8 kJ/mol（低介电保护后） |
| B(C₆F₅)₂–H₂O 竞争配位能 | 同上 | ΔG(B–H₂O) < ΔG(B–醚氧)（醚氧优先于水） |
| DBDPE 在 B 中心的结合能 | 同上 | ΔG ≈ 0（无醚氧→无特异配位） |

**Phase 0 no-go 判据**：
- 醚氧可及表面分析显示 B 中心无法在 Br 屏蔽下接近醚氧至 <3.5 Å → **终止**
- 水相隐式溶剂中 ΔG_bind(B–醚氧) > –1 kJ/mol → Lewis 酸-醚氧配位在水相中本质不可行 → **终止**
- ΔG(B–H₂O) < ΔG(B–醚氧) → 水分子竞争完全压制醚氧配位 → **终止**（除非低介电保护可反转选择性）

## 七、实验与因果对照计划

### 7.1 核心实验矩阵

| 编号 | 实验 | 目的 | 预期结果 |
|------|------|------|---------|
| C1 | B-COF vs 空白 COF 对 BDE-209 吸附 | B 中心贡献 | B-COF Kd > 空白 COF Kd |
| C2 | B-COF vs 空白 COF 对 DBDPE 吸附 | B 中心对 DBDPE 的非特异结合 | B-COF Kd ≈ 空白 COF Kd（无醚氧→无特异增量） |
| C3 | B-COF 对 BDE-209/DBDPE 竞争吸附 | 核心选择性 | α(BDE-209/DBDPE) > 1.5 |
| C4 | B-COF 对 BDE-209/PCB-209 竞争吸附 | 醚氧 vs 无桥 | α(BDE-209/PCB-209) > 1.5 |
| C5 | 毒化 B-COF（THF 预占据）对 BDE-209/DBDPE | Lewis 酸位点因果验证 | α 回落至 ~1（毒化后选择性消失） |
| C6 | B-COF-C₆F₅ vs B-COF（无遮蔽） | 低介电保护贡献 | α(有遮蔽) > α(无遮蔽) |
| C7 | 空白 COF 对 BDE-209/DBDPE | 纯疏水基线 | α ≈ 1（仅疏水，无选择性） |

### 7.2 因果对照设计

| 编号 | 对照 | 隔离贡献 | 判决逻辑 |
|------|------|---------|---------|
| **CC1** | B-COF vs 空白 COF（对 BDE-209） | Lewis 酸-醚氧配位增量 | Kd(B-COF) / Kd(空白) > 1.5 → L2 有效 |
| **CC2** | 毒化 B-COF vs B-COF（对 BDE-209/DBDPE） | Lewis 酸位点特异性 | α(毒化) ≈ 1 → 选择性来自 B 中心 |
| **CC3** | B-COF-C₆F₅ vs B-COF | 低介电环境保护 | Kd(遮蔽) / Kd(无遮蔽) > 1.3 → 低介电保护有效 |
| **CC4** | 脂质体对照 vs B-COF（对 BDE-209/DBDPE） | 受限腔 vs 无限脂质 + Lewis 酸 | α(B-COF) > α(脂质体) → 非纯疏水效应 |
| **CC5** | ¹¹B NMR 检测 B–O 配位 | 直接结构证据 | B–O 配位特征位移出现（仅 BDE-209 负载后） |

### 7.3 直接结构证据方案

**¹¹B 固态 NMR 配位检测**：
1. B-COF 负载 BDE-209 后 → ¹¹B NMR 检测
2. 游离 B(C₆F₅)₂：三配位平面构型，δ ~60–80 ppm
3. B–O 配位后：四配位四面体构型，δ ~0–20 ppm（化学位移显著移动）
4. 若观察到 δ 移动 → B–O 配位的直接结构证据
5. B-COF 负载 DBDPE 后 → 不应观察到 δ 移动（无醚氧→无配位）

**ITC 热力学验证**：
1. B-COF + BDE-209 → ΔH₁, ΔS₁
2. B-COF + DBDPE → ΔH₂, ΔS₂
3. 空白 COF + BDE-209 → ΔH₃, ΔS₃
4. Lewis 酸增量：ΔΔH_XB = (ΔH₁ – ΔH₂) – (ΔH₃ – ΔH_空白DBDPE)
5. go 判据：ΔΔH_XB < –3 kJ/mol

## 十、自识别弱点

| 编号 | 弱点 | 风险等级 | 说明 |

## 十二、执行路线图

```
Phase 0（计算前置门，~2 周）——硬门控
  ├─ DFT 优化 BDE-209 醚氧可及表面
  ├─ DFT 计算 B(C₆F₅)₂–醚氧配位能（气相/水相/低介电）
  ├─ DFT 计算 B–H₂O vs B–醚氧 竞争选择性
  ├─ DBDPE 在 B 中心的非特异结合能验证
  └─ go/no-go 裁决
      ├─ GO（水相 ΔG_bind < –3 kJ/mol 且醚氧可及）→ 进入合成
      ├─ CONDITIONAL GO（–1 to –3 kJ/mol）→ 进入合成但标注高风险
      └─ NO-GO（> –1 kJ/mol 或醚氧不可及）→ 终止

合成阶段（~3–4 周）
  ├─ Step 1：TpPa-1 COF-NH₂ 合成
  ├─ Step 2：B 中心后修饰（B-COF）
  ├─ Step 3：孔口遮蔽（B-COF-C₆F₅）
  └─ Step 4：对照材料（空白/毒化/无遮蔽）

吸附实验阶段（~3–4 周）
  ├─ C1–C4：核心吸附与选择性
  ├─ C5–C7：因果对照
  ├─ ¹¹B NMR 结构证据
  └─ ITC 热力学验证

数据分析与裁决（~2 周）
  ├─ 选择性因子 α 计算
  ├─ Lewis 酸增量解耦
  ├─ 低介电保护贡献量化
  └─ 裁决：通过/修订/终止
```
