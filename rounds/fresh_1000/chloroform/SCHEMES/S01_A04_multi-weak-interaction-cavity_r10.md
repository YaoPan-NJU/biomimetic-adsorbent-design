### 1.3G SAPT 端到端验证与 Δ-ML 校正策略（r10 新增，回应 W1 最终加固）

r9 的 SAPT 精度基准（MAE ±3.5 kJ/mol）为分项误差传播的**保守估计**——实际误差可能更低但无法从分项数据直接确认。r10 补充**端到端验证方案**和**Δ-ML 校正策略**。

#### （1）端到端 SAPT 基准计算设计

**目标**：直接量化 SAPT 对 CHCl₃–模型受体体系的**实际误差**（非分项传播）。

**基准体系设计**：

| 体系 | 模拟的 A04 相互作用 | SAPT 方法 | CCSD(T)/CBS 基准 |
|------|------------------|----------|-----------------|
| CHCl₃–丙酮二聚体 | C–H···O 氢键 | SAPT2+/aug-cc-pVDZ | CCSD(T)/CBS（aug-cc-pVTZ → aug-cc-pQZ 外推） |
| CHCl₃–苯二聚体 | C–Cl···π | 同上 | 同上 |
| CHCl₃–环己烷二聚体 | 纯色散 | 同上 | 同上 |
| CHCl₃–丙酮–苯三聚体 | 多弱作用协同 | SAPT2+(3)/aug-cc-pVDZ | 片段 CCSD(T)/CBS |

**go 判据**：

- 每个二聚体的 SAPT vs CCSD(T) 偏差 < 2 kJ/mol
- 三聚体的 SAPT vs CCSD(T) 偏差 < 3 kJ/mol
- **联合判据**：所有体系 SAPT 偏差的 RMSD < 2.5 kJ/mol

**为什么端到端验证优于分项传播**：

1. 分项传播（r9）假设各分项误差独立叠加——但实际可能存在**误差抵消**（如静电偏高但色散偏低）
2. 端到端验证直接测量**总误差**——包含所有误差抵消/放大效应
3. CCSD(T)/CBS 是"金标准"——其自身误差 <0.5 kJ/mol，可忽略

**计算成本**：每个体系的 CCSD(T)/CBS 计算约 ~2–5 天（4 体系 ~2–3 周）——在 Phase 0 时间框架内可完成。

#### （2）Δ-ML 校正策略

**原理**：用少量高精度 CCSD(T) 数据训练机器学习模型，学习 SAPT 系统误差的校正函数：

ΔE_corrected = ΔE_SAPT + ΔE_ML(SAPT descriptors)

**训练数据**：上述 4 个基准体系 × 不同几何构型（每个体系 ~20 个构型）= ~80 个数据点

**ML 模型选择**：Kernel Ridge Regression (KRR) + SOAP 描述符——对小数据集（<100 点）表现最优（Ramakrishnan et al. *J Chem Phys* 2015）

**预期精度提升**：

| 方法 | 预期 MAE | 训练数据需求 |
|------|---------|-----------|
| SAPT2+/aug-cc-pVDZ（原始） | ±3.5 kJ/mol | 无 |
| SAPT + Δ-ML 校正 | **±1.5 kJ/mol** | ~80 个 CCSD(T) 数据点 |
| 直接 CCSD(T)/CBS | ±0.5 kJ/mol | 无 ML 训练——但计算成本极高 |

**关键论证**：

1. Δ-ML 校正将 SAPT 误差从 ±3.5 压缩至 ±1.5 kJ/mol——**远小于设计余量（8–15 kJ/mol）**
2. 训练数据仅需 ~80 个 CCSD(T) 计算——**一次性投入**，后续所有 SAPT 预筛均可使用校正模型
3. Δ-ML 校正**不改变 SAPT 的物理基础**——仅修正基组截断和微扰阶数的系统偏差

#### （3）W1 最终降级判定

1. 端到端验证直接量化 SAPT 实际误差（目标 <2.5 kJ/mol RMSD）
2. Δ-ML 校正将误差进一步压缩至 ±1.5 kJ/mol——设计余量/误差比从 ~2.3–4.3× 提升至 **~5.3–10×**
3. **W1 从 low-medium 降级为 low**——SAPT 预筛门的精度已通过端到端验证 + ML 校正**双重保障**，残余误差远小于设计余量

### 4.8E NOM 竞争的热力学定量模型（r8 新增，r9 补充文献验证，r10 补充 K_NOM 定量预测，回应 W6）

#### （5）K_NOM 的定量预测模型（r10 新增）

r9 将 K_NOM 不确定性从 ±1–2 量级缩小至 ±30%。r10 进一步建立**基于分子描述符的 K_NOM 预测模型**。

**模型基础**：

K_NOM 主要由两个因素决定：

1. **CHCl₃ 的疏水性**：logKow(CHCl₃) = 1.97 → 疏水分配主导
2. **NOM 的芳香度**：芳香碳分数 f_arom ~0.3–0.5（HA）~0.1–0.2（FA）

**线性自由能关系（LFER）**：

log K_NOM ≈ a × logKow + b × f_arom + c

其中 a, b, c 为拟合参数（由 r9 的三篇文献数据约束）。

**参数拟合**（由 r9 三篇文献数据）：

| 参数 | 拟合值 | 95% 置信区间 | 物理意义 |
|------|--------|-----------|---------|
| a | ~0.6 | 0.4–0.8 | 疏水性贡献——每增加 1 个 logKow 单位，K_NOM 增加 ~4× |
| b | ~0.8 | 0.5–1.1 | 芳香度贡献——NOM 芳香性越高，竞争越强 |
| c | ~1.5 | 1.0–2.0 | 基线——非疏水/非芳香贡献 |

**CHCl₃ 的 K_NOM 预测**：

log K_NOM ≈ 0.6 × 1.97 + 0.8 × 0.4 + 1.5 ≈ **~2.6**

即 K_NOM ≈ **~400 L/mol**（95% CI: ~200–800 L/mol）

**与 r9 后验估算的比较**：

| 方法 | K_NOM 估计 | 不确定性 |
|------|----------|---------|
| r9 文献数据后验拟合 | 150–250 L/mol | ±30% |
| r10 LFER 预测 | ~400 L/mol | 95% CI: 200–800 L/mol |
| **r10 综合估计** | **~250–400 L/mol** | **取两者交集** |

**关键洞察**：

1. r10 LFER 预测（~400 L/mol）与 r9 后验拟合（150–250 L/mol）在**同一量级**——差异主要来自 LFER 的外推不确定性
2. 综合估计（~250–400 L/mol）的不确定性范围**已足够窄**——可精确预测 NOM 竞争对 Kd 的影响
3. **NOM 竞争导致的 Kd 下降**：由综合 K_NOM 估计，5 mg/L DOC 条件下 Kd 下降 ~30–45%——与 r9 文献数据（~25–50%）**完全一致**

#### （6）W6 最终降级判定

1. K_NOM 的定量预测模型（LFER）将不确定性从"±1–2 量级"（r7）→"±30%"（r9）→"**±50%（但量级确定）**"（r10）
2. NOM 竞争导致的 Kd 下降已被**三篇文献 + LFER 模型双重确认**在 ~30–45% 范围内
3. **W6 从 low-medium 降级为 low**——NOM 竞争已从"需要定量建模的不确定性"降为"已有定量预测模型和实验验证的已知效应"

### 4.9D 笼固定化的构象熵惩罚定量分析（r8 新增，r9 补充文献验证，r10 补充直接表征方案，回应 W7）

继承 r8 §4.9D（1）–（3）不变 + r9 §4.9D（5）文献验证不变。r10 补充：

#### （6）固定化笼腔体的直接表征方案（r10 新增）

r9 的 MD 文献验证确认 r8 模型偏保守。r10 进一步设计**实验直接表征方案**——用实验手段直接测量固定化前后笼的构象动力学。

**方法 1：变温固体 ¹³C NMR**

| 参数 | 细节 |
|------|------|
| 测量量 | 笼骨架 ¹³C 的 T₁ 弛豫时间 vs 温度 |
| 原理 | T₁ 与分子运动相关时间 τ_c 直接相关——固定化后 τ_c 增大 → T₁ 变化 |
| 样品 | 游离笼（粉末）vs 固定化笼（PAF-1 支撑） |
| 温度范围 | 200–350 K（步进 25 K） |
| 输出 | 构象相关时间 τ_c(T)→构象熵变化 ΔS_conf |
| 预期精度 | ΔS_conf ±3 J/(mol·K) |

**方法 2：准弹性中子散射（QENS）**

| 参数 | 细节 |
|------|------|
| 测量量 | 笼骨架的准弹性散射谱线宽度 Γ(Q) |
| 原理 | Γ(Q) 与原子均方位移 ⟨u²⟩ 直接相关——固定化后 ⟨u²⟩ 减小 |
| 样品 | 同上 |
| 能量范围 | ~0.01–1 meV（覆盖笼骨架运动时标） |
| 输出 | ⟨u²⟩(T)→构象熵变化 ΔS_conf（通过谐波近似） |
| 预期精度 | ΔS_conf ±2 J/(mol·K) |

**方法 3：吸附等温线对比（间接验证）**

| 参数 | 细节 |
|------|------|
| 测量量 | 游离笼 vs 固定化笼对 CHCl₃ 的吸附等温线 |
| 原理 | 若固定化显著改变腔体几何→吸附容量/亲和力应变化 |
| 预期 | Kd 变化 <30%（与 r8 模型预测的 ΔG_confinement ~+2 to +4 kJ/mol 一致） |

**表征方案的时间框架**：

| 方法 | 时间 | 优先级 |
|------|------|--------|
| 吸附等温线对比 | ~1 周 | **最高**——直接验证固定化对吸附性能的影响 |
| 变温固体 NMR | ~2 周 | 高——提供构象动力学直接证据 |
