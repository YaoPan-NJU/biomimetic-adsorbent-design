### 0.2 r1→r2→r2.1 核心概念变更

**r2 最大概念变更（已被攻击 A1 修正）**：r2 将 r1 中"Cl σ 穴卤键识别维"重定义为"硫族键（chalcogen bonding）识别维"。r2.1 攻击修复指出该重定义存在方向性概念错误——Se/Te σ-hole 与 CHCl₃ 的 Cl 原子之间不构成硫族键（Cl 非 Lewis 碱受体）。r2.1 将维度二进一步重定义为"可极化重原子增强色散"。

**r2.1 维度二最终定义 — 可极化重原子增强色散**：
- 腔壁引入 Se 原子（极化率 2.84 Å³ >> C 1.76 Å³），增强腔壁 London 色散力
- CHCl₃ 三个 Cl 原子提供高可极化分子表面（Cl 极化率 2.18 Å³），与可极化腔壁产生增强的色散相互作用
- 此效应为非方向性、距离依赖的 London 力增强，非方向性硫族键
- 选择性来源：CHCl₃（3 Cl，高可极化表面）> CH₂Cl₂（2 Cl，较低可极化表面）> CCl₄（4 Cl 但更大，snug-fit 位阻罚）
- 文献支撑：Hunt 2010 Science（重原子取代增强蛋白-配体色散力）；Miller 2009 Chem Rev（原子极化率系统）；Pollock 2014 Chem Rev（卤代烃分子间色散力定量）

**r2.1 其他核心修正**：
- 笼骨架：CC3（腔径 ~3.8 Å）→ 大腔有机笼（腔径 ~5 Å）（A2 修正）
- 能量论证：移除"保底 ≥ 3.0 kJ/mol"声称，改为诚实标注设计假设（A3 修正）
- 合成溶剂：CHCl₃ → 甲醇（A6 修正）

### 1.3 r2.1 能量预算（取代 r2 保底论证）

**r2.1 修正声明**：r2 的"能量下限保底论证"（声称 C–H + 色散二维保底 ≥ 3.0 kJ/mol）被攻击 A3 指出存在严重错误——引用的 Abraham 1994 与 Hunter 1993 数据为气相或非极性溶剂值，不适用于水相。水相中 C–H···O 氢键与色散贡献均被水竞争大幅削弱。r2.1 移除保底声称，代以下诚实能量预算表。

**r2.1 能量预算表（设计假设，全部待 DFT-SAPT 验证）**：

| 弱作用 | 气相/非极性溶剂估计 | 水相净估计（扣除竞争后） | 不确定性 | 来源 |
|--------|-------------------|----------------------|---------|------|
| C–H···O 氢键 | ~3–5 kJ/mol | **~0–1 kJ/mol**（水竞争几乎完全抵消） | 高 | Abraham 1994（气相值）；水相中 C–H···O 与 H₂O···O 竞争，净收益极小 |
| 可极化重原子增强色散 | ~3–6 kJ/mol | **~1–3 kJ/mol**（设计假设，待验证） | 高 | 腔内受限环境增强色散，但水相中疏水效应已提供部分驱动；Se 增强增量不确定 |
| snug-fit 色散腔 | ~3–6 kJ/mol | **~1–3 kJ/mol**（设计假设） | 高 | Hunter 1993 模型为气相；水相中疏水效应主导，腔特异贡献不确定 |
| **三成员总 ΔG** | ~9–17 kJ/mol | **~2–7 kJ/mol**（设计假设） | 极高 | 各分项不确定性叠加 |
| **扣除水竞争后净收益** | | **~0–4 kJ/mol** | 极高 | 处于 RT 边缘，核心不确定性 |

**诚实声明**：
1. 水相净收益可能 < RT（~2.5 kJ/mol），方案可能 fail——这是核心风险，无法通过保底论证规避
2. DFT-SAPT 预筛门为 make-or-break：通过则继续，不通过则终止转 A19
3. 不设置"条件 go"或"保底"路径——要么三成员总 |ΔΔG| ≥ 2.5 kJ/mol，要么终止
4. apoferritin 先例（KA ~10⁵ M⁻¹）表明多弱作用协同原理可行，但那是优化后的天然腔，人工腔能否复制为未知数

## 4. 材料架构与选择性机制（r2 更新）

### 4.1 识别单元（r2 更新）

大腔有机笼（腔径 ~5 Å）为识别单元。几何设计参数：
- 腔体自由直径：~4.5–5.5 Å（匹配 CHCl₃ 动力学直径 ~4.5–5 Å，设计值）
- 腔壁功能化：Lewis 碱位点（羰基/醚氧/N-氧化物）× 2–3 个 + 硒醚位点 × 2–3 个（增强色散） + 疏水色散壁
- 配合物化学计量：1:1（CHCl₃:笼，推断）

**r2.1 关键修正 — 笼骨架替换**（攻击 A2）：r2 采用的 CC3 笼腔径仅 ~3.8 Å（Cooper 组 XRD），与 CHCl₃ ~4.5–5 Å 不匹配。r2.1 替换为腔径 ~5 Å 的大腔有机笼，具体候选：
- **候选 1**：CC8 笼（Bacasa 2007 Chem Commun，腔径 ~5.2 Å，(R,R)-环己二胺 + 对苯二甲醛 [4+6] 大腔变体）
- **候选 2**：定制亚胺笼 [4+6] 使用更长连接体（如 4,4''-对三联苯三甲醛）扩大腔径至 ~5 Å
- **候选 3**：氟硼酸酯笼（boronate ester cage）使用刚性二醛 + 硼酸前体，腔径可调
- 具体骨架选择由 Step 0 DFT 筛选确定，方案不锁定单一骨架

**r2.1 关键修正 — 维度二重定义**（攻击 A1）：
- r2：腔壁 Se/Te 提供 σ 穴与 Cl 形成硫族键 → **概念错误**（Cl 非 Lewis 碱受体）
- r2.1：腔壁 Se 原子（极化率 2.84 Å³）增强腔壁 London 色散力，与 CHCl₃ 三个 Cl 原子（高可极化表面）产生增强色散相互作用
- 此效应为非方向性、距离依赖的 London 力增强，非方向性硫族键
- 选择性来源：CHCl₃（3 Cl，高可极化表面）> CH₂Cl₂（2 Cl，较低可极化表面）> CCl₄（4 Cl 但更大，snug-fit 位阻罚）

### 4.2 材料格式（r2 更新）

**固定化离散有机笼聚合物**：

1. **离散有机笼合成**：基于大腔有机笼骨架（CC8 或定制 [4+6] 亚胺笼，腔径 ~5 Å），后修饰引入 Se 位点
2. **固定化**：有机笼通过柔性间隔臂（6-氨基己酸或 PEG₃ 链）共价固定于交联聚苯乙烯骨架，柔性臂保持笼可及性并减少几何扭曲
3. **分级孔结构**：继承 r1
4. **四件式对照**：继承 r1

### 4.3 选择性机制分解（r2 核心更新）

**正交维度一：C–H 氢键识别**（继承 r1，能量预算见 §1.3）
- 腔内 Lewis 碱（羰基/醚氧/N-氧化物）定向捕获 CHCl₃ 酸性 C–H
- 贡献估计：水相净 ~0–1 kJ/mol（设计假设，§1.3）

**正交维度二：可极化重原子增强色散（r2.1 重定义）**
- 腔壁 Se 原子（极化率 2.84 Å³）增强腔壁 London 色散力
- CHCl₃ 三个 Cl 原子提供高可极化分子表面，与可极化腔壁产生增强色散相互作用
- 此效应为非方向性、距离依赖的 London 力增强，非方向性硫族键或卤键
- 对 CH₂Cl₂（2 Cl，较低可极化表面）产生差异识别；对 CCl₄（4 Cl 但更大，snug-fit 位阻罚）亦产生差异
- 贡献估计：~1–3 kJ/mol（设计假设，待 DFT-SAPT 验证，§1.3）
- **诚实标注**：可极化重原子增强色散在水相中的定量数据有限，腔内微环境的外推不确定性高；此维度可能贡献极小甚至为零

**正交维度三：尺寸匹配色散腔**（继承 r1，能量预算见 §1.3）
- 贡献估计：水相净 ~1–3 kJ/mol（设计假设，§1.3）

**协同机制**（r2.1 更新）：三类弱作用在预组织腔内空间排列使总 ΔG > 各单项之和（预组织熵补偿）。r2.1 诚实声明：总 ΔG 可能处于 RT 边缘（~0–4 kJ/mol，§1.3），DFT-SAPT 预筛门为 make-or-break。

**疏水基线**：继承 r1。

**r2.1 新增：BDCM/DBCM 选择性分析**（攻击 A5）：

BDCM（CHBrCl₂）与 DBCM（CHBr₂Cl）是 THM4 中最重要的结构近似竞争物，r2 未充分讨论。r2.1 补充：

| 竞争物 | 分子特性 | 与腔体相互作用 | 预期选择性 |
|--------|---------|----------------|----------|
| BDCM (CHBrCl₂) | 1 C–H + 1 Br + 2 Cl；Br 极化率 3.05 Å³ >> Cl | 可极化表面更高（Br），但分子更大（Br 范德华半径 1.85 Å > Cl 1.75 Å） | snug-fit 腔对 BDCM 有位阻罚；但 Br 高可极化性增强色散——两效应竞争，α 不确定 |
| DBCM (CHBr₂Cl) | 1 C–H + 2 Br + 1 Cl | 可极化表面最高，但分子最大 | snug-fit 位阻罚最大；色散增强也最大——净效应不确定 |

**诚实声明**：BDCM/DBCM 的选择性预测是核心不确定性。Br 的高可极化性增强色散但增大分子尺寸，两效应竞争。实验上须直接测量 α(CHCl₃/BDCM) 与 α(CHCl₃/DBCM)，不得仅报告 CH₂Cl₂/CCl₄ 选择性而回避溴代 THM。

### 4.6 r2 新增：NOM 竞争应对策略

针对 W6（NOM 竞争淹没弱识别信号），r2 引入三层应对：

## 7. 台架合成 SOP 草图（r2 更新）

### Step 0 建模门（r2 分层计算协议）

**r2 更新：三层计算协议**（替代 r1 单层 DFT-SAPT）：

**Layer 1 — GFN2-xTB 快速预筛**（24 h 内完成）：
- 模型体系：CHCl₃ + 腔体简化片段（含 Lewis 碱 + Se/Te 位点 + 色散壁）
- 方法：GFN2-xTB（半经验，含色散校正）
- 计算项：总结合能 + 分项能量
- go 判据：|ΔG_total| ≥ 3 kJ/mol（宽松门，快速排除完全不可行方案）

**Layer 2 — DFT-SAPT 精算**（Layer 1 通过后，1 周内）：
- 方法：ωB97X-D/aug-cc-pVTZ SAPT(DFT) 或 B3LYP-D3/aug-cc-pVTZ CP-corrected
- 溶剂化：SMD 隐式水模型
- 计算项：总结合能 + 三项分解（C–H/增强色散/色散腔）+ 竞争物同法
- go 判据：|ΔΔG_total(CHCl₃ vs H₂O)| ≥ 2.5 kJ/mol

**Layer 3 — MD-FEP 自由能精算**（Layer 2 通过后，2 周内）：
- 方法：显式水分子 MD（TIP4P/2005）+ 自由能微扰（FEP/TI）
- 模型：完整笼 + CHCl₃ + ~500 水分子
- 计算项：绝对结合自由能 ΔG_bind + 竞争物同法
- go 判据：ΔG_bind(CHCl₃) ≤ −3 kJ/mol 且 ΔG_bind(CHCl₃) < ΔG_bind(CH₂Cl₂) 与 ΔG_bind(CCl₄)

**终止规则**：
- Layer 1 fail → 终止转 A19
- Layer 2 fail → 终止（r2.1 移除条件 go 路径）
- Layer 3 fail → 重新评估溶剂化模型偏差；若 Layer 2 通过但 Layer 3 fail，以 Layer 2 结果为准并标注不确定性

### Step 1 离散有机笼合成（r2 具体路线）
