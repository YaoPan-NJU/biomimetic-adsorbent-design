### 1.3A 协同效应判据定量化（r4 新增，回应 W1/W10）

r3 能量预算中净收益 ~0–4 kJ/mol 处于可测边缘，核心问题在于：多弱作用协同是否产生超过各作用独立贡献之和的「超额能量」？r4 引入 **协同超额能量 ΔG_excess** 定量定义：

**ΔG_excess 定义**：

ΔG_excess = ΔG_total(cavity) − ΣΔG_i(independent)

其中：
- ΔG_total(cavity)：完整预组织腔对 CHCl₃ 的总结合自由能（含所有弱作用 + 协同项）
- ΣΔG_i(independent)：各独立弱作用贡献之和（C–H 氢键 + 增强色散 + 色散腔 + 疏水基线），由删除变体计算

**计算方法**（DFT-SAPT Layer 2 扩展）：

| 体系 | 计算内容 | 输出 |
|------|---------|------|
| 完整腔 + CHCl₃ | 总结合能 | ΔG_total |
| 腔（去除 C–H 氢键位点）+ CHCl₃ | 无氢键结合能 | ΔG_no_HB |
| 腔（去除色散增强位点）+ CHCl₃ | 无增强色散结合能 | ΔG_no_disp |
| 腔（去除尺寸匹配壁）+ CHCl₃ | 无色散腔结合能 | ΔG_no_cavity |
| 独立贡献之和 | ΣΔG_i = ΔG_no_HB + ΔG_no_disp + ΔG_no_cavity − 2×ΔG_baseline | ΣΔG_i |

**go 判据细化**（r4 更新 Layer 2）：

- r3 go 判据：|ΔΔG_total(CHCl₃ vs H₂O)| ≥ 2.5 kJ/mol
- r4 go 判据：|ΔΔG_total(CHCl₃ vs H₂O)| ≥ 2.5 kJ/mol **且** ΔG_excess ≥ 1.0 kJ/mol
- **溶剂化模型容差**：若 Layer 3（MD-FEP）与 Layer 2 偏差 < 3 kJ/mol，则溶剂化模型偏差在容差内，Layer 2 ΔG_excess 可信

**ΔG_excess 的物理意义**：

- ΔG_excess ≥ 1.0 kJ/mol → 协同效应超过 RT/2（298K），为物理化学上有意义的协同
- ΔG_excess < 1.0 kJ/mol → 协同效应低于溶剂竞争噪声，多弱作用策略退化为独立作用加和
- ΔG_excess < 0 → 负协同（框架内拮抗），须重新设计

**诚实声明**：ΔG_excess 的精确值依赖 SAPT 能量分解精度与溶剂化模型。DFT-SAPT 对弱作用协同的定量精度估计 ±2 kJ/mol，因此 ΔG_excess ≥ 1.0 kJ/mol 的判据在误差范围内为边界显著。

3. **优势**：
   - 合成简单（聚合物骨架商业可得或合成成熟）

### 4.3C 动力学选择性正交维度（r4 新增，回应 W6/W7）

r3 选择性机制为纯热力学（结合能差异），r4 引入 **动力学选择性** 作为正交补充维度：

**动力学选择性原理**：

多弱作用协同腔对 CHCl₃ 的结合可能存在 **动力学加速效应**——腔体预组织降低了结合过渡态的熵罚，使 CHCl₃ 进入腔体的速率快于竞争物。

**量化方案**：

1. **MD 模拟提取结合速率**：
   - 从 Layer 2 MD 轨迹中提取 CHCl₃/CH₂Cl₂/CCl₄ 进入腔体的平均首次通过时间（mean first passage time, MFPT）
   - MFPT 比值 = 动力学选择性因子 α_kin
2. **预期差异来源**：
   - CHCl₃（~4.5 Å）尺寸最小 → 进入腔体位阻最小 → MFPT 最短
   - BDCM（~5.0 Å）尺寸增大 → MFPT 增大
   - CCl₄（~5.0 Å，对称）→ 无方向性弱作用引导 → MFPT 可能更长
3. **与热力学选择性的正交性**：
   - 热力学选择性依赖平衡结合能差异
   - 动力学选择性依赖过渡态位阻差异
   - 二者独立：即使热力学选择性低（ΔΔG < 2 kJ/mol），动力学选择性仍可提供 α_kin > 1.5
4. **实验验证**：
   - 流通床穿透曲线拟合：动力学模型 vs 热力学模型拟合优度对比
   - 若动力学模型显著优于热力学模型 → 动力学选择性贡献确认

**诚实声明**：动力学选择性为推测性维度，对 CHCl₃ 小分子在 ~5 Å 腔中的动力学效应量级不确定。MD 提取的 MFPT 精度受限于力场与模拟时长。此维度作为补充而非主干。

### 4.6A NOM 尺寸-化学双排斥模型定量预测（r4 新增，回应 W6）

**尺寸排斥定量**：

1. NOM 腐殖酸流体力学直径 d_h ~2–10 nm（中值 ~4 nm）
2. 笼腔入口 ~5 Å（有机笼）或 ~5–15 Å（聚合物支撑腔）
3. 排阻阈值：d_h > d_pore → 排阻效率 >95%（NOM 大分子聚集体）
4. 但 NOM 小分子片段（富里酸，d_h ~1–2 nm）可能进入 → 须化学排斥层补充

**化学排斥定量**：

1. 腔壁疏水性（logKow ~2–3 的 CHCl₃ 在疏水腔中有分配优势）
2. NOM 小分子片段以芳香/极性为主 → 与疏水腔的相互作用模式不同于 CHCl₃
3. 化学选择性 α(CHCl₃/NOM片段) ~2–5（设计假设，基于疏水分配系数差异估算）
