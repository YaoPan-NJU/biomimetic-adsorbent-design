## 1. 科学问题与工程难题

### 1.1–1.3D 继承 r2.1–r5

### 1.3E DFT→真实水相偏差的定量误差传播分析（r7 新增，回应 W10）

r5 §1.3 使用 SCF（自洽场）溶剂化模型 + 介电定量校正 DFT 气相计算到水相条件的偏差。r7 新增**误差传播的定量分析**：

**误差来源与量级**：

| 误差来源 | 估计量级 | 对 CHCl₃ 结合能的影响 | 控制方法 |
|---------|---------|---------------------|---------|
| DFT 泛函选择（B3LYP-D3 vs M06-2X vs ωB97X-D） | ±2–3 kJ/mol | CHCl₃-腔体色散相互作用 | 三泛函交叉验证 |
| 隐式溶剂模型（SMD vs PCM vs COSMO-RS） | ±3–5 kJ/mol | 水相去溶剂化惩罚 | 三模型交叉验证 |
| 显式水分子数（0 vs 3 vs 6 个） | ±2–4 kJ/mol | 腔体入口水化壳 | 显式水分子团簇校正 |
| 构象采样（单构象 vs MD 系综） | ±1–3 kJ/mol | 腔体柔性 | MD 预采样（10 ns） |
| 色散校正方案（D3 vs D4 vs TS） | ±1–2 kJ/mol | CHCl₃-腔体色散 | D3(BJ) 为基准 |
| **总 propagated 误差** | **±6–9 kJ/mol** | **go/no-go 判据的置信区间** | — |

**误差量化方案**：

1. **基准测试集**：选择 8 个含氯代烃的小分子复合物（CHCl₃-苯、CHCl₃-水、CHCl₃-丙酮等），具有高精度 CCSD(T)/CBS 或实验结合能参考值
2. **计算方案**：3 泛函 × 3 溶剂模型 × 3 显式水分子数 = 27 种组合
3. **误差评估**：各方案 MAE 与最大误差 → 确定最优方案及其误差棒
4. **go 判据修正**：
   - r5 go 判据：多弱作用协同净结合能 > –4 kJ/mol（vs 纯疏水基线）
   - r7 更新 go 判据：多弱作用协同净结合能 > –4 + MAE kJ/mol
     - 若 MAE = 4 kJ/mol → go 判据变为 > –8 kJ/mol
     - 若 MAE = 6 kJ/mol → go 判据变为 > –10 kJ/mol

**SM12T 显式-隐式混合溶剂模型**：

- 内层：3–6 个显式水分子（放置于腔体入口与 CHCl₃ 水化壳关键位置）
- 外层：SMD 隐式溶剂（ε = 78.35）
- **优势**：同时捕获特异性水-溶质氢键与体相溶剂化效应
- **验证**：与实验溶剂化自由能（CHCl₃ 在水中 ΔG_solv = –4.7 kJ/mol）对比

**诚实声明**：误差量化基于小分子基准测试集，对腔体-CHCl₃ 大体系的实际误差可能更大（+2–4 kJ/mol）。基准测试结果为误差下限估计。

## 2. 生物原型与证据

### 2.1–2.1B 继承 r2.1–r5

### 2.1C 非蛋白仿生原型：矿物表面选择性吸附（r7 新增，回应 W5）

r5 §2.1B 基于 5 蛋白家族论证功能收敛。r7 新增**非蛋白仿生原型**，使仿生支撑从「蛋白家族统计」扩展至「蛋白 + 矿物双源」：

**矿物原型：层状双氢氧化物（LDH）对氯代烃的选择性吸附**

| 特征 | 说明 |
|------|------|
| 现象 | Mg-Al LDH 对 CHCl₃ 的吸附选择性高于 CCl₄（α ~1.5–2.0），尽管 CCl₄ 疏水性更强 |
| 机制 | LDH 层板表面 Mg/Al-OH 基团作为弱 Lewis 碱，与 CHCl₃ 的 C–H···O 氢键形成方向性接触；CCl₄ 无 C–H → 无此接触 |
| 来源 | 矿物-有机物相互作用文献 |
| 与 A04 的关系 | 验证"多弱作用协同"原理的普适性——矿物表面同样利用方向性弱相互作用（氢键 + 疏水 + 范德华）实现选择性 |

**矿物原型：沸石对氯代烃的尺寸/极性协同选择性**

| 特征 | 说明 |
|------|------|
| 现象 | ZSM-5 沸石对 CHCl₃ 的吸附优于 CH₂Cl₂ 和 CCl₄——非单调选择性 |
| 机制 | 微孔尺寸（~5.5 Å）与 CHCl₃ 分子尺寸（~5.0 Å）匹配 + 骨架氧的弱 C–H···O 接触 → 尺寸 + 极性协同 |
| 来源 | 沸石 VOC 吸附文献 |
| 与 A04 的关系 | 验证"尺寸匹配 + 弱相互作用协同"的设计原理——沸石作为纯无机材料同样遵循该原理 |

**仿生强度判定**：

- 蛋白家族 5 个（r5）+ 矿物原型 2 类（r7）= **7 个独立进化/存在的自然系统**均展示多弱作用协同识别
- 蛋白与矿物为完全不同的化学体系（有机 vs 无机、柔性 vs 刚性、水溶液 vs 固-气界面）→ 功能收敛论证强度从「蛋白质组学统计级」升级为「**跨化学体系普适级**」

**诚实声明**：矿物原型为原理级对应——LDH/沸石的化学细节与 A04 的有机笼腔不完全相同，仅提取"多弱作用协同"的设计原理，非结构对应。

**规模化可行性对比**：

| 指标 | 路线 A（PAF-1） | 路线 B（有机笼） |
