## 4. 材料架构与选择性机制（r4 强化）

### 4.1–4.7a 继承 r3

### 4.9a [r4 新增] 水相 σ 空穴定量能量预算与 Phase-0 实验门（回应 W1）

**问题回顾**：W1（水相 σ 空穴衰减）从 r1 到 r3 连续三轮列为 medium，为本方案最高残余风险。EXEC_SPEC §5.4 要求"A04 卤键 σ 空穴：须前置 DFT/MD 水相 σ 空穴能量预算（C-Cl σ 空穴在水相的深度与方向性）"。r1–r3 均以定性描述回应（"水相显著衰减但双点协同可补偿"），缺乏定量 ΔG 收支。

**策略 1：C-Cl σ 空穴水相能量收支明细**

| 贡献项 | 估算值（kJ/mol） | 来源 | 不确定性 |
|--------|-----------------|------|---------|
| **单个 C-Cl···B 卤键（水相）** | | | |
| 气相 C-Cl···squaramide 卤键 | −8 至 −15 | DFT 文献（Politzer & Murray 2013；Cavallo 2016 综述） | 中 |
| 水相衰减因子 | ×0.3–0.5 | 水相卤键衰减比例（Abella 2017 J Chem Theory Comput） | 高 |
| **水相单键净收益** | **−2.4 至 −7.5** | 气相值 × 衰减因子 | 高 |
| **双键协同（2,6-DCP 双 C-Cl）** | | | |
| 双键加和（2 × 单键） | −4.8 至 −15 | 线性加和 | — |
| 协同增益（双键同时形成 vs 单键序列） | +1 至 +3 | 预组织双受体间距匹配 3.3–3.7 Å 时的熵减优势 | 高 |
| **双键总水相结合能** | **−3.8 至 −18** | 加和 + 协同 | — |
| **去溶剂化罚能** | | | |
| 2,6-DCP 酚氧去溶剂化 | +5 至 +8 | 酚 OH 水合自由能 | 中 |
| 2,6-DCP 双 C-Cl 去溶剂化 | +2 至 +4 | Cl 水合自由能（弱） | 中 |
| 受体去溶剂化（squaramide NH 水合） | +3 至 +6 | squaramide 双 NH 水合自由能 | 中 |
| **去溶剂化总罚能** | **+10 至 +18** | — | — |
| **净结合自由能** | **+6.2 至 0**（乐观）至 **−8.2 至 0**（悲观） | 双键结合 − 去溶剂化罚 | 极高 |

**关键诚实标注**：
- **净结合能可能接近零甚至为正**——水相 σ 空穴卤键对 2,6-DCP 的净收益处于可测边界（0 至 −8 kJ/mol）
- 这与 EXEC_SPEC §5.4 的警告一致："无法给出水相能量裕度者首轮判负"
- **双点协同是唯一希望**：若预组织双受体间距精确匹配 3.5 Å（±0.2 Å），协同增益 +1 至 +3 kJ/mol 可使净收益从"接近零"推至"可测负值"
- **非单调签名是判决关键**：即使绝对亲和力弱，只要 2,6-DCP（C2v 对称双 σ 空穴）> 2,4-DCP（Cs 不对称）> 4-CP（无对称 σ 空穴）的非单调序列成立，方案的选择性主张仍可支撑

**策略 2：Phase-0 水相卤键滴定实验（go/no-go）**

| 实验 | 体系 | 方法 | go 线 | no-go 后果 |
|------|------|------|-------|-----------|
| **P0a** | 模型 squaramide + 1,2-二氯苯（1,2-DCB，2,6-DCP 的简化代用）在 CDCl₃ | ¹H NMR 滴定 | K ≥ 10 M⁻¹（非水相上界参考） | squaramide 对 C-Cl 无结合 → 终止 |
| **P0b** | 同上体系在 D₂O/MeOD (9:1) | ¹H NMR 滴定 / ITC | K ≥ 2 M⁻¹（水相下界） | 水相结合完全消失 → 终止 |
| **P0c** | squaramide 功能化 COF 薄膜 + 1,2-DCB 水溶液 | QCM-D（石英晶体微天平） | Δf ≥ 5 Hz（可测吸附信号） | 固相体系也无信号 → 终止 |
| **P0d** | 1,2-DCB vs 1,3-DCB vs 1,4-DCB 在功能化 COF 上 | QCM-D 竞争吸附 | α(1,2/1,4) ≥ 1.3（非单调趋势） | 无区域选择性差异 → 图案识别退化为非选择性 → 终止 |

**策略 3：若 P0b no-go 的收缩路线**

若水相卤键滴定确认结合完全消失（K < 2 M⁻¹）：
- **路线 A：低介电微环境**——在 COF 孔口引入疏水遮蔽层（如全氟烷基），降低识别位点局部介电常数 → 增强水相卤键（参考 PFOA A02 孔口疏水遮蔽策略）
- **路线 B：离子对增强**——在 squaramide 旁引入季铵阳离子，通过离子对效应增强 C-Cl···B 卤键（阳离子极化 Cl → 增强 σ 空穴深度）
- **路线 C：诚实终止**——若水相 σ 空穴确实不可用，A04 结构性不可行 → 终止并交付"水相卤键可行性边界报告"（方法学交付，符合 EXEC_SPEC §5.5 负结果解耦交付要求）

### 4.9b [r4 新增] 水相 σ 空穴方向性定量评估（补充 W4 闭合）

**问题回顾**：r3 §4.7a 已给出构象锁定三策略，但方向性的定量评估仍缺。W4 虽降为 low-medium，补充定量评估可进一步巩固。

**方向性定量指标**：

| 指标 | 定义 | 理想值 | 可接受范围 |
|------|------|--------|-----------|
| C–Cl···B 角 | 卤键方向性角 | 180° | >150°（有效卤键） |
| Δθ 容差 | 受体取向偏差 | <5° | <15°（方向性贡献不退化） |
| 双键同时满足概率 | MD 统计两个 C-Cl···B 角同时 >150° 的构象占比 | >60% | >40%（最低可接受） |

**MD 验证协议**：
- 体系：2,6-DCP + 双受体 COF 狭缝模型，显式水（TIP3P），300 K
- 模拟时长：200 ns × 3 独立重复
- 输出：C–Cl···B 角分布直方图 + 双键同时满足概率

## 6. 台架合成 SOP（r4 强化）

### 6.1–6.5 继承 r3

### 6.7a [r4 新增] 单体合成可行性分级验证路线（回应 W2）

**问题回顾**：W2（新单体合成风险）从 r1 到 r3 连续三轮列为 medium。核心风险：squaramide 功能化单体（含卤键受体的 COF 构建单元）的合成路线虽在 r3 §7.3c 给出简化方案（路线 B 一锅法），但从未在 COF 骨架语境下实验验证。

**策略：分级合成验证（从简到繁）**

| 阶段 | 合成目标 | 难度 | 验证 | 时间预算 | go 线 |
|------|---------|------|------|---------|-------|
| **Syn-1** | 游离 squaramide 小分子（二乙基 squarate + 苯胺 → 苯基 squaramide） | 低 | ¹³C NMR（δ ~165–170 ppm）+ HRMS | 1 周 | 收率 >70% |
| **Syn-2** | 骨架接枝 squaramide（后合成修饰：已合成 COF + squarate 开环接枝） | 中 | 固态 ¹³C NMR + FTIR + BET | 2 周 | 接枝率 >10 mol% |
| **Syn-3** | 含 squaramide 单体共缩合 COF（预功能化单体 + 醛基单体 →  crystalline COF） | 中-高 | PXRD（结晶度）+ BET + ¹³C NMR | 3 周 | COF 结晶度保持（PXRD 主峰可辨） |
| **Syn-4** | 双受体排布精确控制（间位/对位取代调控受体间距 3.3–3.7 Å） | 高 | SCXRD（单晶结构）或 PXRD + DFT 优化 | 4 周 | 受体间距偏差 <0.5 Å |

**关键决策点**：
- Syn-1 go → 进入 Syn-2（squaramide 化学可行）
- Syn-2 go → 进入 Syn-3（后合成修饰路线可行，作为主路线）
- Syn-3 go → 进入 Syn-4（结晶度可保持，精确排布可行）
- Syn-3 no-go → 退回 Syn-2 后合成修饰路线（放弃预功能化单体路线）
- Syn-2 no-go → 终止（squaramide 无法引入 COF 骨架）

**与 r3 §7.3c 路线 B 的关系**：Syn-1 验证路线 B 的核心化学（squatear 单酯开环-胺化）；Syn-2 验证该化学在 COF 骨架上的适用性。
