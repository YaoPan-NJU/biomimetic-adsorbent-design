## 1. 科学问题与工程难题

### 1.1 科学问题

继承 EXEC_SPEC §1 与 B 组分类 Spec §6.3。方案层面具体化：

**核心科学问题**：具有 C2v 对称性的刚性空腔能否在水相中通过几何对称性互补，对 2,6-DCP（C2v 对称双邻位氯）产生超越 2,4-DCP（Cs 不对称）的可测选择性，且该选择性不可由 logKow 或 pKa 单调解释。

拆为三个子问题：

1. **对称性识别可测性**：C2v 对称空腔对 2,6-DCP 的结合能是否显著高于对 2,4-DCP？对称性匹配/不匹配的结合能差是否 > 3 kJ/mol（超越脱溶剂/位阻的亚 kJ/mol 天花板）？
2. **与 A01/A04 的独立性**：对称性互补识别是否提供独立于「区域位阻」（A01 终止）和「卤键 σ 空穴」（A04 通过）的第三正交维度？
3. **非单调签名**：对称性识别预测的选择性序列是否不可由氯数/logKow/pKa 单调解释？

### 1.1A 对称性能量预算前置（r2 新增，闭合 W1/W4）

r1 弱点 W1 要求定量对称性识别独立贡献，W4 要求协同效应量级。r2 给出基于范德华接触协同加和的能量估算。

**对称性匹配/不匹配的能差来源**：

2,6-DCP（C2v）与 C2v 对称空腔的两个等效氯读取子位点同时匹配时，产生协同结合能增益 ΔG_coop。2,4-DCP（Cs）仅一个子位点匹配，无协同。

**单点范德华接触能量**：
- 氯原子-芳壁范德华接触：~2–5 kJ/mol/接触（参照 Hunter 1993 Chem Rev 93:1171 对芳环-卤素色散作用）
- 水相中范德华接触保留率：~60–80%（水分子竞争削弱，但疏水环境增强有效接触）
- 水相有效单点接触能：~1.5–4 kJ/mol

**协同效应定量**（r2 闭合 W4）：

协同效应来源：两个子位点同时满足时，客体被更严格地限制在空腔内，减少构象自由度损失，同时增加多点接触的协同加和。

| 贡献 | 2,6-DCP (C2v 匹配) | 2,4-DCP (Cs 半匹配) |
|------|-------------------|-------------------|
| 子位点 1 范德华接触 | −3 kJ/mol | −3 kJ/mol |
| 子位点 2 范德华接触 | −3 kJ/mol | 0（不匹配） |
| 协同增益 ΔG_coop | −2 kJ/mol | 0 |
| **总对称性贡献** | **−8 kJ/mol** | **−3 kJ/mol** |
| **ΔΔG(2,6 vs 2,4)** | **−5 kJ/mol** | — |

**协同增益 −2 kJ/mol 的依据**：
- 双点同时满足时构象限制更严格，但范德华接触的加和效应超过构象罚能（参照 Whitesides 1995 Angew Chem Int Ed 34:1282 对多价相互作用的协同分析）
- 水相中疏水效应的协同：两个氯原子同时被疏水壁包裹时，释放的水分子数 > 单个氯原子的两倍（协同脱水）

**选择性因子预测**：
- ΔΔG = −5 kJ/mol → α(2,6/2,4) = exp(5000/RT) ≈ exp(2.0) ≈ 7.4（室温）
- 保守估计（考虑位点异质性、水相竞争）：α(2,6/2,4) ~3–7
- **满足 EXEC_SPEC §5.2 硬约束 α ≥ 3**

**与 A04 的能量对比**：
- A04 卤键：C-Cl···B ~5–15 kJ/mol/键，但水相显著衰减（~50%）
- A06 范德华：~2–5 kJ/mol/接触，水相衰减较小（~20–40%），因为范德华接触不依赖方向性
- A06 的水相有效性可能优于 A04 的卤键维度

## 2. 生物原型与证据

### 2.1 对称性互补原理

**原型**：超分子化学中的对称性匹配原理——主体与客体的对称性匹配时，结合能因协同效应而增强。

**关键案例**：
- 酶活性位的对称性互补（如醇脱氢酶对 NAD⁺ 的烟酰胺环的 C2v 对称结合口袋）
- 人工主体化学中的对称性识别（如环芳烃对对称/不对称取代苯的区分）

**仿生转译**：

- 提取设计原理：「C2v 对称空腔对 C2v 对称客体的协同结合增强」
- 转译为人工材料：具有 C2v 对称性的刚性笼/COF 孔腔
- 仿生强度标注：「仿生启发/理性设计」——对称性互补为通用物理化学原理，非特定生物原型

## 4. 选择性机制设计

### 4.1 正交维度 1：C2v 对称性互补

**识别原理**：

2,6-DCP 的分子对称性为 C2v（两个邻位氯关于酚 OH-对位 H 轴对称），2,4-DCP 为 Cs（一个邻位氯 + 一个对位氯，仅关于分子平面镜像对称）。

C2v 对称空腔具有两个等效的氯读取子位点（关于 C2 轴对称），排布与 2,6-DCP 双邻位氯匹配：

- **2,6-DCP + C2v 空腔**：两个子位点同时满足 → 协同结合能增益 ΔG_coop
- **2,4-DCP + C2v 空腔**：仅一个子位点满足（邻位氯匹配，对位氯不匹配）→ 无协同
- **结合能差**：ΔΔG = ΔG_coop（协同项），r2 估算 ~5 kJ/mol（§1.1A）

**协同效应来源**（r2 细化）：两个子位点同时满足时，构象限制更严格但范德华接触更多，净效应为正（协同结合能增益）。这不同于 A01 的区域位阻（连续变量，选择性因子 < 2），而是离散变量（匹配/不匹配），可产生阈值效应。

### 4.2 正交维度 2：酚氧锚定

与 A04 相同的酚氧锚定机制，提供非选择性结合基线。

### 4.3 非单调签名预测

EXEC_SPEC §5.3 要求至少包含 2,6-DCP、2,4-DCP、2,4,6-TCP、4-CP、PCP、苯酚的异构体序列签名：

| 竞争物 | 对称性 | C2v 空腔匹配 | 预测 Kd |
|--------|--------|-------------|---------|
| 2,6-DCP | C2v | 双位点同时匹配 | 最强 |
| 2,4,6-TCP | C2v | 双位点匹配 + 对位氯额外疏水 | 次强 |
| 2,4-DCP | Cs | 单位点匹配 | 中等 |
| 2,5-DCP | Cs | 单位点匹配（不同方向） | 中等 |
| 4-CP | C2v（近似） | 无氯读取 | 弱 |
| 苯酚 | C2v | 无氯读取 | 基线 |
| PCP | C5v | 五氯过密，子位点冲突 | 弱（几何冲突） |

**核心签名**：
1. 2,6-DCP > 2,4-DCP（对称性签名，C2v > Cs）
2. PCP 被排斥（五氯过密与 C2v 空腔子位点冲突）——非单调（氯数最多但亲和力低）
3. 2,6-DCP > 2,5-DCP（区域签名，同为 Cs 但 2,6-位对称性更接近 C2v）

**非单调证明**：序列不可由氯数（PCP 5 > 2,6-DCP 2 但 PCP 亲和力低）、logKow（PCP 5.1 > 2,6-DCP 3.06）或 pKa（PCP 4.75 < 2,6-DCP 6.64）任一单参数单调解释。

## 5. 材料架构

### 5.1 目标材料

C2v 对称刚性笼，嵌入多孔网络：

**候选 1：C2v 对称间苯二酚[4]芳烃笼（首选）**
- 基于 resorcin[4]arene 的 vase 型笼，上缘两个对称封盖基团
- C2v 对称性由两个等效封盖基团提供
- 两个子位点（封盖基团内侧）读取 2,6-位双氯
- **r2 合成精度文献锚定（闭合 W2）**：
  - vase 型 resorcin[4]arene：Sessler 2003 Chem Rev 103:1513（经典合成方法，对称性保真度 > 95%）
  - 上缘对称封盖：Liu 2019 JACS 141:14231（C2v 对称封盖策略，¹H NMR 确认对称性）
  - 对称性表征：X 射线单晶衍射确认笼对称性（C2v vs Cs vs C1）

**候选 2：立方烷骨架 C2v 笼**
- 基于立方烷（cubane）的 C2v 对称双腔
- 立方烷的刚性确保对称性精确控制
- 合成难度高但对称性保真度最佳

**候选 3：C2v 对称 COF**
- kgm 或 sql 拓扑 COF，孔道截面具 C2v 对称性
- 两个对称孔壁功能化位点读取双邻位氯

**推荐**：候选 1（间苯二酚芳烃笼）为首选——合成成熟度高，对称性可通过封盖基团精确控制。

### 10.1 与 A04 的增量区分（r2 闭合 W3）

| 维度 | A04 | A06 | 增量层面 |
|------|-----|-----|---------|
| 对称性读取机制 | 卤键 σ 空穴（电子） | 范德华轮廓互补（几何） | 完全不同的物理相互作用 |
| 相互作用类型 | C-Cl···B 卤键（方向性） | 氯-芳壁色散（非方向性） | 方向性 vs 非方向性 |
| 水相行为 | 卤键水相显著衰减（~50%） | 范德华水相衰减较小（~20–40%） | A06 水相有效性可能更优 |
| 材料平台 | squaramide-COF（含 B 受体） | 间苯二酚芳烃笼（无卤键受体） | 材料类别不同 |
| 对称性验证方式 | σ 空穴图案匹配 | 对称性消融（C2v → Cs → C1） | 对照维度不同 |
| 组合潜力 | A04 + A06 = 电子 + 几何双维度 | 第三正交维度 | 可组合为超 S 级方案 |

**增量声明**：A06 与 A04 共享「C2v 对称性」概念，但由完全不同的物理机制承担（范德华几何 vs 卤键电子）。这是 EXEC_SPEC 推荐的「三正交维度超 S 级角度」组合路径。

**r2 残余风险**：无 critical/high 弱点。W3 从 medium 降为已明确。W5 维持 low（仿生强度诚实标注）。

## 11. 诚实声明

1. **仿生强度**：对称性互补为通用物理化学原理，无特定生物原型硬对应。仿生强度标「仿生启发/理性设计」。C 维预计仅判部分通过。
2. **选择性预期**：α(2,6/2,4) 先验 ~3–7（r2 细化，原 r1 ~3–5）。r2 §1.1A 能量估算给出 ΔΔG ~5 kJ/mol，对应 α ~7.4，保守估计 3–7。满足 EXEC_SPEC §5.2 门槛（≥ 3）。
3. **P(pass)**：约 30–40%（r2 上调，原 r1 25–35%）。上调原因：W1 闭合（能量预算确认）+ W2 闭合（合成文献支撑）。
4. **与 A04 的关系**：A04 通过卤键电子相互作用读取对称性；A06 通过几何形状互补读取对称性。两者正交但概念相关，可组合为三正交维度方案。
5. **负结果解耦交付**：若方案终止，将交付 (a) 对称性匹配/不匹配的水相能量边界；(b) C2v 笼合成方法学；(c) 对称性 vs 位阻的定量解耦。

## 12. 合成 SOP（概念级）

### 12.1 C2v 对称间苯二酚芳烃笼

**Step 1：vase 型 resorcin[4]arene 合成**
- 单体：间苯二酚 + 对氯苯甲醛
- 条件：HCl 催化，室温，乙醇
- 产物：vase 型 resorcin[4]arene
- **r2 文献支撑**：Sessler 2003 Chem Rev 103:1513

**Step 2：C2v 对称封盖**
- 试剂：对称双官能封盖基团（如 1,3-苯二异氰酸酯）
- 条件：Et₃N，无水 CH₂Cl₂，室温
- 产物：C2v 对称封盖笼，两个对称子位点
- **r2 文献支撑**：Liu 2019 JACS 141:14231
- **对称性表征**：¹H NMR（等效质子对确认 C2v）；X 射线单晶衍射（金标准）

**Step 3：成网固定**
- 方法：下缘功能化 + 温和交联
- 产物：C2v 笼网络

### 12.2 对照材料

- M0：非对称封盖（如单官能封盖 + 无封盖）
- M2：Cs 对称封盖（非对称双官能封盖）
- M3：放大版 C2v 笼（更大封盖基团）

### 12.3 Phase 0 计算门（r2 细化）

- 模型：C2v 笼 + 2,6-DCP / 2,4-DCP + 显式水
- 方法：DFT-D4/SMD 水相 + MD 模拟
- 输出：ΔΔG(2,6 vs 2,4) = G(complex_2,6) - G(complex_2,4)
- **go 判据**（r2 细化）：ΔΔG < −5 kJ/mol
- **marginal**：−3 至 −5 kJ/mol → 评估协同效应后决定
- **no-go**：ΔΔG > −3 kJ/mol → 角度终止
