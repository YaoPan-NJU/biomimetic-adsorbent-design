# 第一部分 设计者方案（第 1 轮）

# 滴滴伊 A02 =CCl₂ 乙烯基二氯卤键阵列读出——脱卤酶卤素识别原理的疏水腔转译

- 槽位：rounds/fresh_1000/dde，角度 A02
- 原型家族：P1 还原脱卤酶（PceA 族）"保守底物捕获区卤素识别"二分架构的原理级转译（族 B；Bommer 2014 Science，PDB 4UQU，摘要直读）+ P2 BphA 平面氯代二芳基疏水裂口架构原理（族 A；Mondello 1997、Master 2001，题录级；Kumar 2011 JMB 2XRX/2XSH，结构级）
- 识别机制轴：=CCl₂ 两个乙烯基氯的 σ-卤键供体图案与疏水腔内几何定位卤键受体的互补匹配，叠加疏水腔协同捕获；对 -CCl₃（DDT，三氯四面体）与 -CHCl₂（DDD，三氯四面体）给出几何失配，对 DDMU（一个乙烯基氯）给出卤键数目差异
- 材料架构轴：刚性疏水腔（COF 或交联有机笼）内壁几何定位吡啶 N-氧化物（PyNO）卤键受体阵列，腔体尺寸匹配 DDE 分子并限制水分子进入
- 先例风险：low（G5 水相吸附零先例；卤键 COF 先例限于非水分析萃取）
- 本轮证据口径：继承简报与 DESIGN_SPACE 已引文献（A01 r1/r2 证据表、DDT EXEC_SPEC 证据链），新增卤键化学与脱卤酶结构证据条目经 Crossref 题录自核标注

### 0.2 A02 角度选择理由

A02 在 DESIGN_SPACE 中定义为"=CCl₂ 乙烯基二氯卤素相互作用图案读出定域阵列腔"。选择理由：

1. **DDE 特异性最强**：=CCl₂ 双乙烯基氯是 DDE 区别于 DDT（-CCl₃ 三氯四面体）、DDD（-CHCl₂ 三氯四面体）和 DDMU（一个乙烯基氯）的最尖锐化学特征
2. **正交维度天然成立**：卤键阵列几何匹配（维 1）+ 疏水腔协同捕获（维 2），满足 GC3 双维度硬约束
3. **先例空白**：G5 水相吸附设计零先例，PADS 估计约 85（起始 100，方向先例 –5×3，平台先例 –3×4）
4. **可区分 DDMU/DDNU**：A01 无法区分 DDE 与其还原产物，A02 通过乙烯基氯数差异（DDE 2 个 vs DDMU 1 个）天然区分
5. **仿生转译链可构建**：脱卤酶活性位卤素识别原理（PceA 保守底物捕获区）→ 疏水腔内定位卤键受体阵列，仿生承重可归于机制原理而非纯工程添加

### 0.3 A02 核心风险预声明

1. **水相卤键削弱**（最高风险）：卤键在水中被竞争水化显著削弱，单点卤键净自由能常仅 1–4 kJ/mol。对策：疏水腔去溶剂化保护（腔内无水环境增强卤键强度至 5–15 kJ/mol/点）
2. **仿生转译强度**：脱卤酶卤素识别为催化上下文中的底物结合，本方案提取"识别"维而舍弃"催化"维，转译为弱架构原理级（类比 Dieldrin S27 中 GABA 腔原理级转译）
3. **吡啶 N-氧化物水相稳定性**：PyNO 在酸性条件下可能质子化丧失卤键受体能力，须控制 pH 工作窗口

## 1. 科学问题与工程难题

### 1.1 科学问题（SP1 收窄）

DDE 的 =CCl₂ 平面桥碳含两个乙烯基氯，无桥氢、无氢键供受体、分子中性。在静电/氢键/酸碱三类把手全缺条件下，能否以卤键供体-受体阵列在水相中对 =CCl₂ 产生几何匹配的选择性捕获，并相对 -CCl₃（DDT）和 -CHCl₂（DDD）给出可测分离因子。

核心未决物理有机化学问题：疏水腔内几何定位的卤键受体阵列与 =CCl₂ 双乙烯基氯的卤键结合，在扣除氯原子与受体双侧去溶剂化代价及腔内残余水竞争后，净自由能是否高于约 1.0 kJ/mol 的可测下限。

### 1.2 工程难题（EC1/EC2 收窄）

本方案覆盖 EC1 的选择性一维（卤键阵列几何匹配）与 EC2 的温和再生一维（低温极性溶剂洗脱）。ng/L 传质维与第三相竞争维部分覆盖。诚实声明：不声称解决四约束全集。

### 1.3 热力学图像（一阶估计）

**疏水本底**：DDE logKow=6.51，DDT=6.91，DDD=6.02（ATSDR 原文核验）。疏水本底偏好 DDT 最强（α_Kow(DDT/DDE)≈2.5，ΔΔG≈2.3 kJ/mol），DDE 次之，DDD 最弱（α_Kow(DDE/DDD)≈3.1，ΔΔG≈2.8 kJ/mol）。

**卤键增量估计**：=CCl₂ 双乙烯基氯在疏水腔内与几何匹配受体形成两点卤键。单点卤键在去溶剂化疏水腔内估计 5–10 kJ/mol（Schneider 2009 水相氢键背景类比；Politzer 2013卤键化学综述），两点合计 10–20 kJ/mol。DDT 的 -CCl₃ 三氯四面体在相同腔内因几何失配（三氯 vs 双氯、四面体 vs 共面），最多形成一点弱卤键且伴随立体排斥，净卤键贡献估计 3–8 kJ/mol。

**净选择性预测**：ΔΔG_halogen(DDE/DDT) ≈ 7–12 kJ/mol，叠加疏水本底 -2.3 kJ/mol（偏向 DDT），净 ΔΔG ≈ 5–10 kJ/mol，对应 α(DDE/DDT) ≈ 8–56。对 DDD：ΔΔG_halogen(DDE/DDD) ≈ 7–12 kJ/mol（DDD -CHCl₂ 仅一个烷基氯可形成弱卤键），叠加疏水本底 +2.8 kJ/mol（偏向 DDE），净 ΔΔG ≈ 10–15 kJ/mol，对应 α(DDE/DDD) ≈ 56–400。

**诚实声明**：以上为量级估计，非精确预测。核心不确定性在于疏水腔内单点卤键强度的实际值（1–15 kJ/mol 跨度），须由阶段 0 实验回答。

## 2. 生物原型与证据

### 2.1 原型 P1（脱卤酶底物捕获区卤素识别，原理级转译）

还原脱卤酶 PceA（PDB 4UQU，Bommer 2014 Science）的"保守 B12 催化支架与可变底物捕获区"二分架构中，底物捕获区通过疏水腔内卤键相互作用识别含氯底物。该架构原理——"疏水腔内几何定位的卤键识别位点"——是本方案的仿生承重来源。

按框架 BPA/ERRγ 先例与 C 组 GC8 约束，PceA 蛋白结构不得直接复制，仅提取设计原理。本方案提取的原理为：(a) 疏水腔提供去溶剂化环境保护卤键；(b) 腔内定位的卤键受体与底物氯原子几何互补。催化功能（B12 介导还原）不在本方案范围内。

**方向性限定**：PceA 的卤素识别服务于催化活化（C-Cl 键断裂），本方案仅提取识别维而舍弃催化维。人工体系中增强方向（卤键受体阵列使 DDE 结合强于受体缺如腔）为本方案独立假设，由受体有无配对实验检验。

### 2.2 原型 P2（BphA 平面氯代二芳基疏水裂口，架构原理级）

BphA 联苯双加氧酶底物结合裂口容纳平面至高度扭转的二芳基骨架（2XRX 联苯二面角约 52°、2XSH 2,6-二氯联苯约 76°，Kumar 2011 JMB）。该裂口的疏水芳壁为 DDE 双(4-氯苯基)骨架提供架构级结合环境原理。

本方案不继承 BphA 的选择性功能（A01 已证明 BphA 不直接提供桥三元组选择性），仅借用"疏水芳壁裂口容纳氯代二芳基"的架构原理作为腔体设计的原理支撑。

| **预期功能** | 两点卤键与 =CCl₂ 双乙烯基氯几何互补，对 DDT（-CCl₃ 三氯四面体，几何失配）和 DDD（-CHCl₂ 三氯四面体，几何失配）给出可测分离因子；对 DDMU（一个乙烯基氯）因卤键数目减半给出差异 |
| **测量** | 受体有无配对实验（α_present/α_absent = 增量因子 EF）；受体间距系列（验证几何匹配最优点）；竞争物谱含 DDT/DDD/DDMU/DDNU + 二级 OCPs（GC2）；固体 ¹H-¹³C HETCOR 探测 PyNO 至 DDE 氯原子空间近接 |
| **因果对照** | 受体缺如配对（核心解耦：无受体腔 vs 有受体腔）；受体间距变异（几何匹配验证）；DDT/DDD/DDMU 竞争实验（选择性谱）；脂质归一化对照（GC1） |

### 可选动态对应（不作硬声称）

卤键受体与 =CCl₂ 的相互作用理论上轻微极化 C-Cl 键，本方案不声称脱氯或矿化（与 A03 还原捕获严格区分），此项仅为机制讨论。

## 4. 材料架构与选择性机制

### 4.1 载体与构筑

**主路线：COF 骨架内定位 PyNO 受体**

选择亚胺键 COF 或 β-酮烯胺 COF 作为刚性骨架平台（理由：晶态可调孔径、芳壁疏水腔、后修饰引入 PyNO）。构筑策略分三步：

1. **骨架构筑**：选择适当单体合成孔径约 1.0–1.5 nm 的 COF（如 TpPa 系列变体），BET 比表面积约 800–1500 m²/g
2. **后修饰引入 PyNO**：通过 COF 骨架上预留的反应位点（如氨基/醛基）后修饰接枝吡啶 N-氧化物基团，控制接枝密度约 0.05–0.2 mmol/g
3. **PyNO 间距调谐**：通过单体比例控制 PyNO 位点间距，制备间距系列（约 2.5/3.0/3.5 埃）以验证几何匹配

**备选路线：交联有机笼**

若 COF 路线的 PyNO 接枝密度或间距控制不可行，备选路线为交联有机笼（如 Pd₆L₄ 型自组装笼的有机类似物），笼内表面直接含 PyNO 基团。优点：离散腔体、尺寸均一；缺点：合成复杂度高、规模化困难。

### 4.2 选择性机制（分层）

**第一层：疏水捕获层（非选择性来源）**。DDE logKow=6.51，高疏水性使疏水腔对 DDE 有强分配驱动。该层提供 ng/L 捕获驱动力，按 Koc 线性标度的疏水本底对 DDT（logKow 6.91）偏好约 2.5 倍、对 DDD（logKow 6.02）偏好约 0.32 倍。疏水本底不构成 DDE 选择性来源（CT1），由受体缺如对照实测。

**第二层：卤键几何匹配层（选择性来源）**。=CCl₂ 双乙烯基氯在疏水腔内与几何定位 PyNO 受体形成两点卤键。DDT 的 -CCl₃ 三氯四面体因 (a) 三氯 vs 双氯数目不匹配、(b) 四面体几何 vs 受体平面排布失配、(c) 第三氯可能产生立体排斥，净卤键贡献显著低于 DDE。DDD 的 -CHCl₂ 仅一个烷基氯可形成弱卤键（sp3 C-Cl σ-hole 弱于 sp2 C-Cl），且几何失配。

**第三层：正交协同**。疏水腔定位 DDE 分子取向，使 =CCl₂ 朝向受体阵列；无腔则受体对水相任意含氯分子无差别结合，无受体则腔不能区分桥碳取代差异。两维协同经受体有无配对实验解耦。

### 4.3 报告口径

总干复合体 mg/g：识别位点理论单层容量按 PyNO 接枝量 0.05–0.2 mmol/g 估算为约 16–64 mg/g（DDE MW 318）。床层口径 mg/mL：COF 填充床堆积密度约 0.2–0.4 g/mL。ng/L 工况下位点占据度极低，核心指标为 Kd 与 α。

### 4.4 再生机制

DDE 结合为可逆卤键加疏水，以低温极性溶剂（甲醇或乙腈）洗脱即可破坏卤键并脱附，全程不进入 PCDD/F 生成温区（GC5）。诚实声明：再生为脱附回收而非破坏。

## 5. 创新性清单 A-E 逐项自判

**A 机制创新**：通过。=CCl₂ 乙烯基氯的卤键阵列几何读出，对 logKow 相近、电荷为零、骨架相同的 DDE/DDT/DDD 产生区分；非疏水分配/静电/尺寸筛分。"疏水腔内定位卤键受体阵列对乙烯基氯的水相几何读出"可被受体有无配对实验直接证伪。结论：A 维通过。

**B 材料架构创新**：部分通过。COF 为成熟平台（弱点），PyNO 功能化有先例。增量：卤键受体几何间距调谐 + DDE 特异识别位点设计。合成路线为后修饰常规手段。结论：B 维部分通过。

**C 仿生转译创新**：有条件通过。提取"脱卤酶底物捕获区疏水腔 + 卤素识别"原理（E1/E9 背书），非官能团拷贝；但原型记载为催化上下文中的底物结合，本方案仅提取识别维，转译为弱架构原理级（类比 Dieldrin S27 中 GABA 腔原理级转译）。若受体有无配对实验无增强，C 维仅余架构原理。结论：C 维有条件通过，附方向性限定。

**D 选择性策略创新**：通过（核心强项）。卤键阵列几何匹配 + 疏水腔协同，对 logKow/电荷/分子量均非单调。对 DDMU 的区分（乙烯基氯数差异）为 A01 不具备的独特能力。竞争物谱含 DDT/DDD/DDMU/DDNU（GC2）。结论：D 维通过。

**E 先例区分**：有条件通过。水相吸附零先例（G5），最近邻为 COF-OCP 非水分析萃取（E5）与碳材料 DDx MD（E6）。增量取决于水相卤键是否存活与受体配对 EF 值。结论：E 维有条件通过。

**总判定**：A、D 通过，C 有条件通过（附方向性限定），B、E 部分通过。满足清单"至少一维明确创新"要求。

## 6. 台架合成 SOP 草图

**步骤一，COF 骨架构筑**。以 1,3,5-三甲酰基间苯三酚（Tp）与对苯二胺（Pa）衍生物为单体，在均相溶剂条件（1,4-二噁烷/均三甲苯 1:1，含 6 M 醋酸催化剂）中 120 °C 溶剂热晶化 72 h。过滤、丙酮/二氯甲烷洗涤、80 °C 真空干燥。小角 XRD 与 N₂ 吸脱附表征孔径与比表面积。

**步骤二，后修饰引入 PyNO**。COF 骨架上预留的氨基位点与 4-吡啶基甲醛缩合引入吡啶基团，随后以 mCPBA（间氯过氧苯甲酸）氧化为 PyNO。控制反应条件调节接枝密度（元素分析 N 含量监控）。部分样品不进行 PyNO 引入，作为受体缺如对照。

**步骤三，受体间距系列**。使用不同比例的 PyNO 功能化单体与非功能化单体共聚合，制备 PyNO 间距约 2.5/3.0/3.5/5.0 埃的系列样品。

**步骤四，表征**。PXRD（晶态确认）、N₂ 吸脱附（BET 孔径/比表面积）、FTIR/固态 NMR（PyNO 确认）、元素分析（接枝量）、TGA（热稳定性）、水汽吸附等温线（润湿态）。

## 7. 实验可证伪设计与成功/失败判据

### 7.1 阶段 0 门控（合成前 go/no-go）

**阶段 0-A：计算核验**。DFT/MD 计算 DDE =CCl₂ 双氯与 PyNO 的卤键结合能在气相和水相中的值。Go 线：气相单点卤键能 ≥ 15 kJ/mol，水相（隐式溶剂）单点卤键能 ≥ 2 kJ/mol。

**阶段 0-B：模型化合物水相滴定**。合成小分子模型（含 PyNO 基团的有机分子，如 4,4'-联吡啶 N,N'-二氧化物），在 D₂O/CD₃CN 混合溶剂中滴定 DDE，以 ¹H NMR 化学位移变化监测结合。Go 线：K ≥ 10 M⁻¹（水相）。

### 7.2 材料级实验阶梯

**S1 受体有无配对**（核心证伪）。同批次合成有/无 PyNO 的 COF，在超纯水中测 DDE 等温线。成功判据：EF = α_present/α_absent ≥ 1.5 且置信区间不跨 1。失败判据：EF < 1.5 经 2 轮受体密度优化无改善。

**S2 竞争物谱**。在 S1 成立后，测 DDT/DDD/DDMU 竞争等温线。报告 α(DDE/DDT)、α(DDE/DDD)、α(DDE/DDMU)。成功判据：α(DDE/DDT) ≥ 2.0。

**S3 脂质归一化对照**。以辛醇-水分配为第三相参照，证明有限体积腔 + 卤键相对无限脂质分配的热力学优势。

**S4 基质耐受性**。在二级出水基质中重复 S1-S3，报告 DOM 干扰程度。

**S5 动力学与床层**。粒径系列摄取动力学；小柱填充床穿透曲线（EBCT 10-30 min）。失败判据：床层接触时间内达平衡摄取 < 50%。

### 7.3 失败模式与对策

| 失败模式 | 诊断 | 对策 |
|---|---|---|
| 阶段 0 计算水相卤键能 < 2 kJ/mol | 卤键在水相本质弱 | 尝试更强受体（硒醚、碲醚）或更疏水腔体；若仍不达标则角度终止 |
| S1 EF < 1.5 | 卤键增量不足以超越疏水本底 | 提高受体密度、优化间距；若 2 轮后仍 < 1.5 则角度终止 |
| S2 α(DDE/DDT) < 2.0 | 对 DDT 选择性不足 | 检查腔体尺寸是否过大（DDT 也可进入）；缩小孔径增强几何排斥 |
| S5 动力学饿死 | COF 晶粒过大、传质受限 | 制备 COF 纳米晶/薄膜；或换用交联有机笼（离散腔体传质路径短） |

## 9. 风险与诚实标注

### 9.1 事实/推断/假设分层

| 主张 | 层级 | 支撑 |
|---|---|---|
| DDE =CCl₂ 含两个乙烯基氯 | 事实 | 分子结构（PubChem CID 3035） |
| PceA 底物捕获区含卤素识别 | 来源支持的线索 | E1 摘要级 |
| 卤键在去溶剂化腔内可增强至 5–15 kJ/mol | 推断 | E3 综述级 + E7 水相背景类比 |
| PyNO 间距匹配 Cl-Cl 距可产生选择性 | 设计假设 | 无直接先例，须实验验证 |
| α(DDE/DDT) ≥ 2.0 可达 | 设计假设 | 热力学一阶估计，高度不确定 |

### 9.2 核心未决

1. 水相卤键在疏水腔内的净强度（阶段 0 回答）
2. PyNO 在 COF 骨架上的可接枝密度与间距控制精度
3. COF 水相长期稳定性（亚胺键 COF 在 pH 4-10 范围内一般稳定，但须实测）

### 9.3 安全警示

- COF 单体（醛类、胺类）部分有刺激性/毒性，合成须在通风橱内操作
- mCPBA 为氧化剂，PyNO 氧化步骤须控温防爆
- DDE 为持久性有机污染物，实验操作须按 POPs 处置规程
