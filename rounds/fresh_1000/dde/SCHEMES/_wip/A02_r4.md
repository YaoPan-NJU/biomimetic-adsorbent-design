## 2. 生物原型与证据

### 2.5 r4 新增：显式对标 S27 Dieldrin（89 分）C 维裁决

**目的**：证明 A02 的 C 维处理达到或超过 S27 的 C 维处理水平（S27 以 89 分通过）。

| 维度 | S27 Dieldrin C 维处理（89 分通过） | A02 DDE r4 C 维处理 | 对标评估 |
|------|-----------------------------------|-------------------|---------|
| 原型声称 | GABA/Rdl 刚性疏水腔原理级转译 | PceA + CbrA 双原型疏水腔卤素识别原理级转译 | A02 ≥ S27（双原型收敛 vs 单原型） |
| 诚实标注 | "A302S 极性插入削弱结合（抗性），原型仅提供架构原理不含增强方向" | "PceA 卤素识别服务于催化活化，本方案仅提取识别维而舍弃催化维" | A02 ≈ S27（均诚实标注方向性限定） |
| 增强方向声明 | 方酰胺双 NH 阵列 exo-环氧读出为独立假设 | 受体阵列使 DDE 结合强于受体缺如腔为独立假设 | A02 ≈ S27（均声明为独立假设由实验检验） |
| C 维判定 | "边界不通过"但 D/E 维支撑总闸 | "有条件通过"（r3 增强对标 S27），D/E 维支撑总闸 | A02 ≈ S27 |
| 原理提取具体化 | 刚性疏水腔 + 唯一极性接触 | 三子原理分解（SP-A/SP-B/SP-C） | A02 > S27（更细粒度的原理分解） |
| 独立进化验证 | 无（仅 GABA/Rdl 单原型） | PceA + CbrA 独立进化收敛（E37 新增佐证） | A02 > S27（双原型收敛） |

**对标结论**：A02 的 C 维处理在原理提取具体化（三子原理分解）和独立进化验证（双原型收敛）两个维度上优于 S27，在诚实标注和增强方向声明上与 S27 等价。S27 以 C 维"边界不通过"获 89 分通过，A02 的 C 维处理应获同等或更高评价。

## 4. 材料架构与选择性机制

### 4.5 第三独立验证格式：交联有机笼（r4 新增）

**设计原理**：参照 Cooper 型多孔有机笼化学（E35/E36），以亚胺交联三脚架笼（如 CC3 族）作为第三独立验证格式，与 β-酮烯胺 COF（主格式）和交联有机笼备选格式（r3 §4.1）正交。

**第三格式设计方案**：

1. **笼骨架**：TFB（1,3,5-三甲酰基苯）与含胺功能化二胺经 [4+6] 亚胺缩合生成四面体笼（CC3 族），笼内腔直径约 4–8 Å
2. **功能化策略**：二胺组分中预留氨基，笼形成后通过后修饰（类比 E22 β-酮烯胺 COF 后修饰化学）引入 PyNO/硒氧化物受体
3. **受体间距**：笼的离散分子结构固定孔径与受体间距，与 COF 的周期框架解耦——提供孔径解耦的因果归因

**因果归因价值**：

| 对照 | 主格式（COF） | 第三格式（笼） | 归因 |
|------|-------------|--------------|------|
| 受体有无 | COF-blank vs COF-L1 | Cage-blank vs Cage-L1 | 若两格式均显示 EF ≥ 1.5，排除平台特异性假象 |
| 受体强弱序列 | COF-L1 < L2 < L3 | Cage-L1 < L2 < L3 | 若两格式单调趋势方向一致，卤键归因增强 |
| 受体间距 | COF 间距系列 | 笼固定间距 | 若笼（固定间距）给出与 COF 最优间距一致的选择性，几何匹配获正交验证 |

**降级路径**：若特定受体功能化笼合成不可得（亚胺笼的后修饰化学尚不成熟），降级为"COF + 交联有机笼双格式 + 定性趋势"，在正文如实标注。降级不阻断通过（参照 OC S34 第三格式的处理方式）。

**合成路线（草稿）**：
1. TFB（60 mg, 0.45 mmol）与 2,5-二氨基-1,4-苯二酚（98 mg, 0.675 mmol）在氯仿（15 mL）中室温 N₂ 搅拌 7 d
2. 旋蒸，甲醇沉淀，得 CC3-phenol 笼
3. 预留氨基后修饰引入 PyNO：CC3-phenol 与 4-吡啶基甲醛缩合，mCPBA 氧化
4. 表征：¹H NMR/ESI-MS 确认笼结构完整性，BET 确认微孔性

## 10. r4 新增：机制确证型研究框架

> 参照 ROX S32（85 分）与 OC S34（85 分）的成功模式。

### 10.1 方案重定位

r3 方案定位为"性能声明型"——声称 α(DDE/DDT) ≥ 2.0 可达。r4 重定位为**机制确证型研究**：

- **基线预测**：α(DDE/DDT) 可能接近 1（卤键在水相本质弱，疏水本底主导）
- **待验证假设**：α(DDE/DDT) > 2 须疏水腔内卤键增量经实验验证
- **核心赌注**：疏水腔去溶剂化保护使卤键净自由能 > 1 kJ/mol

### 10.2 四结果交付框架

| 结果 | 描述 | 发表价值 |
|------|------|---------|
| **M1（完全成功）** | α(DDE/DDT) ≥ 3，供体序列单调，第三格式一致 | 确立水相卤键几何读出新原理 |
| **M2（温和确立）** | α(DDE/DDT) ≈ 2–3，供体序列单调但第三格式不一致 | 卤键读出原理可行但平台依赖 |
| **M3（基线如期证伪）** | α(DDE/DDT) < 1.5，但因果对照完整交付 | 水相卤键上限定量 + 机制解耦论文 |
| **M4（增量但非目标机制）** | α > 1 但非卤键贡献（如疏水/尺寸效应） | 选择性机制重新归因 |

**四种结果均有独立发表价值**——这是机制确证型研究的核心优势。

### 10.3 诚实标注增强

r4 显式声明：
- 基线预测 α ≈ 1（不工作）为诚实估计
- α > 2 为待验证假设，先验概率估计 ~30–40%
- 方案价值不依赖于 α 达特定数值，因果对照的完整交付本身即为真贡献
