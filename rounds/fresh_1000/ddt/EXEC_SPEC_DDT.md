**实验浓度三点**：0.5–5 ng/L（一般流域溶解相）、50–200 ng/L（GB 3838 评价量级）、1–5 µg/L（WHO 准则值与非洲热点）。ng/L 级工作需 Kd ≥ 10⁴ L/kg。

### 1.2 难去除机制（四维瓶颈）

1. **选择性把手缺失**（最尖锐）：DDT/DDE/DDD 同为双(4-氯苯基)骨架，仅 C1 桥取代不同（–CCl₃/=CCl₂/–CHCl₂），中性无解离无氢键供受体，静电/氢键/酸碱把手全部不可用
2. **第三相分配竞争主导**：吸附剂须与颗粒有机碳（Karickhoff Koc-Kow 框架）、DOC 络合增溶、生物脂相竞争；GAC 土壤改性反例（Denyes 2016）证实非特异分配失效
3. **转化而非矿化**：还原路径普遍止步 DDD/DDE/DDMU，脱氯化氢方向（DDT→DDE）为失活方向，氯质量平衡罕见闭合
4. **强吸附与再生困难耦合**：logKAC 8.47–9.26 与脱附困难并存，再生路径均伴能耗与 POPs 二次废物

### 1.3 核心识别维度

C1 桥取代差异是自然界唯一读取 DDT/DDE/DDD 的维度：
- **DDT**：–CCl₃ 四面体 + 桥 β-氢（5 Cl）
- **DDE**：=CCl₂ 平面（无桥氢，4 Cl）
- **DDD**：–CHCl₂ 四面体（4 Cl）

自然界读取该差异的机制仅两种：脱氯化氢酶（β-消除，要求桥 β-H + –CCl₃ 同时存在）和还原脱氯（DDT→DDD 且 DDE 不反应）。

## 3. 角度预分类（S/A/B/X）

> 对每个角度执行 TFG/PADS/ODC 预筛评估。继承 GLOBAL_SPEC §3 预筛机制与 C 组分类 Spec §7 组特异参数。

### 预筛方法说明

- **TFG**（热力学可行性门）：C 组为中性非解离分子，FM3 不直接适用，但须检查弱氢键受体/卤键在水相净结合自由能、竞争物相对结合能、ng/L 工况 Kd 要求
- **PADS**（先例密度评估）：起始 100，直接先例 –15/篇，方向先例 –5/篇，平台先例 –3/篇；>50 标记先例饱和
- **ODC**（正交维度检查）：C 组因无静电/氢键/酸碱把手，须 ≥2 个正交维度；单参数单调退化（logKow 单调）不通过

## 4. 历史教训注入

### 4.1 DDT 自身终止方案教训

#### S20_A04 桥几何形状读出腔 — 终止

- **失败根因**：单独形状排阻落入 CT3 机制空洞（MIP 机制空洞）
- **教训**：轮廓识别角度须以机制驱动空腔设计（非模板印迹）自辩，并报告 DDE/DDD 分离因子；单独形状维度不通过创新性 D 维，须与 A01/A05 正交叠加
- **对后续角度的影响**：A04 已降为 X 级；A21 和 A05 须将形状维作为正交维度之一而非唯一识别轴

#### S21_A21 双表位正交预组织 — 终止

- **失败根因**：具体失败模式须回溯方案台账；角度机制原理本身正交维度丰富（三维正交），但实现层面遇到障碍
- **教训**：多预组织功能化笼的合成可行性与位点间拮抗是核心风险；单维消融对照须在合成前设计
- **对后续角度的影响**：A21 保留为 A 级但须以不同材料平台重试；合成路线可行性为 go/no-go 门控

### 4.2 Dieldrin S27_A01 成功模式提取（89 分通过）

Dieldrin A01 是 C 组唯一通过方案，其成功模式对 DDT 角度设计有直接指导意义：

1. **"刚性疏水腔 + 唯一极性把手几何读出"策略**：方酰胺双 NH 阵列对环氧氧的几何依赖读出——该策略可迁移至 DDT 的 –CCl₃ 卤键阵列读出（A05）或桥双基序反应性读出（A01）
2. **阶段 0 模型化合物水相滴定 go/no-go 门控**：go 线 K ≥ 10 M⁻¹，作为合成前第一道门——应成为 DDT 所有涉及弱相互识别角度的标准做法
3. **诚实标注仿生强度与方向性限定**：A302S 极性插入削弱结合（抗性），原型仅提供架构原理不含增强方向——DDT 的 GSTe2 原型同样为蛋白，转译限于双基序几何与反应性原理
4. **修正热力学图像**：采用实测 logKow 排序，疏水本底非近简并——DDT 系 logKow 6.9/6.5/6.0 差异虽小但非零，须精确核算
5. **迭代轨迹**：r1=70 → r2=89，每轮有实质议题闭合（热力学勘误、介孔润湿态、合成路线修正、原型方向限定、羰基占据）

### 4.3 DDE A01 结构性脆弱教训（r2=75，未通过）

DDE A01 的结构性脆弱对 DDT 角度选择有警示意义：

1. **窗口 0–1 埃问题**：DDE 平面轮廓与 DDT 最优取向的厚度差异仅约 0–1 埃，达线高度依赖"狭缝诱导受限平面化"这一未证假设——**DDT 的 –CCl₃ 四面体 vs DDE =CCl₂ 平面的几何反差远大于 DDE 自身的平面轮廓读出，是更有利的识别维度**
2. **C 维仿生转译不通过**：承重选择性（厚度门控双壁三明治）为工程添加、非 BphA 转译，本质为理性化学设计——**DDT 角度须确保仿生转译链完整，不可将选择性承重全部归于工程侧**
3. **反转余量小**：DDE/DDT 反转须狭缝净供约 4 kJ/mol 特异 ΔΔG 以翻转约 2.3 kJ/mol 疏水本底偏向——**DDT 角度设计须确保识别增量 ΔΔG_geo > 1.0 kJ/mol 且有余量**

### 4.4 DDT 与 DDE 角度地图共享与差异

| 维度 | DDT（–CCl₃ 四面体 + 桥 β-H） | DDE（=CCl₂ 平面，无桥氢） |
|------|------|------|
| 桥反应性读出 | ✅ 脱氯化氢酶双基序（攫氢 + –CCl₃ 口袋）| ❌ 无桥氢，β-消除不可用 |
| 还原反应性读出 | ✅ –CCl₃ → –CHCl₂ | ❌ =CCl₂ 不被同路径还原 |
| 卤键阵列 | ✅ 三氯四面体 σ-hole 阵列 | 双氯共面阵列（图案不同） |
| 形状轮廓 | 四面体桥 | 平面桥（几何反差大，有利识别） |
| 识别把手丰富度 | **丰富**（5 个 Cl + 桥 β-H + –CCl₃） | **贫乏**（4 个 Cl，无桥氢） |
| 正交维度构建难度 | **中等** | **极高**（窗口 0–1 埃） |

**核心结论**：DDT 的识别把手比 DDE 丰富得多（–CCl₃ 四面体 + 桥 β-H 提供反应性与几何双维度），这是 DDT 角度设计相对 DDE 的结构性优势。DDE A01 的结构性脆弱（窗口 0–1 埃、C 维不通过）反证 DDT 的桥反应性读出（A01）和卤键阵列读出（A05）是更有前景的角度。

## 5. 竞争物谱锁定

### 5.1 三层竞争物架构（DDT 特异）

| 层级 | 竞争物类别 | 具体物质 | 威胁等级 | 说明 |
|------|-----------|---------|---------|------|
| **第一层：桥三元组** | DDT 系代谢物/异构体 | DDE（=CCl₂ 平面）、DDD（–CHCl₂ 四面体） | **极高** | 同骨架最近竞争物，桥碳差异是唯一识别维度 |
| | 位置异构体 | o,p'-DDT（Cs 不对称） | 高 | 工业品含 15–20%，对称性差异可作辅助识别 |
| | 结构近似物 | methoxy-DDT、dicofol（含 –CCl₃ 或类似桥） | 高 | 甲氧基/羟基可叠加氢键维区分 |
| **第二层：跨类 OCPs** | 不同类 OCPs | Dieldrin、Endosulfan、β-HCH | 高 | 非芳基笼状/平面 OCP，A06 EDA 轴可区分 |
| | 氯代芳烃 | PCB 类（PCB-209 等） | 高 | 疏水同系而非异构，体积更大可尺寸筛分 |
| | 氯苯类 | PeCB、HCB | 中 | 小分子氯代芳烃 |
| **第三层：基质竞争** | 天然有机物 | 腐殖酸/富里酸（疏水位点抢占） | 高 | 第三相分配主导 |
| | 颗粒/沉积物 | 有机碳、DOC、脂质相 | 高 | 吸附剂须与颗粒有机碳竞争 |
| | 共存农药 | 毒死蜱、菊酯类 | 中 | 特定场景共存 |

### 5.2 竞争物使用规则（DDT 特异）

1. **桥三元组为必须**：所有选择性声称须含 DDE 和 DDD 作为竞争物，仅报告不同类物质（如 NOM）的选择性不构成证据
2. **分离因子报告**：必须报告对 DDE/DDD 的分离因子 α，不得仅报告总容量或去除率
3. **脂质归一化对照**：所有选择性声称须以脂质/有机质归一化对照排除 logKow 单调解释
4. **分层证明**：先证第一层（桥三元组），再扩展到第二、三层

## 6. 诚实上限预估

### 6.1 预估方法

基于 24 个角度的预分类结果、C 组历史通过率和 DDT 特异性约束，预估实际可通过方案数。

### 6.2 约束因素

1. **机制空间本征狭窄**：DDT 无氢键/无解离把手，可行识别维度仅剩 C1 桥几何-电子差异、形状轮廓、卤键、疏水形状匹配
2. **破坏性平台先例饱和**：还原-破坏谱系密集且全非选择（T3），反应性角度普遍 high 风险
3. **C 组历史通过率**：C 组 6 种污染物中仅 Dieldrin 1 个通过方案（S27_A01=89），DDT 已有 2 个终止
4. **正交维度构建困难**：C 组因无静电/氢键/酸碱把手，GC3 双维度正交硬约束是最尖锐挑战
5. **水相弱相互作用削弱**：卤键、弱氢键、色散力在水相被竞争水化显著削弱

### 6.3 预估结果

| 等级 | 角度数 | 预期通过率 | 预期通过数 |
|------|--------|-----------|-----------|
| S 级 | 2 | 30–50% | 0–1 |
| A 级 | 5 | 15–30% | 0–2 |
| B 级 | 7 | 5–15% | 0–1 |
| **合计** | **14**（排除 X 级 10 个） | — | **0–4** |

**诚实上限预估：1–3 个通过方案**，远低于 50 槽上限。

理由：
- S 级 A01 和 A05 正交维度最丰富但各有核心化学可行性风险（水相攫氢能垒 / 水相卤键削弱）
- A 级 A21 已有一次终止经历，重试须以不同材料平台
- A 级 A03 不能声称桥区分，选择性维度有限
- B 级角度多受先例饱和或单参数退化限制
- 参考 Dieldrin 经验（17 角度中 1 个通过），DDT 24 角度中 1–3 个通过属合理预期

**诚实声明**：若 S/A 级角度全部终止，DDT 实际通过数可能为 0。此结果符合 GLOBAL_SPEC G8 耗尽条款（"诚实的 N < 50 优于凑数的 50"）。

## 7. 执行建议

### 7.1 推荐首先执行的角度（S 级）

#### 第一优先：A01 脱氯化氢酶 β-消除双基序反应性识别腔

- **理由**：正交维度最丰富（3 维）、先例密度最低（PADS=10）、仿生转译链最完整（GSTe2 双基序几何 → 人工疏水腔内预组织位阻碱 + –CCl₃ 口袋）
- **预期迭代轮次**：3–5 轮（参考 Dieldrin r1=70→r2=89 轨迹）
- **核心风险**：水相固相攫氢能垒与"捕获不转化"控制的化学可行性
- **go/no-go 门控**：
  1. 阶段 0 模型化合物（含桥 β-H 的 DDT 类似物 vs 无桥氢 DDE）水相滴定，go 线 K ≥ 10 M⁻¹
  2. 碱强度梯度实验：弱碱（不攫氢）vs 强碱（攫氢），验证双基序协同
- **终止条件**：阶段 0 水相滴定 K < 10 M⁻¹ 且经 2 轮碱强度优化仍无改善

#### 第二优先：A05 –CCl₃ 三氯四面体卤键阵列识别

- **理由**：正交维度丰富（3 维）、先例密度低（PADS=12）、与 A01 正交（A01 为反应性读出，A05 为非共价卤键读出）
- **预期迭代轮次**：3–5 轮
- **核心风险**：水相卤键被竞争水化显著削弱
- **go/no-go 门控**：
  1. 阶段 0 卤键受体-DDT 类似物水相滴定，对比无受体对照
  2. 供体强弱序列（脲 < 硫脲 < 方酰胺）α 响应验证
- **终止条件**：卤键受体有无配对实验 α(DDE/DDT) < 1.5 且经 2 轮受体优化仍无改善

### 7.2 S 级失败后的 A 级执行顺序

1. **A21**（双表位正交预组织）—— 直接回答 SP1 协同可加和性，但须以不同于 S21 的材料平台
2. **A03**（有限体积受限疏水腔）—— 热力学最可行，但不能声称桥区分
3. **A10**（电化学电位门控）—— 正交维度独特（电位窗口 + 捕获/释放切换）
4. **A18**（CD/cavitand 主客体）—— 须用 γ-CD 或 cavitand 解决腔径失配
5. **A13**（硫调制 ZVI）—— 破坏性路线，须定位为破坏段

### 7.3 通用终止条件

每个角度在以下条件下终止：

1. **阶段 0 门控失败**：模型化合物水相滴定未达 go 线且经 2 轮优化无改善
2. **迭代耗尽**：2 轮设计-攻击-裁决未通过（< 85 分或仍有 critical/high），经 3 次重建仍不通过
3. **结构性不可行**：核心识别机制在水相条件下本质不可行（如卤键结合能 < 水竞争代价）
4. **选择性不达标**：对 DDE/DDD 分离因子 α < 2.0 经 2 轮优化无改善

### 7.4 通用硬约束检查清单

每个 DDT 方案进入正式评分前须逐项通过：

- [ ] 因果链贯通（G1）：DDT 难去除根因 → 传统方法做不到 → 生物原型 → 设计原理 → 人工材料 → 可证伪实验
- [ ] 至少 1 条硬仿生对应（G2）：实现于人工材料，六列完整
- [ ] 创新性五维至少一维明确创新（G3）
- [ ] 正交维度 ≥ 2（GC3），各维度独立贡献可量化
- [ ] 竞争物谱含 DDE/DDD（GC2），报告分离因子 α
- [ ] 脂质/有机质归一化对照（GC1）
- [ ] 实验浓度匹配 ng/L 级主目标场景（GC4）
- [ ] 氯质量平衡闭合（GC7，涉及转化路径时）
- [ ] 阶段 0 模型化合物水相滴定 go/no-go（GC6）
- [ ] 再生路径避开 PCDD/F 生成温区（GC5）
- [ ] 仿生强度诚实标注（毒性受体标注为"原理级参考"）（GC8）
