- 槽位：rounds/fresh_1000/ddt，角度 A01
- 原型家族：DDT-脱氯化氢酶（本质为谷胱甘肽 S-转移酶 GSTe2；Clark & Shamaan 1984；Sternburg 1954；伊蚊 GSTe2 2005）β-消除双基序读出

## 1. 科学问题与工程难题（方案层面具体化）

### 1.1 科学问题

DDT 为中性非解离分子，无氢键供体/受体、无 pKa/电荷把手，唯一区分 DDT/DDE/DDD 桥三元组的维度是 C1 桥取代差异（–CCl₃ 四面体 + 桥 β-H / =CCl₂ 平面 / –CHCl₂ 四面体）。本方案的机制问题是：

**能否将预组织位阻碱与 –CCl₃ 互补四面体口袋共定位于刚性疏水受限腔内，使双基序同时就位，在水相中对 DDT 产生几何-反应性协同识别，并实现"捕获不转化"（保留识别而不落入 DDE 失活方向）？**

核心未决项为三个物理有机化学问题：

1. **攫氢能垒**：位阻碱（pKa 约 10–11 的受阻叔胺或 pKa 约 7–8 的 π 碱）在水相固-液界面能否攫取 DDT 桥 β-H？攫氢后形成的碳负离子/离子对在受限腔内是否稳定至足以产生可测结合信号，还是立即引发 β-消除生成 DDE（即落入失活方向）？
2. **双基序协同量化**：双基序（攫氢碱 + –CCl₃ 口袋）的协同结合自由能 ΔΔG_dual 是否显著大于单基序之和（ΔΔG_base + ΔΔG_pocket）？若协同不显著（ΔΔG_dual ≈ ΔΔG_base + ΔΔG_pocket），则正交维度退化为加和而非协同，D 维创新削弱。
3. **水相卤键存活**：–CCl₃ 四面体亚腔内的卤键受体（碘代三唑/硒醚）在水相中的净结合收益是否超过竞争水化代价？参考狄氏剂 S27 经验（E13 Schneider 2009），水相卤键净收益常仅数个 kJ/mol。

### 1.2 工程难题

本方案覆盖简报 EC1 四约束中的选择性维（双基序门控对桥三元组的区分）与捕获维（疏水腔驱动 ng/L 捕获）。第三相竞争维（EC1-CT4）部分覆盖——受限腔的有限体积可饱和性区别于无限脂质分配，但脂质归一化对照仍为必设。再生维（EC3）采用低温溶剂洗脱（甲醇/乙腈），避开 PCDD/F 生成温区（CT5）。ng/L 传质维（SP4/EC4）为高风险项，mg/L 批次不构成 ng/L 床层证据（T10）。

**诚实声明**：本方案不声称解决四约束全集。核心赌注在科学问题 1–3 的实验回答。

### 1.3 热力学图像

DDT 系 logKow 实测值（简报 §1.1，verified/abstract_read 混合）：DDT 约 6.5–6.9（取中值 6.7）、DDE 约 6.5、DDD 约 6.0。疏水本底对三者的偏好序为 DDT ≈ DDE > DDD，差异不足以支撑分配型选择性（CT1）。因此：

- 疏水腔提供 ng/L 捕获驱动力（非选择性来源）
- 选择性来自双基序协同识别增量 ΔΔG_dual，须 > 1.0 kJ/mol 方可产生可测分离因子
- 脂质/有机质归一化对照为必设反证（GC1/CT4）

## 2. 生物原型与证据

### 2.1 原型 P1：GSTe2 β-消除双基序（原理级参考，非蛋白复制）

DDT-脱氯化氢酶本质为 Epsilon 类 GST（GSTe2），催化 DDT → DDE + HCl 的 β-消除反应。该酶对底物的严格要求构成双基序门控：

- **攫氢碱位**：酶活性位点碱残基攫取桥 β-H（Lipke & Kearns 1959 证明消除反应的立体化学要求）
- **–CCl₃ 离去基识别腔**：–CCl₃ 四面体嵌入疏水亚腔，Cl 与腔壁形成卤键/范德华接触
- **双基序同时就位**：DDE 无桥 β-H（=CCl₂ 平面）不被攫氢→不被消除；DDD 无 –CCl₃（–CHCl₂ 四面体）虽可被攫氢但离去基不同→消除速率极低

**原型使用约束（T8/GC8）**：GSTe2 为蛋白，按框架禁作主干仿生原型本体。本方案仅提取"双基序同时就位门控"的架构原理，以人工疏水 COF 腔内预组织位阻碱 + 卤键受体亚腔实现。原型记载方向为催化消除（DDT → DDE），本方案将方向反转为"捕获不转化"——此为独立设计假设，无原型背书。

## 3. 仿生对应矩阵（两条硬对应，六列完整）

### 硬对应 HC1（刚性疏水受限腔：疏水捕获加取向预组织）

- **生物特征**：GSTe2 活性位点为疏水受限腔，容纳 DDT 双(4-氯苯基)骨架并限制其取向，使桥碳区域朝向催化残基（推断，无 DDT-GSTe2 共晶结构）。
- **来源支持**：E1（GST 为 DDT 靶标酶）、E2（GSTe2 赋予抗性）、E3（消除反应立体化学要求底物在活性位点内特定取向）。
- **材料实现**：刚性疏水 COF 笼（孔径约 1.2–1.5 nm，匹配 DDT 分子横截面约 0.9–1.0 nm），骨架由联苯/三苯胺构建单元缩合形成晶态孔道，孔壁含芳基/全氟芳基疏水层。受限腔驱动 ng/L 捕获并预组织 DDT 取向使桥碳区域朝向腔内功能位点。
- **预期功能**：疏水分配驱动 ng/L 捕获（Kd ≥ 10⁴ L/kg 为必要条件），决定疏水本底排序（DDT ≈ DDE > DDD），不构成桥三元组选择性来源（CT1），仅为双基序识别的承载层。
- **测量**：单组分等温线（Kd, q_max）；三元竞争等温线（DDT/DDE/DDD）；N₂ 吸脱附与 COF PXRD 确认孔径与结晶度；空白 COF（无碱、无卤键受体）贡献。
- **因果对照**：无功能化空白 COF 对照（分离疏水驱动与双基序识别两维）；孔径对照（大孔 COF vs 微孔 COF，量化受限效应）。

### 硬对应 HC2（双基序门控：位阻碱攫氢 + –CCl₃ 四面体卤键亚腔）

- **生物特征**：GSTe2 活性位点碱残基攫取桥 β-H，同时 –CCl₃ 嵌入疏水亚腔形成多接触点卤键/范德华锚定；双基序同时就位方发生消除（E3 立体化学要求）。DDE 无桥氢不被攫取，DDD 无 –CCl₃ 离去基锚定弱。
- **来源支持**：E1/E2/E3（双基序几何与立体化学要求）；人工增强方向（捕获不转化）为本方案独立假设，无原型背书。
- **材料实现**：COF 腔内共定位两个功能单元——(i) 位阻碱（TEMPO 衍生受阻哌啶胺或 Tri-n-octylamine 类受阻叔胺，pKa 约 10–11），预组织朝向腔内，与 DDT 桥 β-H 几何互补；(ii) –CCl₃ 互补四面体亚腔，由碘代三唑/硒醚卤键受体阵列构成，几何匹配 –CCl₃ 三氯四面体 σ-hole 阵列（Cl···N(oxide)/Se 距离约 3.0–3.5 Å，C–Cl···A 角度约 150–180°）。
- **预期功能**：双基序协同识别——DDT（桥 β-H + –CCl₃ 双特征存在）被双基序同时捕获；DDE（无桥氢）仅 –CCl₃ 类似的双氯共面阵列可接触亚腔但无攫氢碱协同，结合弱；DDD（无 –CCl₃，–CHCl₂ 四面体卤键图案不同）亚腔匹配差且攫氢后离去能力弱。协同增量 ΔΔG_dual > ΔΔG_base + ΔΔG_pocket 为设计核心赌注。
- **测量**：碱有无配对（含碱 COF vs 无碱 COF，同骨架）；碱强度梯度（受阻胺 pKa 10–11 vs 吡啶碱 pKa 5–6 vs 无碱）；卤键受体有无配对（含碘代三唑 vs 无受体 COF）；三元竞争分离因子 α(DDE/DDT)、α(DDD/DDT)；阶段 0 模型化合物水相滴定。
- **因果对照**：
  - 碱缺如配对（同骨架 COF 无碱位点，解耦攫氢维贡献）
  - 卤键受体缺如配对（同骨架 COF 无碘代三唑/硒醚，解耦 –CCl₃ 口袋维贡献）
  - 碱强度梯度（弱碱 vs 强碱，验证攫氢贡献随碱强度标度）
  - 卤键受体强弱梯度（硒醚 > 碘代三唑 > 吡啶-N-氧化物，验证 –CCl₃ 口袋贡献随受体强度标度）
  - 2×2 因子对照（碱有/无 × 受体有/无，四组材料，量化双基序协同交互作用项）
  - DDE/DDD 竞争物谱强制包含（GC2）
  - 脂质归一化对照（GC1/CT4）

### 可选动态对应（不作硬声称）

位阻碱攫取桥 β-H 后形成的碳负离子/离子对在受限腔内若稳定存在（不立即消除 HCl），则"捕获不转化"成立；若碳负离子快速消除 HCl 生成 DDE，则材料实际为破坏性而非捕获性。此动态行为为实验未定变量，以产物谱监测（GC-MS/MS 检测 DDE/DDD/DDMU 生成）裁决，不作先验声称。

## 4. 材料架构与选择性机制

### 4.1 载体与构筑

**载体选择**：晶态 COF 为优先平台（二级材料优先级，GLOBAL_SPEC §G6），理由：
1. COF 晶态骨架提供确定孔道几何（孔径分布窄），优于非晶 HCP
2. COF 内可预设计功能单体位置，实现碱位点与卤键受体亚腔的空间共定位
3. COF 骨架疏水性可通过全氟芳基构建单元调谐
4. 避免 MOF（水稳定性差，GLOBAL_SPEC §G6 避免级）

**COF 骨架构筑**：
- 构建单元 A：1,3,5-triformylphloroglucinol (Tp) 或 2,3,6,7-tetraformyl-9,9-dialkylfluorene（全氟代变体可选），提供三角/四角连接节点
- 构建单元 B：联苯胺或 3,3',5,5'-tetraaminobiphenyl，提供刚性线性连接
- 缩合条件：溶剂热法（均三甲苯/1,4-二噁烷，120 °C，72 h），得晶态 β-ketoenamine 或 imine COF
- 孔径目标：约 1.2–1.5 nm（匹配 DDT 横截面约 0.9–1.0 nm + 功能基团空间）

**功能化策略**（两步后修饰）：
1. **位阻碱引入**：COF 骨架含残余醛基或氨基位点，经还原胺化接枝 TEMPO-胺衍生物（4-amino-TEMPO 或 2,2,6,6-tetramethyl-4-piperidinone 衍生叔胺），或直接在单体设计中嵌入哌啶 N-oxide 单元
2. **卤键受体亚腔构筑**：通过 CuAAC 点击化学或酰胺偶联，将碘代三唑-羧酸或硒醚-胺接枝于 COF 孔道内，位于碱位点邻位（目标距离约 0.5–0.8 nm，匹配 DDT 桥碳到 –CCl₃ 的分子内距离约 0.3–0.4 nm 加上连接臂长度）

**四组 2×2 因子材料**：

| 编号 | 位阻碱 | 卤键受体亚腔 | 用途 |
|------|--------|-------------|------|
| M1 | + | + | 完整双基序材料 |
| M2 | + | − | 解耦攫氢维贡献 |
| M3 | − | + | 解耦 –CCl₃ 口袋维贡献 |
| M4 | − | − | 空白载体对照（仅疏水腔） |

### 4.2 选择性机制（分层）

**第一层：疏水受限耦合层（非选择性来源）**

COF 疏水腔驱动 ng/L 捕获。按 logKow 排序（DDT 6.7 ≈ DDE 6.5 > DDD 6.0），疏水本底对三者偏好弱（ΔlogKow < 0.7），α_Kow 预测 < 5。该层提供捕获驱动力但不提供桥三元组选择性（CT1）。Kd ≥ 10⁴ L/kg 为必要条件层（GC4），不计入选择性证据。

**第二层：攫氢碱-桥 β-H 反应性识别维（选择性来源之一）**

位阻碱（pKa 约 10–11）预组织朝向腔内，与 DDT 桥 β-H 几何互补。攫氢形成 C⁻···BH⁺ 离子对，在受限疏水腔内低介电环境中稳定化。DDE 无桥氢→不被攫取→无此维贡献。DDD 有桥氢（–CHCl₂）但 C-H 酸性更强（两个 Cl 吸电子），攫氢热力学更有利但 –CCl₃ 口袋不匹配（见下），双基序不协同。

**第三层：–CCl₃ 四面体卤键亚腔维（选择性来源之二）**

碘代三唑/硒醚卤键受体阵列几何匹配 –CCl₃ 三氯四面体 σ-hole 阵列。DDT –CCl₃ 呈三氯四面体排布（三个 Cl 在四面体顶点，σ-hole 朝向 Cl 延长线方向），与三个卤键受体形成几何依赖的 Cl···A 接触（C–Cl···A 角度约 150–180°，距离约 3.0–3.5 Å）。DDE =CCl₂ 呈双氯共面排布（仅两个 Cl，共面而非四面体），卤键图案不同（二点共面 vs 三点四面体），亚腔几何匹配差。DDD –CHCl₂ 为双氯四面体（两个 Cl），卤键图案为二点四面体（不同于 DDT 的三点四面体），匹配度介于 DDT 与 DDE 之间。

**第四层：双基序协同（核心赌注）**

双基序（攫氢碱 + –CCl₃ 口袋）共定位于同一腔内，DDT 同时接触两个功能单元时产生协同结合：攫氢使 DDT 锚定于腔内特定取向，–CCl₃ 口袋在该取向下实现最大卤键接触。协同增量 ΔΔG_dual > ΔΔG_base + ΔΔG_pocket 为核心赌注。若协同成立（2×2 因子交互作用项显著），D 维正交维度为三维（攫氢反应性 + 卤键几何 + 双基序协同），创新性充分。若协同不成立（交互作用项 ≈ 0），D 维退化为两维加和，仍通过 GC3 双维度要求但创新性削弱。

**对 logKow、电荷、分子量均非单调**：DDT/DDE/DDD logKow 差异 < 0.7、电荷全为零、MW 差异 < 40，双基序识别不依赖任何单一物化参数。

### 4.3 "捕获不转化"控制（核心设计假设）

**风险**：位阻碱攫取桥 β-H 后，碳负离子可能快速消除 Cl⁻ 生成 DDE（即催化 β-消除），材料从捕获性变为破坏性，且产物 DDE 更顽固（CT7）。

**控制策略**：
1. **碱强度调谐**：受阻胺 pKa 约 10–11 足以攫氢但不足以驱动消除（GSTe2 活性位点碱 pKa 更高且有多残基协同催化）；若 pKa 约 7–8 的弱碱（吡啶碱/π 碱）仍可产生可测结合信号，则"捕获不转化"更可信
2. **低温设计**：实验在 10–25 °C 进行，消除反应活化能垒高于攫氢，低温有利于捕获态稳定
3. **受限腔位阻**：COF 腔内空间受限，β-消除要求反式共平面 H-C-C-Cl 几何，受限腔可能阻止该构象排列
4. **产物谱监测**：GC-MS/MS 实时监测 DDE/DDD/DDMU 生成，若检出 DDE 生成则材料为破坏性而非捕获性，须重新定位

**诚实声明**："捕获不转化"为本方案最大化学可行性赌注。若阶段 0 或材料级实验检出显著 DDE 生成，方案须重定位为"反应性捕获-缓释"或终止。

### 4.4 报告口径

- 总干复合体 mg/g：识别位点理论单层容量按碱接枝量 0.05–0.2 mmol/g 估算为约 18–71 mg/g（DDT MW 354.5）
- 床层口径 mg/mL：COF 填充床堆积密度约 0.2–0.4 g/mL
- ng/L 工况下位点占据度极低，核心指标为 Kd 与 α 而非工作容量
- 可及位点密度以元素分析（N、Se、I）加 DDT 饱和滴定回算
- 空白载体贡献（M4）须独立测量并从选择性计算中扣除

### 4.5 再生机制

DDT 结合为可逆卤键 + 疏水 + 离子对（攫氢后），以低温极性溶剂（甲醇/乙腈，含 0.1% 甲酸以质子化碱位点）洗脱即可破坏结合并脱附，全程不进入 PCDD/F 生成温区（CT5）。诚实声明：再生为脱附回收而非破坏，DDT 进入溶剂流需二次处置。

## 5. 创新性清单 A-E 逐项自判

**A 机制创新**：通过。双基序门控（攫氢碱 + –CCl₃ 卤键口袋协同）超越普通疏水分配/静电/尺寸筛分；对桥三元组（DDT/DDE/DDD）产生非 logKow 单调的几何-反应性识别。"受限疏水腔内预组织位阻碱 + 卤键受体亚腔的双基序协同捕获"可被 2×2 因子对照直接证伪。核心保留：水相攫氢能垒与"捕获不转化"控制为未证赌注。

**B 材料架构创新**：部分通过。COF 为成熟平台（弱点），但双基序共定位于 COF 腔内的空间组织为新；2×2 因子对照设计提供协同量化方法学。合成路线方法学贡献中等（COF 后修饰为常规手段，但双功能共定位的位点控制为新）。改进方向：若 COF 合成困难，可换用离散有机笼或 HCP。

**C 仿生转译创新**：通过，附方向性限定。提取"双基序同时就位门控"架构原理（E1/E2/E3 背书），非蛋白复制；原型记载方向为催化消除，本方案反转为"捕获不转化"——此方向反转为独立设计假设，无原型背书，由碱强度调谐与低温设计支撑。T8 纪律保持（GSTe2 仅作原理级参考）。

**D 选择性策略创新**：通过，最强维度。三维正交：(i) 攫氢反应性（DDT/DDD 有桥氢 vs DDE 无），(ii) –CCl₃ 卤键几何（DDT 三氯四面体 vs DDE 双氯共面 vs DDD 双氯四面体），(iii) 双基序协同（仅 DDT 同时满足双基序）。桥三元组 logKow/电荷/MW 均近同而双基序识别差异大，单参数单调解释不成立。三层竞争物谱含结构近似物（GC2）。

**E 先例区分**：通过。DDT 反应性识别吸附剂零先例（G2）；双基序几何转译为水相吸附设计零先例。量化标尺：2×2 因子交互作用项 + α(DDE/DDT) ≥ 2.0 + 阶段 0 水相滴定 K。增量足以独立发表条件系于水相攫氢信号可测与"捕获不转化"成立。

**总判定**：A、C、D 三维展示明确创新性（D 最强），满足"至少一维明确创新"；B 部分通过已标注改进方向；E 通过。清单通过。

## 6. 台架合成 SOP 草图

### 步骤一：COF 骨架构建

TpPa-COF 或类似 β-ketoenamine COF 为骨架参考（已知高结晶度、水稳定性好）。

- 1,3,5-triformylphloroglucinol (Tp, 0.3 mmol) + p-phenylenediamine (Pa, 0.45 mmol)
- 溶剂：均三甲苯/1,4-二噁烷 (1:1 v/v, 6 mL)
- 条件：Pyrex 管密封，120 °C 溶剂热 72 h
- 后处理：离心，丙酮/乙醇洗涤各 3 次，120 °C 真空活化 12 h
- 表征：PXRD（确认晶态，与模拟图谱对照）、N₂ 吸脱附（BET 比表面积、孔径分布）、FT-IR（β-ketoenamine 特征峰 ~1580 cm⁻¹）、SEM/TEM

### 步骤二：功能单体引入（碱位点 + 卤键受体前体）

**路线甲（后修饰法）**：
- COF 骨架含残余醛基（Tp 单元未完全缩合位点），或经部分脱保护引入氨基
- 还原胺化接枝 4-amino-TEMPO（受阻哌啶胺自由基，后续还原为胺）或 N-Boc-4-piperidone 后脱保护
- CuAAC 点击化学接枝碘代三唑-羧酸（5-iodo-1H-1,2,3-triazole-4-carboxylic acid）于骨架炔基位点
- 硒醚变体：二苯硒醚-胺衍生物经酰胺偶联接枝

**路线乙（单体设计法，更优但合成更复杂）**：
- 设计含碱功能基团的二胺单体（如 N-(4-aminophenyl)-2,2,6,6-tetramethylpiperidin-4-amine），直接与 Tp 缩合
- 卤键受体在缩合后通过孔道内后修饰引入

**2×2 因子材料合成**：
- M1（碱+受体）：完整双功能化
- M2（碱 only）：仅碱功能化，卤键受体步骤跳过
- M3（受体 only）：仅受体功能化，碱步骤跳过
- M4（空白）：无功能化 COF

### 步骤三：表征

- 元素分析（C、H、N、Se、I）定功能基团载量
- 固态 ¹³C CP/MAS NMR 确认接枝
- FT-IR 确认特征官能团
- BET 确认接枝后孔道保留（孔径缩小但可及）
- XPS 确认表面元素组成与化学态
- 碱位点 pKa 测定：电位滴定或指示剂吸附法
- DDT 饱和滴定回算可及位点密度

### 步骤四：质量控制

- COF 结晶度：PXRD 主峰强度与模拟图谱匹配度 > 70%
- 接枝率：元素分析 N > 1.5 wt%（碱位点）、I > 3 wt% 或 Se > 2 wt%（受体位点）
- 孔道可及性：接枝后 BET 表面积 > 200 m²/g
- 无蛋白、无折叠肽

## 7. 实验与因果对照计划

### 7.1 阶段 0：模型化合物水相滴定（第一道 go/no-go）

**合成前进行，不经此关不合成材料。**

**模型碱**：
- 2,2,6,6-tetramethylpiperidine (TMP, pKa ~10.8)——位阻碱代表
- Tri-n-octylamine (TOA, pKa ~10.5)——非环受阻叔胺代表
- 4-(dimethylamino)pyridine (DMAP, pKa ~9.7)——π 碱代表
- Triethylamine (TEA, pKa ~10.7)——非位阻对照

**模型卤键受体**：
- 1-iodo-4-methylbenzene（碘代芳烃，σ-hole 强度中）
- 1,4-diiodotetrafluorobenzene（强 σ-hole）
- Diphenyl selenide（硒醚，强卤键受体）
- Pyridine N-oxide（弱卤键受体）

**模型客体**：
- DDT 类似物：1,1-diphenylethane（无氯，仅桥 β-H 探测碱结合）
- CCl₃ 类似物：chloroform（单 C-Cl，卤键受体探针）与 carbon tetrachloride（四 C-Cl，–CCl₃ 四面体探针）
- 完整 DDT 水溶度极低（约 1–5 µg/L，约 3–14 nM），直接滴定困难

**方法**：
- ¹H NMR 化学位移滴定（碱 NH/CH 与客体质子位移，25 °C）
- ITC 交叉验证（水相直接测量，DMSO 助溶剂 ≤ 2% 并做校正）
- UV-Vis 滴定（含生色团客体）

**go/no-go 线**：
- **go**：K(模型碱 + 模型客体) ≥ 10 M⁻¹（ΔG ≤ −5.7 kJ/mol），独立两批可重复
- **caution**：K 在 3–10 M⁻¹，进入合成但效应下限下压
- **terminate**：K < 3 M⁻¹ 或不可检（水相攫氢/卤键贡献化学上可忽略）

**碱强度梯度预期**：TMP ≈ TOA > DMAP > TEA（位阻碱 vs 非位阻碱的区分在于位阻碱攫氢后碳负离子稳定化而非碱强度本身）

**"捕获不转化"前置检验**：模型碱 + DDT（饱和浓度 ~5 µg/L）混合 24 h，GC-MS/MS 检测 DDE 生成。若检出 DDE > 5% 转化，则"捕获不转化"假设受质疑，须调整碱强度或终止。

### 7.2 材料级等温线与三元竞争

**竞争物谱（三层，GC2）**：

| 层级 | 竞争物 | 威胁等级 | 说明 |
|------|--------|---------|------|
| 第一层 | DDE（=CCl₂ 平面，无桥氢） | 极高 | 双基序门控核心对照 |
| 第一层 | DDD（–CHCl₂ 四面体，无 –CCl₃） | 极高 | 双基序门控核心对照 |
| 第一层 | o,p'-DDT（Cs 不对称） | 高 | 位置异构 |
| 第一层 | methoxy-DDT | 高 | 甲氧基可叠加氢键维 |
| 第二层 | Dieldrin | 高 | 非芳基笼状 OCP |
| 第二层 | PCB-209 | 高 | 疏水同系，体积更大 |
| 第二层 | β-HCH | 中 | 全氯环己烷 |
| 第三层 | 腐殖酸（HA） | 高 | NOM 疏水位点抢占 |
| 第三层 | DOC | 高 | 第三相分配竞争 |

**浓度三点**：
- 0.5–5 ng/L（一般流域溶解相，主目标场景）
- 50–200 ng/L（GB 3838 评价量级）
- 1–5 µg/L（WHO 准则值与非洲热点）

**基质**：
- 机制与因果对照：超纯水（规约 G9）
- 基质耐受性：二级出水加标
- 分析：GC-MS/MS 或 GC-ECD，单体分辨

### 7.3 因果对照（解耦双基序）

**核心对照（2×2 因子）**：

| 对照 | 目的 | 预期 |
|------|------|------|
| M1 vs M4（完整 vs 空白） | 双基序总增量 | M1 > M4，总增量 = ΔΔG_dual |
| M1 vs M2（受体有 vs 无） | –CCl₃ 口袋维贡献 | M1 > M2，口袋增量 = ΔΔG_pocket |
| M1 vs M3（碱有 vs 无） | 攫氢维贡献 | M1 > M3，攫氢增量 = ΔΔG_base |
| (M1−M4) vs (M2−M4)+(M3−M4) | 协同交互作用 | 若 > 加和则协同成立 |

**补充对照**：
- 碱强度梯度：受阻胺 (pKa 10–11) vs 吡啶碱 (pKa 5–6) vs 无碱
- 卤键受体强弱梯度：硒醚 > 碘代三唑 > 吡啶-N-氧化物 > 无受体
- 脂质归一化对照（GC1/CT4）：测各单体 Kow，材料选择性谱与 Kow 谱对比
- 产物谱监测：GC-MS/MS 检测 DDE/DDD/DDMU，量化"捕获不转化"程度
- 氯质量平衡（GC7）：液相 Cl⁻ 离子色谱 + 固相氯元素分析

### 7.4 再生、泄漏、稳定性

- **再生**：甲醇/乙腈（含 0.1% 甲酸）低温洗脱，5 循环以上，测 Kd 与 α 保留率
- **泄漏**：循环液 TOC 与骨架元素（C、N）监测，阈值 5 循环累计 < 5%
- **稳定性**：pH 5–9 水解稳定性，COF 骨架结晶度跨循环监测
- **床层**：ng/L 填充床穿透实验（报 BV、EBCT、mg/g 与 mg/mL、空白载体贡献）

## 8. 成功与失败判据（可证伪、可量化）

### 8.1 必要条件层（不计入选择性证据）

- Kd(DDT) ≥ 10⁴ L/kg（ng/L 驱动力门槛）
- 阶段 0 go 线通过（K ≥ 10 M⁻¹）
- "捕获不转化"：DDE 生成 < 5%（24 h 饱和浓度接触）

### 8.2 成功判据（须同时满足）

1. **双基序协同成立**（核心）：2×2 因子交互作用项 > 0 且统计显著（p < 0.05），即 ΔΔG_dual > ΔΔG_base + ΔΔG_pocket
2. **桥三元组选择性**：α(DDE/DDT) ≥ 2.0 且 α(DDD/DDT) ≥ 2.0（超纯水三元竞争，0.5–50 ng/L，n ≥ 3）
3. **碱解耦成立**：M1 vs M3（碱有 vs 无）差异显著，证明攫氢维独立贡献
4. **卤键受体解耦成立**：M1 vs M2（受体有 vs 无）差异显著，证明 –CCl₃ 口袋维独立贡献
5. **脂质归一化**：材料 DDT 选择性谱显著偏离 Kow 谱
6. **真实基质**：二级出水 α(DDE/DDT) ≥ 1.5（允许衰减）
7. **再生与稳定性**：5 循环后 Kd 与 α 保留 ≥ 80%
8. **氯质量平衡**：液相 Cl⁻ + 固相氯回收率 90–110%

### 8.3 失败判据

1. **阶段 0 失败**：K < 3 M⁻¹（不合成材料，角度终止或转 A05/A10 变体）
2. **双基序协同不成立**：交互作用项 ≈ 0（加和而非协同），D 维退化为两维加和，创新性削弱——不单独否决但须重建
3. **桥三元组选择性不足**：α(DDE/DDT) < 2.0 经 2 轮碱/受体优化无改善
4. **"捕获不转化"失败**：DDE 生成 > 20%（材料实际为破坏性，须重定位为反应性捕获或终止）
5. **Kd < 10⁴ L/kg**：ng/L 驱动力不足
6. **真实基质 α < 1.5**：不稳健

### 8.4 可测效应下限

双基序协同即便仅贡献 ΔΔG_dual ≈ 1.0–1.5 kJ/mol 额外稳定化，298 K 对应 α ≈ 1.5–1.8，叠加疏水本底（α_Kow 约 2–5）得总 α 约 3–9，已可被三元竞争分辨。低于 1.0 kJ/mol 即低于等温线拟合不确定度，判双基序贡献不可测。

### 8.5 灰区条款

α(DDE/DDT) 落于 1.5–2.0（有贡献但不足），须重建（碱强度调谐、亚腔几何精化、与 A03/A05 耦合）或终止，单槽至多 3 次重建（规约迭代政策）。

## 9. 自识别弱点

**弱点一（中心风险）：水相攫氢能垒**。位阻碱在水相固-液界面攫取 DDT 桥 β-H 的能垒为核心化学可行性赌注。GSTe2 活性位点为多残基协同催化（碱 + 疏水腔 + 底物取向），人工系统仅靠单一位阻碱可能不足以克服能垒。阶段 0 模型化合物滴定为第一道门，材料级产物谱监测为最终裁决。

**弱点二："捕获不转化"控制**。攫氢后碳负离子/离子对可能快速消除 HCl 生成 DDE，材料从捕获性变为破坏性。碱强度调谐（弱碱优先）、低温设计、受限腔位阻为三道控制，但均为设计假设而非已证结论。若 DDE 生成 > 5%，方案须重定位。

**弱点三：水相卤键削弱**。–CCl₃ 四面体亚腔内的卤键受体在水相中的净结合收益可能仅数个 kJ/mol（E8 Schneider 2009），竞争水化显著削弱。阵列协同（三点同时接触）可能补偿单点削弱，但为未证假设。

**弱点四：COF 合成复杂性**。双功能共定位（碱 + 受体）于 COF 腔内的合成控制为真正挑战；位点随机分布可能导致双基序无法同时就位。2×2 因子设计可量化协同，但合成可行性为 go/no-go 前置条件。

**弱点五：原型方向反转**。GSTe2 记载方向为催化消除（DDT → DDE），本方案反转为"捕获不转化"，此方向无原型背书。仿生转译 C 维因此趋薄——若"捕获不转化"被证伪，C 维仅余"双基序门控"架构原理。

**弱点六：ng/L 填充床动力学无先例**。DDT ng/L 水相吸附为零先例领域（G3），mg/L 批次不构成 ng/L 床层证据（T10）。床层寿命、传质、穿透行为均为高风险项。

**弱点七：第三相竞争**。吸附剂须与颗粒有机碳、DOC、脂质相竞争（CT4）。受限腔的有限体积可饱和性为理论优势，但实际优势须以脂质归一化对照量化证明。

**弱点八：模型客体外推间隙**。阶段 0 以 chloroform/CCl₄ 等小分子为卤键探针，对 DDT（大分子、低水溶度）为乐观外推；DDT 本征结合常数最终以材料级三元竞争为准。

**弱点九：氯质量平衡闭合**。涉及攫氢/消除反应路径，须闭合氯质量平衡（GC7）。若 Cl⁻ 释放显著，材料为破坏性而非捕获性。

**弱点十：碱位点质子化竞争**。环境 pH 约 6–8，位阻碱 pKa 约 10–11，部分质子化引入正电荷，可能促进阴离子 NOM 吸附（阳离子桥联）或改变攫氢能力。

## 10. 终止条件

按 EXEC_SPEC_DDT.md §7.3 通用终止条件：

1. 阶段 0 模型化合物水相滴定 K < 3 M⁻¹ 且经 2 轮碱强度优化无改善 → 角度终止
2. 材料级 α(DDE/DDT) < 2.0 经 2 轮优化无改善 → 角度终止
3. "捕获不转化"失败（DDE 生成 > 20%）且无法通过碱强度调谐解决 → 角度终止
4. 2 轮设计-攻击-裁决未通过（< 85 分或仍有 critical/high），经 3 次重建仍不通过 → 槽位终止

---

## 11. 与 A05 的互补关系预注册

A05（–CCl₃ 三氯四面体卤键阵列识别）为同污染物另一 S 级角度，与 A01 正交：A01 为反应性读出（攫氢碱），A05 为非共价卤键读出。若 A01 的攫氢维失败但 –CCl₃ 口袋维存活，可与 A05 耦合（A01 碱位点 + A05 卤键阵列）重建；反之亦然。两角度共享 –CCl₃ 亚腔化学但识别轴不同，失败模式分析可交叉受益。
