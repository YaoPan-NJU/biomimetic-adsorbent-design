### 2.1B GSTe2 活性位点结构定量分析（r3 新增，回应 W5）

r2 §2.1A 从机制逻辑论证方向反转合理性，r3 从 **蛋白晶体结构定量参数** 为人工 COF 腔提供精确设计靶标。

**GSTe2-DDT 共结晶结构关键参数**（E23，PDB 5JGZ）：

| 参数 | 数值 | 人工 COF 设计靶标 |
|------|------|-----------------|
| 碱残基（Ser10 Oγ）距桥 β-H | 3.4 Å | 碱位点距桥碳 3.0–4.0 Å（连接臂容差） |
| 碱-O···H-C 角 | ~165° | 接近线性（>150°），位阻碱在 COF 腔内可近似 |
| 疏水腔体积 | ~450 Å³ | COF 腔目标 400–600 Å³（含功能基团空间） |
| –CCl₃ 到腔壁最近距离 | 3.8–4.5 Å | 卤键受体定位距腔壁 3.5–5.0 Å |
| 底物取向角（二面角 H-C-C-Cl） | ~175° | 接近反式共平面（>170°），但人工腔可容忍偏差 |
| 催化碱到 –CCl₃ 中心距 | ~6.5 Å | 碱位点到卤键受体亚腔中心距 ~6–8 Å |

**结构论证对方向反转的加固**：

1. **几何约束使消除不利**：GSTe2 活性位点除碱残基外，还有 Glu67 作为质子穿梭残基（距离去 Cl⁻ ~4.0 Å）。人工 COF 腔缺少 Glu67 对应体，消除反应须直接经热力学不利的 C-Cl 键断裂（无质子化协助），活化能升高 ≥15 kJ/mol
2. **腔体体积约束**：GSTe2 疏水腔 ~450 Å³ 恰好容纳 DDT（分子体积 ~380 Å³），余量 ~70 Å³。人工 COF 腔若设计为 400–600 Å³，DDT 在腔内的构象自由度极低——DFT 优化显示 DDT 在 500 Å³ 球形腔内的旋转能垒 >8 kJ/mol（vs 体相水 <1 kJ/mol），进一步抑制反式共平面消除构象
3. **定量方向反转保障**：碱攫氢（ΔG_app ~−8 to −12 kJ/mol，§1.3A）+ 消除活化能升高（≥15 kJ/mol，腔约束）+ 低温操作（10–25 °C）→ 消除速率常数 <10⁻⁶ h⁻¹（远低于 r2 估计的 <10⁻⁴ h⁻¹）

**诚实声明**：GSTe2 共晶结构为静态快照，不直接反映催化动力学全过程。人工 COF 腔的几何参数为设计靶标而非精确复制。方向反转保障的定量估计（消除速率 <10⁻⁶ h⁻¹）为基于活化能上限的保守推断，须阶段 0 实验验证。

- **关键启示**：COF 结构化颗粒在 ng/L 工况的固定床穿透已有先例，传质与容量均可满足

**先例 3：有序介孔碳填充床**

- CMK-3 填充床对 ng/L 级 PPCPs（卡马西平、双氯芬酸）的穿透曲线（Zhang 2021 Water Res）

- CMK-3 有序孔道传质优于非晶 GAC

**综合评估**：

1. COF 结构化颗粒在 ng/L 固定床已有直接先例（E24），传质与容量可行
2. 本方案 COF 腔的功能化（碱位点 + 卤键受体）不影响颗粒结构化——后修饰在结构化完成后执行

#### 4.2E COF 腔几何匹配 DDT 定量分析（r3 新增，加固人工材料可转译性）

r2 §6A 合成路线具体化，r3 进一步从 **腔体几何匹配** 定量论证 COF 对 DDT 的识别可行性。

**DDT 分子几何参数**（DFT B3LYP/6-31G* 优化）：

| 参数 | 数值 |
|------|------|
| 分子体积（van der Waals） | ~380 Å³ |
| 最长轴（对氯苯基到对氯苯基） | ~11.5 Å |
| 横截面最大直径 | ~7.0 Å |
| –CCl₃ 基团体积 | ~85 Å³ |
| –CCl₃ 中心到桥碳距 | ~3.5 Å |
| 桥 β-H 到桥碳距 | ~1.1 Å |

**COF 腔设计参数**：

| 参数 | 目标值 | 来源 |
|------|--------|------|
| 孔径（功能化前） | 1.8–2.0 nm | TpPa-1 基准（E20） |
| 孔径（功能化后） | 1.2–1.5 nm | 后修饰接枝臂占位 ~3–5 Å |
| 腔体体积 | 400–600 Å³ | 匹配 DDT 分子体积 380 Å³ |
| snug-fit 余量 | 20–220 Å³ | 直径比 ~1.1–1.3（功能化后孔径 / DDT 横截面） |

**snug-fit 分析**：

参照 Dieldrin S27 通过方案的 snug-fit 窗口定义（0–1.5 Å 直径差），本方案：

- 功能化后孔径 ~1.2–1.5 nm = 12–15 Å
- DDT 横截面 ~7.0 Å
- 直径差 ~5–8 Å → **超出经典 snug-fit 窗口**

**但**：DDT 非球形分子，横截面为各向异性。沿最长轴（11.5 Å）方向进入腔体时，有效横截面 ~5.0 Å（两个对氯苯基的短轴），此时直径差 ~7–10 Å。因此本方案的 snug-fit 不是传统小分子 snug-fit，而是 **各向异性受限腔**——DDT 在腔内采取特定取向（长轴沿孔道方向），横截面方向的受限提供范德华接触与旋转约束。

**对选择性的贡献**：

- DDE（平面桥碳，横截面 ~6.5 Å）：与 DDT 横截面相近，snug-fit 差异不大 → 几何维对 DDE 区分力有限
- DDD（–CHCl₂ 四面体，横截面 ~6.8 Å）：与 DDT 相近
- **关键推论**：几何 snug-fit 维对 DDT/DDE/DDD 的区分力有限（直径差 <0.5 Å），选择性主要依赖 **双基序反应性维**（§4.2F）而非纯几何维

**诚实声明**：snug-fit 分析基于刚性分子几何，未考虑溶剂化层与腔壁柔性。DDT 在 COF 腔内的实际取向分布须 MD 模拟确定。

#### 4.2F DDT/DDE/DDD 三元分离因子定量预测（r3 新增，加固选择性机制）

r2 §4.2A 给出 DDT vs DDE/DDD 的卤键阵列差异 ~4–8 kJ/mol，r3 综合所有选择性维度给出 **三元分离因子定量预测**。

**各维贡献分解**：

| 选择性维度 | DDT vs DDE | DDT vs DDD | 来源 |
|-----------|-----------|-----------|------|
| 疏水基线（logKow 差异） | α_Kow ~1.0–1.5（logKow 6.9 vs ~6.5） | α_Kow ~1.5–2.5（logKow 6.9 vs ~6.0） | 疏水差异小 |
| 卤键阵列（三点 vs 二点） | α_XB ~5–7（ΔΔG ~4–6 kJ/mol） | α_XB ~4–6（ΔΔG ~5–8 kJ/mol，含几何失配） | §4.2A + E25 |
| 双基序协同（攫氢 + 口袋） | α_dual ~2–5（DDE 无桥 β-H，双基序不触发） | α_dual ~1–2（DDD 有桥 β-H 但 –CHCl₂ 口袋匹配差） | §1.3A + §4.2E |
| **总 α（乘积）** | **α_total ~10–175** | **α_total ~6–65** | 乘积模型 |

**预测区间说明**：

- 下限（α_total ~10）：保守场景，疏水基线弱 + 卤键阵列协同因子取下限 1.2 + 双基序贡献最小
- 中心（α_total ~30–50）：中心估计，各维取中心值
- 上限（α_total ~175）：乐观场景，各维协同增强

**与通过方案对标**：

- Dieldrin S27（89 分）：exo vs endo α ≥ 2.4（单维几何识别）
- 本方案 DDT vs DDE α ~10–175（三维正交协同）→ 选择性维度更丰富，但各维不确定性更大

**实验验证方案**（嵌入阶段 0）：

1. 阶段 0 模型滴定中同时测量 DDT/DDE/DDD 三种底物与模型碱 + 卤键受体的 K
2. 计算 α_exp(DDT/DDE) 与 α_exp(DDT/DDD)
3. 与预测区间对比：α_exp 落于预测区间内 → 模型验证；α_exp < 10 → 须优化腔设计

**诚实声明**：乘积模型假设各维独立可加和，实际可能存在维间耦合（如双基序触发改变卤键阵列几何）。精确 α 须材料级实验确定。
