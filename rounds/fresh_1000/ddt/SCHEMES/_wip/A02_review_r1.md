## 3. 能否达到 85？天花板分析

### 提分路径评估

| 修订动作 | 预期提分 | 可行性 |
|---|---|---|
| 补充 ng/L 动力学定量估算（基于 Heckel 2022 k₂ + 限域因子 + DDT 位阻修正） | +3–4 因果闭环 | 高（纯计算，不需实验） |
| 补充 DDE 还原电位 vs Co(I) 电位定量分析，排除或收窄 SET 风险 | +2–3 选择性机制 | 中（需检索 DDE 电化学文献） |
| 全文核验 Heckel 2022 + Kallman 1963 | +1–2 证据完整性 | 高 |
| 补充 DFT 能垒比较（Co(I)-N₄ 对 DDT vs DDE） | +2 因果闭环，+1 选择性 | 中（需计算化学） |
| 壳层传质定量估算 | +1 可转译性 | 高 |
| 原创性提升 | 0–1 | 低（先例密度为结构性约束） |

**乐观天花板**：66 + 4 + 3 + 2 + 2 + 1 + 1 = **79/100**。

**结论：A02 的天花板约 78–80，不可能达到 85。**

原因：
1. **原创性结构性天花板**（10–11/15）：Berry 1977/Shimakoshi 2004/Wang 2012 三重先例不可消除。即使四重交集全部实验证明，原创性也仅从"已知化学的新工况"提升至"已知化学的新设计原理"，不足以达到 13+/15。
2. **因果闭环的 ng/L 动力学**：即使补充定量估算，在 DDT 位阻效应下 k₂ 的不确定性跨越 2 个数量级，设计阶段无法消除——这是实验才能回答的问题。因果闭环天花板约 15–16/20。
3. **选择性机制的 SET 阴影**：即使定量分析表明 SET 在热力学上不利，Ding & Xu 2016 的 DDE 50.9% 转化数据始终存在，选择性声称只能收窄为"动力学偏好"而非"绝对惰性"。天花板约 19–20/25。

**85 分要求**：因果 17 + 选择性 21 + 可转译 17 + 原创 13 + 对照 9 + 证据 8 = 85。其中原创 13 和选择性 21 在 A02 框架内不可达。

## 4. A01→A02 轨迹（73→86）能否重复？

**不能。** 原因：

1. A01 的 r1→r2 提分（73→86，+13）核心来自：(a) Born 方程证明低介电腔去稳定 E2 极性过渡态（+因果闭环）；(b) 离散笼替代 HCP 解决精度问题（+可转译性）；(c) 全文核验补证据（+证据）。这些修订动作在 A02 中无对应物。
2. A01 的原创性为 14/15（零先例），r2 无需在原创性上提分。A02 的原创性天花板为 10–11/15，结构性低于 A01。
3. A01 的核心攻击（logKow 基线淹没）在 r2 被 Born 方程定量化解。A02 的核心攻击（ng/L 动力学）无法在设计阶段被定量化解——需要实验数据。
4. A01 r2 攻击为 0c/0h。A02 的 C1（动力学）和 H1（SET）在设计阶段无法完全消除。

**A02 的合理 r2 预期**：66→74–78（revise，仍不通过）。

## 5. 裁决

### 判定：**revise**（非 terminate）

理由：
- 方案科学方向正确（SN2 机制选择性为真正的化学识别维度）
- 与 A01 为真正不同的反应机制（不构成重复）
- 实验设计完备，可证伪性强
- DOI 无编造，证据诚实
- 设计者对风险的自我评估诚实（R1–R5 均有效）

不判 terminate 的理由：
- 核心问题（ng/L 动力学）可通过补充定量估算部分化解（即使结论为"边缘可行"，也比"完全未量化"好）
- SET 路径可通过电位匹配分析收窄
- 方案在修订后虽不能达 85，但可作为 DDT 设计空间中有价值的"有条件通过"方案记录

不判 pass 的理由：
- 1 CRITICAL + 2 HIGH 未决
- 独立评分 66/100，远低于 85 通过线
- 天花板分析表明即使充分修订也只能达 78–80

### 修订要求（若进入 r2）

1. **必须**：补充 ng/L 动力学定量估算（k₂ 外推 + 位阻修正 + 限域因子 + 表面反应修正），给出 24h 转化率的乐观/悲观/中位估计。
2. **必须**：补充 DDE 还原电位文献检索与 Co(I)-N₄ 电位匹配分析，定量评估 SET 路径热力学可行性。
3. **建议**：全文核验 Heckel 2022（获取对 DDT 类似物的 k₂ 数据或位阻讨论）。
4. **建议**：收窄选择性声称为"动力学偏好"（DDT/DDE 速率比 10–100）而非"绝对惰性"（10⁶–10⁸）。
5. **建议**：补充 Co(I) 电位调谐策略（给电子取代基使电位负移→增强还原力但增加 SET 风险；吸电子取代基反之）作为选择性优化维度。
