# 第一部分 设计者方案（第 2 轮）

# GenX A03 多酚醚离子载体反极性醚氧双锚点改性大环

污染物：六氟环氧丙烷二聚酸 GenX（HFPO-DA，全氟-2-丙氧基丙酸，CF3CF2CF2-O-CF(CF3)-COOH，C6HF11O3，分子量约 330）。靶标形态：环境 pH 下完全解离的单价全氟醚羧酸根阴离子。目标水质场景：市政二级出水及受纳水体（ng/L 级，10 ng/L 为美国 NPDWR 强制 MCL 阈值线，EPA 89 FR 32532）。口径约定：容量以总干复合体 mg/g 报告，床层以 packed-bed mg/mL 报告，附可及位点密度与空白载体贡献。

## 0. 与 A01 终止教训的系统对照

A01（score=36，terminate）的四重根本缺陷与本方案的规避策略：

| A01 缺陷 | 缺陷本质 | A03 规避策略 |
|---|---|---|
| 缺陷一：疏水机制近乎失效（logKow~0.5-1.5，活性炭容量仅 PFOA 的约 40%） | 单锚点（仅羧酸根头基），残余疏水退化为残余项 | **双锚点识别**：羧酸根头基 + 链内醚氧（-O-CF2-）协同锚定；醚氧为 GenX 区别于线性 PFCA 的独立识别柄，不依赖疏水贡献 |
| 缺陷二：中性脲供体在水相已知强结合四面体硫酸根（Gale 2015/Bondy 2004） | 单锚点体系中硫酸根为同构负债，无正交维度补偿 | **几何反差签名**：双锚点要求羧酸根与醚氧的空间图案同时匹配，硫酸根仅满足其一（几何失配于醚氧位），提供正交第二维度 |
| 缺陷三：氧阴离子洞原型稳定定域过渡态氧负离子，GenX 呈离域基态羧酸根 | 仿生保真度缺口，C 维边界态 | **原型切换**：从氧阴离子洞（定域 O⁻）切换到多酚醚离子载体（醚氧/羟基阵列配位多氧底物），后者天然识别含多氧原子的底物，保真度提升 |
| 缺陷四：中性供体阵列捕获强水合永久阴离子结合能上限不足 | 单锚点结合能可能不足以支撑 ng/L 级捕获 | **双锚点结合能叠加**：两个独立锚定位点各贡献结合能分量，总结合能 = 羧酸根锚定 + 醚氧锚定 + 协同项，高于单锚点 |

**核心区别一句话**：A01 仅识别羧酸根头基（一个锚定点），A03 同时识别羧酸根头基与链内醚氧（两个锚定点）。A01 不利用 GenX 最关键的分子特征（醚氧键），A03 将该特征反转为识别柄。

**A01 残余价值的继承**：A01 终止方案自身指出"GenX 应转 A03/A04 醚氧双锚点角度（设计自身指出 GenX 对线性短链 PFCA 的支链/醚氧几何区分属 A03/A04，A01 不利用链内醚氧故对 GenX vs PFBA/PFPeA/PFHxA 区分有限）"。本方案正是该方向的实现。

## 1. 科学问题与工程难题

**科学问题（SP-A03）。** GenX 分子含两个可识别特征——羧酸根头基（-COO⁻，静电与氢键识别的主把手）和链内醚氧（-O-CF2-，氢键受体且为还原条件下水合电子的优势攻击位，Bao 2018，doi:10.1021/acs.est.8b02172）。线性短链 PFCA（PFBA、PFPeA、PFHxA）共享羧酸根头基但不含链内醚氧。由此引出核心科学问题：

> 在 mM 背景阴离子存在下，一组预组织的双位点识别单元能否同时锚定羧酸根头基与链内醚氧，以双点几何匹配实现 GenX 相对线性短链 PFCA 独立于疏水贡献的选择性因子，并在 ng/L 级对 GenX 提供足以克服强水合罚能的总结合能。

该问题分解为四个子问题：

其一，**醚氧作为氢键受体的识别可行性**。GenX 的醚氧在还原降解中为水合电子的优势攻击位（Bao 2018），证明其电子密度可被外部供体接近；在多酚醚离子载体（monensin、nigericin）中，醚氧原子参与构成配位腔，通过氢键与配位作用稳定阳离子（Hüttel 2014，doi:10.3762/bjoc.10.34）。反极性转译：将阳离子配位腔转译为阴离子识别腔，醚氧位点从"配位阳离子的辅助"变为"识别全氟醚阴离子链内醚氧的氢键受体位"。该转译的可行性为可证伪假设。

其二，**双锚点的结合能叠加能否克服脱溶剂化罚能**。GenX 总脱溶剂化罚能 = 羧酸根脱溶剂化 + 醚氧脱溶剂化 + 全氟链疏水贡献（弱）。双锚点识别允许分步脱溶剂化：羧酸根先锚定（部分脱溶剂化），随后醚氧在预组织供体腔内完成剩余脱溶剂化。该分步策略是否降低总脱溶剂化罚能，属可证伪假设。

其三，**双锚点几何匹配对线性 PFCA 的区分**。GenX 的羧酸根-醚氧距离与角度由 α-CF3 支链与全氟醚骨架构型决定（DFT 优化几何，待计算标定）。线性 PFCA 无醚氧，仅满足羧酸根位点，在醚氧位点呈几何失配。两维度的正交性来自：羧酸根维度区分 GenX 与硫酸根（平面 vs 四面体），醚氧维度区分 GenX 与线性 PFCA（有醚氧 vs 无醚氧）。

其四，**大环预组织对双锚点几何的锁定**。β-环糊精或杯芳烃大环提供本征预组织腔体，脲/酰胺供体修饰于腔壁，使羧酸根锚定位与醚氧锚定位的空间距离与 GenX 的羧酸根-醚氧间距匹配。大环的构象锁定降低结合熵罚，但也限制对 GenX 构象异质体的适应性——该张力由实验裁定。

**工程难题（EP-A03）。** 把上述双锚点识别原理转译为可再生、可放大的大环-POP 复合吸附剂。具体工程命题：

- 超痕量背景（10 ng/L GenX 对 mM 硫酸根、mg/L DOC）下双锚点选择性因子能否维持；
- 大环修饰 POP 的合成可重复性与位点密度均匀性；
- 抗色谱置换：双锚点预组织多点锚定能否阻滞长链 PFOA 对已吸附 GenX 的置换（Wang 2019，简报陷阱 6）；
- 再生条件与脱氟耦合的二次废物最小化。

## 2. 生物原型与证据

**原型家族**：天然多酚醚离子载体（polyether ionophores），包括 monensin A/B、nigericin、lasalocid、salinomycin 等，主要由链霉菌属（Streptomyces）产生。原型核心机制：多酚醚骨架中的醚氧原子与羟基氧原子构成多齿配位阵列，通过氢键与配位作用选择性结合特定阳离子（K⁺、Na⁺、H⁺），其选择性由醚氧/羟基的空间排布与底物离子尺寸匹配决定（Hüttel 2014；Mercurio 1997）。

**反极性转译原理**：天然多酚醚离子载体利用醚氧阵列配位阳离子（正电荷底物）；本方案将该原则反极性转译——设计人工识别单元中的氢键供体阵列同时锚定阴离子的两个特征位点（羧酸根 + 醚氧），识别负电荷底物。转译距离诚实标注：离子载体配位阳离子是事实，转译为识别全氟醚阴离子的双锚点为工程假设，无直接生物先例。

## 3. 仿生对应矩阵

口径：生物特征 → 来源支持 → 材料实现 → 预期功能 → 测量 → 因果对照。硬对应两条（HC1 羧酸根锚定、HC2 醚氧锚定），原则级对应一条（HC3 双锚点协同几何匹配）。

### HC1（硬对应——羧酸根头基锚定位）

| 列 | 内容 |
|---|---|
| **生物特征** | 多酚醚离子载体（monensin）的羧酸根配位端：monensin 含一个游离羧酸基团，参与阳离子配位循环中的质子耦合释放；其羧酸根邻近的醚氧/羟基阵列构成多齿配位环境（Hüttel 2014，E1） |
| **来源支持** | E1（Hüttel 2014 综述 monensin 结构与配位机制）、E2（Mercurio 1997 构象研究） |
| **材料实现** | 大环（β-环糊精或杯[4]芳烃）孔壁修饰的脲基元（双 NH 供体对），几何匹配 GenX 羧酸根头基的平面双齿接受构型（O-C-O 约 120°，O···O 约 2.2 Å）；脲供体处于大环腔体提供的低介电局部环境 |
| **预期功能** | 以双点定向氢键锚定 GenX 羧酸根头基，贡献独立于疏水与静电的识别结合能分量 |
| **测量** | ¹⁵N 固态 NMR（脲 NH 负载前后化学位移变化）；ATR-FTIR Δν(NH)；ITC 结合焓（模型羧酸根底物如三氟乙酸根 vs 三氟甲磺酸根） |
| **因果对照** | **单锚点对照 M1-Me**：N,N'-二甲基脲阻断体（等立体，移除 NH 供体但保持骨架），若丧失羧酸根结合优势则证明脲双供体为载荷项；**几何错位对照 M1-geo**：脲供体间距不匹配羧酸根 O···O 距离的变体 |

### HC2（硬对应——醚氧锚定位，本方案核心创新对应）

| 列 | 内容 |
|---|---|
| **生物特征** | 多酚醚离子载体的醚氧配位阵列：monensin 与 nigericin 骨架含多个醚氧原子（-C-O-C-），这些醚氧作为氢键受体/配位原子参与构成离子配位腔，与特定离子尺寸匹配（Hüttel 2014，E1；Mercurio 1997，E2） |
| **来源支持** | E1（Hüttel 2014，醚氧阵列构成配位腔）、E2（Mercurio 1997，醚氧几何角色）、E3（Bao 2018，GenX 醚氧为水合电子优势攻击位，证明醚氧电子密度可被外部接近） |
| **材料实现** | 大环腔壁的第二组氢键供体，**r2 引入四级供体强弱序列**：(D1) 酰胺 NH；(D2) 脲 NH；(D3) 硫脲 NH；(D4) 方酰胺 NH。供体强度序列依据：Dieldrin S27 已验证脲 < 硫脲 < 方酰胺对环氧氧的氢键强度单调序列（89 分 pass），本方案类比应用于醚氧识别。空间位置匹配 GenX 链内醚氧（-O-CF2-）的几何构型；供体为醚氧提供双点氢键（NH···O-CF2），将 GenX 醚氧从“氢键受体”反转为“被氢键供体识别的位点” |
| **预期功能** | 锚定 GenX 链内醚氧，提供线性 PFCA（无醚氧）不具备的第二识别维度；与 HC1 协同给出 GenX 对 PFBA/PFHxA 的独立选择性因子。**r2 新增预期**：供体强弱序列应给出 GenX/PFHxA 选择性因子单调响应（D1 < D2 < D3 < D4），若序列不单调则醚氧氢键归因不成立 |
| **测量** | ¹⁹F NMR 化学位移变化（醚氧邻近 CF₂ 的 ¹⁹F 信号在负载前后位移，表征醚氧位点接触）；模型醚氧底物（二乙二醇二甲醚 vs 己烷）的竞争吸附差异；GenX vs PFHxA 选择性因子；**r2 新增**：供体强弱序列系列（D1/D2/D3/D4）的 GenX/PFHxA 选择性因子单调性检验 |
| **因果对照** | **醚氧缺失对照 M2-noEO**：以 PFHxA（线性 C6 PFCA，无醚氧）为底物，若 M1 对 PFHxA 的亲和力与对 GenX 相当或更高，则醚氧锚定位非载荷项；**供体移除对照 M2-des**：醚氧位点的供体 NH 换为 N-甲基取代（移除供体 NH），若 GenX 选择性下降而 PFHxA 不受影响，则醚氧位点供体为载荷项；**r2 新增：供体强弱序列对照 M2-series**：D1/D2/D3/D4 四级供体变体，报 GenX/PFHxA 选择性因子单调响应 |

### HC3（原则级对应——双锚点协同几何匹配）

| 列 | 内容 |
|---|---|
| **生物特征** | 多酚醚离子载体的多齿协同配位原则：monensin 对 K⁺ 的选择性来自 6 个氧原子（醚氧+羟基+羧酸根）的协同配位，单一位点的贡献不足以解释选择性，多齿协同为选择性来源（Hüttel 2014，E1） |
| **来源支持** | E1（Hüttel 2014，多齿协同原则）、E20（Warshel 2006，预组织降低结合熵罚）、E21（Busschaert 2015，疏水遮蔽腔体增强水相阴离子识别） |
| **材料实现** | β-环糊精/杯芳烃大环腔体同时承载羧酸根锚定位（脲）与醚氧锚定位（酰胺），两位点间距由大环骨架预固定，匹配 GenX 羧酸根-醚氧间距（DFT 优化，待标定）；腔体疏水壁提供脱溶剂化门控与残余疏水贡献 |
| **预期功能** | 双锚点协同给出超加和结合能（ΔΔG_dual > ΔΔG_carboxylate + ΔΔG_ether），即协同项为正；同时以几何匹配给出 GenX 对线性 PFCA 与硫酸根的双重选择性 |
| **测量** | GenX、PFHxA、PFBA、硫酸根的系统等温吸附与 ITC 焓熵分解；双锚点变体 vs 单锚点变体的结合能差给出协同项；变温吸附 van't Hoff 分析 |
| **因果对照** | **间距错位对照 M3-spacing**：改变大环上两位点间距（如换用不同尺寸杯芳烃或不同 rim 修饰的环糊精），若间距偏离 GenX 最优值时选择性下降，则几何匹配为载荷项；**单锚点加和对照**：物理混合单锚点材料（仅羧酸根脲 + 仅醚氧酰胺），若选择性低于双锚点一体材料，则协同为载荷项 |

### 对应边界声明

1. **反极性转译距离**：多酚醚离子载体配位阳离子（K⁺/Na⁺），本方案转译为识别阴离子（GenX 羧酸根+醚氧）。自然界不存在以醚氧阵列识别全氟醚阴离子的进化原型。HC2 的“硬”指其为带因果对照的坚定设计承诺，不指生物功能同源。原型提供的是“多氧底物的多齿几何匹配”设计原则，而非具体识别化学。
2. **HC1 与 A01 的区别**：HC1 虽也锚定羧酸根，但在 A03 中 HC1 是双锚点体系的一部分，不单独承担选择性；HC2（醚氧锚定）提供正交第二维度。A01 仅依赖 HC1 类似机制而失败，A03 通过双锚点规避 A01 的单锚点缺陷。
3. **C 维诚实标注**：多酚醚离子载体的“多齿几何匹配”原则为通用超分子设计原则（Cram/Lehn），非原型特异提取；反极性转译（阳离子配位→阴离子双锚点识别）为受启发的工程假设，非原型直接转译。创新清单 C 维预期判为不通过（诚实标注），与 PFOA A02 处理方式一致。
4. **r2 精确化——转译边界分层**：明确区分「有生物先例部分」与「工程外推部分」：
   - **有生物先例部分**：多酚醚离子载体的醚氧/羟基阵列构成多齿配位腔，通过几何匹配选择性结合特定底物（Hüttel 2014，E1）——此为事实
   - **工程外推部分**：(a) 将阳离子配位腔反转为阴离子识别腔；(b) 将“多氧底物”范围从天然含氧有机底物扩展到全氟醚羧酸阴离子；(c) 将酶活性位精度转译为大环-POP 腔壁供体阵列。三项外推均无直接生物先例
   - **r2 收窄声称**：不声称“反极性转译”为仿生原型特异提取，仅声称“多氧底物多齿几何匹配”为通用设计原则的工程应用。C 维维持不通过判定

## 4. 材料架构与选择性机制

### 4.1 载体选择：大环-POP 复合体

**主平台**：脲/酰胺双功能化 β-环糊精交联多孔有机聚合物（β-CD-UAm-POP）。

选择理由：
- β-环糊精提供本征预组织锥形腔（上口径约 6.0 Å，下口径约 5.7 Å，腔深约 7.8 Å），rim 羟基可功能化为脲/酰胺供体；
- Weiss-Errico 2017（E5）已证明环糊精可包合全氟醚羧酸，19F NMR 机制证据支持环糊精腔对全氟醚链段的容纳能力；
- 交联 POP 格式提供高比表面积与工程颗粒形态，避免环糊精单独使用时的水溶性与回收问题；
- 材料复杂度定位：二级优先（多孔聚合物/大环），优于 MOF/蛋白，符合 G6 约束。

**备选平台**：杯[4]芳烃-脲/酰胺功能化共价三嗪框架（CTF-Calix-UAm）。杯芳烃提供可调腔径与刚性预组织，CTF 骨架提供化学稳定性与高比表面积。

### 4.2 识别单元设计

**双功能供体单体**（草稿结构，待 DFT 优化；r2 修订引入供体强弱序列）：

以 β-环糊精为起点：
1. **初级修饰（rim 脲化）**：β-CD rim 羟基经胺连接体（如 N-(2-氨乙基)胺乙基）与芳基异氰酸酯反应，引入脲基元（双 NH 供体对），作为羧酸根锚定位（HC1）。
2. **次级修饰（腔壁供体化——r2 四级供体强弱序列）**：β-CD 腔壁仲羟基分别功能化为以下四级供体：
   - **D1 变体**：酰胺化（如与 4-羧基苯甲酰氯反应），酰胺 NH 作为醚氧锚定位（r1 基线）
   - **D2 变体**：脲化（如与苯基异氰酸酯反应），脲双 NH 供体对（中等强度）
   - **D3 变体**：硫脲化（如与苯基异硫氰酸酯反应），硫脲双 NH 供体对（较强，因 S 极化率增强 NH 酸性）
   - **D4 变体**：方酰胺化（如与 3,5-双(三氟甲基)苯基方酰胺反应），方酰胺双 NH 供体对（最强，pKa ≈ 3.5–4.5）
   供体强度序列依据：Dieldrin S27 已验证脲 < 硫脲 < 方酰胺对环氧氧的氢键强度单调序列（89 分 pass）
3. **交联**：修饰后的 β-CD 与二异氰酸酯（如 4,4'-二苯基甲烷二异氰酸酯 MDI）或环氧氯丙烷交联，形成不溶性 POP 颗粒

**r2 合成简化策略**：若 rim 与腔壁修饰反应正交性允许，尝试一步共修饰策略（rim 脲化 + 腔壁供体化同时进行），减少合成步骤。或采用预合成双功能化单体（同时含 rim 脲与腔壁供体基团）后交联策略。。

**位点间距标定**（阶段 −1 前置计算；r2 增强）：
- GenX 分子构象分析：DFT 优化（B3LYP/6-311+G(d,p)，水相 PCM 模型），提取羧酸根中心到醚氧原子的距离（估计约 4-6 Å，取决于构象），**r2 新增**：报优势构象分布（不只单一最优构象），为位点间距设计提供构象系综输入
- β-CD rim 到腔壁的可用距离（约 3-7 Å，取决于连接体长度）
- **r2 新增：分段容纳策略**：GenX 全长约 10-12 Å，β-CD 腔深约 7.8 Å。策略：羧酸根头基在 rim 脲位锚定（HC1），醚氧链段在腔壁/腔内供体位锚定（HC2），全氟尾链（-CF3）伸出腔外。该分段策略使双锚点均在可达范围内，但全氟尾链的疏水贡献可能因部分暴露而减弱
- 匹配度由阶段 −1 DFT/MM 预筛裁定，连接体长度作为可调参数。

### 4.3 选择性机制三层次

**机制 A：脱溶剂化门控（物理基底，必要非创新）**

与 PFOA A02 的机制 A 平行。GenX 进入大环疏水腔须付脱溶剂化罚能：
- 羧酸根脱溶剂化：水合自由能约 −365 kJ/mol（乙酸根为代理，Marcus 1991，E5 引自 PFOA A02）；
- 醚氧脱溶剂化：醚氧水合较弱（醚氧为弱氢键受体，水合自由能估计 −20 至 −40 kJ/mol，推断值待核验），脱溶剂化罚能低于羧酸根；
- 大环疏水腔提供低介电环境，降低离子入孔后的介电罚能（E20 Warshel 2006）。

二价硫酸根（约 −1080 kJ/mol）的总脱溶剂化罚能约为 GenX 的 2-3 倍，被排斥于疏水腔外。本机制为中性疏水腔材料的共有性质，单独不构成创新。

**机制 B：羧酸根锚定（HC1，承 A01 遗产但非独立选择性来源）**

脲双 NH 供体对与 GenX 羧酸根头基的平面双齿氢键（O-C-O 约 120°）。该锚定提供基础结合能但不提供对硫酸根或线性 PFCA 的选择性——对硫酸根的几何区分承 A01 教训（脲供体对硫酸根亦强结合），对线性 PFCA 无区分（共享羧酸根头基）。机制 B 的角色是"必要锚定桩"，非选择性来源。

**机制 C：醚氧锚定（HC2，核心创新选择性来源；r2 修订）**

r1 使用酰胺 NH 供体（D1）与 GenX 链内醚氧（-O-CF2-）的双点氢键。r2 引入四级供体强弱序列（D1 酰胺 < D2 脲 < D3 硫脲 < D4 方酰胺），以更强供体提升醚氧锚定结合能上界。该锚定提供两个正交选择性维度：

维度一（对硫酸根）：硫酸根无醚氧特征，在醚氧锚定位完全失配；硫酸根仅满足机制 A 的脱溶剂化排斥 + 机制 B 的羧酸根位竞争（几何失配于脲双供体对），双锚点体系对硫酸根的选择性 = 机制 A 排斥 × 机制 B 几何失配 × 机制 C 完全失配，三重排斥。

维度二（对线性 PFCA）：PFBA/PFHxA 无醚氧，仅满足机制 B 的羧酸根锚定，在机制 C 完全缺失；GenX 同时满足机制 B + C，结合能差 = 醚氧锚定贡献 + 可能的协同项。该维度为 A03 相对 A01 的核心增量。**r2 新增**：供体强弱序列（D1 < D2 < D3 < D4）应给出 GenX/PFHxA 选择性因子单调递增，若序列不单调则醚氧氢键归因不成立（类比 Dieldrin S27 供体序列方法）

**总选择性轮廓**：
- GenX 对硫酸根：选择性来自机制 A+B+C 三重排斥（预期高选择性因子）；
- GenX 对线性 PFCA（PFBA/PFHxA）：选择性来自机制 C（醚氧锚定，独立于疏水贡献）；
- GenX 对 PFOA：选择性来自机制 C（PFOA 无醚氧）+ 机制 A 的尺寸排斥（PFOA 全氟碳链较长，可能受腔径限制）；
- 选择性轮廓为"GenX 偏好"，明确不主张对全部 PFAS 的广谱优势。

## 5. 创新性检查清单 A-E 逐项自判

**A 机制创新：有条件通过→r2 增强。**
选择性机制超越普通疏水分配/静电吸附/尺寸筛分：提出双锚点识别（羧酸根+醚氧）作为 GenX 对线性 PFCA 的正交选择性来源。醚氧锚定维度在 GenX 吸附领域无先例。扣分项：醚氧作为氢键受体的结合能可能偏弱。r2 缓解：引入四级供体强弱序列（D1 酰胺 < D2 脲 < D3 硫脲 < D4 方酰胺），以更强供体提升醚氧锚定结合能上界，并提供因果单调性验证。据实判为有条件通过。

**B 材料架构创新：有条件通过→r2 增强。**
大环-POP 双功能化（脲+供体双位点）构成新的空间组织方式；等骨架因子系列扩展至包括 M1-D2/D3/D4 供体强弱序列变体（r2 新增），提供完整因果拆解 + 机制单调性验证。扣分项：β-CD 交联 POP 为已知平台，新颖性限于双功能化部署 + 供体序列部署。

**C 仿生转译创新：不通过（诚实标注，r2 精确化）。**
“多氧底物的多齿几何匹配”为通用超分子原则（Cram/Lehn），非多酚醚离子载体特异提取。r2 精确化：§3 对应边界声明新增第 4 条，明确区分「有生物先例部分」与「工程外推部分」，收窄声称范围。C 维维持不通过判定。

**D 选择性策略创新：通过→r2 增强。**
两个正交选择性维度：(1) 羧酸根锚定区分 GenX 与硫酸根；(2) 醚氧锚定区分 GenX 与线性 PFCA。r2 增强：供体强弱序列（D1-D4）提供选择性来源的因果单调性验证——若序列不单调则醚氧氢键归因不成立，为比 r1 更严格的证伪设计。

**E 先例区分：有条件通过→r2 增强。**
r2 新增 E27（Wang 2020 GenX 降解动力学）进一步支持醚氧作为识别把手的独特性。Weiss-Errico 2017 与本方案的区分更明确（§11 弱点 4）。

**总判定**：D 通过，A/B/E 有条件通过，C 不通过（诚实标注）。满足"至少一维明确创新"准入门。

## 6. 台架合成 SOP 草图

### 6.1 主平台 β-CD-UAm-POP

**材料与试剂**（分析纯级）：β-环糊精（β-CD）；4,4'-二苯基甲烷二异氰酸酯（MDI）或环氧氯丙烷（交联剂）；N-(2-氨乙基)胺乙基异氰酸酯或对应胺（rim 脲化）；4-异氰酸酯基苯甲酰氯或 4-羧基苯甲酰氯（腔壁酰胺化）；无水 DMF、吡啶、THF、去离子水。

**步骤**（草稿，参数待优化）：

1. **β-CD 初级修饰（rim 脲化）**：β-CD（10 mmol）溶于无水 DMF（50 mL），加 N-(2-氨乙基)胺乙基异氰酸酯（20 mmol），60°C N₂ 12 h。旋蒸除溶剂，乙醇洗，得 rim-胺化 β-CD-NH₂。取产物（5 mmol）溶于无水 DMF，加苯基异氰酸酯（12 mmol），室温 N₂ 6 h，得 rim-脲化 β-CD-U。

2. **次级修饰（腔壁酰胺化）**：β-CD-U（3 mmol）溶于无水吡啶（30 mL），冰浴下滴加 4-异氰酸酯基苯甲酰氯（10 mmol），缓慢升温至室温，N₂ 12 h。得双功能化 β-CD-UAm。

3. **交联成 POP**：β-CD-UAm（2 mmol）与 MDI（8 mmol）在无水 DMF（20 mL）中混合，80°C N₂ 24 h。产物研磨、索氏提取（DMF/乙醇/水各 12 h），60°C 真空干燥，得 β-CD-UAm-POP。

4. **对照材料同步制备**：
   - M0：β-CD 直接与 MDI 交联（无脲/酰胺修饰）
   - M1-Me：rim 脲化使用 N,N'-二甲基苯基脲衍生物
   - M1-desEO：腔壁酰胺使用 N-甲基-4-异氰酸酯基苯甲酰氯
   - M1-U-only：仅步骤 1（rim 脲化），跳过步骤 2
   - M1-Am-only：仅步骤 2（腔壁酰胺化），跳过步骤 1
   - QA-ref：rim 修饰改为缩水甘油基三甲基氯化铵

### 6.2 表征

BET/BJH 与孔径分布；元素分析（N 含量，位点密度 mmol/g）；ATR-FTIR（脲 C=O 1640-1660 cm⁻¹、酰胺 C=O 1650-1680 cm⁻¹、NH 约 3300 cm⁻¹）；¹³C 固态 NMR；TGA（修饰载量）；XPS N1s；zeta 电位（确认近中性）；SEM/TEM 形貌。

## 7. 实验与因果对照计划

### 7.1 阶段 −1：计算预筛与模型验证（台上架前判决）

1. **GenX 分子几何优化**：DFT（B3LYP/6-311+G(d,p)，水相 PCM）提取羧酸根中心到醚氧的距离与角度分布（优势构象），为位点间距设计提供输入。
2. **双锚点复合物 DFT**：模型脲-酰胺双供体 + GenX 阴离子，报 NH···O 距离、结合能、与单供体分别结合的能量差（协同项上界估计）。
3. **模型醚氧底物结合序**：¹H NMR 滴定（D₂O 或 D₂O/10% DMSO-d₆），模型双供体对二乙二醇二甲醚（醚氧代理）vs 己酸根（羧酸根代理）vs 乙酸根的结合序。

### 7.2 阶段 0：机制预实验（超纯水）

1. **等温线**：M0、M1、**M1-D2、M1-D3、M1-D4**（r2 新增供体序列变体）、M1-Me、M1-desEO、M1-U-only、M1-Am-only、M1-phys-mix、QA-ref，GenX 10 ng/L 至 10 mg/L 六点以上跨度，ng/L 段 LC-MS/MS 在线 SPE 测定。
2. **结构近似物竞争**：PFBA、PFPeA、PFHxA（线性短链 PFCA，无醚氧）；TFA、PFPrA（GenX 降解中间体）；ADONA；PFOA。等摩尔与真实稀释比两种配比。
3. **无机阴离子梯度**：SO₄²⁻ 0/0.1/1/5 mM；HCO₃⁻、Cl⁻、NO₃⁻ 按二级出水水平。
4. **因果归因**：
   - 羧酸根锚定贡献 = M1-U-only − M0
   - 醚氧锚定贡献 = (M1 − M1-U-only) − (M1-Am-only − M0)（交互项为协同）
   - 协同项 = M1 − (M1-U-only + M1-Am-only − M0)
   - 预组织贡献 = M1 − M1-phys-mix（一体材料 vs 物理混合）
   - **r2 新增：供体强弱序列因果单调性** = M1-D1 < M1-D2 < M1-D3 < M1-D4 的 GenX/PFHxA 选择性因子单调递增
5. **焓熵分解**：ITC（模型底物 + POP），多温度等温线 van't Hoff。

### 7.3 阶段 1：真实基质与工程

1. **真实基质**：市政二级出水（DOM 分组分：<3 kDa、HON、全 NOM）；加标回收与竞争物谱。
2. **床层**：RSSCT 或微型固定床，EBCT 5/10/30 min，进水 GenX 50 ng/L + 背景 PFAS 谱，穿透终点 10 ng/L（MCL），报 BV 与 packed-bed mg/mL。
3. **抗色谱置换**：混合 PFAS 进料（GenX + PFOA），测 GenX 穿透曲线，与 QA-ref 与 M1-U-only 比较（双锚点是否阻滞置换）。
4. **再生**：MeOH 溶剂竞争（主）+ MeOH/饱和 NaCl（辅），5 循环。
5. **泄漏与稳定性**：每循环出水测 β-CD 碎片、脲/酰胺水解产物、总有机氮；pH 4-10 水解稳定性 90 天加速。

## 8. 成功与失败判据

### 成功判据（须同时满足核心项）

S1. M1 在 1000 ng/L 超纯水中 GenX 容量 q ≥ 0.1 mg/g 干复合体（设计阈值，待实测标定），扣除 M0 空白后净识别贡献显著。

S2. M1 对 GenX 的亲和力（Kd）显著高于 M1-U-only（仅羧酸根锚定），差异归因于醚氧锚定贡献（核心声称）。

S3. M1 的 GenX/PFHxA 选择性因子（分布系数比）≥ 3，且 M1-desEO 的选择性因子回落至 ≤ 1.5（醚氧锚定位为载荷项）。

S4. 1 mM 硫酸盐下 M1 的 SF(GenX/SO₄²⁻) ≥ 10，且高于 QA-ref 的 SF。

S5. 协同项 > 0：M1 的结合能 > M1-U-only + M1-Am-only − M0（一体双锚点优于单锚点加和）。

S6. 混合 PFAS 床层中 M1 的 GenX 穿透 BV 不低于 QA-ref，且 GenX/PFOA 共进料下 GenX 早穿透被双锚点阻滞。

S7. 再生回收率 ≥ 80%，5 循环容量保持 ≥ 75%。

**S2-series（r2 新增）**：供体强弱序列 M1-D1 / M1-D2 / M1-D3 / M1-D4 对 GenX/PFHxA 选择性因子单调递增（D1 < D2 < D3 < D4）。若序列不单调，则醚氧氢键归因不成立，需诊断原因。

### 失败判据（任一即证伪或收缩）

F1（醚氧锚定证伪）：M1 与 M1-U-only 对 GenX 的亲和力无显著差异，或 M1-desEO 的选择性因子不回落，则醚氧锚定位非载荷项，A03 核心主张坍塌，收缩为 A01 变体（应终止）。

F2（协同项证伪）：M1 的结合能 ≤ M1-U-only + M1-Am-only − M0（无协同或负协同），双锚点协同主张坍塌；若此时 M1-U-only 单独亦不满足 A01 遗留的选择性要求，则方案终止。

F3（硫酸盐过结合）：1 mM 硫酸盐下 M1 的 GenX Kd 下降 >80%，或 SF(GenX/SO₄²⁻) ≤ 1，则脱溶剂化门控失效，与 A01 同构负债。

F4（基质崩溃）：二级出水中 GenX Kd 低于超纯水的 20%，或 DOM 使 Kd 降幅 >50%。

F5（工程不达标）：EBCT 10 min 下 50 ng/L 进料 10 ng/L 穿透 <200 BV。

F6（合成失败）：双功能化 β-CD-POP 不可重复或位点密度低于检测限。

**F7（r2 新增：供体序列不单调）**：M1-D1/D2/D3/D4 的 GenX/PFHxA 选择性因子不呈单调递增，则醚氧氢键归因不成立。若 D4 反降，诊断是否为空间排斥/过度结合/非氢键机制。若全不单调，则 HC2 机制主张坍塌，方案终止。

## 11. 自识别弱点

1. **醚氧锚定结合能可能偏弱**：醚氧为弱氢键受体（相比羧酸根氧），酰胺 NH 对醚氧的氢键强度在水相中可能不足以提供显著选择性增量。这是 A03 最本征的热力学风险。缓解：阶段 −1 DFT 预筛提供结合能上界估计，若上界 <2 kcal/mol 则提前预警。**r2 缓解升级**：引入醚氧位供体强弱序列（酰胺 NH < 脲 NH < 硫脲 NH < 方酰胺 NH），以更强供体提升醚氧锚定结合能上界（§4.2/§4.3 r2 修订）。

2. **反极性转译距离大**：多酚醚离子载体配位阳离子，转译为识别阴离子为工程外推，无直接生物先例。C 维诚实标注不通过。**r2 精确化**：§3 对应边界声明 r2 修订，明确区分「有生物先例部分」（多氧底物多齿几何匹配原则）与「工程外推部分」（反极性转译），收窄声称范围。

3. **大环腔尺寸匹配不确定性**：β-CD 腔径（约 6 Å）对 GenX 分子（全长约 10-12 Å）可能仅部分容纳，双锚点位的空间可达性依赖连接体优化，存在合成不可达风险。**r2 缓解**：§4.2 引入 GenX 构象分析前置任务 + 分段容纳策略（羧酸根头基在 rim 脲位锚定，醚氧链段在腔壁/腔内酰胺位锚定，全氟尾链伸出腔外）。

4. **先例邻近风险**：Weiss-Errico 2017 环糊精-全氟醚羧酸 19F NMR 已触及环糊精-全氟醚相互作用，虽仅为机制证据无吸附平台，但若其已报道醚氧参与的线索，增量可能收窄。**r2 区分**：Weiss-Errico 2017 为环糊精天然腔对全氟醚链段的非特异包合（¹⁹F NMR 位移变化），无醚氧特异识别声称、无吸附平台、无选择性因子；本方案为人工双功能化大环-POP 的醚氧特异锚定，增量明确。

5. **A01 阴影**：A03 的羧酸根锚定维度（HC1）与 A01 机制高度重叠。若醚氧锚定（HC2）被证伪，A03 将退化为 A01 变体，应继承 A01 的终止结论。**r2 强化**：F1 失败判据前置——若 S2 实验中 M1 与 M1-U-only 对 GenX 亲和力无显著差异，立即启动 A01 终止继承程序，不做额外迭代。

6. **合成复杂度**：双功能化大环-POP 的合成路线多步、位点密度与均匀性控制困难，可能影响可重复性。**r2 简化**：§6.1 合成路线优化——将两步修饰合并为一步共修饰策略（若rim/腔壁反应正交性允许），或采用预合成双功能化单体后交联策略。

7. **ng/L 传质瓶颈**：大环-POP 的颗粒内扩散在 ng/L 级极低驱动力下可能先于平衡选择性成为限制（简报陷阱 6、工程难题 EC1）。**r2 缓解**：§7.3 阶段 1 增加分级孔道策略（大孔传质通道 + 介孔/大环识别位点）。

8. **定量阈值的性质**：第 8 节多数阈值为待测设计规格，非已验证事实；pKa（约 0-1 或约 3.05）与 logKow（约 0.5-1.5）引简报标注待核验。

---

> **方案定位总结**：GenX A03 以多酚醚离子载体的多齿几何匹配原则为仿生启发，提出羧酸根+醚氧双锚点识别策略，核心创新在于将 GenX 的链内醚氧从“亲水弱点”反转为“识别柄”，以独立于疏水贡献的正交维度区分 GenX 与线性 PFCA。方案定位为机制确证型研究——基线预测为双锚点协同可能不显著（先验中等偏低），若实验证实协同则确立新识别原理，若证伪则交付醚氧锚定对全氟醚阴离子选择性的机制解耦论文（S_deconvolution），与 PFOA A02 的负结果交付模式一致。
