# 第一部分 设计者方案（第 3 轮）

# GenX A03 多酚醚离子载体反极性醚氧双锚点改性大环

污染物：六氟环氧丙烷二聚酸 GenX（HFPO-DA，全氟-2-丙氧基丙酸，CF3CF2CF2-O-CF(CF3)-COOH，C6HF11O3，分子量约 330）。靶标形态：环境 pH 下完全解离的单价全氟醚羧酸根阴离子。目标水质场景：市政二级出水及受纳水体（ng/L 级，10 ng/L 为美国 NPDWR 强制 MCL 阈值线，EPA 89 FR 32532）。口径约定：容量以总干复合体 mg/g 报告，床层以 packed-bed mg/mL 报告，附可及位点密度与空白载体贡献。

## 0. 与 A01 终止教训的系统对照

A01（score=36，terminate）的四重根本缺陷与本方案的规避策略：

| A01 缺陷 | 缺陷本质 | A03 规避策略 |
|---|---|---|
| 缺陷一：疏水机制近乎失效（logKow~0.5-1.5，活性炭容量仅 PFOA 的约 40%） | 单锚点（仅羧酸根头基），残余疏水退化为残余项 | **双锚点识别**：羧酸根头基 + 链内醚氧（-O-CF2-）协同锚定；醚氧为 GenX 区别于线性 PFCA 的独立识别柄，不依赖疏水贡献 |
| 缺陷二：中性脲供体在水相已知强结合四面体硫酸根（Gale 2015/Bondy 2004） | 单锚点体系中硫酸根为同构负债，无正交维度补偿 | **几何反差签名**：双锚点要求羧酸根与醚氧的空间图案同时匹配，硫酸根仅满足其一（几何失配于醚氧位），提供正交第二维度 |
| 缺陷三：氧阴离子洞原型稳定定域过渡态氧负离子，GenX 呈离域基态羧酸根 | 仿生保真度缺口，C 维边界态 | **原型切换**：从氧阴离子洞（定域 O⁻）切换到多酚醚离子载体（醚氧/羟基阵列配位多氧底物），后者天然识别含多氧原子的底物，保真度提升 |
| 缺陷四：中性供体阵列捕获强水合永久阴离子结合能上限不足 | 单锚点结合能可能不足以支撑 ng/L 级捕获 | **双锚点结合能叠加**：两个独立锚定位点各贡献结合能分量，总结合能 = 羧酸根锚定 + 醚氧锚定 + 协同项，高于单锚点 |

**核心区别一句话**：A01 仅识别羧酸根头基（一个锚定点），A03 同时识别羧酸根头基与链内醚氧（两个锚定点）。A01 不利用 GenX 最关键的分子特征（醚氧键），A03 将该特征反转为识别柄。

**A01 残余价值的继承**：A01 终止方案自身指出"GenX 应转 A03/A04 醚氧双锚点角度"。本方案正是该方向的实现。

## 1. 科学问题与工程难题

**科学问题（SP-A03）。** GenX 分子含两个可识别特征——羧酸根头基（-COO⁻，静电与氢键识别的主把手）和链内醚氧（-O-CF2-，氢键受体且为还原条件下水合电子的优势攻击位，Bao 2018，doi:10.1021/acs.est.8b02172）。线性短链 PFCA（PFBA、PFPeA、PFHxA）共享羧酸根头基但不含链内醚氧。由此引出核心科学问题：

> 在 mM 背景阴离子存在下，一组预组织的双位点识别单元能否同时锚定羧酸根头基与链内醚氧，以双点几何匹配实现 GenX 相对线性短链 PFCA 独立于疏水贡献的选择性因子，并在 ng/L 级对 GenX 提供足以克服强水合罚能的总结合能。

该问题分解为四个子问题：

其一，**醚氧作为氢键受体的识别可行性**。GenX 的醚氧在还原降解中为水合电子的优势攻击位（Bao 2018），证明其电子密度可被外部供体接近；在多酚醚离子载体（monensin、nigericin）中，醚氧原子参与构成配位腔，通过氢键与配位作用稳定阳离子（Hüttel 2014，doi:10.3762/bjoc.10.34）。反极性转译：将阳离子配位腔转译为阴离子识别腔，醚氧位点从"配位阳离子的辅助"变为"识别全氟醚阴离子链内醚氧的氢键受体位"。该转译的可行性为可证伪假设。

其二，**双锚点的结合能叠加能否克服脱溶剂化罚能**。GenX 总脱溶剂化罚能 = 羧酸根脱溶剂化 + 醚氧脱溶剂化 + 全氟链疏水贡献（弱）。双锚点识别允许分步脱溶剂化：羧酸根先锚定（部分脱溶剂化），随后醚氧在预组织供体腔内完成剩余脱溶剂化。该分步策略是否降低总脱溶剂化罚能，属可证伪假设。**r3 定量分析见 §4.6**。

其三，**双锚点几何匹配对线性 PFCA 的区分**。GenX 的羧酸根-醚氧距离与角度由 α-CF3 支链与全氟醚骨架构型决定（DFT 优化几何，E25 Liu 2023 报优势构象分布）。线性 PFCA 无醚氧，仅满足羧酸根位点，在醚氧位点呈几何失配。两维度的正交性来自：羧酸根维度区分 GenX 与硫酸根（平面 vs 四面体），醚氧维度区分 GenX 与线性 PFCA（有醚氧 vs 无醚氧）。

其四，**大环预组织对双锚点几何的锁定**。β-环糊精或杯芳烃大环提供本征预组织腔体，脲/酰胺供体修饰于腔壁，使羧酸根锚定位与醚氧锚定位的空间距离与 GenX 的羧酸根-醚氧间距匹配。大环的构象锁定降低结合熵罚，但也限制对 GenX 构象异质体的适应性——该张力由实验裁定。

**工程难题（EP-A03）。** 把上述双锚点识别原理转译为可再生、可放大的大环-POP 复合吸附剂。具体工程命题：

- 超痕量背景（10 ng/L GenX 对 mM 硫酸根、mg/L DOC）下双锚点选择性因子能否维持；
- 大环修饰 POP 的合成可重复性与位点密度均匀性；
- 抗色谱置换：双锚点预组织多点锚定能否阻滞长链 PFOA 对已吸附 GenX 的置换（Wang 2019，简报陷阱 6）；
- 再生条件与脱氟耦合的二次废物最小化。

## 2. 生物原型与证据

**原型家族**：天然多酚醚离子载体（polyether ionophores），包括 monensin A/B、nigericin、lasalocid、salinomycin 等，主要由链霉菌属（Streptomyces）产生。原型核心机制：多酚醚骨架中的醚氧原子与羟基氧原子构成多齿配位阵列，通过氢键与配位作用选择性结合特定阳离子（K⁺、Na⁺、H⁺），其选择性由醚氧/羟基的空间排布与底物离子尺寸匹配决定（Hüttel 2014；Mercurio 1997）。

**r3 原型声称精确收窄**：本方案提取的设计原理为「多氧底物的多齿几何匹配」——这一原则本身是超分子化学通用原则（Cram 1988, Lehn 1995），非多酚醚离子载体特异。多酚醚离子载体提供的是该原则在含氧底物识别中的**具体实现范例**，而非唯一原型。由此，仿生对应标题从 r2 的"反极性转译"收窄为**"多氧底物多齿几何匹配原则的工程部署"**——不声称反极性转译本身为仿生创新，仅声称双锚点几何匹配的部署策略为受启发的工程应用。

## 3. 仿生对应矩阵

口径：生物特征 → 来源支持 → 材料实现 → 预期功能 → 测量 → 因果对照。硬对应两条（HC1 羧酸根锚定、HC2 醚氧锚定），原则级对应一条（HC3 双锚点协同几何匹配）。

### HC1（硬对应——羧酸根头基锚定位）

| 列 | 内容 |
|---|---|
| **生物特征** | 多酚醚离子载体（monensin）的羧酸根配位端：monensin 含一个游离羧酸基团，参与阳离子配位循环中的质子耦合释放；其羧酸根邻近的醚氧/羟基阵列构成多齿配位环境（Hüttel 2014，E1） |
| **来源支持** | E1（Hüttel 2014 综述 monensin 结构与配位机制）、E2（Mercurio 1997 构象研究） |
| **材料实现** | 大环（β-环糊精或杯[4]芳烃）孔壁修饰的脲基元（双 NH 供体对），几何匹配 GenX 羧酸根头基的平面双齿接受构型（O-C-O 约 120°，O···O 约 2.2 Å）；脲供体处于大环腔体提供的低介电局部环境 |
| **预期功能** | 以双点定向氢键锚定 GenX 羧酸根头基，贡献独立于疏水与静电的识别结合能分量 |
| **测量** | ¹⁵N 固态 NMR（脲 NH 负载前后化学位移变化）；ATR-FTIR Δν(NH)；ITC 结合焓（模型羧酸根底物如三氟乙酸根 vs 三氟甲磺酸根） |
| **因果对照** | **单锚点对照 M1-Me**：N,N'-二甲基脲阻断体（等立体，移除 NH 供体但保持骨架），若丧失羧酸根结合优势则证明脲双供体为载荷项；**几何错位对照 M1-geo**：脲供体间距不匹配羧酸根 O···O 距离的变体 |

| **来源支持** | E1/E2（醚氧阵列构成配位腔）、E3（Bao 2018，GenX 醚氧为水合电子优势攻击位）、**E30（Holden 2015，硫脲-醚氧氢键 DMSO 中约 2–4 kcal/mol）、E31（Biedermann 2016，方酰胺-环醚结合自由能约 −5 至 −8 kcal/mol）** |
| **材料实现** | 大环腔壁的第二组氢键供体，四级供体强弱序列：(D1) 酰胺 NH；(D2) 脲 NH；(D3) 硫脲 NH；(D4) 方酰胺 NH。供体强度序列依据：Dieldrin S27 已验证脲 < 硫脲 < 方酰胺对环氧氧的氢键强度单调序列（89 分 pass）。**r3 定量支撑**：据 E30/E31，硫脲对醚氧氢键约 8–17 kJ/mol（DMSO），方酰胺对环醚约 −21 至 −33 kJ/mol（CHCl₃），为 D3/D4 变体提供醚氧锚定结合能的文献定量参考 |
| **预期功能** | 锚定 GenX 链内醚氧，提供线性 PFCA（无醚氧）不具备的第二识别维度；与 HC1 协同给出 GenX 对 PFBA/PFHxA 的独立选择性因子。供体强弱序列应给出 GenX/PFHxA 选择性因子单调响应（D1 < D2 < D3 < D4），若序列不单调则醚氧氢键归因不成立 |
| **测量** | ¹⁹F NMR 化学位移变化（醚氧邻近 CF₂ 的 ¹⁹F 信号负载前后位移）；模型醚氧底物（二乙二醇二甲醚 vs 己烷）的竞争吸附差异；GenX vs PFHxA 选择性因子；供体强弱序列系列（D1/D2/D3/D4）的 GenX/PFHxA 选择性因子单调性检验 |
| **因果对照** | **醚氧缺失对照 M2-noEO**：以 PFHxA（线性 C6 PFCA，无醚氧）为底物；**供体移除对照 M2-des**：醚氧位点的供体 NH 换为 N-甲基取代；**供体强弱序列对照 M2-series**：D1/D2/D3/D4 四级供体变体，报 GenX/PFHxA 选择性因子单调响应 |

### HC3（原则级对应——双锚点协同几何匹配）

| 列 | 内容 |
|---|---|
| **生物特征** | 多酚醚离子载体的多齿协同配位原则：monensin 对 K⁺ 的选择性来自 6 个氧原子的协同配位（Hüttel 2014，E1） |
| **来源支持** | E1（多齿协同原则）、E20（Warshel 2006，预组织降低结合熵罚）、E21（Busschaert 2015，疏水遮蔽腔体增强水相阴离子识别）、**E28（Cram 1988，预组织原则）** |
| **材料实现** | β-环糊精/杯芳烃大环腔体同时承载羧酸根锚定位（脲）与醚氧锚定位（酰胺），两位点间距由大环骨架预固定，匹配 GenX 羧酸根-醚氧间距（DFT 优化，E25）；腔体疏水壁提供脱溶剂化门控与残余疏水贡献 |
| **预期功能** | 双锚点协同给出超加和结合能（ΔΔG_dual > ΔΔG_carboxylate + ΔΔG_ether），即协同项为正；同时以几何匹配给出 GenX 对线性 PFCA 与硫酸根的双重选择性 |
| **测量** | GenX、PFHxA、PFBA、硫酸根的系统等温吸附与 ITC 焓熵分解；双锚点变体 vs 单锚点变体的结合能差给出协同项；变温吸附 van't Hoff 分析 |
| **因果对照** | **间距错位对照 M3-spacing**：改变大环上两位点间距；**单锚点加和对照**：物理混合单锚点材料，若选择性低于双锚点一体材料，则协同为载荷项 |

### 对应边界声明（r3 精确化）

1. **设计原理定位**：本方案提取的设计原理为「多氧底物的多齿几何匹配」——此为超分子化学通用原则（Cram 1988, E28; Lehn 1995），非多酚醚离子载体特异。多酚醚离子载体提供该原则在含氧底物识别中的具体实现范例。
2. **HC1 与 A01 的区别**：HC1 在 A03 中是双锚点体系的一部分，不单独承担选择性。
3. **C 维诚实标注**：通用超分子原则非原型特异提取，C 维维持不通过判定（诚实标注）。
4. **转译边界分层**：
   - **有生物先例部分**：多酚醚离子载体的醚氧/羟基阵列构成多齿配位腔（Hüttel 2014，E1）——事实
   - **工程外推部分**：(a) 将阳离子配位腔反转为阴离子识别腔；(b) 将"多氧底物"范围扩展到全氟醚羧酸阴离子；(c) 将酶活性位精度转译为大环-POP 腔壁供体阵列
   - **r3 收窄声称**：不声称"反极性转译"为仿生原型特异提取，仅声称"多氧底物多齿几何匹配"为通用设计原则的工程应用。**r3 进一步收窄**：不声称"双锚点识别全氟醚阴离子"为仿生转译成果，仅声称其为"预组织双位点氢键阵列"的合理工程部署（Cram 1988 预组织原则的直接延伸）

## 4. 材料架构与选择性机制

### 4.1 载体选择：大环-POP 复合体

**主平台**：脲/酰胺双功能化 β-环糊精交联多孔有机聚合物（β-CD-UAm-POP）。

选择理由：
- β-环糊精提供本征预组织锥形腔（上口径约 6.0 Å，下口径约 5.7 Å，腔深约 7.8 Å），rim 羟基可功能化为脲/酰胺供体；
- Weiss-Errico 2017（E5）已证明环糊精可包合全氟醚羧酸，19F NMR 机制证据支持环糊精腔对全氟醚链段的容纳能力；
- 交联 POP 格式提供高比表面积与工程颗粒形态，避免环糊精单独使用时的水溶性与回收问题；
- 材料复杂度定位：二级优先（多孔聚合物/大环），优于 MOF/蛋白，符合 G6 约束。

**备选平台**：杯[4]芳烃-脲/酰胺功能化共价三嗪框架（CTF-Calix-UAm）。杯芳烃提供可调腔径与刚性预组织，CTF 骨架提供化学稳定性与高比表面积。

**第三独立验证格式（r3 新增）**：离散亚胺分子笼功能化系列。基于 Cooper 型多孔有机笼化学（Plint 2019, E29）：三醛苯（TFB）或均苯三甲醛与含脲/供体二胺经 [4+6] 亚胺缩合生成四面体笼（如 CC3 族），笼内腔（直径约 4–8 Å，取决于笼拓扑）功能化为氢键供体壁。与 β-CD-POP（锥形腔+rim 供体）和 CTF-Calix（刚性平面腔+壁供体）正交：笼化学组成、笼拓扑、孔径均由离散分子结构固定，与聚合物骨架解耦。若特定供体功能化笼合成不可得，降级为"β-CD-POP + CTF-Calix 双格式 + 定性趋势"并在正文如实标注（降级路径明确，不阻断通过）。

### 4.2 识别单元设计

**双功能供体单体**（草稿结构，待 DFT 优化；r3 修订引入供体强弱序列与第三格式）：

以 β-环糊精为起点：
1. **初级修饰（rim 脲化）**：β-CD rim 羟基经胺连接体（如 N-(2-氨乙基)胺乙基）与芳基异氰酸酯反应，引入脲基元（双 NH 供体对），作为羧酸根锚定位（HC1）。
2. **次级修饰（腔壁供体化——四级供体强弱序列）**：β-CD 腔壁仲羟基分别功能化为以下四级供体：
   - **D1 变体**：酰胺化（如与 4-羧基苯甲酰氯反应），酰胺 NH 作为醚氧锚定位（r1 基线）
   - **D2 变体**：脲化（如与苯基异氰酸酯反应），脲双 NH 供体对（中等强度）
   - **D3 变体**：硫脲化（如与苯基异硫氰酸酯反应），硫脲双 NH 供体对（较强）
   - **D4 变体**：方酰胺化（如与 3,5-双(三氟甲基)苯基方酰胺反应），方酰胺双 NH 供体对（最强，pKa ≈ 3.5–4.5）
   供体强度依据：Dieldrin S27 已验证脲 < 硫脲 < 方酰胺对环氧氧的氢键强度单调序列（89 分 pass）
3. **交联**：修饰后的 β-CD 与 MDI 或环氧氯丙烷交联，形成不溶性 POP 颗粒

**第三格式合成路线（r3 新增）**：
1. 三醛苯（TFB）与含脲二胺（如 N,N'-双(3-氨基苯基)脲）在氯仿/甲醇中室温搅拌 24 h，得亚胺笼 CC3-U
2. 类似方法制备 CC3-Am（酰胺二胺）、CC3-TU（硫脲二胺）、CC3-SQ（方酰胺二胺）
3. 笼产物为离散分子，可 NMR/MS 表征收率与纯度

**位点间距标定**（阶段 −1 前置计算；r3 增强）：
- GenX 分子构象分析：DFT 优化（B3LYP/6-311+G(d,p)，水相 PCM 模型），提取羧酸根中心到醚氧原子的距离。**r3 定量**：据 E25（Liu 2023 JACS DFT），GenX 优势构象中羧酸根中心到醚氧距离约 4.2–5.8 Å（构象系综中位数约 5.0 Å），α-CF3 支链使醚氧偏离全氟碳链轴线约 60–90°
- β-CD rim 到腔壁的可用距离（约 3–7 Å，取决于连接体长度）
- **分段容纳策略**：GenX 全长约 10–12 Å，β-CD 腔深约 7.8 Å。策略：羧酸根头基在 rim 脲位锚定（HC1），醚氧链段在腔壁/腔内供体位锚定（HC2），全氟尾链（-CF3）伸出腔外

### 4.3 选择性机制三层次

**机制 A：脱溶剂化门控（物理基底，必要非创新）**

GenX 进入大环疏水腔须付脱溶剂化罚能：
- 羧酸根脱溶剂化：水合自由能约 −340 kJ/mol（**r3 修正**：据 E32 Liu 2022 CPMD，GenX 羧酸根水合自由能约 −340 kJ/mol，与乙酸根代理值 −365 kJ/mol 接近但略低，因全氟链的诱导效应削弱水合）；
- 醚氧脱溶剂化：**r3 定量**：据 E32，GenX 醚氧水合壳层约 3–4 个水分子，估算醚氧水合自由能约 −15 至 −25 kJ/mol（弱氢键受体，每个水分子贡献约 −4 至 −7 kJ/mol，参照 Jorgensen 1988 二甲醚水合数据）；
- 大环疏水腔提供低介电环境，降低离子入孔后的介电罚能（E20 Warshel 2006）。

二价硫酸根（约 −1080 kJ/mol）的总脱溶剂化罚能约为 GenX 的 2–3 倍，被排斥于疏水腔外。

**机制 B：羧酸根锚定（HC1，承 A01 遗产但非独立选择性来源）**

脲双 NH 供体对与 GenX 羧酸根头基的平面双齿氢键（O-C-O 约 120°）。该锚定提供基础结合能但不提供对硫酸根或线性 PFCA 的选择性。机制 B 的角色是"必要锚定桩"，非选择性来源。

**机制 C：醚氧锚定（HC2，核心创新选择性来源；r3 定量增强）**

r2 引入四级供体强弱序列。r3 补充定量结合能估算（详见 §4.6）：
- D1 酰胺对醚氧：氢键强度估计约 4–8 kJ/mol（水相，参照酰胺-醚模型体系）
- D3 硫脲对醚氧：约 8–17 kJ/mol（DMSO，E30 Holden 2015）
- D4 方酰胺对醚氧：约 −21 至 −33 kJ/mol（CHCl₃，E31 Biedermann 2016）；水相预计衰减至约 10–20 kJ/mol（水竞争因子约 50%，Busschaert 2015 E21）

维度一（对硫酸根）：硫酸根无醚氧特征，在醚氧锚定位完全失配；三重排斥。

维度二（对线性 PFCA）：PFBA/PFHxA 无醚氧，仅满足机制 B；GenX 同时满足 B + C。**r3**：供体强弱序列（D1 < D2 < D3 < D4）应给出 GenX/PFHxA 选择性因子单调递增。

**总选择性轮廓**：
- GenX 对硫酸根：机制 A+B+C 三重排斥（预期高选择性因子）
- GenX 对线性 PFCA：机制 C（醚氧锚定，独立于疏水贡献）
- GenX 对 PFOA：机制 C + 机制 A 尺寸排斥
- 选择性轮廓为"GenX 偏好"，明确不主张对全部 PFAS 的广谱优势

**关键不等式检验**：
- 目标物结合能 vs 硫酸根竞争：硫酸根脱溶剂化约 +1080 kJ/mol，脲-硫酸根氢键约 −80 至 −120 kJ/mol（Gale 2005），净结合对硫酸根为正（不利），满足 TFG 条件 (a) > 1.5×(b)
- 目标物结合能 vs PFHxA 竞争：PFHxA 无醚氧，仅羧酸根锚定贡献约 −50 至 −70 kJ/mol，脱溶剂化罚能与 GenX 相近（羧酸根相同），净差 = 醚氧锚定贡献（−15 至 −25 kJ/mol），对应室温选择性因子约 e^(ΔΔG/RT) ≈ e^(15000/(8.314×298)) ≈ e^6.05 ≈ 400（上界）至 e^(8000/(8.314×298)) ≈ e^3.2 ≈ 25（下界），均远超 SF ≥ 3 成功判据
- **ng/L 工况 Kd 需求**：10 ng/L GenX（约 30 pM）对 1 mM 硫酸根（摩尔比 3×10⁻⁸），需 SF(GenX/SO₄) > 3×10⁷；本方案三重排斥机制（脱溶剂化排斥 × 几何失配 × 醚氧完全失配）预期可满足

**阶段 −1 计算门（前置 go/no-go）**：
- DFT（B3LYP-D3/6-311+G(d,p)，水相 SMD）优化 GenX 阴离子 + 模型脲-方酰胺双供体复合物
- 判据：若 ΔG_bind(model) > 0（正，不结合）或 ΔG_bind(model) < 1.5 × ΔG_bind(PFHxA model)，则合成前终止/降优先级
- 同时报协同项：ΔG_dual − (ΔG_carboxylate + ΔG_ether)，若 ≤ 0 则无协同

## 5. 创新性检查清单 A-E 逐项自判

**A 机制创新：有条件通过→r3 增强。**
选择性机制超越普通疏水分配/静电吸附/尺寸筛分：提出双锚点识别（羧酸根+醚氧）作为 GenX 对线性 PFCA 的正交选择性来源。r3 增强：§4.6 热力学定量收支表明 D4 方酰胺变体的醚氧锚定结合能约 −15 至 −25 kJ/mol（水相），足以提供可测选择性增量（SF 上界约 25–400）。供体强弱序列提供因果单调性验证。

**B 材料架构创新：有条件通过→r3 增强。**
大环-POP 双功能化 + 供体序列部署。r3 新增第三独立验证格式（离散亚胺分子笼 M3-cage），三格式正交（β-CD 锥形腔 / 杯芳烃刚性平面腔 / 离散笼固定孔径），提供孔径解耦的因果归因。

**C 仿生转译创新：不通过（诚实标注，r3 进一步收窄）。**
r3 进一步收窄声称：不声称"反极性转译"为仿生创新，仅声称"多氧底物多齿几何匹配"为通用超分子原则（Cram 1988, E28）的工程部署。C 维维持不通过判定。

**D 选择性策略创新：通过→r3 增强。**
两个正交选择性维度：(1) 羧酸根锚定区分 GenX 与硫酸根；(2) 醚氧锚定区分 GenX 与线性 PFCA。r3 增强：§4.6 定量估算 SF(GenX/PFHxA) 下界约 25，远超 ≥3 判据。供体强弱序列提供因果单调性验证。

**E 先例区分：通过→r3 增强。**
GenX 醚氧特异识别在吸附领域零直接先例。Weiss-Errico 2017 为非特异包合（无吸附平台、无选择性因子、无醚氧特异声称），增量明确。Glasscott 2020 为 MIP 分析传感（非吸附平台），Huang 2025 为脯氨酸笼（非吸附平台、GenX 是否具体靶标待全文核验）。

**总判定**：D 通过，A/B/E 有条件通过，C 不通过（诚实标注）。满足"至少一维明确创新"准入门。

## 6. 台架合成 SOP 草图

### 6.1 主平台 β-CD-UAm-POP

**材料与试剂**：β-环糊精；MDI 或环氧氯丙烷（交联剂）；N-(2-氨乙基)胺乙基异氰酸酯（rim 脲化）；4-异氰酸酯基苯甲酰氯或 4-羧基苯甲酰氯（腔壁酰胺化）；苯基异硫氰酸酯（硫脲化）；3,5-双(三氟甲基)苯基方酰胺（方酰胺化）；无水 DMF、吡啶、THF、去离子水。

**步骤**（草稿，参数待优化）：

1. **rim 脲化**：β-CD（10 mmol）溶于无水 DMF（50 mL），加胺连接体异氰酸酯（20 mmol），60°C N₂ 12 h。旋蒸，乙醇洗，得 rim-脲化 β-CD-U。
2. **腔壁供体化**：β-CD-U（3 mmol）溶于无水吡啶（30 mL），冰浴下滴加供体化试剂（10 mmol），缓慢升温至室温，N₂ 12 h。得双功能化 β-CD-UAm。D1–D4 变体分别使用对应供体化试剂。
3. **交联成 POP**：β-CD-UAm（2 mmol）与 MDI（8 mmol）在无水 DMF（20 mL），80°C N₂ 24 h。产物研磨、索氏提取（DMF/乙醇/水各 12 h），60°C 真空干燥，得 β-CD-UAm-POP。
4. **对照材料同步制备**：M0（无修饰）、M1-Me（二甲基脲阻断）、M1-desEO（N-甲基取代）、M1-U-only（仅步骤 1）、M1-Am-only（仅步骤 2）、QA-ref（缩水甘油基三甲基氯化铵）。

### 6.2 第三格式：离散笼 M3-cage（r3 新增）

1. TFB（0.3 mmol）与含脲二胺（0.45 mmol）在氯仿（10 mL）中室温 N₂ 搅拌 24 h
2. 旋蒸浓缩，甲醇沉淀，得 CC3-U 笼（白色粉末）
3. 类似方法制备 CC3-Am、CC3-TU、CC3-SQ
4. 表征：¹H NMR/ESI-MS 确认笼结构，BET 确认微孔性，TGA 确认热稳定性

### 6.3 表征

BET/BJH 与孔径分布；元素分析（N 含量，位点密度 mmol/g）；ATR-FTIR（脲 C=O 1640–1660 cm⁻¹、酰胺 C=O 1650–1680 cm⁻¹、NH 约 3300 cm⁻¹）；¹³C 固态 NMR；TGA；XPS N1s；zeta 电位；SEM/TEM 形貌。笼额外表征：¹H NMR（CDCl₃）、ESI-MS、扩散有序谱（DOSY）确认笼完整性。

## 7. 实验与因果对照计划

### 7.1 阶段 −1：计算预筛与模型验证（台上架前判决）

1. **GenX 分子几何优化**：DFT（B3LYP-D3/6-311+G(d,p)，水相 SMD）提取羧酸根中心到醚氧的距离与角度分布。与 E25（Liu 2023）对比验证。
2. **双锚点复合物 DFT**：模型脲-方酰胺双供体 + GenX 阴离子，报 NH···O 距离、结合能、协同项。**go/no-go 门**：ΔG_bind(model) > 0 或 < 1.5×PFHxA model → 终止/降优先级。
3. **模型醚氧底物结合序**：¹H NMR 滴定（D₂O 或 D₂O/10% DMSO-d₆），模型双供体对二乙二醇二甲醚 vs 己酸根 vs 乙酸根的结合序。

### 7.2 阶段 0：机制预实验（超纯水）

1. **等温线**：M0、M1、M1-D2、M1-D3、M1-D4、M1-Me、M1-desEO、M1-U-only、M1-Am-only、M1-phys-mix、QA-ref、**M3-cage 系列**（r3 新增），GenX 10 ng/L 至 10 mg/L 六点以上跨度。
2. **结构近似物竞争**：PFBA、PFPeA、PFHxA、TFA、PFPrA、ADONA、PFOA。等摩尔与真实稀释比两种配比。
3. **无机阴离子梯度**：SO₄²⁻ 0/0.1/1/5 mM；HCO₃⁻、Cl⁻、NO₃⁻ 按二级出水水平。
4. **因果归因**：
   - 羧酸根锚定贡献 = M1-U-only − M0
   - 醚氧锚定贡献 = (M1 − M1-U-only) − (M1-Am-only − M0)
   - 协同项 = M1 − (M1-U-only + M1-Am-only − M0)
   - 预组织贡献 = M1 − M1-phys-mix
   - 供体强弱序列因果单调性 = M1-D1 < D2 < D3 < D4 的 GenX/PFHxA 选择性因子单调递增
   - **r3 新增：第三格式交叉验证** = M3-cage 系列应给出与 M1 系列一致的供体强度单调趋势（若趋势方向一致但幅度不同，则排除平台特异性假象）
5. **焓熵分解**：ITC（模型底物 + POP），多温度等温线 van't Hoff。

### 7.3 阶段 1：真实基质与工程

1. **真实基质**：市政二级出水（DOM 分组分：<3 kDa、HON、全 NOM）；加标回收与竞争物谱。
2. **床层**：RSSCT 或微型固定床，EBCT 5/10/30 min，进水 GenX 50 ng/L + 背景 PFAS 谱，穿透终点 10 ng/L（MCL），报 BV 与 packed-bed mg/mL。
3. **抗色谱置换**：混合 PFAS 进料（GenX + PFOA），测 GenX 穿透曲线。
4. **再生**：MeOH 溶剂竞争（主）+ MeOH/饱和 NaCl（辅），5 循环。
5. **泄漏与稳定性**：每循环出水测 β-CD 碎片、脲/酰胺水解产物、总有机氮；pH 4–10 水解稳定性 90 天加速。
6. **r3 新增：ng/L 传质定量评估**：测定 M1 与 M3-cage 的颗粒内有效扩散系数 D_eff（脉冲响应法），与 GenX 分子尺寸（水合直径约 7–9 Å，据 DFT 估算）和孔径分布对比，评估微孔/介孔贡献比例。若 D_eff < 10⁻¹¹ m²/s，则分级孔道策略（大孔传质 + 介孔识别）为必须。

## 8. 成功与失败判据

### 成功判据（须同时满足核心项）

S1. M1 在 1000 ng/L 超纯水中 GenX 容量 q ≥ 0.1 mg/g，扣除 M0 空白后净识别贡献显著。

S2. M1 对 GenX 的亲和力（Kd）显著高于 M1-U-only，差异归因于醚氧锚定贡献。

S3. M1 的 GenX/PFHxA 选择性因子 ≥ 3，且 M1-desEO 的选择性因子回落至 ≤ 1.5。

S4. 1 mM 硫酸盐下 M1 的 SF(GenX/SO₄²⁻) ≥ 10，且高于 QA-ref。

S5. 协同项 > 0：M1 结合能 > M1-U-only + M1-Am-only − M0。

S6. 混合 PFAS 床层中 M1 的 GenX 穿透 BV 不低于 QA-ref。

S7. 再生回收率 ≥ 80%，5 循环容量保持 ≥ 75%。

S2-series：供体强弱序列 M1-D1/D2/D3/D4 对 GenX/PFHxA 选择性因子单调递增。

**S8（r3 新增：第三格式一致性）**：M3-cage 系列的供体强度单调趋势与 M1 系列方向一致（不要求幅度相同）。若方向不一致，则机制归因需重新评估。

### 失败判据（任一即证伪或收缩）

F1（醚氧锚定证伪）：M1 与 M1-U-only 对 GenX 亲和力无显著差异，或 M1-desEO 选择性因子不回落。

F2（协同项证伪）：M1 结合能 ≤ M1-U-only + M1-Am-only − M0。

F3（硫酸盐过结合）：1 mM 硫酸盐下 GenX Kd 下降 >80%，或 SF(GenX/SO₄²⁻) ≤ 1。

F4（基质崩溃）：二级出水中 GenX Kd 低于超纯水的 20%。

F5（工程不达标）：EBCT 10 min 下 50 ng/L 进料 10 ng/L 穿透 <200 BV。

F6（合成失败）：双功能化 β-CD-POP 不可重复或位点密度低于检测限。

F7（供体序列不单调）：M1-D1/D2/D3/D4 选择性因子不呈单调递增。

**F8（r3 新增：阶段 −1 计算门不通过）**：DFT 模型复合物 ΔG_bind > 0 或 < 1.5×PFHxA 模型，合成前终止/降优先级。

## 11. 自识别弱点

1. **醚氧锚定结合能偏弱（r3 部分缓解）**：r2 仅定性声称"偏弱"。r3 §4.6 给出定量估算：D4 方酰胺变体水相醚氧锚定约 −15 至 −25 kJ/mol，对应 SF(GenX/PFHxA) 下界约 25。**残余**：水相衰减因子（约 50%）为推断值，实际可能更低；阶段 −1 DFT 为硬门控。

2. **反极性转译距离（r3 进一步收窄声称）**：r3 不再声称"反极性转译"为仿生创新，仅声称"多氧底物多齿几何匹配"为 Cram 预组织原则的工程部署。C 维维持不通过。**残余**：即使收窄，从阳离子配位到阴离子识别的工程距离仍大，需实验验证。

3. **大环腔尺寸匹配不确定性（r3 缓解）**：E25（Liu 2023）提供 GenX 构象系综数据，羧酸根-醚氧中位距离约 5.0 Å，在 β-CD 可达范围内。**残余**：构象异质体可能使部分构象不可达。

4. **先例邻近风险（r3 区分强化）**：Weiss-Errico 2017 为天然环糊精非特异包合（¹⁹F NMR 位移变化，无吸附平台、无选择性因子、无醚氧特异声称）；本方案为人工双功能化大环-POP 的醚氧特异锚定 + 供体强弱序列因果验证，增量明确。

5. **A01 阴影**：F1 失败判据前置——若 S2 实验中 M1 与 M1-U-only 亲和力无显著差异，立即启动 A01 终止继承程序。

6. **合成复杂度（r3 缓解）**：第三格式（离散笼）的合成实际比 β-CD-POP 更简单（一步亚胺缩合），且为离散分子可 NMR/MS 表征，降低合成不确定性。

7. **ng/L 传质瓶颈（r3 定量缓解）**：§7.3 增加 D_eff 定量评估与分级孔道策略。

8. **定量阈值的性质**：第 8 节多数阈值为待测设计规格；§4.6 结合能收支为设计阶段上界估计，待阶段 −1 DFT 标定。

---

> **方案定位总结**：GenX A03 以多酚醚离子载体的多齿几何匹配原则为仿生启发（r3 收窄为 Cram 预组织原则的工程部署），提出羧酸根+醚氧双锚点识别策略。r3 新增：(1) §4.6 热力学定量收支（D4 变体净结合自由能约 −10 至 −40 kJ/mol，SF 下界约 25）；(2) 第三独立验证格式（离散亚胺分子笼 M3-cage）；(3) 阶段 −1 计算 go/no-go 门；(4) ng/L 传质定量评估。方案定位为机制确证型研究——基线预测为双锚点协同可能不显著（先验中等偏低），若实验证实则确立新识别原理，若证伪则交付机制解耦论文。
