### 1.4D 腔内介电环境保护定量标度（r5 新增，回应 W1）

r4 能量预算中腔内有效卤键强度基于定性推断（ε ~2–5），r5 建立 **卤键强度-介电常数标度关系** 的定量模型：

**标度关系推导**：

卤键结合自由能 ΔG_XB 与介质介电常数 ε 的关系可近似为：

ΔG_XB(ε) ≈ ΔG_XB(vacuum) × f(ε)

其中 f(ε) 为介电屏蔽函数。基于 Born-Onsager 模型与 DFT 隐式溶剂计算交叉校准：

f(ε) ≈ 1/(1 + a·(1 – 1/ε))

参数 a 由 DFT 四点扫描（ε = 2, 5, 10, 80）拟合确定。

**DFT 四点扫描方案**：

| ε 值 | 物理对应 | 预期 ΔG_XB(HCBD-吡啶, 单点) |
|------|---------|------------------------------|
| 2 | 深疏水腔内（COF 微孔） | ~6–8 kJ/mol |
| 5 | 部分水化腔内 | ~4–6 kJ/mol |
| 10 | 孔口/浅腔 | ~2–4 kJ/mol |
| 80 | 体相水 | ~1–2 kJ/mol |

**标度关系校验**：

- Gómez-Suárez 2022 JACS（E18）实验值：低介溶剂中 C–Cl···O 卤键 ~6–10 kJ/mol → 与 ε = 2 计算值一致
- CB[7] 腔内卤键增大 5–20 倍（E19）→ 对应 ε ~2–5 范围，与标度关系吻合
- Schneider 2009 Angew（E13 引用）水相氢键净收益 ~数个 kJ/mol → 卤键在水相中类似量级

**腔内有效卤键能量三档估计**（6 位点阵列，PEF = 2.0 中心估计）：

| 场景 | ε_cavity | 单价 ΔG_XB | 6 × ΣΔG_single | PEF | ΔG_multi |
|------|----------|-----------|----------------|-----|----------|
| 保守 | 5 | –4 kJ/mol | –24 kJ/mol | 1.5 | **–36 kJ/mol** |
| 中心 | 3 | –5.5 kJ/mol | –33 kJ/mol | 2.0 | **–66 kJ/mol** |
| 乐观 | 2 | –7 kJ/mol | –42 kJ/mol | 2.5 | **–105 kJ/mol** |

**与竞争物的能量差**（选择性来源）：

| 竞争物 | ΔΔG_XB vs HCBD（保守，6 位点） | 来源 |
|--------|-------------------------------|------|
| PCE | ~8 kJ/mol（少 2 个 C–Cl σ 穴） | σ 穴数差异 |
| HCE | ~4 kJ/mol（σ 穴数同但几何不同） | 几何匹配差异 |
| TCE | ~12 kJ/mol（少 3 个 σ 穴） | σ 穴数差异 |
| CCl₄ | ~6 kJ/mol（四面体几何不匹配） | 几何 + σ 穴数 |

**诚实声明**：标度关系 f(ε) 为近似模型，对卤键-腔体体系无直接实验验证。a 参数值须 Phase 0 DFT 四点扫描确定。上表数值为设计假设，非实验测量值。

### 1.4E 「湿则弱选择、干则难可及」困境（r5 显式命名，回应 W1/W5）

类比 Dieldrin A01 通过方案的 N3 处理，r5 显式命名并预注册本方案的核心工程/机制张力：

**困境描述**：

- **分支 W（润湿态）**：孔内充满水，传质好、位点全可及，但水相竞争使卤键弱（ε ~80 等效），选择性依赖多价协同 + PEF
- **分支 D（气充态）**：孔内低介电（ε ~2–5），卤键强，但 ng/L 水相客体须克服毛细管侵入压才能进入孔内

**Washburn 侵入压估算**：

- 接触角 θ ~120°（疏水 COF 孔壁），孔径 d ~1.5 nm
- P_invasion = –4γcosθ/d ≈ 20 MPa（~200 bar）
- 环境压下热力学稳态为气充态

**r5 处置策略**：

1. **选择性证明在润湿态内完成**：决定性卤键配对测量在同材料同润湿态内完成，选择性证明不依赖孔内干燥
2. **标准预润湿规程**：所有吸附实验以乙醇预湿→水相交换为统一初始态
3. **两分支预注册**：
   - 分支 W 为默认实验态，效应下限按保守估计（§1.4D 保守场景）
   - 分支 D 为乐观情形预注册，不依赖
4. **润湿态表征**（§7 Step 2 新增）：水汽吸附等温线 + 高压水侵入-挤出

**诚实声明**：该困境为方案固有属性，不可消除，只能管理。分支 W 下卤键净收益处于可测边缘（保守 ~36 kJ/mol 总结合能，扣除疏水基线后净卤键增量 ~4–8 kJ/mol），Phase 0 门控为关键 go/no-go。

### 2.1A 功能收敛仿生论证框架（r5 新增，回应 W3）

r4 继承 r2 的「卤碳-蛋白接触基元」原型描述，r5 升级为 **功能收敛论证**：

**功能收敛论证逻辑**：

1. **结构仿生**（弱）：卤碳-蛋白复合物中 C–Cl···O/N 接触基元 → Lewis 碱衬里微孔腔（直接结构类比，但原型为 incidental 结合，W3 维持）
2. **功能收敛**（中等）：自然界多种疏水腔体进化出对卤代有机分子的结合能力（卤代烷脱卤酶 LinB/DhaA、谷胱甘肽 S-转移酶 GST-PcpF、卤代麻醉剂结合蛋白），其共同设计原则为：
   - **原则 P1**：疏水腔体预富集卤代客体（去溶剂化协同）
   - **原则 P2**：腔壁预组织 Lewis 碱位点（方向性卤键/氢键）
   - **原则 P3**：多点接触阵列（非单点结合，多价协同）
3. **本方案对应**：
   - P1 → β-酮烯胺 COF 疏水微孔（去溶剂化环境保护）
   - P2 → 4 类 Lewis 碱受体库（方向性卤键受体）
   - P3 → 6 位点卤键阵列（多价协同，PEF ~1.5–3.0）
4. **仿生强度判定**：功能收敛论证不依赖特定蛋白结构，而是基于自然界反复出现的设计原则。仿生强度标为「功能原理级仿生启发」（中等）

**诚实声明**：功能收敛论证仍非直接进化原型（C 维中等强度）。W3（原型为 incidental）为固有属性，不可修复，但功能收敛论证使仿生支撑从「结构原理级」升级为「功能原理级」。

### 4.3C 疏水基线解耦定量协议（r5 新增，回应 W2/DC1）

r4 继承 r2 的 logKow 解耦策略，r5 具体化为 **双变量 LFER 残差分析**：

**解耦协议**：

1. **第一步：建立疏水基线**
   - 测量空白载体（无 Lewis 碱 COF）对 HCBD/PCE/HCE/TCE/CCl₄ 的 Kd
   - 拟合 logKd vs logKow 线性关系 → 疏水基线 LFER
   - 预期：logKd = a·logKow + b（a ~0.8–1.0）

2. **第二步：测量功能化材料 Kd**
   - 测量 Lewis 碱功能化 COF 对同一竞争物谱的 Kd
   - 计算残差 ΔlogKd = logKd(functional) – logKd(baseline)

3. **第三步：残差归因**
   - 若 ΔlogKd 随 σ 穴数/卤键受体强度单调增加 → 卤键增量确认
   - 若 ΔlogKd 仅随 logKow 变化 → 卤键贡献不显著，退化为疏水基线
   - **go 判据**：HCBD 的 ΔlogKd > 0.5（对应 α_XB > 3，卤键增量可测）

4. **双变量 LFER**：
   - logKd = a·logKow + b·N_XB + c
   - 其中 N_XB = 可用 σ 穴数（HCBD = 6, PCE = 4, HCE = 6, TCE = 3, CCl₄ = 4）
   - 若 b > 0 且统计显著（p < 0.05）→ 卤键维确认独立于疏水基线

### Step 0B 模型化合物→材料外推间隙量化（r5 新增，回应 W10）

**外推衰减因子（Extrapolation Attenuation Factor, EAF）定义**：

EAF = K_a(material) / K_a(model_compound)

其中 K_a(material) 为材料级 HCBD 结合常数，K_a(model_compound) 为 Step 0A NMR 滴定测得的模型受体-HCBD 结合常数。

**EAF 预期值**：

| 因素 | 衰减贡献 | 说明 |
|------|---------|------|
| 位点固定化 | ×0.3–0.8 | 接枝降低构象自由度 |
| 腔体约束 | ×1.5–3.0 | 多价协同增强（PEF） |
| 骨架介电保护 | ×2–5 | 腔内低介环境增强 |
| 位点非均一性 | ×0.5–0.8 | 分布宽度降低有效亲和力 |
| **净 EAF** | **×0.5–5** | **设计假设，须材料级实验确定** |

**r5 处置**：

1. Step 0A 模型化合物 K_a 为上限估计（无腔体约束）
2. 材料级实验为最终仲裁
3. EAF 的精确值须材料级配对实验确定
4. 若 Step 0A K_a ≥ 10 M⁻¹ 但材料级 Kd 未达判据 → EAF < 1，原因归于位点固定化/非均一性，须优化接枝策略
