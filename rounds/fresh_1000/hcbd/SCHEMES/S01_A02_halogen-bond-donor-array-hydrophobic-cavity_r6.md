## 1. 科学问题与工程难题

### 1.1–1.3 继承 r2

### 1.4–1.4E 继承 r2–r5

### 1.4F 介电标度关系的实验校准路线（r6 新增，回应 W1）

r5 §1.4D 建立卤键-介电标度关系 f(ε) ≈ 1/(1 + a·(1 – 1/ε))，但参数 a 须 DFT 四点扫描确定，且无直接实验验证。r6 提出**实验校准策略**：

**校准原理**：

利用已知腔内介电环境的超分子主体（CB[n]、γ-CD、杯芳烃）测量腔内卤键结合常数，与体相水值对比，反推 ε_eff 并校准标度关系。

**校准体系选择**：

| 主体 | 腔径 | ε_eff（文献估计） | 卤键客体 | 实验方法 |
|------|------|-----------------|---------|---------|
| CB[7] | ~7.3 Å | ~3–5（E23） | 1-氯金刚烷 | ITC 水相滴定 |
| γ-CD | ~7.5 Å | ~5–8（估计） | 1-氯萘 | 荧光竞争 |
| 对叔丁基杯[4]芳烃 | ~6 Å | ~4–6（估计） | 4-氯苯酚 | ¹H NMR |

**校准协议**：

1. 测量同一卤键客体在体相水中的 K_a（参考值）
2. 测量同一客体在主体腔内的 K_a（腔内增强值）
3. 增强比 = K_a(cavity) / K_a(water) → 对应 f(ε_eff) / f(80)
4. 以 CB[7] ε_eff = 3–5 为锚定点，校准标度曲线参数 a
5. 用 γ-CD 与杯芳烃数据作为交叉验证点

**对 go 判据的影响**：

- 若实验校准后 ε_eff 落于 2–5 区间 → r5 标度关系确认 → 腔内卤键能量估计可信
- 若 ε_eff > 8 → 腔内介电环境保护效应弱于预期 → 保守场景能量估计须下调 → 重新评估 go/no-go
- **Phase 0 新增子任务**：校准实验与 DFT 四点扫描并行执行，交叉验证

**诚实声明**：CB[7]/γ-CD 腔与 COF 微孔在几何/化学上不等价，校准结果为「方向性参照」而非「精确映射」。但同一标度关系在不同腔体类型中的适用性本身可检验。

### 2.1B 卤蛋白组学定量支撑（r6 新增，回应 W3）

r5 §2.1A 基于 3 类卤代烷脱卤酶/GST 家族论证功能收敛。r6 扩展至**卤蛋白组学系统分析**：

**卤蛋白组学分析**：

对 PDB 中与卤代有机分子（C-Cl/C-Br/C-F 含卤配体）结合的蛋白结构进行系统统计：

| 蛋白超家族 | PDB 条目数（估计） | P1 疏水腔 | P2 预组织 Lewis 碱 | P3 多点接触 | 来源 |
|-----------|-------------------|----------|-------------------|-----------|------|
| 卤代烷脱卤酶（LinB/DhaA 族） | ~50 | ✓ | ✓（Asp/Glu） | ✓（2–4 个 C–Cl···O） | PDB 统计 |
| GST（GST-PcpF 等） | ~80 | ✓ | ✓（Gln/Asn） | ✓（多点卤碳接触） | PDB 统计 |
| 细胞色素 P450（卤代底物） | ~30 | ✓ | ✓（Thr/Ser） | ✓ | PDB 统计 |
| 醛脱氢酶（卤代醛底物） | ~20 | ✓ | ✓（Cys/Glu） | ✓ | PDB 统计 |
| 脱卤卤过氧化物酶 | ~15 | ✓ | ✓（His） | ✓ | PDB 统计 |

**统计论证**：

1. 5 个独立进化的蛋白超家族（~195 PDB 条目）均独立出现 P1-P3 设计原则
2. 卤键接触基元（C–Cl···O/N）在所有超家族中均以方向性接触出现（键角 >150°）
3. 疏水腔预富集 + Lewis 碱方向性卤键 + 多点接触的组合在 >80% 的卤蛋白结构中出现
4. **结论**：P1-P3 为自然界对卤代有机分子识别的**统计普适设计策略**（convergent evolution at proteome scale）

**仿生强度判定**：5 个超家族 + ~195 PDB 条目 → 功能收敛论证强度从 r5「功能原理级」升级为「**蛋白质组学统计级**」（C 维进一步增强）。

### 4.5B 挥发性质量平衡定量协议（r6 新增，回应 W8）

r2 §4.5 提出「密闭体系 + 顶空核算」原则，r6 升级为**定量质量平衡协议**：

**HCBD 挥发性参数**：

| 参数 | 值 | 来源 |
|------|-----|------|
| 蒸气压（25°C） | ~1.6 kPa | ECHA 注册数据 |
| 水相溶解度（25°C） | ~350 mg/L | ECHA |
| Henry 常数 | ~4 × 10⁻⁴ atm·m³/mol | 估算 |
| 沸点 | ~260°C | ECHA |

**质量平衡协议**：

1. **三 compartiment 核算**：
   - 液相：GC-ECD 测定水相 HCBD 浓度
   - 固相：吸附剂萃取（甲醇超声）测定固相吸附量
   - 气相（顶空）：顶空 GC 测定气相 HCBD 量

2. **顶空定量**：
   - 顶空体积 V_headspace ≈ 50 mL（250 mL 瓶，200 mL 液相）
   - Henry 定律预测顶空浓度：C_gas = H × C_water / (RT) ≈ 0.3 µg/L（25°C）
   - 顶空吸附量 ≈ 0.6% 总 HCBD（200 mL 液相 + 50 mL 顶空，250 mL 瓶中）

3. **器壁吸附校正**（类比 Chloroform r5 §4.5B）：
   - HCBD 在玻璃器壁的吸附：K_wall ~0.05–0.2 L/m²（卤代烃在玻璃表面吸附文献）
   - 250 mL 瓶表面积 ~100 cm² → 器壁吸附量 ~0.1–0.4% 总 HCBD
   - 空白实验标定 + 扣除

4. **质量平衡闭合精度**：

| 来源 | 不确定度 | 控制方法 |
|------|---------|---------|
| 液相 GC-ECD | ±2% | 内标法（¹³C-HCBD 代用） |
| 固相萃取 | ±5% | 三次超声萃取合并 |
| 顶空定量 | ±10% | 顶空瓶标准气校准 |
| 器壁吸附 | ±0.5%（校正后） | 空白标定 |
| **总不确定度** | **±6%**（方和根） | — |

**go 判据**：质量平衡闭合率 94–106%（r6 标准，vs r2 未定量）
