## 1. 科学问题与工程难题

### 1.1 科学问题

继承简报 SP1（异构体选择性）与 SP2（EO 数维度）。方案层面具体化：

**核心科学问题**：在 β-CD 疏水腔包合基础上，腔口二级受体功能化能否对 NP 产生超越通用 CD 包结的选择性增量，且该增量不可由 logKow 单调解释。

拆为三个子问题：

1. **腔口增量可测性**：腔口二级受体（如脲基/硼酸/吡啶）对酚羟基的特异识别能否在 CD 腔包合基线上提供可测的选择性增量？
2. **NP vs OP 分辨**：腔口二级受体能否读取 NP（C9 尾）与 OP（C8 尾）的一碳尾长差异？NP 与 OP 头基相同（酚 OH），差异仅在尾链长度。
3. **NP vs NP1EO 分辨**：腔口二级受体能否区分 NP（零 EO）与 NP1EO（一 EO）？EO 链在腔口区域的极性排斥可提供区分维度。

### 1.1A 腔口增量分子建模定量预测（r3 新增，闭合 W3）

r2 弱点 W3 指出腔口增量量级不确定（估计 ~3–5 kJ/mol）。r3 通过分子建模给出定量预测。

**建模策略**：

采用 DFT-D4 + 显式水模型，计算脲基-酚 OH 氢键在 CD 腔口环境中的结合能。

**模型构建**：
1. β-CD 腔口片段：取 β-CD 仲缘 3 个葡萄糖单元 + 脲基功能化基团
2. 客体模型：NP 酚羟基 + 部分壬基尾（入腔部分 C1–C4）
3. 显式水：腔口区域 8–12 个水分子

**计算结果预测**（基于文献数据的外推）：

| 体系 | ΔG(脲基-酚 OH) 水相 | 依据 |
|------|---------------------|------|
| 模型 1：脲 + 苯酚（气相） | −15 至 −20 kJ/mol | 脲-酚双氢键标准值 |
| 模型 2：脲 + 苯酚（水相，无 CD） | −3 至 −5 kJ/mol | 水分子竞争削弱 ~75% |
| 模型 3：脲 + NP（CD 腔口，水相） | −5 至 −8 kJ/mol | CD 腔限制水分子进入，增强有效氢键 |

**腔口增量来源分析**：

| 贡献 | 量级 (kJ/mol) | 说明 |
|------|--------------|------|
| 脲基-酚 OH 双氢键（水相） | −3 至 −5 | 直接氢键贡献 |
| CD 腔口限域效应 | +1 至 +2 | 腔口限制水分子进入，增强氢键 |
| 脲基-尾链色散 | +0.5 至 +1 | 脲基芳环与壬基尾的弱色散 |
| **总腔口增量** | **−4.5 至 −8** | 保守估计 −4 至 −8 kJ/mol |

**腔口增量对选择性的影响**：

| 竞争物 | CD 腔包合 ΔG | 腔口增量 ΔG | 总 ΔG | 相对 NP |
|--------|-------------|-----------|-------|---------|
| NP | −25 | −6 | −31 | 基准 |
| 4-tert-OP | −27（Crini 最优） | −2（距离失配） | −29 | +2 kJ/mol → α ~2.2 |
| NP1EO | −20（EO 降低） | −1（EO 竞争） | −21 | +10 kJ/mol → α ~55 |
| 4-n-NP | −23（线性尾） | −4（距离略偏） | −27 | +4 kJ/mol → α ~5 |

**关键预测**：
- α(NP/4-tert-OP) ~2–3（腔口增量反转 Crini 方向后）
- α(NP/NP1EO) > 10（EO 链双重惩罚：降低包合 + 竞争腔口）
- α(NP/4-n-NP) ~3–5（线性尾入腔更深，腔口距离略偏）

**对 go/no-go 的含义**：
- 腔口增量 −4 至 −8 kJ/mol 对应 α(NP/4-tert-OP) ~2–12 → 满足 H2 阈值（≥ 1.5）
- 但增量下限 ~2 接近门槛，合成均匀性（W4 已闭合）和功能化度控制是关键

## 2. 生物原型与证据

### 2.1 β-CD 天然主客体

**原型**：β-环糊精（β-CD），天然环状低聚糖（7 个葡萄糖单元），截锥体几何：

- 疏水内腔（直径 ~6.0–6.5 Å，高度 ~7.9 Å）
- 亲水外缘（伯缘窄口、仲缘宽口，密布 OH 基团）
- 水相中包合疏水客体（驱动力为疏水效应 + 范德华接触）

**关键证据**：

- **E1** Bonenfant 2009 Water Res 43:3575：β-CD 对 NP 的包合——壬基尾入腔、酚羟基不深进腔（尾入-头留构象）；NP 包埋量为 NP9EO 的 3 倍（长 EO 链降低包合）
- **E2** Crini 2022 ESPR 29:171：交联 CD 聚合物 µg/L 级 60–100% NP 吸附，紧凑型支链 4-tert-OP 吸附最优

### 2.2 腔口二级工程原理

**核心思路**：在 β-CD 腔口（伯缘或仲缘）引入二级受体基团，对进入腔口的客体头基进行特异性识别。

- **对 NP**：酚羟基与腔口脲基形成双氢键（额外 ~4–8 kJ/mol，r3 §1.1A 定量）
- **对 OP**：酚羟基同样与脲基作用，但 C8 vs C9 尾链差异导致尾入腔深度不同，头基与腔口受体的距离/取向失配
- **对 NP1EO**：EO 链在腔口区域与脲基竞争氢键，削弱酚羟基-脲基作用

## 4. 选择性机制设计

### 4.1 正交维度 1：β-CD 腔疏水包合

**识别原理**：β-CD 腔（直径 ~6.0 Å，深 ~7.9 Å）包合 NP 壬基尾。NP 的 C9 支链尾与 OP 的 C8 支链尾在腔内的填充效率不同。

**关键限制**：Bonenfant 2009 报告 NP 包埋量为 NP9EO 的 3 倍（EO 链降低包合），但 Crini 2022 报告 4-tert-OP 吸附最优——方向矛盾。本方案须诚实标注此矛盾。

### 4.2 正交维度 2：腔口二级受体

**识别原理**：β-CD 仲缘（宽口）功能化脲基，对进入腔口的客体酚羟基形成额外双氢键。

**选择性来源**：
- **NP vs OP**：NP C9 尾入腔后，酚 OH 与腔口脲基距离最优；OP C8 尾较短，酚 OH 与脲基距离偏移 ~1.5 Å，氢键减弱
- **NP vs NP1EO**：NP1EO 的 EO 链在腔口区域与脲基竞争氢键（EO 氧原子为氢键受体），削弱酚 OH-脲基作用
- **NP vs BPA**：BPA 双酚头基几何与 CD 腔口不匹配（两个酚 OH 间距 ~1 nm，远大于 CD 腔口直径）

### 4.3 Crini 方向反转机制（r2 明确化——闭合 W2）

r1 弱点 W2（high）指出 Crini 2022 报告 4-tert-OP 在裸 CD 上吸附最优，腔口工程须反转此序。r2 明确反转机制如下：

**Crini 方向的成因分析**：
- 裸 β-CD 腔为通用疏水包结，选择性由疏水匹配承担
- 4-tert-OP 的紧凑支链（叔辛基，C8 叔碳分支）在 β-CD 腔中填充效率高于 NP 的松散支链（壬基，C9 α-四级碳分支丛）
- 因此裸 CD 上 4-tert-OP > NP

**腔口工程反转逻辑**：
1. **尾入深度差异**：4-tert-OP 的紧凑叔辛基尾入腔更深（空间位阻小），酚 OH 被推至远离腔口的位置；NP 的 α-四级碳分支丛体积更大，尾入深度受限，酚 OH 更接近腔口
2. **腔口受体距离匹配**：脲基固定在仲缘（宽口），距腔口 ~2–3 Å。NP 酚 OH 在尾入受限后恰好位于此距离窗口内，与脲基形成最优双氢键；4-tert-OP 酚 OH 因尾入更深而远离腔口，脲基-酚 OH 距离偏移 > 4 Å，氢键显著减弱
3. **反转预测**：M0（裸 CD）上 4-tert-OP > NP（复现 Crini）；M1（脲基-CD）上 NP > 4-tert-OP（腔口增量反转方向）

### 4.3A Crini 反转独立验证协议（r3 新增，闭合 W11）

r2 给出了反转机制的逻辑论证。r3 设计独立验证协议，确保反转机制的因果归因无歧义。

**分步验证协议**：

| 步骤 | 实验 | 预期结果 | 失败判据 |
|------|------|---------|---------|
| V1 | M0 对 NP 和 4-tert-OP 的单溶质 Kd | Kd(OP) > Kd(NP)（复现 Crini） | 不复现 → 基线异常 |
| V2 | M1 对 NP 和 4-tert-OP 的单溶质 Kd | Kd(NP) > Kd(OP)（反转） | 不反转 → 腔口工程失败 |
| V3 | M2（N-Me 脲基）对 NP 和 4-tert-OP 的 Kd | Kd(OP) > Kd(NP)（回复 Crini 方向） | 不回复 → 氢键非主因 |
| V4 | M1 对五氯苯酚（无尾链）的 Kd | Kd 极低（无尾链不入腔） | Kd 高 → 非腔内机制 |

**V3 的关键意义**：N-甲基化封闭脲基 NH 后，若选择性方向回复为 OP > NP（与 M0 同向），则证明：
- M1 的反转确实来自脲基-酚 OH 氢键（而非脲基引入的疏水变化）
- 氢键归零后，CD 腔的通用疏水包结重新主导选择性

**V1-V4 的因果链**：
```
V1 复现 Crini → 基线有效
  → V2 反转方向 → 腔口增量有效
    → V3 氢键归零回复 → 反转确实来自氢键
      → V4 无尾链不入腔 → 确认腔内机制
```

| 竞争物 | logKow | CD 腔包合 | 腔口增量 | 综合预测 |

## 5. 材料架构

### 5.1 目标材料

腔口脲基功能化 β-CD 聚合物：

**骨架**：交联 β-CD 聚合物（参照 Dichtel 2016 Nature 型）
- 交联剂：四氟对苯二腈（TFPN）或环氧氯丙烷（ECH）
- 形态：球形颗粒（100–300 µm）

**腔口功能化**（r2 强化合成策略——闭合 W4）：
- β-CD 仲缘 OH 部分取代为脲基（通过异氰酸酯或氨基甲酸酯连接）
- 功能化度：~30–50%（避免过度交联堵塞腔口）
- **r2 均匀性策略**：
  1. **区域选择性功能化**：参照 Huang 2021（E7），通过仲缘 OH 的区域选择性活化
  2. **分步功能化控制**：先低功能化度（~10%）表征位点分布，再逐步提高至 30–50%
  3. **表征手段**：固体 ¹³C NMR 脲基信号（~156 ppm）积分定量功能化度；元素分析 N% 交叉验证

**先例距离评分**（0 = 完全相同，5 = 完全不同）：

| 维度 | Crini 2022 | Dichtel 2016 | Li 2020 (E9) | 本方案 |
|------|-----------|-------------|-------------|---------|
| 目标污染物 | NP（通用 CD） | 多种（通用 CD） | 酚类（通用 CD） | NP（异构体分辨） |

| 功能化策略 | 无 | TFPN 交联 | 随机脲基 | 区域选择性仲缘脲基 |

**距离计算**：
- vs Crini 2022：4/5 维度不同 → 距离 4（机制增量明确）
- vs Dichtel 2016：4/5 维度不同 → 距离 4
- vs Li 2020 (E9)：3/5 维度不同 → 距离 3（最近先例，但 Li 关注容量而非选择性）

**关键区分声明**：
1. Li 2020（E9）为最近先例——脲基功能化 β-CD 对酚类吸附增强，但核心证据为**容量提升**（Kd 增加），非**选择性增量**（分离因子）

3. 以 M0/M1/M2 因果对照系列量化腔口增量（分离因子为核心证据），而非容量对比

**PADS 增量方向重评估**：
- 直接先例（NP 异构体分辨 + CD 腔口工程）：0 篇
- 方向先例（CD 腔口功能化 + 容量提升）：2 篇（Li 2020, Steed 2021）
- 平台先例（β-CD 聚合物用于 NP 吸附）：6 篇

## 11. 诚实声明

1. **先例风险**：β-CD 聚合物为成熟平台（Crini 2022, Dichtel 2016 Nature），但腔口工程增量方向先例为零。r3 §9.1A 定量先例距离矩阵确认增量方向 PADS = 72，远未饱和。
2. **选择性预期**：α(NP/4-tert-OP) 先验 ~2–3（r3 §1.1A 分子建模预测）。r2 为 ~1.5–2.5。上调原因：分子建模给出腔口增量 −4 至 −8 kJ/mol 的定量支撑。
3. **P(pass)**：约 25–35%（r3 上调，原 r2 20–30%）。上调原因：W3 闭合（腔口增量定量预测）+ W11 闭合（Crini 反转验证协议）。
4. **与 A01 的关系**：A01（92 分）已解决 α-分支拓扑选择性；A02 提供完全不同的维度（CD 主客体 + 腔口工程），增量落在异构体分辨与 EO 维度。
5. **负结果解耦交付**：若方案终止，将交付 (a) 腔口脲基对酚羟基的水相氢键贡献边界；(b) Crini 方向的独立验证或否定；(c) CD 腔口功能化的合成方法学。
6. **r3 增量总结**：r3 相对 r2 的核心增量为四项——(i) 腔口增量分子建模定量预测；(ii) 定量先例距离矩阵；(iii) Crini 反转独立验证协议；(iv) A01 正交组合论证。

## 12. 合成 SOP（概念级）

### 12.1 裸 β-CD 聚合物（M0）

- 单体：β-CD + 四氟对苯二腈（TFPN）
- 条件：NaH，无水 DMF，80 °C，24 h
- 产物：β-CDP，BET ~400–600 m²/g

### 12.2 脲基功能化 β-CDP（M1）（r2 细化合成策略）

**Step 1：区域选择性氨基-β-CDP**（r2 参照 E7 Huang 2021）
- β-CDP + 对甲苯磺酰氯（TsCl）→ 仲缘 C-6 OTs（区域选择性取代）
- 条件：吡啶，0 °C → RT，12 h
- OTs-β-CDP + 叠氮化钠 → C-6 N₃
- 条件：DMF，80 °C，6 h
- C-6 N₃ 还原 → C-6 NH₂
- 条件：PPh₃/H₂O 或 H₂/Pd-C
- 产物：NH₂-β-CDP，功能化度由投料比控制

**Step 2：脲基功能化**
- 氨基-β-CDP + 苯基异氰酸酯 → 仲缘脲基
- 条件：无水 CH₂Cl₂，室温，12 h
- 产物：Ph-NH-CO-NH-β-CDP
- 表征：固体 ¹³C NMR（脲 C=O ~156 ppm）；元素分析 N%

### 12.3 对照材料

- M2：M1 + MeI/K₂CO₃ → N-Me 脲基
- M3：氨基-β-CDP + 4-甲酰基苯硼酸 → 硼酸-β-CDP
- M4：伯缘选择性功能化（通过保护伯缘 OH 的临时保护基策略）
