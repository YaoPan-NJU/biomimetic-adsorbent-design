# 第一部分 设计者方案（第 1 轮）

## 0. 角度定位与最关键的诚实前置（反转论证）

本角度的原型 AbAlkB 的**天然方向与本设计所需方向相反**，这是全案最大风险，必须在开篇讲清楚，否则后续对应关系是空转。

【事实，full_text_read】Naing 2013（AbAlkB 纯化酶底物特异性，J Inorg Biochem 121:46–52）正文与 Highlights 给出两条关键事实：其一，纯化 AbAlkB「氧化范围广，但**偏好位阻小（sterically unhindered）的 C–H 键**」（Highlights 第 3 条；正文以 norcarane 自由基钟给出 [2]:[3]=1:3.1，即优先氧化位阻小、可及性高的 3 位而非位阻大的 2 位）；其二，**十六烷（C16）无可检测氧化**（Results 第 3.节：hexadecane showed no detectable oxidation），而讨论指出「底物通道中存在单个大体积氨基酸残基控制底物特异性」（Discussion，引 van Beilen 2005 J Bacteriol 187:85）。

据此，AbAlkB 的生物学功能是：**用一条有限深度的底物通道设定链长上限（C16 被拒）**，并**在通道内偏好位阻小的 C–H 键（即排斥位阻大/支化位点）**。若照搬这一方向，材料会「排斥支链、偏好线性短链」——恰与捕获支链 NP 的目标相反。

【设计假设，本角度的反转核心】本设计不复制酶的化学（ipso 无关，AlkB 的二铁加氧化学按 T8 排除），只转译其**几何门控原则**，并把两个几何维度**各自独立、方向明确地**重新接地：

- **轴一（主轴，狭缝深度＝链长窗口）**：转译 AbAlkB「有限通道深度设定链长上限」的原则。狭缝深度 D 设定为「刚好容纳紧凑支链 C9 尾＋酚头在缝口锚定」的窗口，使**更长的线性表面活性剂尾段（LAS 线性 C10–C13、长链 NPEO 的乙氧基链）无法完整埋入**而付出部分插入/去溶剂化罚，被梯度排斥。此轴方向与 AbAlkB 的链长上限**同向**（都是"太长的被拒"），转译最稳。
- **轴二（次轴，狭缝宽度＝支链几何互补）**：这是**反转轴**。AbAlkB 在通道内排斥位阻大的 C–H；碳狭缝微孔的自然倾向也是线性优先填充（见 2.3 节 Jiang 2005、Castro-Gutiérrez 2021）。本设计**反其道**：把狭缝宽度 W 调到与支链 C9 的大截面（α-四级碳约 0.55–0.6 nm）**双壁互补（commensurate）**，使支链尾获得两壁范德华最优接触（可饱和限域），而同碳数**线性尾（4-n-NP，截面约 0.4 nm）在同宽狭缝内欠填充（under-fill）、每接触自由能低** → 支链 > 线性偏好。此轴方向为反转，**效应量小、风险高**，必须以宽度梯度＋单维消融实验强制证明，否则本轴证伪（见第 8 节 kill-switch）。

【诚实声明】轴一有稳固的生物与材料双重接地（AbAlkB C16 拒＋碳分子筛链长截断），轴二是投机性反转假设。本案的价值主张主要落在**轴一对 NPEO/LAS 的梯度分离**；轴二对 4-n-NP 的区分是加分项而非命门。NP 对 OP（C8 vs C9，同支化同头基）是全谱最难对，仅靠深度窗口约 1 个 CH2 的分辨，如实列为最可能证伪的子主张。

与已通过的 NP-A01 的机制区分（硬要求）：A01 是**α-分支拓扑读取（形状选择腔，ipso 逆读标尺）**，读的是分支的**拓扑/构型**；A04 读的是**链长（深度窗口）＋末端堆积/宽度互补（截面）**，是"尺寸-几何筛分"而非"拓扑识别"，两者机制轴正交，材料架构（3D 预组织腔 vs 2D/1D 刚性狭缝）亦不同。

## 1. 科学问题与工程难题（方案层面具体化）

### 1.1 科学问题（继承简报 SP1，具体化）

在酚羟基为烷基酚家族共有头基（NP、OP、NPnEO、BPA 同含，头基单维无选择性）、且 NP/OP/异构体 logKow 近简并的前提下，**能否以一维刚性狭缝的"深度＋宽度"几何参数，构造对 NP 相对其乙氧基前体家族（NP1EO/NP2EO/长链 NPEO）与线性长尾表面活性剂（LAS）的梯度分离，且该分离不可由 logKow 单调导出？** 四条可检验子问题：

- SP-A04-1（深度窗口）：狭缝深度梯度是否使 NP 保留基本恒定、而链更长的 NPEO/LAS 保留随深度收窄而系统性下降（梯度分离因子）？
- SP-A04-2（宽度互补/反转）：在链长受控前提下，狭缝宽度是否能使支链 C9（NP）相对线性 C9（4-n-NP）产生可测且方向为"支链 > 线性"的分离因子？
- SP-A04-3（单调性破除）：上述分离因子与 logKow 的相关是否弱（|r|<0.3）、且吸附呈可饱和 Langmuir（限域位点有限）而非线性分配？
- SP-A04-4（真实基质保持）：二级出水/含 DOC 与共存表面活性剂基质中，深度窗口选择性保持率是否 ≥ 超纯水的 50%？

### 1.2 工程难题（继承 EC1/EC2/EC3、T1/T10）

- EC1'（形状筛分-传质耦合）：狭缝须精确控制深度 D（约 0.8–1.2 nm 窗口）与宽度 W（约 0.55–0.65 nm 窗口），且在水相中刚性不塌陷；ng/L–µg/L 低驱动力下要求 Kd≈10^4 L/kg，同时分钟级 EBCT 内可达，支链尾入缝传质本身慢（Seo 2021：支链扩散活化能约为线性的 4 倍），须分级孔（大孔输运＋狭缝识别）。
- EC2'（高摩尔过剩竞争）：二级出水 DOC mg/L 级、NPEO µg/L 级摩尔过剩；深度窗口须把长链竞争物排在窗口外，而非仅靠亲和力硬拼。
- EC3'（温和再生与碱耐受）：pKa≈10.3 给 pH 12 酚盐化脱附杠杆，但刚性碳/COF 狭缝与缝口锚定基须耐碱循环、缝几何不衰减（T9，NP 专属再生为文献空白）。
- T1/T10 命门：疏水容量单调（脂肪/污泥/AC）对 NP/OP、NP 异构体无分辨；本案须以**可饱和限域（Langmuir）＋几何互补**破单调，并以结构近似物分离因子＋有机质归一化对照自辩；mg/L 批次容量不作 ng/L 选择性证据，必须给 Kd 与固定床 BV 标尺。

### 1.3 设计假设（逐条可证伪，阈值不下调）

- H1（深度窗口，主轴）：狭缝深度匹配材料对 SF(NP / 长链 NPEO(≥NP4EO)) ≥ 5、SF(NP / LAS-C12) ≥ 5 为完全成功；且**深度梯度序列**中 NP 保留系数变异 < 30%、而 NPEO/LAS 保留随深度收窄单调下降（相关显著）。SF < 2 或无梯度 → H1 证伪。
- H2（宽度互补，反转次轴）：链长受控下 SF(NP / 4-n-NP) ≥ 2 且方向为支链优先，随宽度梯度呈峰形（存在最优 W）为成功；SF ≈ 1（0.8–1.25）或方向相反 → H2 证伪（轴二死，不牵连 H1）。
- H3（单调性破除）：分离因子与 logKow 的 |r| < 0.3 且不显著；NP 吸附等温线呈 Langmuir（可饱和），拟合优于 Freundlich/线性分配。若保留随 logKow 单调（|r|>0.7）→ 退化为疏水分配，全轴证伪（T1）。
- H4（真实基质）：二级出水中深度窗口 SF ≥ 超纯水的 50%，空白载体（无狭缝同化学碳）无 NPEO/LAS 梯度分离。
- H5（再生-动力学）：pH 12 或甲醇再生 5 循环容量保持 ≥ 80%、SF 漂移 ≤ 20%；支链 NP 在分级孔珠中 t90 ≤ EBCT/3。
- H0（OP 子主张，弱）：SF(NP / 4-tert-OP) 若 ≥ 1.5 为额外成功；若 < 1.2（不可测）则如实记为"深度窗口不分辨 C8/C9 一碳差"，此子主张证伪不牵连 H1（NPEO/LAS 分离为主价值）。

边界声明（诚实标注）：
1. AbAlkB 底物为**烷烃**，非水相烷基酚；缝深门控在水相烷基酚上的有效性**无直接文献**，属真空白，须本案实验建立（这是本角度的一手创新点也是主要风险）。
2. AbAlkB 的链长上限（C16 拒）是**催化通道**几何，本案转译为**吸附狭缝**几何，物理转导不同（催化 vs 平衡吸附），属**几何/统计对应**而非机制等同。
3. E4/E5 的自然方向是"纳线性、排支链"，与本设计轴二反转方向相反；引用它们既作物理基础（狭缝确能按尺寸/构型筛分）也作**风险坦白**（默认倾向对我不利，须靠宽度调优反转）。
4. 禁止活污泥/完整微生物/蛋白酶（T8）；AbAlkB 仅作机制原型证据出现。

## 3. 仿生对应矩阵

### HC1 链长窗口的深度门控（**硬对应**，几何统计对应，主轴）

- 生物特征【事实，E1】：AbAlkB 底物通道有限深度设定链长上限——十六烷（C16）无可检测氧化，通道内单个大体积残基控制底物特异性。
- 来源支持：E1（full_text_read），E2（分支/链长决定代谢路由，原理级旁证）。
- 材料实现：刚性狭缝，深度 D 调至约 0.8–1.2 nm 窗口，缝口设酚羟基氢键锚定位（吡啶/羰基/酚受体），使 NP 以"头锚缝口、支链 C9 尾入缝"取向（E7 支持尾入-头留构象）；尾长超过窗口的 NPEO 乙氧基链、LAS 线性 C10–13 尾无法完整埋入、付部分插入＋去溶剂化罚。
- 预期功能【推断】：SF(NP / 长链 NPEO)、SF(NP / LAS) 随深度收窄而拉开；NP 自身保留在窗口内基本恒定。
- 测量：单组分 Kd 与固定床分离因子；**狭缝深度梯度序列**（浅/匹配/深三档，见 7 节）的保留-深度曲线。
- 因果对照：深度梯度消融（浅缝：连 NP 尾都埋不下 → NP 保留也降；匹配缝：NP 高、长链低；深缝：长链回升，选择性消失）；空白无狭缝碳无梯度分离。

### HC2 支链截面的宽度互补（**第二对应**，反转轴，设计假设承重）

- 生物特征【事实＋推断，E1/E2】：AbAlkB 偏好位阻小 C–H（对分支位阻敏感）；植烷酸 β-甲基分支改变代谢路由（分支几何被识别）。生物侧对"分支"是**排斥/改道**方向。
- 来源支持：E1（位阻偏好，full_text_read）、E2（分支位置识别，abstract_read）、E3/E4（材料侧形状/尺寸可分，full_text_read/metadata）。
- 材料实现【设计假设】：狭缝宽度 W 调至约 0.55–0.65 nm，与支链 C9 大截面双壁互补（可饱和限域，两壁 vdW 最优）；同碳数线性尾（4-n-NP）截面小、欠填充、每接触自由能低 → 支链优先。**方向为反转**（对 E1/E4/E5 的自然倾向取反）。
- 预期功能【设计假设】：SF(NP / 4-n-NP) ≥ 2 且随 W 呈峰形（最优宽度存在）。
- 测量：宽度梯度序列 SF(NP/4-n-NP)-W 曲线；显式溶剂 PMF/GCMC 预测最优 W。
- 因果对照：宽度消融（过窄：支链被排，NP 保留骤降；最优：支链 > 线性；过宽：两者皆弱、区分消失）；深度固定只变宽度，与只变深度（HC1）的双向消融交叉验证正交性。

### HC1×HC2 正交叠加（D 维核心证据）

- 主张【设计假设】：深度窗口（管长/NPEO/LAS）与宽度互补（管支链截面/4-n-NP）为两个**可独立调节的几何自由度**；成对材料（仅调深度、仅调宽度、双调）应呈**可加性/正交性**：深度梯度改变 SF(NP/NPEO) 而不显著改变 SF(NP/4-n-NP)，宽度梯度反之。
- 测量：2×2（±匹配深度 × ±匹配宽度）材料矩阵的双因素方差分解。
- 证伪：若两因子强耦合、无法分解，或单调依赖同一物化参数（logKow/尺寸）→ 正交叠加假设不成立，退化为单维尺寸筛分。

## 4. 材料架构与选择性机制

### 4.1 识别单元（非蛋白、非折叠肽）

识别单元＝**刚性狭缝的几何本身（深度 D × 宽度 W）＋缝口氢键锚定基**。无蛋白、无印迹模板（区别于 MIP，T2）、无折叠肽。缝口锚定基为固相共价接枝的小分子氢键受体（如吡啶氮、羰基、或残余酚羟基），仅用于固定 NP 取向（头留缝口、尾入缝），使深度门控有确定的"测量参考零点"；锚定为**支持元件**，机制承重在 D/W 几何。

### 4.2 载体类别（不预设，给两条并行候选）

- 候选 A（首选，材料侧接地最强）：**聚酰亚胺热解碳分子筛（CMS）**，6FDA 基前驱体，热解温度/前驱体扭转自由度调 D、W（E3 已证狭缝孔可调、形状选择）。颗粒/中空纤维/整体柱格式。
- 候选 B（并行）：**刚性狭缝型 COF/HCP** —— 层间距可设计的柱撑（pillared）二维 COF，层间即"狭缝"，柱高＝深度类比、层内孔＝宽度类比；缝口以酚受体功能化。
- 分级孔：两条候选均须叠加大孔/介孔输运网络（HIPE 或造孔剂），保证 EBCT 内 t90（EC1'、H5）。

### 4.3 选择性机制与打破 logKow 单调（T1 自辩）

- 可饱和限域（Langmuir）：狭缝位点数有限，NP 满占后不再线性增长，区别于脂肪/AC 的疏水分配（近线性/Freundlich）。这是破单调的第一支柱。
- 几何互补（形状）：深度门控（长度）与宽度互补（截面）均是形状变量，与 logKow 正交。NP 与 4-n-NP logKow 近简并（线性甚至略高），若观察到支链优先，只能来自几何而非疏水（H3）。
- 有机质归一化对照：DOC/NOM 存在下测 OC-归一化 Kd，若几何选择性保持而普通疏水吸附被 NOM 压平，佐证机制非分配。

### 4.4 容量口径（按 SPEC.md 要求）

报告：总干复合体容量 mg/g（含载体死重）**与** packed-bed mg/mL（堆积床体积归一）；可及狭缝位点密度（由探针分子/CO2 或正丁烷占据估算 µmol/g）；**空白载体（无狭缝同化学碳）本征吸附**必测并从选择性中扣除。ng/L–µg/L 主场景以 Kd（L/kg）与固定床 BV（穿透前处理床体积）为主标尺，mg/L 批次仅作机制/容量上限参考，不作选择性证据（T10）。

## 5. 创新性检查清单逐维结论（A–E）

- A 机制维（选择性识别机制）：**清晰新颖**。以"链长深度窗口（排长线性尾）× 支链截面宽度互补（纳紧凑支链）"双几何自由度正交筛分 NP，且**明确反转** AbAlkB/碳分子筛"纳线性排支链"的天然方向——NP 题录级零先例（简报 G1/DESIGN_SPACE A04 备注：题录级零先例）。通过。
- B 材料架构维：**未达独立新颖**（诚实）。CMS/狭缝碳、柱撑 COF 均为既有平台；本案的架构增量在"缝深/缝宽双窗口＋缝口锚定"的功能配置，而非新载体。载体本身不构成创新，避免落入 T3 载体替换。**结论：B 维不作为通过依据。**
- C 选择性策略维：**新颖**。以缝深梯度对 NPEO/LAS 做"链长排斥梯度"、以缝宽对 4-n-NP 做"截面互补反转"，并强制单调性破除（Langmuir＋几何），是区别于 CD 包合（E9，紧凑支链优先、方向相反）与 MIP（模板）的新策略。通过。
- D 仿生转译维：**硬对应成立但含反转风险**。HC1（链长窗口）转译稳（AbAlkB C16 拒，full_text）；HC2（宽度反转）为设计假设承重，须消融证明。转译诚实、边界清楚。通过（以 HC1 为硬对应担保）。
- **通过规则判定**：A、C、D 三维清晰超越先例，满足"≥1 维明确新颖且非载体替换/参数微调"。**创新性清单：通过**（承重在 A/D 的"反转链长窗口"与 C 的"梯度＋反转"策略）。

## 7. 实验与因果对照计划

### 7.1 核心实验：单维消融（D 维承重）

**三组材料矩阵**（正交设计核心，直接回答 HC1×HC2）：
- 仅调深度（宽度固定于最优）：D-浅 / D-匹配 / D-深，测 SF(NP/NP4EO)、SF(NP/LAS)、SF(NP/4-n-NP)。预期：NPEO/LAS 分离随深度变化，4-n-NP 分离基本不变。
- 仅调宽度（深度固定于匹配）：W-窄 / W-匹配 / W-宽，测同上。预期：4-n-NP 分离随宽度呈峰形，NPEO/LAS 分离基本不变。
- 双调（匹配 D × 匹配 W）vs 空白（无狭缝同化学碳）：全谱分离因子。

### 7.2 竞争物与结构近似物（强制谱系）

按简报硬约束，竞争序列（难→易）：4-tert-OP（C8 vs C9，最难，H0 弱主张）＞ 4-n-NP（线性 C9，H2 反转轴）＞ NP1EO/NP2EO/长链 NPEO（乙氧基维，H1 主轴）＞ LAS-C12（线性长尾＋阴离子，H1）＞ BPA（异类酚）。均在**超纯水（机制）与二级出水（真实基质，H4）**双条件测。

### 7.3 等温线与单调性检验（T1）

- NP、4-n-NP、OP 各测等温线，判 Langmuir vs Freundlich/线性；报可饱和容量与位点密度。
- 分离因子对 logKow 回归，报 |r| 与显著性（H3）。
- OC-归一化 Kd 对照（加/不加 NOM）。

### 7.4 低浓度真实标尺（T10）

- 固定床穿透：50 ng/L / 0.5 µg/L / 1.4 µg/L 进水，EBCT 5–10 min，报穿透 BV 与 Kd(≈10^4 L/kg 目标)。
- 二级出水实样穿透（含 DOC、NPEO、LAS 背景），报 NP 与 NPEO/LAS 竞争穿透曲线。

### 7.5 再生、泄漏、稳定性、床层（H5/T9）

## 8. 成功与失败判据（可证伪）与 kill-switch

**完全成功**（全部满足）：H1（SF(NP/NPEO)≥5、SF(NP/LAS)≥5 且深度梯度成立）＋ H3（|r(logKow)|<0.3、Langmuir）＋ H4（真实基质 ≥50%）＋ H5（再生/动力学）。H2（支链反转）与 H0（OP）为加分。

**部分成功**：H1＋H3＋H4 成立但 H2 证伪（4-n-NP 不分辨）——角度作为"NP/前体家族链长分离器"成立，如实降级为单轴（深度窗口）方案。

**kill-switch（任一触发 → 本角度整体失败或重大降级）**：
- K1：深度梯度对 NP-vs-NPEO/LAS **无分离或不成梯度** → 主轴 H1 死 → **角度失败**（这是承重轴）。
- K2：支链/线性保留比 ≈ 1（SF(NP/4-n-NP) 0.8–1.25）或方向相反 → H2 死 → 轴二废，方案降级为单轴（不整体失败）。
- K3：分离因子随 logKow 单调（|r|>0.7）且等温线为线性分配 → 退化为疏水树脂（T1）→ **角度失败**。
- K4：SF(NP/4-tert-OP)<1.2 → H0 子主张失败，如实记"深度窗口不分辨 C8/C9"，不牵连主轴。
- K5：真实基质 SF < 超纯水 25%（NOM 堵缝/竞争压垮）→ 工程失败。

## 9. 攻击/裁决占位与最终自评

### 9.1 已预判的攻击点（供攻击者核对）

1. **反转方向站不住**：E1/E4/E5 的自然方向是纳线性排支链；轴二要反转，攻击者会问"凭什么宽度调优就能让支链优于线性、而不是又回到线性优先"。答：轴二本就是设计假设、以宽度梯度＋PMF 强制证伪；主价值在轴一（链长窗口，方向同 AbAlkB，不涉反转）。
2. **NP/OP 一碳差不可分**：承认，列为 H0 弱主张与 K4，不作承重。
3. **缝深门控在水相烷基酚上无先例**：真空白，如实标为一手创新点＋主风险；以 E7（β-CD 尾入-头留）作取向旁证，但缝深水相门控须本案建立。
4. **与 A01 重叠**：机制轴不同（链长/末端堆积 vs α-分支拓扑读取），架构不同（狭缝 vs 3D 预组织腔）；已在第 0 节声明。
5. **支链尾传质慢**（E3：支链扩散 Ea 约线性 4 倍）：以分级孔缓解，H5 设 t90 门。
