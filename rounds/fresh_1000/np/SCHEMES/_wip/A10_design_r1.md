# 第一部分 设计者方案（第 1 轮）

## 0. 角度定位与全案最关键的诚实前置

本角度的原创性**不能**落在"又一个形状选择腔"上——那会塌缩为已通过的同胞 **A01（S26，92 分）** 的载体替换，在创新清单 A/C/D 维不通过。本案的原创性承载点是一条与 A01 正交的新识别自由度：**对位氢键锚定维与 α-分支拓扑维之间的"非加和协同"（2D non-additivity）本身**，并把该非加和性做成可用**双突变热力学循环（double-mutant cycle）**直接测量、可证伪的核心 D 维证据。

### 0.1 与 A01 的机制区分（硬要求，全案命门）

【事实】A01 §4.1 的两条设计轴——"腔深短于线性 C9 全长以排线性、纳紧凑支链"与"腔口宽度匹配支链截面"——**都是几何/形状维**；A01 的酚羟基腔口锚定（其 HC2）的功能是**固定分子取向**（"腔口锚定固定分子取向"，A01 §4.1、HC2），使形状维得以读取拓扑。因此 A01 承重的选择性是**单一形状维**，锚定是形状读取的**几何使能器（enabler）**，而非独立产生分辨力的维度。A01 自评 A 维虽写"二维正交"，但两维的物理来源都是范德华形状互补，锚定不贡献独立的、可解耦的分辨自由能。

【本案的新自由度，设计假设】A10 把锚定从"取向使能器"升格为**独立的、几何可编程的识别维度**，并令其与形状维**耦合**产生一个**非加和交叉项（cooperativity cross-term）**：

- A01 的可调设计变量：腔深 D、腔宽 W（两者皆形状）。锚定位置固定于腔口，非独立可调变量。
- **A10 新增的可调设计变量：锚定基团与形状亚腔之间的相对几何矢量（间距 d、取向角 θ）**。这是 A01 没有的空间组织自由度。d、θ 被做成一个"几何匹配系列"（matched series），交叉项（协同自由能）在匹配几何处最大。
- **A10 的核心物理量：交叉耦合自由能 ΔΔG_int**（下 §4.3 定义），在 A01 的设计逻辑里**恒为零**（A01 从不主张协同交叉项）。A10 主张 ΔΔG_int 显著为负（正协同/超加和）**且其大小本身对 NP 相对结构近似物具选择性**。这是相对 A01 真正新增的、可实验证伪的识别自由度。

一句话：**A01 靠"形状腔读拓扑，锚定只定向"；A10 靠"就位门控的限域氢键，使锚定维与形状维非加和地放大彼此的分辨力"。** 若实验测得 ΔΔG_int≈0（加和），A10 即塌缩为"A01+平庸锚定"，本角度终止（§8 kill-switch KS1）。

### 0.2 承重轴收敛到 logKow 近简并硬对（避 T1）

承重放在三对 logKow 单调/近简并**不可分**的硬对上，且每对的分辨都来自 ΔΔG_int 而非疏水容量：

- **NP / 4-n-NP**（同碳数 C9、同酚头，logKow 近简并且线性略高——对本案有利）：分辨来自"线性尾无法在锚定所定几何下同时就位于分支亚腔 → 协同崩塌"。
- **NP / 4-tert-OP**（C9 vs C8，同 α-四级碳、同酚头，logKow 相邻近简并）：分辨来自 C8 尾在匹配几何处的有效摩尔浓度/贴合度退化 → 协同部分损失。
- **NP / NP1EO**（同壬基尾，头基由酚 OH 变为一乙氧基，摩尔常过量）：分辨来自锚定氢键供受体身份与几何改变（酚 OH vs 醚氧）+ 极性 EO 段抗埋入 → 协同崩塌。

长链 NPEO、LAS 属 logKow 可分/电荷平庸可分的**平庸对**，仅作**外围对照**（验证抗污与非承重方向），不承重（避 T1）。

## 1. 科学问题与工程难题（方案层面具体化）

### 1.1 科学问题（承接简报 SP1/SP2）

【承接 SP1】在酚羟基为烷基酚家族共有头基的前提下，酚羟基氢键锚定与支链壬基尾形匹配能否构成**正交识别**，使 NP 对 OP、4-n-NP、NP1EO 的分离因子偏离 logKow 单调预测。

【承接 SP2】ipso 途径以 α-碳分支拓扑区分 NP 异构体。人工受体能否以几何方式读取该拓扑差异。

【A10 方案层具体化——把 SP1×SP2 合成一个可判定命题】ipso 途径的底物规则是**合取式（conjunctive）**的：既要求对位酚（酚盐锚定，共用识别位点，见 E3 卤代 NP 竞争抑制）**又**要求 α-支化拓扑（E1、E4）——只满足其一不是好底物。本案把这条"两特征合取"的生物逻辑转译为**协同双点合成受体**，并提出可判定的科学问题：**在水相、就位门控的限域微环境中，酚羟基氢键锚定维与 α-分支形状维能否产生显著的、且对 NP 相对结构近似物具选择性的非加和耦合自由能 ΔΔG_int，使双维受体的分离因子显著超越任一单维受体？**

可证伪判据（核心）：以**双突变热力学循环**测四角受体（双维 / 仅形状无锚定 / 仅锚定放宽容腔 / 双消融空白）对竞争谱的结合自由能，计算 ΔΔG_int = ΔG₁₁ − ΔG₁₀ − ΔG₀₁ + ΔG₀₀；要求 ΔΔG_int(NP) 显著负（协同）且 |ΔΔG_int(NP)| 显著大于 |ΔΔG_int(4-n-NP)|、|ΔΔG_int(NP1EO)|。

### 1.2 工程难题（承接 EC1/EC2）

- **EC1 具体化（就位门控的限域氢键）**：水相 pH 6–8.5，酚 OH 的氢键被本体水竞争淹没（静电亦无效，pKa≈10.3）。工程难题是构建一个**先由疏水尾埋入预付去溶剂化、再将酚 OH 定位到部分去溶剂化的限域微环境**的受体，使一条本来"淹没"的氢键**仅在正确就位时**才变得有效且有分辨力。这正是协同交叉项的物理来源，也是 A10 把"水竞争"从劣势转为**开关式资产**的关键。
- **EC2 具体化（ng/L–µg/L 低驱动力 + 高摩尔过量竞争）**：DOC mg/L 级、NPEO µg/L 级摩尔过量，需 Kd≈10⁴ L/kg 与分钟级 EBCT 可达的分级传质，且选择性须在真实二级出水基质中保持。
- **EC-A10 特有（几何匹配系列的可控合成）**：d、θ 匹配系列要求锚定臂长/角度可离散调，且成网后腔构象与臂矢量不塌陷——预组织的刚性化是协同的前提。

### 1.3 设计假设（逐条可证伪）

- **H1（协同核心，非加和层）**：匹配几何受体对 NP 的 ΔΔG_int ≤ −3 kJ/mol（协同显著，设计值），且 |ΔΔG_int(NP)| ≥ 2×|ΔΔG_int(4-n-NP)|、≥ 2×|ΔΔG_int(NP1EO)|；ΔΔG_int 在 −1.5 至 −3 kJ/mol 判机制成立但量级中等；|ΔΔG_int| < 1.5 kJ/mol 或非选择判 H1 证伪（KS1）。
- **H2（双维超越单维层）**：SF_双维(NP/4-n-NP) ≥ 3 且 ≥ 2×max(SF_仅形状, SF_仅锚定)（即双维分离因子显著超越单维之较大者，体现非加和），SF_双维(NP/4-tert-OP) ≥ 2。
- **H3（就位门控层）**：ΔΔG_int 随疏水亚腔就位质量单调（就位不良则协同崩塌）；限域氢键存在的光谱证据（就位后酚 OH 伸缩频率位移/¹⁵N 或 ¹⁷O 标记锚定基化学位移变化）在双维受体出现、在仅形状受体消失。
- **H4（拓扑维正交于 logKow）**：Kd 与 logKow 相关系数绝对值 < 0.3 且不显著；异构体滞留与立体效应指数（E2 方向）相关（可选序列层）。
- **H5（网络与再生层）**：笼固定于刚性网络后本征协同选择性保持（二级出水 SF ≥ 超纯水 SF 的 50%），pH 12 酚盐化或甲醇洗脱 5 循环容量保持 ≥ 80%、SF 漂移 ≤ 20%。
- **H6（动力学层）**：分级孔珠中 t90 ≤ EBCT 的 1/3，动力学 SF ≥ 平衡 SF 的一半。

## 2. 生物原型与证据

### 2.1 原型家族与机制概要

原型家族（用户指定）：**ipso 途径 α-碳拓扑读取（Gabriel 2008，E1）+ 烷基酚对位/分支几何基序（Routledge 1997，E6，仅毒性/几何背景，T6）+ 漆酶-NP/OP 异构体对接（Mo/Zeng 2018，E5）**。转译内容限于**几何/统计/氢键拓扑**，碳正离子 1,2-C,O 迁移化学与蛋白结构按 T8 明确排除。

【事实，abstract_read，本轮 PubMed efetch PMID 18800507 逐字核】Gabriel 2008（EST 42:6399–6408）：Sphingobium xenophagum Bayram 降解技术 NP 导致异构体组成显著漂移；单异构体转化率与其 α-取代模式（六个质谱组）强相关；规则为"**α-碳位阻越小、主链长 4–6 碳者降解越快**"；最难降解主异构体（Group 4）鉴定为 4-(1,2-二甲基-1-丙基丁基)酚（NP193a/b，含大体积 α-CH₃、α-CH(CH₃)C₂H₅）；ipso 羟化导致自然体系中大体积 α-取代异构体的选择性富集；YES 测定表明 Group 4 异构体雌激素效价高——降解富集高雌激素异构体存在实质风险。（→ 拓扑维方向 + 富集风险 T4 背景。）

【线索/事实，abstract_read，简报 PubMed 核继承】Li 2011（Arch Environ Contam Toxicol，10.1007/s00244-010-9576-4，E3）：**卤代 NP 竞争性抑制非卤代 NP 在 Bayram 中的转化，证明对位取代酚共用同一识别位点**——即酚（酚盐）锚定是识别的组成部分，且识别对两特征（对位酚 + 支化尾）呈**合取**依赖。这是 A10 "两特征合取 → 协同双点"转译的直接生物依据。

【线索，abstract_read，简报继承】Gabriel 2005（JBC 280:15526，E4）：4-NP 的 ipso 羟化新途径与 α-四级碳底物判据；线性 4-n-NP 的 α-碳带氢，不进入该途径。

【线索，metadata_verified，本轮 Semantic Scholar 核】Mo、Zeng 等 2018（Bioprocess Biosyst Eng，10.1007/s00449-017-1866-z，E5）：题为"漆酶（Trametes versicolor）与 NP/OP 异构体相互作用的分子对接模拟"。题录/venue/作者/年经核确认存在；**摘要被出版方省略，未取正文，本条仅 metadata_verified，不承重**，仅作"NP/OP 异构体在同一识别口袋内经酚头 + 支链尾双点定位"的几何旁证；其对接口袋几何**不得**作为材料腔尺寸的定量依据（T8：蛋白结构不直接转译）。

### 2.2 非加和/协同的物理有机学基础（转译的定量骨架，非生物原型）

协同交叉项不是本案臆造，而是超分子化学成熟概念，用作**材料侧可测量的定量骨架**（非仿生对应，避免过度声称）：

- 【事实，metadata_verified，本轮核】Jencks 1981（PNAS 78:4046，E7）："On the attribution and additivity of binding energies"——双点结合的总自由能可分解为两组分内在自由能加一"连接自由能（connection Gibbs energy）"，即非加和项/有效摩尔浓度的理论根据。
- 【事实，metadata_verified，本轮核】Hunter & Anderson 2009（Angew Chem Int Ed 48，10.1002/anie.200902490，E8）："What is cooperativity?"——螯合协同（chelate cooperativity）与有效摩尔浓度 EM 的判据框架，界定正协同/负协同/加和。
- 【事实，metadata_verified，本轮核】Cockroft & Hunter 2007（Chem Soc Rev 36:172–188，10.1039/b603842p，E9）："Chemical double-mutant cycles: dissecting non-covalent interactions"——化学双突变循环，用四角受体/客体系统隔离并**定量测量**两相互作用之间的耦合自由能。**这是 A10 §7 三件套消融的严格化形式与 ΔΔG_int 的测量方法学来源。**

【诚实边界】E7–E9 是物理有机学方法学/理论，不是 NP 或酶的直接证据；A10 用它们把"非加和"变成可计算、可测量的量，但**协同大小与选择性在水相 NP 体系中成立与否，是本案待证伪的设计假设，无先例背书**（见 §9 W1、KS1）。

## 3. 仿生对应矩阵（≥1 条硬对应，六列完整）

### HC1（硬对应，核心）：ipso 途径"两特征合取底物规则" → 协同双点合成受体（非加和交叉项）

- **生物特征**：ipso 途径对底物的判据是合取式——既需对位酚（E3 共用识别位点，卤代竞争抑制）**又**需 α-支化拓扑（E1、E4），二者缺一显著降低进入途径的能力。（诚实：这是代谢/抑制/异构体选择性层面的推断，酶侧其电子起源为稳定中间体的阳离子特征 + 酚盐锚定，**无测定的结合协同耦合能**；本对应为"合取逻辑→协同设计"的**逻辑/几何转译**，非共活性位点机制复制，T8 遵守。）
- **来源支持**：E1、E3、E4；定量骨架 E7–E9。
- **材料实现**：深腔 cavitand（α-分支形状亚腔）+ 上缘单臂收敛氢键锚定基（对位酚 OH 的供受体），二者置于**匹配相对矢量 (d, θ)**；成一"几何匹配受体系列"。
- **预期功能**：满足两特征（支链就位 + 酚 OH 锚定）的 NP 获得**超加和**结合（连接自由能/EM 加成，E7、E8）；仅满足其一者（线性尾无法在锚定几何下就位；或无酚 OH 头基）只得加和/单点结合 → NP 相对 4-n-NP、NP1EO 的分辨被交叉项**放大**。
- **测量**：双突变循环四角受体的 ΔG，计算 ΔΔG_int（E9 方法）；单异构体/近似物 1:1 ITC + ¹H NMR 滴定；固定床分离因子。
- **因果对照**：四角受体系统本身即因果对照（见 §4.3、§7.2）——仅形状无锚定、仅锚定放宽容腔、双消融空白。

### HC2（硬对应）：就位门控的限域氢键（水竞争→开关式资产）

- **生物特征**：ipso 识别在（去溶剂化的）酶口袋内以酚（盐）锚定 + 支链就位联合发生（E3、E5 几何旁证）。
- **来源支持**：E3、E5（旁证，不承重）；就位几何旁证 E11（β-CD⊃NP 尾入头驻）。
- **材料实现**：疏水深腔先埋入壬基尾（预付去溶剂化并定位酚 OH 到腔口部分去溶剂化微环境），收敛锚定基在此限域处与酚 OH 成定向氢键。
- **预期功能**：本体水中被淹没的氢键**仅在正确就位时**有效并具分辨力；线性 4-n-NP 就位不良 → 氢键淹没 → 协同崩塌；NP1EO 极性 EO 抗埋入 + 醚氧几何不匹配 → 协同崩塌。
- **测量**：H3 光谱证据（就位后酚 OH 伸缩频率位移；¹⁵N/¹⁷O 标记锚定基化学位移变化；ROESY 取向）；ΔΔG_int 随就位质量单调。
- **因果对照**：锚定基甲基化（废除氢键，仅形状）预期光谱信号与协同项消失；壬基苯甲醚（无 OH）滞留比。

### HC3（软对应，可选序列层）：立体效应指数序列（拓扑维正交于 logKow）

- **生物特征**：出水残留与立体效应指数正相关 R²=0.76（E2）。
- **材料实现/测量/对照**：同 A01 HC3——单异构体 Kd 对立体效应指数回归，Kd 对 logKow 零检验（|r|<0.3）。此维**与 A01 共享**，非 A10 原创承载点，仅作正交性佐证。

## 4. 材料架构与选择性机制（非蛋白）

### 4.1 识别单元

**深腔 cavitand（间苯二酚芳烃/焦性没食子酚芳烃衍生 vase 型深腔）+ 上缘单臂收敛氢键锚定基**。三要素：

1. **α-分支形状亚腔**（深腔本体）：腔深匹配紧凑 α-支链 C9 分支丛轴向尺寸且短于线性 C9 全长（约 1.1 nm），腔宽匹配支链横向截面（α-四级碳约 0.55–0.6 nm）；线性尾在酚 OH 被锚定时无法完整埋入。尺寸不引用文献，由 §6 Step 0 显式溶剂建模给出，标计算设计值。
2. **收敛氢键锚定臂**：上缘单点接刚性 spacer，末端为收敛的氢键供/受体（候选：2-氨基吡啶/2,6-二酰胺基吡啶/脲/Kemp 酰亚胺羧酸），投射于腔口上方，与就位客体的对位酚 OH 成定向氢键。
3. **几何匹配系列（A10 特有可调变量）**：以 2–3 种 spacer 长度/角度离散调 (d, θ)，构成匹配系列；ΔΔG_int 在匹配几何处最大，失配成员作对照（此即 A01 无的空间组织自由度）。

### 4.2 格式、成网化学与对照

- **水溶性模型受体**（下缘羧酸盐亲水化，不占锚定位）：用于 ITC/¹H NMR/双突变循环测本征 ΔΔG_int 与 pH 7/12 可逆性。
- **成网固定**：沿用 A01 已通过的两条非 CMR 温和路线——(A) 下缘降冰片烯 + 刚性芳基双四嗪无催化 IEDDA 点击；(B) 下缘乙烯基 + DVB-80 自由基悬浮（HIPE 大孔）；Friedel-Crafts 仅作备选并前置腔体/臂矢量保留光谱证据（¹H NMR vase 图样、¹³C CP-MAS、客体置换可及性、锚定臂 ¹⁵N/FTIR 保留）。载体类别（间苯二酚芳烃 POP / HCP / COF）非发明，见 E16。
- **四角受体（双突变循环，全案证据核心，见 §7.2）**：R11 双维（匹配几何 + 锚定）、R01 仅形状（锚定基甲基化）、R10 仅锚定放宽容腔（腔扩壁失配、保留锚定）、R00 双消融空白（扩腔 + 甲基化）。四者同化学骨架、同成网路线，仅差两处"突变"。

### 4.3 选择性机制分解与非加和的定义

- **主选择性来源＝交叉耦合项 ΔΔG_int**（非加和）。定义（E9 双突变循环）：对某客体 G，ΔΔG_int(G) = ΔG₁₁(G) − ΔG₁₀(G) − ΔG₀₁(G) + ΔG₀₀(G)，其中下标为 (锚定, 紧腔) 的有/无。ΔΔG_int < 0 为正协同（超加和）。
- **物理来源**：就位门控的限域氢键（HC2）——疏水就位预付去溶剂化并定位酚 OH，使限域氢键有效；连接自由能/EM 加成（E7、E8）使双点结合超加和。
- **避 T1**：分辨力不来自疏水容量（logKow 近简并/单调对本案有利），而来自 ΔΔG_int 这一**不可由单一物化参数导出**的交叉项；体积受限使位点可饱和（Langmuir），疏水仅作驱动力不作选择性来源。Kd 对 logKow 零检验（H4）强制。
- **对 octa acid 谱系 2:1 胶囊风险（E17）**：沿用 A01 论证——下缘共价固定几何阻断笼-笼二聚，ng/L 占据质量作用不利二聚；可溶受体若现 2:1 须 DOSY/Job 图解耦后以 1:1 常数入比较。

### 4.4 报告口径与泄漏锚定

容量以总干复合体 mg/g（mg/L 级平台）与 packed-bed mg/mL 双口径报告；可及位点密度 µmol/g（受体接入量 ¹³C CP-MAS/元素分析 + 腔口/锚定可及性探针置换 ¹H NMR）；**空白载体（R00 及无受体网络）贡献逐竞争物报告占比**；工艺参照同 EBCT/同进水浓度 GAC 并排床（E14）。残留单体/连接体泄漏报告限取健康基准低一个数量级：styrene 10 µg/L（EPA MCL 0.1 mg/L，E19）；无监管值物种 0.075 µg/L（TTC 导出 0.75 µg/L 低一数量级，E18），LC-MS/MS 与 GC-MS-SIM 专属痕量方法，超限即格式失败。

## 5. 创新性检查清单 A–E 逐项结论（显式对比 A01）

- **A 机制创新：通过。** 选择性来源为**就位门控限域氢键驱动的锚定维×形状维非加和交叉项 ΔΔG_int**，超越普通疏水/静电/尺寸筛分，且可被双突变循环直接证伪。**对比 A01**：A01 承重为单一形状维、锚定为定向使能器（交叉项恒零）；A10 把交叉项本身做成识别原理与核心证据，是新增识别自由度。诚实限制：协同/EM 概念在超分子化学已成熟（E7–E9），增量在"用于 NP 就位门控限域氢键 + 与 α-拓扑耦合"的具体命题。
- **B 材料架构创新：部分通过（中等）。** 新空间组织自由度＝锚定基↔形状亚腔相对矢量 (d,θ) 的几何匹配系列（A01 只调 D、W）。诚实限制：cavitand + 收敛识别臂在超分子化学有先例，载体类别非发明（E16、E17）；B 维中等，与 A01 同档。
- **C 仿生转译创新：通过。** 转译"ipso 两特征合取底物规则→协同双点受体"的**逻辑/几何原则**，超越官能团类比，且提取了不可由常规化学直觉直接得到的原则（合取识别→就位门控协同）。**对比 A01**：A01 转译"α-拓扑逆读标尺"（单特征形状读取）；A10 转译"合取→协同"（两特征耦合）。诚实限制：无结构生物学支撑，为逻辑/几何统计对应，E5 仅 metadata 不承重，T8 遵守。
- **D 选择性策略创新：通过（本案最强）。** 两个正交识别维经**双突变循环四角受体**解耦，非加和交叉项为核心可证伪量；承重收敛到 logKow 近简并硬对（NP/4-tert-OP、NP/NP1EO、NP/4-n-NP）；竞争谱含结构近似物 + 氯代 NP + BPA；Kd–logKow 零检验强制；长链 NPEO/LAS 仅作外围平庸对照不承重（避 T1）。**对比 A01**：A01 三件套消融解耦形状/锚定但承重单一形状维；A10 三件套即双突变四角，直接测交叉项。
- **E 先例区分：通过。** 系统检索（简报 G3/G7 交汇零直接先例；本轮复核 NP-协同双点受体/双突变循环 NP 选择性吸附零命中）；与最近先例可量化区分——CD 基线偏好 4-tert-OP（E10，须反转）、A01 单形状维（须测出非零选择性 ΔΔG_int）、A03 SBA-15 双位点（限中孔硅、无非加和判据、无 ng/L 场景）。增量：若 ΔΔG_int 显著且选择性成立，足以独立发表。

**结论**：A、C、D、E 通过，B 部分通过（中等）；D 为最强承载维，满足"至少一维超越先例且显式对比 A01"。

## 6. 台架合成 SOP 草图（两级 go/no-go 门先于成网）

- **Step 0 建模门（先于合成投入）**：客体库构象搜索（GFN2-xTB / B3LYP-D3）；对 2–3 个候选 (d,θ) 受体，用显式溶剂 PMF/双去耦（double-decoupling）计算四角受体对 NP、4-n-NP、4-tert-OP、NP1EO 的 1:1 结合自由能并算 ΔΔG_int。**go 判据：匹配受体 ΔΔG_int(NP) ≤ −1.5 kJ/mol 且对 NP 的 |ΔΔG_int| 大于对 4-n-NP、NP1EO（在硅中即体现选择性）**；不满足则换臂几何重设计，两轮仍不满足则角度终止（KS1 前置）。输出标计算设计值。
- **Step 1 受体库与把手**：间苯二酚芳烃前体→深腔缩合（喹喏啉/苯并咪唑酮壁）；上缘单点接收敛锚定臂（2-氨基吡啶/二酰胺基吡啶/脲，含 ¹⁵N 标记用于 HC2 光谱）；下缘双把手（降冰片烯/乙烯基）与羧酸水溶衍生物；¹H/¹³C NMR、HRMS 确证。制备四角变体 R11/R10/R01/R00。
- **Step 2 可溶受体本征结合与双突变循环（go/no-go 其二）**：单异构体/近似物 ITC + ¹H NMR 滴定（µg/L–mg/L，低浓需预浓缩或 ≤1% DMSO-d₆）；Job/DOSY 定化学计量（检出 2:1 胶囊则全局拟合提 1:1）；ROESY 定取向；四角受体测 ΔΔG_int。**go 判据：ΔΔG_int(NP) ≤ −1.5 kJ/mol 且对 NP 选择性成立**；否则 H1 证伪、角度终止（KS1）。
- **Step 3 单异构体库**（与 Step1–2 并行）：优先靶标 E1 点名的 NP193a/b 等富集异构体；技术 NP 液相分离 + 定向合成；商品 4-n-NP/4-tert-OP/2-NP/3-NP/NP1EO 采购；降级口径同 A01。
- **Step 4 成网与表征**：路线 A/B 成珠，索氏活化、超临界 CO₂ 干燥；N₂ 吸脱附、¹³C CP-MAS、FTIR、TGA、SEM/压汞、残留单体 GC-MS；腔口/锚定臂可及性探针置换 ¹H NMR。
- **Step 5**：按 §7 网络选择性、床层、再生。

## 7. 实验与因果对照计划

### 7.1 竞争物与结构近似物谱

**承重硬对**：NP（α-四级碳，优先 NP193a/b）/ 4-n-NP（同碳数线性，拓扑维）；NP / 4-tert-OP（C9 vs C8，同 α-四级碳）；NP / NP1EO（同尾，头基变）。**取向/锚定探针**：2-NP、3-NP（对位偏好）、4-n-壬基苯甲醚（无 OH）。**风险/生态位**：2-氯-4-n-NP（氯代 NP，自合成，E1 富集/T4 背景）。**异类酚**：BPA。**外围平庸对照（不承重）**：长链 NPEO（NP4EO+）、LAS（线性 C10–C13）——验证平庸可分维不被误当承重。**基质**：Suwannee 河腐殖酸（mg/L DOC）、LAS/NP1EO 跨 CMC 混配、真实市政二级出水（加标 + 本底）、DOC 匹配超纯水对照。

### 7.2 双突变循环（核心因果证据，E9 方法）

四角受体 R11/R10/R01/R00 × 全竞争谱，全浓度并行，测各 ΔG，算 ΔΔG_int(G)。**判定**：(i) ΔΔG_int(NP) 显著负（协同）；(ii) |ΔΔG_int(NP)| ≥ 2×|ΔΔG_int(4-n-NP)|、≥ 2×|ΔΔG_int(NP1EO)|（协同本身具选择性）；(iii) 无锚定/放宽容腔任一单维受体的 SF 显著低于双维（H2 超越性）。此即用户要求的"仅锚定放宽容腔/仅形状无锚定/双维"三件套的严格化（四角含双消融空白基线）。

### 7.3 其他因果对照

logKow 零检验兼查摩尔体积单调（H4）；立体效应指数相关（HC3 可选）；等温线形状（Langmuir 饱和 vs Freundlich 线性分配）；HC2 光谱门控证据（就位后酚 OH 频移 / 锚定基 ¹⁵N 位移在 R11 现、R01 失）；可溶受体 2:1 胶囊化学计量检验 + 网络 1:1 确认。

### 7.4 真实基质、再生、泄漏、稳定性、床层

- 二级出水加标回收 + 本底，DOC 匹配超纯水对照；SF 以二级出水/超纯水比值表达（H5）。
- 再生：甲醇优先，pH 12 NaOH 阶梯为第二路径（下缘酚盐化失稳风险，同 A01 W7），≥5 循环报容量保持/SF 漂移/锚定光谱保留（含限域氢键光谱）。
- 泄漏：出水 TOC + 单体/连接体 LC-MS/MS、GC-MS-SIM，限值见 §4.4。
- 稳定性：pH 2/7/12 浸泡、碱循环老化、NOM 三循环污堵-恢复；点击连接水解监测。
- 床层：EBCT 5–10 min，0.5 µg/L 级 BV 穿透（10% 穿透点），mg/mL 床容量，GAC 并排（E14）；动力学 SF（H6）。
- 风险闭合（T4）：捕获型，不涉氯化/氧化产物；仍设单异构体组成漂移监测（重点 NP193a/b 高雌激素组分）+ 三流股 YES（E15），验收以 EEQ 去除 + 组成漂移联合判定，母体质量去除不单独验收。

### 7.5 kill-switch 判据（预注册）

- **KS1（角度存亡）**：Step 0 或 Step 2 测得匹配受体 ΔΔG_int(NP) > −1.5 kJ/mol，**或** ΔΔG_int 对 NP 相对 4-n-NP/NP1EO 无选择性（加和塌缩）→ A10 塌缩为"A01+平庸锚定"，**角度终止**（这是全案最可能触发点）。
- **KS2**：SF_双维 未超越单维之较大者的 2 倍（H2 不成立）→ 非加和主张不成立，降级或终止。
- **KS3**：Kd 与 logKow 正相关且交叉项不显著（T1 命中）→ 退化为疏水分配，证伪。

## 8. 成功与失败判据（可证伪、可量化）

### 8.1 成功（完全成功须同时满足 S1–S6）

- **S1（协同核心）**：ΔΔG_int(NP) ≤ −3 kJ/mol 且 |ΔΔG_int(NP)| ≥ 2×|ΔΔG_int(4-n-NP)|、≥ 2×|ΔΔG_int(NP1EO)|（完全成功）；−1.5 至 −3 kJ/mol 为机制确认但量级中等（仅支持机制成立主张）。
- **S2（超越性）**：SF_双维(NP/4-n-NP) ≥ 3、SF_双维(NP/4-tert-OP) ≥ 2，且 SF_双维 ≥ 2×max(SF_仅形状, SF_仅锚定)。
- **S3（网络亲和/容量）**：Kd(NP) ≥ 10⁴ L/kg 为优、5×10³ 为可行下限；总干复合体容量 ≥ 10 mg/g（设计值）；packed-bed ≥ 3 mg/mL；位点密度如实报告。
- **S4（选择性保持）**：二级出水 SF ≥ 超纯水 50%；空白 R00 无异构体选择性；R01/R10 的 ΔΔG_int 均近零。
- **S5（再生/泄漏）**：5 循环容量保持 ≥ 80%、SF 漂移 ≤ 20%、锚定光谱保留；泄漏低于健康基准锚定限。
- **S6（动力学）**：t90 ≤ EBCT 1/3，动力学 SF ≥ 平衡 SF 一半。

### 8.2 失败（任一触发对应证伪/重设计）

- **F1**＝KS1：协同项不显著或非选择 → H1 证伪、角度终止（塌缩为 A01）。
- **F2**＝KS3：Kd 与 logKow 正相关且交叉项不显著 → T1 命中、H4 证伪。
- **F3**：R01（仅形状）SF 与 R11 无显著差异 → 锚定维不贡献、协同不成立（等价 A01，本角度无增量）。
- **F4**：可溶受体协同成立但网络 SF 消失 → 格式工程失败，允许一次重设计；仍不通过则终止。
- **F5**：4-tert-OP 优于支链 C9 NP（Crini 方向 E10）→ 轮廓/协同读取证伪。
- **F6**：二级出水 SF < 1.5 或 Kd < 10³ → 主场景不可行。
- **F7**：碱循环容量保持 < 50% 或锚定光谱消失 → 转温和洗脱，再不成立则工程终止。
- **F8**：泄漏超限 → 成网化学重设计。
