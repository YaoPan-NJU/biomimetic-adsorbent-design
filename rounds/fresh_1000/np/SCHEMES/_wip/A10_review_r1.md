## 一、承重问题 C1 的独立核验：A01 是否已含非零 anchor×shape 交叉项？

A10 的**全案命门**（其 §0.1 自述"全案命门"）压在一句可判定事实主张上：

> "A10 的核心物理量：交叉耦合自由能 ΔΔG_int……在 A01 的设计逻辑里**恒为零**（A01 从不主张协同交叉项）。"（A10 §0.1 / §5-A）

若此命题为真，A10 相对 A01 新增一个真正的识别自由度；若为假，A10 塌缩为"A01 的 DMC 重述 + 锚定位置参数寻优"。这是本案唯一的枢纽，我逐字重读 A01 正文自判。

### 1.1 先记一处双方共同的引文失真（独立发现）

设计者 §0.1 与攻击者 C1 **都**把一句话当作 A01 原文直引：
- 设计者：'A01 的酚羟基腔口锚定（其 HC2）的功能是**固定分子取向**（"腔口锚定固定分子取向"，A01 §4.1、HC2）'
- 攻击者：'A01 §4.1 / HC2 明文："腔口边缘氢键锚定**固定分子取向**，使形状维**得以读取拓扑**"（原文"固定分子取向，使形状维得以读取拓扑"）'

我在 A01 全文检索："读取拓扑 / 得以读取 / 使形状维 / 取向使能" —— **0 命中**。A01 HC2 的实际原文是（A01 line 111）：

> "预期功能：分子取向固定，α-分支丛被锁定在紧邻腔口的轮廓区；对位偏好（2-NP 与 3-NP 滞留下降）。"

即攻击者所引"使形状维得以读取拓扑"**并非 A01 原文**，属其对 A01 的转写；设计者所引亦为转写。裁决者不采信任何一方对 A01 的引文，改以 A01 实际正文判定。**这一失真不影响 C1 结论**，因为承重证据不在 HC2 转写句，而在 A01 §4.1 的机制描述句（下）。

### 1.2 A01 实际正文表明其形状分辨"条件依赖于锚定就位"

A01 §4.1 识别单元几何（A01 line 128，逐字）：

> "闭腔底深度 D 匹配 α-四级碳 C9 紧凑分支丛的轴向尺寸且短于线性 C9 链全长（约 1.1 nm），**线性异构体在酚羟基锚定于腔口边缘时无法完全入腔**，须付出链弯折罚或部分尾段暴露于水，支链异构体可完全入腔……腔口边缘氢键锚定固定酚羟基。"

关键在"线性异构体**在酚羟基锚定于腔口边缘时**无法完全入腔"——A01 明确把"线性尾被排斥（形状分辨）"设为**锚定就位的条件后果**。用双突变循环（DMC）语义翻译：

- ΔΔG_int(G) = ΔG₁₁ − ΔG₁₀ − ΔG₀₁ + ΔG₀₀，即"有锚定时的形状分辨"减"无锚定时的形状分辨"。
- A01 自陈：无锚定固定取向时，线性尾**可以**改以尾入深腔（甚至比支链尾更深地填腔），形状排斥被显著削弱或反向；有锚定时线性尾被迫"头驻腔口、尾弯折"从而付罚。
- 故"有锚定的形状分辨" ≠ "无锚定的形状分辨" → **ΔΔG_int(A01) ≠ 0**。

A01 §4.3（line 139）确实把两维称为"正交第二维度"，但"正交（作为独立设计轴）"不等于"加和（无耦合）"；A01 的**运作机制描述**（条件性排斥）决定物理，而该描述是耦合的。即便对 A01 作最善意解读，其交叉项也**非零**。

### 1.3 C1 裁定

**A10 的枢纽命题"A01 交叉项 ≡ 0"为假**，被 A01 §4.1 自身正文证伪（线性尾排斥被明文设为锚定就位的条件后果，即一个非零 anchor×shape 耦合，只是 A01 未用 DMC 词汇命名并测量它）。

由此，A10 相对 A01 的"新识别自由度"塌缩为两块，均不构成新识别原理：
- **(a) 命名/测量重述**：把 A01 已存在的 anchor×shape 耦合改用 DMC 四角受体词汇描述并加测一个数（ΔΔG_int）；
- **(b) (d,θ) 参数寻优**：把 A01 固定于腔口的锚定位置离散化为"匹配系列"并挑最优——这是对 A01 架构中"锚定放在何处"的参数优化，命中 T2/T3（参数/构型变体），非 A01 原理无法覆盖的新维。

**关于设计者新自由度的一点独立让步（不改结论）**：A10 把锚定-亚腔相对矢量 (d,θ) 显式化为可调设计变量，确实是 A01 未显式调节的变量（A01 可调变量为 D、W，锚定固定于腔口）。若 (d,θ) 能**在 A01 等效四角受体基线之上**再打开一个不可由 D、W 覆盖的分辨自由度，则 A10 有真增量。但这需要证明"赢过 A01 等效受体"而非仅"赢过双消融空白 R00"——而 A01 交叉项非零，故"赢过 R00"≠"赢过 A01"。设计者全案（§7.2、§8.1 S1）的判据只对照双消融空白，未设 A01 等效基线，因此其原创性论证在方法上**不能**证明超越 A01。**C1 成立，判 critical，open。**

C1 与已终止的 A04 同构：A04 被判死的形状正是"相对已通过 A01 无独立新维 + 修补路径互斥"（A04 存档 line 43、54）。A10 是同一结构性原创性天花板。

## 二、限域氢键交叉项在本体水（pH 6–8.5）中的热力学可行性独立评估

A10 全案选择性承重于 HC2"就位门控限域氢键"产生的显著负交叉项 ΔΔG_int。我逐项独立推演其热力学，特别针对承重硬对（尤其 NP/4-tert-OP，酚头相同）。

### 2.1 本体水中单条中性酚 OH···受体氢键净自由能 ≈ 0 到几 kJ/mol

中性酚 OH（pKa≈10.3，pH 6–8.5 全中性，静电无效）与受体氢键基成键，须先各自去水合；焓增益被去溶剂化罚大幅抵消，水相净贡献通常仅零到几 kJ/mol，且强依赖去溶剂化程度。这是主客体化学共识——亦即为何 DMC 定量 H 键**螯合协同**的经典工作（Hunter 组）须在**低极性非竞争性有机溶剂**中完成。设计者引 E7–E9（Jencks/Hunter/Cockroft-Hunter）为"非加和可存在、可测"的骨架，但同一框架对**弱、水竞争氢键预测低协同**——即 E7–E9 对水相本案实为**中性偏不利**的先验，而非背书。攻击者 L2 对此的指认成立。

### 2.2 几何自相矛盾：腔口是溶剂暴露最强处，非去溶剂化深埋口袋

A10 要求疏水尾**入腔**、酚 OH 留在**腔口（rim）**并在此就位（§4.1、HC2"酚 OH 定位到腔口部分去溶剂化微环境"）。酶中增强的限域氢键位于**深埋**口袋；本案几何**强制** OH 停在受体溶剂暴露最强的腔口。设计者的缓解论证是"疏水尾预付去溶剂化 + 收敛臂在腔口上方投射造半封闭 niche"，理论上可造**部分**去溶剂化，但"腔口半封闭 niche"能在本体水中产生**可测且承重选择性**的去溶剂化增强，缺乏先例、且与"OH 须留腔口"的几何强约束张力真实。攻击者 H2-2 的"要么 OH 深埋破坏形状读取、要么 OH 腔口仍被水淹没"是二分极化的强表述；物理上存在中间态（部分去溶剂化），但该中间态能否稳健 >kT 无保证。裁定：这是**真实的 high 级科学风险**，非绝对不可能，但先验不利。

### 2.3 量级 vs kT，与柔性臂预组织熵罚

- RT(298 K) = 8.314×298 ≈ **2.48 kJ/mol**。设计者完全成功阈 ΔΔG_int ≤ −3 kJ/mol ≈ 1.2 RT；机制成立阈 −1.5 kJ/mol ≈ **0.6 RT**。即"机制成立"下限本身低于 kT，交叉项符号（正协同 vs 反协同）在此微环境无先验保证。此推算独立复核**正确**。
- 单臂收敛氢键基挂在 spacer 上，水相构象采样广；锁定到 (d,θ) 匹配几何须付预组织熵罚，量级常与一条弱氢键焓增益相当或更大，进一步把净 ΔΔG_int 压向零甚至变正。

### 2.4 NP/4-tert-OP 承重对：归因逻辑独立复核

攻击者 H5 断言"该对酚头完全相同、锚定维是不变量，故涉锚定的耦合不可能对该对产生选择性、逻辑不自洽"。此表述**部分过头，我不全盘采信**：ΔΔG_int 按定义正是 anchor×shape **耦合**，而 shape（C9 支尾 vs C8 支尾）在该对上确实变化；若 C8 尾就位质量退化削弱了对限域氢键的门控，则 ΔΔG_int(NP) 与 ΔΔG_int(4-tert-OP) **可以**不同——设计者逻辑在此并非自相矛盾。

但攻击者的**实质结论仍成立**：无论把该对的分辨归于"纯形状"（A01 战场）还是"形状门控的氢键耦合"（A10），**可观测的选择性都是尾形效应**，而 A01 已覆盖；要把该分辨专门归因于交叉项，须让四角 DMC 干净解析一个亚 kT 量（见 2.5）。且 Crini 基线（E10/BRIEF T7）方向为 4-tert-OP 吸附最优，A10 与 A01 一样须先反转此方向。故 NP/4-tert-OP **不是** anchor 维的合格判定对，只能作纯 shape 对照对。承重硬对三对（NP/4-n-NP、NP/4-tert-OP、NP/NP1EO）中，唯一 anchor 真正变化的是 NP/NP1EO，而该对又被"NP1EO 更亲水 + 极性 EO 抗埋入"的纯疏水/形状先验覆盖。攻击者 H5 的承重对掏空成立（表述细节我已修正）。

### 2.5 亚 kT 交叉项的可测性（H3 独立复核）

ΔΔG_int 是四个独立 ΔG 的"差之差"，误差传递给出 σ(ΔΔG_int) = 2σ（四项等权、独立）。以 3σ 解析 −1.5 kJ/mol 需每测 σ < 0.25 kJ/mol。R10/R01/R00（放宽容腔/甲基化）为弱结合体（Kd 落 mM 级），其 ITC/NMR ΔG 误差常 ≥0.5–1 kJ/mol → 2σ ≥ 1–2 kJ/mol，**大于目标绝对值**。结论：KS1 阈本身处噪声带内，DMC 很可能给出"**不可判定**"而非"证伪"。此推算独立复核正确，构成 D 维"核心可证伪量"的实质风险。M1（真实材料上四角受体无法干净单维消融、独立性假设破坏）叠加放大此风险。

### 2.6 热力学小结

限域氢键交叉项在本体水 pH 6–8.5 承重选择性的物理先验**净不利**：单条中性 H 键净能 ≈0/亚 kT、腔口暴露几何张力、柔性臂熵罚、目标量级 <RT、承重对可由纯形状覆盖、亚 kT 量落测量噪声内。这不是"量级中等"的可闭合风险，而是**全案唯一承载论点**的先验不利 + 零先例 + r1 零 in-silico/实验数据。

## 五、VERDICT

**terminate（结构性原创性天花板 + 热力学先验不利，r1 即判，非文本可修）。**

裁定理由链：
1. **C1（open critical）已成立且非待数据**：A10 全案命门"A01 交叉项≡0"经 A01 §4.1 原文（"线性异构体在酚羟基锚定于腔口边缘时无法完全入腔"）独立证伪，A10 塌缩为 A01 的 DMC 重述 + 锚定位置参数寻优。
2. **修补路径互斥封死（A04 同构）**：闭合 C1 须同时 (i) 撤回"A01≡0"改以 A01 等效四角受体实测/算得 ΔΔG_int(A01) 作真基线，(ii) Step 0 显式溶剂算出稳健、选择性、且**大于 A01 等效受体**（非仅大于双消融空白）的 ΔΔG_int，(iii) 证明 (d,θ) 是 A01 原理无法覆盖的新维。而 (ii) 与第二节四重不利先验（腔口暴露自相矛盾 / 亚 kT 不可解析 / 无仿生原型 / 承重对纯形状可分）正面冲突：算大多半是去溶剂化理想化或漏计熵罚的伪影，诚实算小即退回 A01（路径乙终止）。
