- 污染物：奥克立林（octocrylene, OC，CAS 6197-30-4，C₂₄H₂₇NO₂）｜角度：A04｜slug：michael-covalent-capture

- 状态：首轮设计完成，待攻击-裁决

## 0. 方案定位与已通过方案正交性声明

**已通过方案 S34（A01）机制概述**：OC 的 α-氰基-二苯基丙烯酸酯核作为 π 电子受体，与预组织富电子芳腔发生供体-受体电荷转移（CT）作用。选择性来源为非共价 CT 相互作用（可逆吸附）。

**本方案（A04）机制概述**：OC 的 α-氰基丙烯酸酯 C=C 为强迈克尔受体（电子亏缺双键），表面固定亲核基团（硫醇/胺）对其发生共价迈克尔加成。选择性来源为共价捕获（不可逆加成），区别于 S34 的非共价 CT。

**正交性矩阵**：

| 维度 | S34（A01） | S57（A04） | 正交性 |
|------|-----------|-----------|--------|
| 识别机制 | 非共价 CT（供体-受体 π-π） | 共价迈克尔加成（亲核-C=C） | 机制正交：非共价 vs 共价 |
| 电子学根源 | OC 核电子亏缺 → CT 受体 | OC 核电子亏缺 → 迈克尔受体 | **同源异流**：同一电子学根源的不同化学表达 |
| 可逆性 | 可逆吸附 | 共价捕获（可逆共价或位点更新） | 热力学正交 |
| 选择性逻辑 | 电子密度差（OC vs EHMC） | 双键电子密度差（OC 亲电 vs EHMC 亲核） | 选择性同源但表达不同 |
| 材料平台 | β-酮烯胺 COF + 离散笼 | 硫醇/胺功能化介孔碳/树脂 | 平台正交 |
| 原型 | 光合反应中心电子预组织 | 瞬间胶机理（氰基丙烯酸酯亲核聚合） | 原型正交 |

## 1. 科学问题与工程难题

### 1.1 科学问题

OC 的 α-氰基丙烯酸酯 C=C 因氰基强吸电子效应而极度电子亏缺，是经典迈克尔受体（瞬间胶即以此机理聚合）。相反，EHMC 的甲氧基取代使 C=C 电子富集，不作迈克尔受体。这一电子学差异与 S34 的 CT 识别同源（均源自 OC 核电子亏缺），但化学表达完全不同：CT 为非可逆 π-π 作用，迈克尔加成为共价键形成。

本方案的机制问题是：**能否在水相中性 pH 下，利用表面固定亲核基团（硫醇/胺）对 OC 电子亏缺 C=C 的迈克尔加成，实现 OC 的选择性共价捕获，且该共价捕获对 EHMC（电子富集，不作迈克尔受体）产生选择性？**

核心科学赌注：
1. 水相中性 pH 下硫醇/胺对 α-氰基丙烯酸酯的迈克尔加成速率是否足够
2. 共价捕获是否可逆（逆迈克尔/retro-aldol 释放二苯甲酮风险，命中 T2）
3. 共价捕获对胶束/DOM 增溶的热力学竞争是否免疫（非平衡吸附的优势）

### 1.2 工程难题

- **EC1 ng/L 工况**：主目标场景 ng/L–低 µg/L
- **EC2 再生**：共价捕获须走可逆共价（碱促逆迈克尔）或位点更新
- **EC3 碳质量平衡**：须闭合碳质量平衡，追踪二苯甲酮泄漏（GC7/T2）
- **EC4 产物毒性**：迈克尔加成产物（硫醇-OC 加合物）毒性须评估

### 1.3 设计假设

介孔碳或树脂表面固定硫醇（-SH）或仲胺（-NH-）亲核基团。硫醇/胺对 OC 的 α-氰基丙烯酸酯 C=C 发生迈克尔加成：

```
R-SH + OC(>C=C(CN)(COPh)₂) → R-S-C(CN)(COPh)₂（共价加合物）
```

反应选择性来源：OC 的 C=C 因氰基吸电子而亲电性强（迈克尔受体），EHMC 的 C=C 因甲氧基供电子而亲核性强（不作迈克尔受体）。选择性来自双键电子密度差异，非疏水性差异。

## 2. 生物原型与证据

### 2.1 原型家族

**P1 氰基丙烯酸酯亲核聚合化学（瞬间胶机理）**：α-氰基丙烯酸酯在弱亲核试剂（包括水、醇、胺）下即聚合，是确立的化学反应性。提供"电子亏缺 C=C 对亲核试剂高反应性"的化学原理。

**P2 谷胱甘肽 S-转移酶（GST）亲核捕获原理（原理级参考）**：GST 催化谷胱甘肽硫醇对亲电底物的共轭加成，原理为硫醇亲核攻击电子亏缺双键。按框架条款为原理级参考，不作直接仿生。

## 3. 材料架构

### 3.1 主平台：硫醇功能化介孔碳

**首选**：硫醇功能化介孔活性炭
- 介孔活性炭（4–8 nm 孔径）提供 OC 传质通道
- 硫醇基团通过硫醇化试剂（如 2-巯基乙胺）接枝于碳表面含氧基团
- 硫醇 pKa ~8–10，中性 pH 下部分去质子化为硫醇盐（更强亲核体）

**次选**：硫醇功能化超交联聚合物（HCP）

### 3.2 亲核位点优化

- **亲核性强弱序列**：硫醇盐（RS⁻）> 仲胺（R₂NH）> 伯胺（RNH₂）> 醇（ROH）
- **微环境 pKa 调谐**：疏水孔道降低局部极性，提升硫醇去质子化程度
- **位点密度**：目标 0.1–0.5 mmol/g（避免过高密度导致交联/聚集）

### 3.3 再生策略

- **可逆共价路线**：碱性条件（pH > 11）促逆迈克尔反应，释放 OC
- **位点更新路线**：若逆迈克尔不可行，以氧化再生硫醇位点（周期更新）

## 4. 选择性机制分层

### 4.1 两层架构

| 层 | 机制 | 角色 | 选择性贡献 |
|---|------|------|-----------|
| 第一层 | 疏水预浓缩（碳表面） | 使能层，非选择性来源 | 无（logKow 单调） |
| 第二层 | 迈克尔共价加成 | **选择性来源**（双键电子密度差） | OC 亲电 vs EHMC 亲核 |

### 4.2 选择性逻辑

- **OC vs EHMC**：OC C=C 电子亏缺（氰基吸电子）→ 迈克尔受体；EHMC C=C 电子富集（甲氧基供电子）→ 不作迈克尔受体
- **OC vs 二苯甲酮（DP2）**：DP2 无 C=C → 不作迈克尔受体
- **OC vs 多环麝香**：无极性 C=C → 不作迈克尔受体

### 4.3 与 S34 的选择性同源对比

S34 与 A04 共享同一电子学根源（OC 核电子亏缺），但化学表达不同：
- S34：CT 非共价 → 可逆吸附 → 分离因子 α
- A04：迈克尔共价 → 不可逆捕获 → 反应速率选择性

若两方案均通过，构成 OC 角度地图中"同一疼痛-同源电子学-两种化学表达"的互补方案对。

### 4.4 竞争物谱

| 层级 | 竞争物 | 预期行为 |
|------|--------|---------|
| 第一层 | EHMC | 电子富集 C=C，不作迈克尔受体 |
| 第二层 | BP-3、4-MBC、homosalate | 无氰基丙烯酸酯结构，不作迈克尔受体 |
| 第三层 | NOM | 疏水竞争 + 亲核基团可能被 NOM 羰基占据 |

## 5. 可证伪实验设计

### 5.1 Stage 0 反应性门（前置 go/no-go）

**模型反应**：
1. 小分子硫醇（如半胱氨酸或巯基乙醇）+ OC 在水相中性 pH 下的反应速率
2. HPLC 监测 OC 消失 + 加合物生成

**Go 线**：30 min 内 OC 转化率 > 50%（摩尔比 1:1，室温，pH 7）
**No-go**：30 min 转化率 < 10% → 水相中性 pH 迈克尔加成不可行

### 5.2 关键实验

| 实验 | 目的 | 通过判据 |
|------|------|---------|
| E-1 OC/EHMC 混合竞争 | 共价选择性 | OC 去除 ≥ 80%，EHMC 去除 < 20%（α ≥ 4） |
| E-2 因果对照系列 | 无亲核基团/去氰基类似物/亲核强弱序列 | C1 无共价捕获；C2 去氰基不反应 |
| E-3 反应动力学 | 硫醇-OC 加成速率 | 表观 k > 0.01 min⁻¹ |
| E-4 逆迈克尔/再生 | 碱性条件释放 | pH 12 下加合物分解 > 50% |
| E-5 二苯甲酮泄漏 | 碳质量平衡 | 二苯甲酮泄漏 < 1%（retro-aldol 控制） |
| E-6 NOM 竞争 | 二级出水基质 | OC 去除率下降 < 30% |
| E-7 5 循环 | 位点更新或可逆共价 | 容量保持 ≥ 70% |

### 5.3 失败判据

- Stage 0 水相中性 pH 迈克尔加成不可行（转化率 < 10%）→ 终止
- OC/EHMC α < 2 → 电子密度差不产生选择性
- 二苯甲酮泄漏 > 5%（retro-aldol 失控）→ 命中 T2，终止
- 亲核位点被 NOM 完全毒化 → 不可行

## 9. 与 S34 的互补性声明

S34（A01）以非共价 CT 识别腔实现可逆吸附选择性，本方案（A04）以共价迈克尔加成实现不可逆捕获选择性。两方案：
- **机制正交**：非共价 CT vs 共价迈克尔加成
- **化学表达正交**：π-π 电子互补 vs 亲核-亲电共价键形成
- **同源异流**：共享同一电子学根源（OC 核电子亏缺），但化学表达完全不同
- **失败模式互补**：S34 风险在水相 CT 弱；A04 风险在水相迈克尔加成慢
- **再生互补**：S34 可逆吸附易再生；A04 共价捕获再生困难但有位点更新路线
