# S35 · octocrylene A02 氰基与酯羰基偶极定向氢键锚位阵列（r1 设计稿）

- 污染物：奥克立林（OC，CAS 6197-30-4）｜角度：A02｜slug：cyano-ester-dipole-HB-array
- 轨迹：r1 = **本文件**
- 状态：r1 设计者交付，待攻击者/裁决者审理
- 与 A01 的正交声明：A01（S34，passed 85）以 OC 电子亏缺氰基丙烯酸酯核为 π 电子受体、构建供体-受体电荷转移腔（**电子维**）；A02 以 OC 的 α-氰基偶极与酯羰基为氢键受体对、构建预组织供体阵列（**极性/偶极维**）。二者为同靶正交机制轴：A01 读核电子密度差，A02 读氰基有无与偶极排布。

## 一、科学问题与工程难题

### 1.1 科学问题
水相中预组织氢键供体阵列（硫脲/脲/squaramide）能否在疏水遮蔽腔内对 OC 独有的 α-氰基-酯羰基偶极对实现定向双锚定，产生可测的 ΔΔG_dipole 增量，并区分仅差一个氰基的 EHMC（以甲氧基取代氰基）？

操作化判据：分离因子 α(OC/EHMC) 在供体阵列功能化材料 vs 供体全阻断对照（N-甲基化）上的差值，以及 α(OC/de-cyano-OC) 的比值。

### 1.2 工程难题
- **水相竞争**：氰基为极弱氢键受体（pKBHX ≈ 0.3–0.5，Laurence 2009 数据库标度；Laurence et al. 2009, doi:10.1021/jm801331y, PMID 19537797，**metadata_verified**）。硫脲 NH 在水中深度水化（thiourea-H₂O 结合能 ~33 kJ/mol per H₂O，Weiqun et al. 2005, doi:10.1016/j.theochem.2005.06.012，**metadata_verified**），水二聚体 H 键仅 ~21 kJ/mol（Feyereisen et al. 1996）。氰基-硫脲 H 键在水相本体中热力学不自发（ΔG ≈ 0 或正）。
- **OC/EHMC 区分极窄**：EHMC 甲氧基 pKBHX ≈ 0.5–0.7（脂肪醚氧），**不弱于** OC 氰基 pKBHX ≈ 0.3–0.5。单氰基位点的纯 H 键信号可能**不利于** OC 选择性。
- **logKow 单调陷阱**（T1）：OC logKow ~6.1–7.12，EHMC logKow ~5.9–6.1，差值 ≤1.0 单位。任何测得的 α 必须经脂质/有机质归一化排除 logKow 梯度解释。

### 1.3 设计策略应对
上述难题决定本方案**不能走本体水相 H 键识别**路线，必须：
1. **疏水遮蔽腔**：排除本体水，降低供体位点水化壳竞争（类比蛋白结合口袋排除水，Fleming 2010 PMID 20804202，**abstract_read**）；
2. **偶极-偶极静电互补**：氰基偶极矩大（乙腈 μ = 3.92 D），预组织供体阵列的 NH 部分正电荷定向排列与偶极互补，此静电分量在疏水腔内衰减慢、对氰基有几何选择性；
3. **双位点协同**：同时锚定氰基-N 与酯羰基-O（仅 OC 的 α-氰基丙烯酸酯同时具备二者、且间距固定），EHMC 的甲氧基氧在空间上不对应氰基位置（甲氧基在苯环对位而非 α-位），双锚几何对 EHMC 失配。

### 2.2 证据链总结
- **正面**：腈基在疏水口袋中作为 H 键受体有密集晶体学证据（E2, E3）；硫脲/脲/squaramide 预组织供体阵列化学成熟（E6, E7；本项目 PFBS S17）；OC 氰基丙烯酸酯偶极矩大（静电互补有物理基础）。
- **反面（诚实边界）**：**水相本体中腈基与硫脲供体的 1:1 H 键结合无直接溶液相实验先例**——所有正面先例（E2, E3）均在固相晶体或蛋白疏水口袋中。本方案的水相疏水腔内识别为**未经实验证实的推断**，须以 Stage −1 计算门 + Stage 0 等温滴定量热 go/no-go 前置。
- **关键定量缺口**：OC 氰基丙烯酸酯（α-位共轭腈）的精确 pKBHX 值未有实验测定，文献仅有简单腈类数据（E1）。α-氰基丙烯酸酯的 pKBHX 预期受酯羰基与苯基共轭调制，可能高于简单脂肪腈（0.39）但具体值未知，列为 Stage 0 必测参数。

## 四、材料架构与选择性机制

### 4.1 材料平台

**主平台**：β-酮烯胺水解稳定 COF（与 A01 共享骨架化学，降低合成风险），孔壁嵌入预组织 H 键供体阵列。

**供体单元候选**（三选一，按 pKa/NH 酸性排序）：
1. **硫脲**（Ar-NH-CS-NH-Ar'）：NH pKa ~21（DMSO），双 NH 共面，C=S 极化增 NH 酸性，本项目 PFBS S17 先例（E6）；
2. **Squaramide**（3,4-二氨基环丁-3-烯-1,2-二酮）：两 NH 共面汇聚，酸性强于硫脲（环张力+C=O 共轭），E7 squaramide 阴离子受体先例；
3. **脲**（Ar-NH-CO-NH-Ar'）：NH 酸性弱于硫脲，但 C=O 比 C=S 的 π 共轭更强致 NH 供体性更可调。

**主选硫脲**（与 PFBS S17 化学连续性），辅以 squaramide 作第二独立格式验证。

**供体阵列设计**：
- 双供体构型：两个硫脲单元经刚性芳基间隔（如 1,3-苯二甲胺骨架）固定，双硫脲共 4 个 NH，几何匹配 OC 氰基-N 与酯羰基-O 的间距（DFT 预扫 ~3.5–4.0 Å）；
- 三供体构型（备选）：C₃ 对称三足骨架（1,3,5-三氨甲基苯，同 PFBS S17 T 位点骨架），三个硫脲汇聚——但因 OC 仅两个受体位点（氰基+酯羰基），三供体可能过度约束。

**骨架系列**（等拓扑因果对照）：
| 成员 | 描述 | 功能 |
|---|---|---|
| **D（供体功能化）** | COF 孔壁嵌入双硫脲阵列 | OC 结合总亲和（疏水 + 偶极 H 键） |
| **M-CH₃（N-甲基阻断）** | 等骨架，硫脲 NH 全部 N-甲基化 | 移除 H 键供体，保骨架+疏水 → 隔离供体贡献 |
| **M0（裸骨架）** | 无功能化 β-酮烯胺 COF | 纯疏水基线 |
| **D-mono（单硫脲）** | 仅一个硫脲单元（双锚缺一） | 隔离双锚协同 |
| **D-flex（柔性间隔）** | 双硫脲经柔性烷基链连接（非预组织） | 隔离预组织贡献 |
| **D-sq（squaramide 替代）** | 双 squaramide 替代双硫脲 | 独立供体化学验证 |

### 4.2 选择性机制三层分层

**第一层：疏水预浓缩（非选择性来源）**
- OC logKow ~6.1–7.12 → 疏水 COF 孔壁自发富集 OC；
- 贡献总容量但不构成 OC/EHMC 选择性来源（二者 logKow 差 <1.0）；
- 以 M0 裸骨架 uptake 量化此分量。

**第二层：偶极定向 H 键锚定（选择性来源，主判据）**
- 疏水腔排除本体水后，预组织硫脲 NH 阵列对 OC 氰基-N 与酯羰基-O 的定向双 H 键：
  - **静电分量**：氰基偶极（μ ~3.9 D）与 NH 部分正电荷阵列的偶极-偶极互补，在低介电疏水腔内衰减慢（ε ~2–4），作用距离可达 ~5 Å；
  - **H 键分量**：氰基-N 作为弱 H 键受体（pKBHX ~0.3–0.5）接受 NH 供体，酯羰基-O（pKBHX ~1.0）接受另一 NH 供体；
  - **几何分量**：双锚定要求氰基-酯羰基间距 ~3.5–4.0 Å 与特定角度，仅 OC 的 α-氰基丙烯酸酯满足；EHMC 的甲氧基在苯环对位（距酯羰基 ~7–8 Å），无法同时双锚。
- ΔΔG_dipole = ΔG(OC, D) − ΔG(OC, M-CH₃) − [ΔG(EHMC, D) − ΔG(EHMC, M-CH₃)]
- 预期 ΔΔG_dipole ~1–3 kJ/mol（诚实预估下界；对应 α(OC/EHMC) ~1.5–3.3 at 298 K）

**第三层：刚性有限腔几何窗口（使能，非独立选择性来源）**
- 腔体体积限定 OC 的 L 形轮廓可入、过大多环麝香不可入（移交 A03/A13 协同）；
- 本层在本方案中为使能角色，不作为 A02 的独立选择性宣称。

### 4.3 因果对照逻辑

**核心因果签名**：R = [q(OC,D) − q(OC,M-CH₃)] / [q(EHMC,D) − q(EHMC,M-CH₃)]
- R > 1 → 供体阵列对 OC 有特异贡献（氰基信号存在）
- R ≈ 1 → 供体贡献对 OC/EHMC 等价（氰基信号不存在，假设证伪）
- R < 1 → 供体阵列反而偏好 EHMC（氰基非正面贡献，假设证伪）

**辅助签名**：
- q(OC,D) / q(de-cyano-OC,D) > 1.5 → 氰基对 OC 结合有正贡献
- q(OC,D) / q(de-cyano-OC,D) ≈ 1 → 氰基贡献不存在
- α 全谱（OC/EHMC/BP-3/DP2/HHCB/AHTN/EHS/HS/avobenzone）对 logKow 的线性 R² < 0.7 → 非纯疏水
- α 全谱对 logKow 的线性 R² > 0.9 → 纯疏水（命中 T1，假设证伪）

## 五、创新性检查清单逐项结论（A–E）

### A. 机制创新
- [x] 超越普通疏水分配/静电/尺寸筛分？**是**。偶极定向 H 键阵列读取 OC 独有的氰基丙烯酸酯极性单元，机制正交于 logKow。
- [x] 可被因果对照推翻的新识别原理？**是**。N-甲基阻断 + de-cyano 类似物 + α-logKow 线性三支柱因果签名 R，均可推翻。
- [x] 目标水质场景独特适用性？**是**。OC 为唯一含 α-氰基的常见 UV 过滤剂，EHMC 为结构最近竞争物。

### B. 材料架构创新
- [x] 超越载体替换/孔径调参？**是**。预组织双硫脲阵列的几何匹配设计，非简单功能化。
- [x] 新空间组织方式？**部分**。疏水腔内预组织供体阵列概念在超分子化学中成熟（Gale 2015 E7），但首次应用于水相 OC 捕获为新场景。
- [ ] 合成方法学贡献？**否**（诚实边界）。β-酮烯胺 COF + 硫脲后功能化为成熟化学，无新方法学。

### C. 仿生转译创新
- [x] 超越官能团类比？**部分**。从蛋白口袋的疏水遮蔽 + H 键识别提取"疏水腔排除水使弱 H 键可行"的设计原则，非单纯官能团移植，但转译距离大（蛋白→多孔骨架）。
- [x] 保留核心功能逻辑？**是**。疏水排除水 + 定向供体匹配弱受体的逻辑保留。
- 诚实边界：蛋白口袋的精细预组织度（Å 级）远超 COF 孔壁（~nm 级分散），转译落差如实标注。

### D. 选择性策略创新
- [x] 不可由单一物化参数单调解释？**是**。氰基偶极识别正交于 logKow，且 OC/EHMC logKow 差 <1.0。
- [ ] 两个正交维度协同？**否（本方案仅单维）**。A02 仅极性/偶极维；正交协同（偶极 × 几何）属 A13，本方案不移交。
- [x] 竞争物谱含结构近似物？**是**。EHMC 为 OC 最近结构近似物（仅氰基/甲氧基之差），竞争物谱全覆盖。

### E. 先例区分
- [x] 系统先例检索完成？**是**。OC 氰基识别零先例（G1/G2 全空）；腈基 H 键受体在药物化学密集但均非水相吸附语境。
- [x] 与最近先例可实验量化区分？**是**。最近先例为蛋白口袋腈基 H 键（E2），本方案为多孔骨架水相吸附，量化口径为 α(OC/EHMC) + 因果签名 R。
- [x] 增量足以独立发表？**边界**。若 α(OC/EHMC) ≥ 2 且 R > 1 成立，为水相偶极识别中性疏水污染物的首例，增量成立；若 R ≈ 1 或 α < 1.5，增量不成立，交付机制解耦论文。

**创新性清单总判**：A 通过、D 通过（单维但正交于 logKow）、E 通过；B 部分通过（标注边界）、C 部分通过（标注转译距离）。满足"至少一维明确可验证创新"门槛。

## 六、台架合成 SOP 草图

### 6.1 双硫脲功能化 COF（D 成员）
1. **β-酮烯胺 COF 合成**（同 A01 S34 SOP）：1,3,5-三甲酰苯 + 2,5-二烷氧基对苯二胺（供体壁）或 2,5-二氨基联苯（中性壁），6 M AcOH 催化，120 °C 溶剂热 72 h，得层状 COF；
2. **后功能化接枝**：COF 孔壁预留 -NH₂ 位点（合成时掺入 10–20 mol% 2,4-二氨基苯甲醛作接枝把手），与 4-硝基苯基异硫氰酸酯（或 3-硝基苯基，E6 取代基）在 DMF 中 60 °C 反应 24 h，得孔壁硫脲；
3. **双硫脲阵列构建**：接枝前体为 1,3-苯二甲胺双异硫氰酸酯（预合成：1,3-苯二甲胺 + 2 eq 硫光气 → 双 -NCS），与 COF -NH₂ 反应，得刚性间隔双硫脲；
4. **纯化**：DMF/MeOH/丙酮索氏萃取 48 h，120 °C 真空活化 12 h。

### 6.2 对照成员合成
- **M-CH₃**：D 成员合成后，硫脲 NH 经 NaH/MeI 在 DMF 中 0 °C→RT 甲基化（全阻断）；
- **M0**：裸 β-酮烯胺 COF，无后功能化；
- **D-mono**：掺入 5 mol% 接枝把手 + 单异硫氰酸酯（4-硝基苯基-NCS）反应；
- **D-flex**：己二胺双异硫氰酸酯替代 1,3-苯二甲胺双异硫氰酸酯（柔性间隔）；
- **D-sq**：双 squaramide 前体（3,4-二氯环丁-3-烯-1,2-二酮 + 2 eq 芳胺 → 双 squaramide-NHS 酯），与 COF -NH₂ 偶联。

### 6.3 表征
- PXRD（结晶度、层间距）；N₂ 吸附 BET（比表面积、孔径分布）；FT-IR（NH 3300–3400 cm⁻¹、C=S 1500–1550 cm⁻¹、C=O squaramide 1650–1700 cm⁻¹）；固体 ¹³C CP/MAS NMR（硫脲 C=S ~180 ppm、squaramide C=O ~170 ppm）；元素分析（N、S 质量分数→功能化度）；TGA（热稳定性）。

## 七、实验与因果对照计划

### 7.1 批次等温线（超纯水，25 °C，pH 7）
- 吸附质：OC、EHMC、de-cyano-OC（2-乙基己基-3,3-二苯基丙烯酸酯，定制合成或 DFT 模拟）、BP-3、4-MBC、DP2、HHCB、AHTN、EHS、homosalate、avobenzone；
- 材料系列：D、M-CH₃、M0、D-mono、D-flex、D-sq（至少 6 成员）；
- 口径：q（mg/g 总干复合体），初始浓度 0.1–10 mg/L（高浓参照，标"不与 ng/L 工况比"），另设 1 µg/L 单点 Kd；
- 报告：Langmuir/Freundlich 拟合，Kd at C→0，q_max，b。

### 7.2 选择性谱
- α(OC/X) = [Kd(OC)/Kd(X)]_D / [Kd(OC)/Kd(X)]_M0（供体贡献归一化分离因子）；
- 竞争物谱：EHMC（结构最近）、BP-3（酚 OH 可能 H 键）、4-MBC（无氰基无酯羰基）、DP2（降解产物，更小更平面）、HHCB/AHTN（多环麝香，无极性单元）、EHS/HS（水杨酸酯/水杨酸，酯羰基但无氰基）、avobenzone（β-二酮烯醇，强 H 键受体）；
- 主判据：α(OC/EHMC)_corrected ≥ 2（供体归一化后）。

### 7.3 等温滴定量热（ITC）
- OC/EHMC/de-cyano-OC 分别与 D、M-CH₃ 在 25 °C 水相滴定；
- 读取 ΔH, ΔS, Ka, n（化学计量）；
- 核心判据：ΔΔH_dipole = ΔH(OC,D) − ΔH(OC,M-CH₃) − [ΔH(EHMC,D) − ΔH(EHMC,M-CH₃)] 显著为负。

### 7.4 DFT 能量分解（Stage −1 前置计算门）
- 方法：ωB97X-D/def2-TZVP + SMD(water) 溶剂模型；
- 体系：双硫脲模型分子 + OC/EHMC/de-cyano-OC 1:1 复合物；
- SAPT0 能量分解：静电、交换排斥、诱导、色散四分量；
- Go/No-go 判据：|ΔΔE_elec+ind(OC vs EHMC)| < ~1 kJ/mol → 合成前降优先级。

### 7.5 真实基质
- S2 市政二级出水（DOC 5–10 mg/L）：1 µg/L OC + 等摩尔竞争物混合，批次 + 柱实验；
- DOM 效应：humic acid 0–20 mg/L 梯度，q_OC 衰减曲线；
- 表面活性剂：SDS 0–5 mg/L（模拟洗涤废水），q_OC 衰减。

### 7.6 再生与稳定性
- 再生：MeOH 洗脱（3 BV），5 循环容量保持率；
- 稳定性：pH 3–11 浸泡 7 d，PXRD/BET/FT-IR 前后对比；
- 泄漏：UV-Vis 监测流出液有机碎片（二苯甲酮特征峰 290 nm）。

### 7.7 ng/L 工况（可选，依赖 A19 预浓缩协作）
- 100 ng/L OC + 100 ng/L 竞争物混合，大体积批次（1 L），GC-MS/MS 定量；
- 判据：Kd(OC) ≥ 10⁴ L/kg，α(OC/EHMC) ≥ 2。

## 八、成功与失败判据（可证伪）

### 8.1 通过判据（须全部满足）
1. 因果签名 R > 1（统计显著，p < 0.05，三重复）；
2. α(OC/EHMC)_corrected ≥ 2（供体归一化后，D 端 vs M-CH₃ 端）；
3. q(OC,D)/q(de-cyano-OC,D) > 1.5（氰基贡献）；
4. α 全谱对 logKow 线性 R² < 0.7（非纯疏水）；
5. ITC ΔΔH_dipole 显著为负（与 M-CH₃ 差值 t 检验 p < 0.05）；
6. DFT SAPT 静电+诱导分量 OC vs EHMC 差 ≥ 2 kJ/mol（计算验证）；
7. q_max(OC,D) ≥ 15 mg/g（合理容量）；
8. S2 二级出水 OC 去除 ≥ 70%，5 循环 ≥ 70%，二苯甲酮泄漏 < 2%。

### 8.2 失败判据（任一即止）
1. R ≈ 1（供体贡献对 OC/EHMC 等价，氰基信号不存在）；
2. α(OC/EHMC)_corrected < 1.3 或统计不可区分；
3. q(OC,D) ≈ q(de-cyano-OC,D)（氰基贡献为零）；
4. α 全谱 vs logKow R² > 0.9（纯疏水，命中 T1）；
5. ITC ΔΔH_dipole 不显著或为正；
6. DFT SAPT 静电分量 OC vs EHMC 差 < 0.5 kJ/mol；
7. M-CH₃ 阻断后 OC 结合不降或升高；
8. S2 容量 < 30% 初值且判为 DOM 增溶主导；
9. 骨架崩塌（PXRD 非晶化 + BET < 50% 初值）。

### 8.3 Stage −1 计算门（前置）
DFT-SAPT 预示双硫脲模型对 OC vs EHMC 的 ΔΔE_elec+ind < 0.5 kJ/mol 或符号反转 → 合成前降优先级，残余价值移交 A13（偶极 × 几何协同）。

### 8.4 Stage 0 实验门
OC α-氰基丙烯酸酯的 pKBHX 实测（与 4-氟苯酚 CCl₄ 中 FT-IR 滴定）：若 pKBHX(OC-CN) < 0.3（极弱，低于乙腈），则水相偶极识别热力学不可行，合成前终止。

## 九、攻击预判与诚实风险

### 9.1 最大承重风险：水相偶极 H 键信号幅度（HIGH）
- **攻击**：氰基 pKBHX ~0.3–0.5 极弱，硫脲 NH 水化能 ~33 kJ/mol，即使疏水腔部分排水，残余水分子仍可竞争供体 NH，偶极 H 键增量可能 < RT（~2.5 kJ/mol），不可测。
- **设计者回应**：诚实承认此为核心科学赌注。应对：(a) Stage −1 DFT-SAPT 前置量化偶极静电分量在低介电腔内的可达幅度；(b) 偶极-偶极互补（非纯 H 键）在 ε~2–4 的疏水腔内衰减慢，静电分量可能主导（氰基 μ = 3.9 D，偶极-偶极作用能 ~μ₁μ₂/4πε₀εr³，r=4 Å, ε=3 → ~3–5 kJ/mol）；(c) Stage 0 pKBHX 实测 go/no-go。若两门均过，信号可达 ~2–5 kJ/mol（α ~2–7），可测。

### 9.2 次大风险：EHMC 甲氧基非 inferior（MEDIUM-HIGH）
- **攻击**：EHMC 甲氧基 pKBHX ~0.5–0.7 可能不低于甚至高于 OC 氰基 pKBHX ~0.3–0.5。供体阵列可能反而更偏好 EHMC。
- **设计者回应**：诚实承认 pKBHX 比较不利于氰基。但 A02 的选择性不来自单位点 H 键强度，而来自：(a) 双锚几何——氰基-酯羰基间距固定且双供体可匹配，EHMC 甲氧基-酯羰基间距/角度失配；(b) 偶极矩差——OC 氰基丙烯酸酯整体偶极（α-位 CN + 酯 C=O 协同）大于 EHMC（对位 OCH₃ + 酯 C=O 非协同排列）。R 签名的实验判定为最终仲裁。

### 9.3 logKow 陷阱（MEDIUM）
- **攻击**：α(OC/EHMC) 可能完全由 logKow 差（OC ~6.8 vs EHMC ~5.9，差 ~0.9 单位）解释。
- **设计者回应**：(a) 供体归一化分离因子 α_corrected = α(D)/α(M0) 消除疏水基线；(b) 全谱 α vs logKow 线性 R² < 0.7 为非疏水判据；(c) de-cyano-OC 类似物与 OC logKow 近（仅差 α-CN 贡献 ~0.2–0.3 单位），α(OC/de-cyano-OC) 不受 logKow 梯度污染。

### 9.4 仿生转译距离（LOW-MEDIUM）
- **攻击**：蛋白口袋 Å 级预组织度 vs COF 孔壁 nm 级分散，转译落差使"仿生"宣称弱化。
- **设计者回应**：诚实承认。定位为"概念迁移"（H3 动态对应），非"直接转译"（H1 硬对应）。核心仿生原则为"疏水排水使弱 H 键可行"，此原则在 COF 孔壁（疏水内壁排水）可保留。

## 十、报告口径

- 批次等温线：q（mg/g 总干功能化复合体），初始 ≥ 1 mg/L 的点明文标"高浓参照，不与 ng/L 工况比"（陷阱 6）；
- 动态床：穿透 BV 与 µg/mL 床，报实测湿沉降堆密度 ρ_b，总干换算 q_g = q_bed / ρ_b；
- 可及位点密度：紧结合探针分子（如 4-硝基苯酚与硫脲的已知 Ka）饱和吸附，mmol 受体/g 复合体；
- 受体臂质量分数：TGA + 元素分析（N、S）；
- M0 空白 uptake 单独报告，讨论供体贡献时扣除但容量口径不扣除；
- 材料环境属性：主体芳烃 COF + 硫脲/squaramide，非氟取代基。
