## 1. 简报锁定

### 1.1 污染物画像（锁定，不可修改）

| 参数 | 值 | 来源 |
|------|-----|------|
| 分子式 | C₁₂Cl₁₀ | PubChem CID 16318 |
| 摩尔质量 | 498.6 g/mol | PUG-REST |
| logKow | ~8.18（通行值）；XLogP3 8.3 | Hawker & Connell 1988 / PubChem API |
| 水溶度 | 推断 ng/L 级（无独立实测值） | Mackay 1980 / Li & Andren 1994 推断 |
| 构型 | 扭转（二面角 ~85°–90°），非共平面 | Pedersen 1975 X 射线晶体结构 |
| C–H 键数 | 零 | 结构决定 |
| 氢键供/受体 | 无 | 结构决定 |
| 可电离基团 | 无 | 结构决定 |
| logKAC（AC-水） | 7.39–9.59（三氯至五氯实测，十氯外推高端） | Global NEST J 2013 |

**可用化学性格仅四类**：(1) 全氯代轮廓（无任何 C–H）；(2) 四邻氯强制的扭转构象与最大空间体积（~1.0 nm）；(3) 十个 C–Cl σ 空穴的卤键阵列（内禀弱，Cl < Br < I）；(4) 还原反应性（全氯代芳环热力学最易被还原，但邻位氯空间受阻为最慢步骤）。常规识别四维（静电、氢键、金属配位、酸碱）因分子无锚点而全部失效。

**构型更正声明**：PCB-209 含四个邻位氯（2,2',6,6'），强制两苯环绕单键取扭转构象（二面角 ~85° 以上），非共平面。该扭转构象正是 PCB-209 无二噁英样活性的结构原因。任何"平面 π 夹持腔体"先验不适用（DT-P1 / DC8）。

### 1.2 主目标场景（锁定）

| 场景 | 浓度 | 角色 |
|------|------|------|
| **市政二级出水及其受纳地表水（溶解相）** | **pg/L–亚 ng/L 级（推断）** | **主目标** |
| 工业点源排水 | µg/L 级（高端验证） | 可选验证 |
| 地下水/饮用水源 | 对比场景（EPA MCL 0.5 µg/L 总 PCB） | 对比 |

**关键负面发现（锁定）**：PCB-209 单体**无任一真实水体实测浓度**（简报 search_executed 负面发现，Wolkersdorfer 2025 综述全文 verified）。水相 PCB 由低/中氯同系物主导，矿区排水检出最高氯数亦仅七氯。PCB-209 溶解态预期不高于 ΣPCB 且因 logKow ~8.2 大概率处于 pg/L 至亚 ng/L 级（推断）。

**实验浓度三点**：0.1–1 ng/L（锚定 ΣPCB 均值至高端）、10–100 ng/L（锚定受纳水体高端与矿区排水低段）、0.5–1 µg/L（锚定 EPA MCL，仅验证高驱动力容量，不作性能主口径）。机制与因果对照按规约用超纯水。ng/L 级工况要求 Kd ≥ 10⁴ L/kg 量级。

### 1.3 监管锚点（锁定）

- 美国 EPA 总 PCB 饮用水 MCL 0.0005 mg/L（0.5 µg/L），MCLG 零（E19，官方表 verified）
- 欧盟 WFD 优先物质清单不含 PCB（E20，EUR-Lex 页面 verified）
- 斯德哥尔摩公约：2025 年前消除含 PCB 设备、2028 年前废物无害化管理、废物阈值 0.005%（E22，公约官网 verified）

### 5.2 竞争物谱使用规则

1. 先证第一层（最危险竞争物 PCB-207/208/194 等九氯/八氯近异构体），再扩展第二、三层
2. 结构近似物为必须（DC2）：仅报告 NOM 选择性不构成证据
3. 分离因子 α 必须报告（不得仅报告总容量或去除率）
4. 脂质/有机质归一化对照排除 logKow 单调解释（DC1）
5. **PCB-209 特异性约束**：因 PCB-209 无实测水浓度，竞争实验须以 ΣPCB 量级 + 单体份额推断表述，不得声称实测浓度下的选择性

## 6. 诚实上限预估

### 6.1 通过概率预估

| 角度 | 首槽通过概率 | 主要瓶颈 |
|------|------------|---------|
| A01+A03 组合（S 级） | ~20–30% | 水相卤键削弱（DT3/DT-P3）；扭转轮廓 Å 级预组织合成复杂度；PCB-209 无实测水浓度 |
| A23（S 级） | ~10–20% | 合成复杂度极高；多维协同非加和性证明困难；各维贡献独立量化 |
| A10（A 级） | ~15–25% | 电位选择性是否区分十氯与九氯未知；好氧水体溶解氧排斥 |
| A15（A 级） | ~10–20% | β-CD 腔径失配；通用 CD 不能解决九氯/八氯选择性 |
| A 级其余 | ~10–15% | 各角度特异性瓶颈 |
| B 级 | ~5–10% | 选择性轴单薄/先例密集 |

### 6.2 预期通过总数

基于 23 角度 + 50 槽上限 + 上述概率，预估 PCB-209 通过方案数 **1–3 个**（诚实上限 ~3）。角度天花板低于多锚点污染物的根本原因是：(1) 可用化学性格仅四类且均内禀弱；(2) 还原脱氯生物窗口外（T6）关闭六个反应性角度；(3) 疏水分配单调陷阱（T1）使高 logKow 成为双刃剑。

### 6.3 天花板分析

- **扭转/形状读出族**（A01/A18/A20）：天花板 ~80–88。扭转几何正交 logKow 为核心优势；但 Å 级预组织合成难度 + 近异构体不可分为内禀限制
- **卤键族**（A03）：天花板 ~82–88。水相卤键削弱为核心限制；多价预组织 + DFT 能量预算门控可部分补偿
- **正交乘积族**（A23）：天花板 ~85–92（若合成可行）。多维协同为非加和性提供最高上限，但合成复杂度为最大风险
- **受限腔/尺寸族**（A02/A15/A16）：天花板 ~78–85。须叠加正交维度
- **还原捕获-破坏族**（A04/A05/A07–A10）：天花板 ~75–82。先例密度 + PCB-209 脱氯活性零先例
- **光化学/传质使能族**：天花板 ~72–80。为使能维度而非独立识别

## 7. 执行建议

### 7.1 首槽推荐：A01+A03 组合（扭转轮廓 × C–Cl 卤键阵列）

**选择理由**：

1. **D 组 Spec 明确推荐的 S 级组合**：扭转轮廓形状 + C–Cl 卤键阵列构成核心正交二维
2. **PCB-209 独特化学性格最大化利用**：扭转构象（D DT 不具备的独立维度）+ 十氯卤键阵列（内禀弱但多点预组织可补偿）
3. **正交维度明确**：改变卤键受体不影响扭转几何，改变腔壁扭转轮廓不影响卤键位点——两个独立维度
4. **与 SL02 教训互补**：SL02 单独 A01 失败于 (1) 靶标合理性 (2) Weh 2023 先例 (3) logKow 单调；A01+A03 组合通过卤键阵列维解决 (3) 通过重构靶标解决 (1)
5. **PADS 极低**：水相卤键阵列用于 PCB 选择性吸附 + 扭转互补腔 = 零直接先例
6. **阶段 0 门控可前置证伪**：DC9 要求的水相卤键滴定 go/no-go 可在合成前执行

### 7.2 前置门槛（Phase 0）

| 门控 | 内容 | go 判据 | no-go 后果 |
|------|------|---------|-----------|
| **建模门** | DFT-D4 计算 PCB-209/PCB-207 与卤键受体（吡啶-N-氧化物/硒醚）的水相结合能 | ΔΔG(PCB-209 vs PCB-207) ≥ 1 kJ/mol（卤键阵列贡献） | 换角度或终止 |
| **扭转匹配门** | PCB-209 二面角（Pedersen 1975 全文核验）与腔壁扭转轮廓匹配的分子建模 | 扭转互补腔对 PCB-209 的范德华接触密度 > 平面腔 >20% | 收窄主张为类级判别 |
| **多价门** | 评估腔内卤键位点数量对净结合能的贡献 | 多价（≥4 位点）净收益 > 单价 3 倍 | 调整位点密度 |
