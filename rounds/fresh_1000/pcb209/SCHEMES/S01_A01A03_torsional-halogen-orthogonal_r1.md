## 一、科学问题与工程难题

### 1.1 科学问题（SP）

PCB-209 中性、无氢键供受体、无解离基团、零 C–H，四个邻位氯强制两苯环绕单键取扭转构象（二面角 ~85°–90°，Pedersen 1975）。在静电、氢键、酸碱把手全部缺失条件下，能否以**扭转构象轮廓互补**与**十个 C–Cl σ 空穴的卤键阵列几何匹配**作为两个正交且不可被 logKow 还原的识别维度，在水相实现对 PCB-209 相对共平面竞争物（PCB-77/126/169、TCDD、平面 PAH）与九氯近异构体（PCB-207/208）的可测分离因子？

### 1.2 工程难题（EC）

水相 PCB 由低/中氯同系物主导，PCB-209 单体溶解相仅 pg/L–亚 ng/L 量级且无实测（只能由 ΣPCB 量级 + 单体份额推断）。传统黑碳/GAC 对平面芳烃 π 面吸附强，恰对扭转 PCB-209 弱（Jonker & Koelmans 机制），且随 logKow 单调、无同系物/构象选择性。同时满足 ng/L 驱动力下足够捕获动力学、抗第三相竞争（沉积物竞争使 AC-水分配下调 16 倍，Werner 2006）、PCB-209 对共平面/九氯近异构体选择性三条约束的设计窗口是否存在，为首要工程问题。

### 1.3 闭环主张

**扭转互补腔 + 腔内卤键受体阵列**的二维正交协同，使材料在水相对 PCB-209 产生不可由单一 logKow 或单一维度解释的滞留差异：
- **维 1（扭转几何）**：接纳扭转 PCB-209，几何排斥共平面竞争物（PCB-77/126/169、TCDD、平面 PAH）
- **维 2（卤键阵列）**：十个 C–Cl σ 空穴与腔内预组织卤键受体阵列的几何匹配，对十氯相对九氯/八氯产生弱但可测的分离因子
- **正交性**：改变卤键受体不影响扭转几何匹配，改变腔壁扭转轮廓不影响卤键位点排布——两个独立维度
- **诚实边界**：本主张不声称对九氯近异构体的高分离因子（二者扭转/体积近同），卤键维贡献为"弱但可测"（数个 kJ/mol 量级）

## 二、疼痛-机制同源

PCB-209 难以被现有平面 π 吸附剂捕获（扭转构象削弱平面堆叠，Jonker & Koelmans 机制），恰是其可被"扭转互补腔"选择性识别的根源：同一扭转性质既是常规吸附失效的原因，又是几何识别的把手。同时，PCB-209 的十个 C–Cl σ 空穴（通常被视为弱相互作用的劣势）在预组织卤键受体阵列中转化为多点识别优势——氯原子数最多者拥有最密集的卤键位点阵列，构成正交于扭转几何的第二识别维度。

自然界 AhR 平面腔对非平面 PCB 的排斥（Safe 1994；Van den Berg 2006 WHO-TEF 体系将非平面 PCB 归零 TEF）是"平面腔判别扭转构象"的进化实证；而卤键供体-受体化学（Wilcken 2012；Cavallo 2016）为 C–Cl σ 空穴的方向性识别提供了非蛋白化学基础。

## 四、材料架构与选择性机制

### 4.1 人工识别单元（非蛋白）

**扭转互补卤键受体功能化笼（TCHC）**：

- **骨架**：间苯二酚[4]芳烃 cavitand 或超交联 HCP/COF，提供刚性扭转互补腔
  - 间苯二酚芳烃路径：C2-对称 cavitand 上缘四个芳环按邻四氯联苯扭转角预组织（~85°–90° 二面角），下缘功能化引入卤键受体
  - HCP/COF 路径：晶态骨架提供孔径均一的扭转互补孔道，孔壁功能化引入卤键受体
- **卤键受体位点**：吡啶-N-氧化物（强受体，水相稳定性好）或硒醚（更强受体但氧化敏感），按 PCB-209 的 Cl–Cl 距离图案（邻位 Cl–Cl ~3.2 Å、间位 ~5.5 Å、对位 ~7.3 Å）布置 4–6 个受体位点
- **疏水腔壁**：芳烃骨架本身提供疏水预浓缩（L1 层），但通过有限体积可饱和区别于无限分配

### 4.2 选择性分层

| 层级 | 机制 | 角色 | 正交性 |
|------|------|------|--------|
| **L1** | 疏水预浓缩（logKow ~8.2） | 前置、非选择性 | 非选择性层 |
| **L2** | 扭转构象互补 | **选择性主判据维 1** | 正交于 logKow |
| **L3** | C–Cl 卤键阵列几何匹配 | **选择性主判据维 2** | 正交于 L2 |
| **L4** | 体积窗口（~1.0 nm 受限腔） | 使能，尺寸排斥 | 辅助 |

### 4.3 容量口径

- 总干复合体 mg PCB-209/g
- packed-bed mg PCB-209/mL
- 可及腔密度（mmol/g）
- 空白骨架分配本底（无卤键受体骨架）
- 脂质/有机质归一化对照（区分受限腔与无限分配）

## 六、台架合成 SOP 草图

### 路径 A：间苯二酚[4]芳烃 cavitand 功能化

1. **骨架构建**：间苯二酚 + 醛缩合制备 resorcin[4]arene 四醇前体（Cram & Cram 经典路线）
2. **上缘扭转预组织**：通过上缘芳环的桥连基元（如 –CH=N– 或 –N=N– 偶氮桥）锁定 ~85°–90° 扭转角
3. **下缘卤键受体引入**：下缘羟基经烷基化连接吡啶-N-氧化物基元（4 位或 6 位取代），或硒醚基元（–Se–Ar）
4. **交联固定化**：将 cavitand 通过乙烯基/炔基交联到多孔骨架（SBA-15 孔道内原位聚合或自交联形成纳米海绵）
5. **表征**：SSNMR（¹³C、⁷⁷Se）、PXRD（孔道有序性）、N₂ 吸脱附（BET 表面积/孔径分布）、XPS（卤键受体确认）

### 路径 B：HCP/COF 扭转孔道功能化

1. **骨架构建**：选择适当单体（如 C2-对称扭转二醛 + 联苯二胺）通过亚胺/β-酮烯胺缩合制备 COF
2. **孔径调控**：通过单体长度调控孔径至 ~1.0–1.2 nm（匹配 PCB-209 扭转横截面）
3. **孔壁功能化**：后合成修饰引入卤键受体（如 N-氧化吡啶基胺接枝到骨架醛基位点）
4. **表征**：同路径 A

### 路径选择判据

Phase 0 建模门决定路径：若间苯二酚芳烃 cavitand 的扭转轮廓匹配度 > COF 路径，选 A；若 COF 的晶态有序性提供更好孔径控制，选 B。

## 八、成功与失败判据（实验级）

### 8.1 通过（须全部）

1. α(PCB-209/PCB-77) ≥ 3 且 α(PCB-209/TCDD) ≥ 3（扭转几何维承重）
2. α(PCB-209/PCB-207) ≥ 1.5（卤键阵列维承重，诚实标注为"弱但可测"）
3. CC2 平面腔对照对 PCB-209 摄取回落 >60%（几何反转成立）
4. CC3 无受体变体对九氯近异构体 α → 1（卤键贡献解耦）
5. 饱和等温线 + 脂质归一化证明可饱和受限腔而非无限分配（DC1）
6. 全谱 α 与 logKow 非线性（R² < 0.8）（非纯疏水）
7. Kd ≥ 10⁴ L/kg（ng/L 工况可行性）

### 8.2 失败（任一）

1. CC2 平面腔与扭转腔对 PCB-209 摄取等价（扭转几何非承重）
2. CC3 无受体变体仍保持对九氯的分离（卤键非承重，选择性来自其他维度）
3. 全谱 α 与 logKow 线性 R² > 0.9（纯疏水，命中 T1）
4. Kd < 10³ L/kg（ng/L 工况不可行）
5. Phase 0 建模门 no-go（DFT 净卤键收益 < 1 kJ/mol）

## 九、靶标合理性论证（回应 SL02 A1）

SL02 r1=64 首要 HIGH 为"靶标合理性"：PCB-209 非二噁英样、毒性远低于共平面 PCB，设计"接纳非毒 PCB-209 排斥更毒共平面 PCB"方向存疑。

**本方案靶标重构**（三选一，按优先级）：

**(a) 最高氯代持久性示踪/最难捕获极端案例**：PCB-209 为 209 种 PCB 中氯代度最高者（logKow ~8.2、水溶度 ng/L 级、全邻位取代致最慢脱氯），是 PCB 同系物中热力学最难捕获的极端案例。成功捕获 PCB-209 意味着材料对全氯代 POP 具有极限捕获能力，方法论可推广至其他极端疏水 POP（BDE-209、HCB 等）。

**(b) 高氯 PCB 类靶标 + 共平面/非共平面双读出**：材料设计目标扩靶为"高氯代 PCB（Cl₈₋₁₀）"，同时具备扭转/共平面双读出能力——既能捕获非共平面高氯 PCB（如 PCB-209/208/207），也能通过卤键阵列维捕获共平面 dl-PCB（如 PCB-77/126/169，毒性最高的二噁英样 PCB）。这一双读出方向使材料具有直接的环境毒理学价值。

**(c) 若 (a)(b) 均不成立**：本角度按靶标合理性终止。

**本方案默认采用 (a)+(b) 组合论证**，在方案文件中同时承载"极端案例方法论"与"高氯 PCB 类 + 共平面/非共平面双读出"。

## 十、残余风险与后续

### 10.1 关键不确定性

1. **PCB-209 二面角具体值**：Pedersen 1975 待全文核验； Andersson 1997 计算值与晶体值可能偏差
2. **水相卤键净收益**：DFT 表明 PCB 的 Cl 卤键弱于 PBDE/甲状腺激素（Chem Eur J 2020），水相竞争水化进一步削弱；多价预组织能否补偿至可测水平为核心证伪点
3. **Å 级扭转预组织合成可达性**：间苯二酚芳烃 cavitand 的扭转角控制精度与卤键受体定位精度
4. **ng/L 工况可测性**：PCB-209 水相原液因高疏水性与器壁亲和在储存中表观浓度漂移（MethodsX 2026），须温度辅助稳定化协议

### 10.2 与后续角度的关系

- 本 S01（A01+A03 组合）承担扭转几何维 + 卤键阵列维
- 若 S01 通过，A23（多表位正交预组织）将在 S01 基础上叠加全氯代轮廓维与可选还原维
- 若 S01 失败于卤键维（CC3 结果），A03 单独角度降级，转向 A02/A15 叠加扭转维
- 若 S01 失败于扭转维（CC2 结果），A01 降级，转向 A15/A10 独立角度
