## 四、材料架构与选择性机制（r3 强化）

### 4.1–4.3 继承 r2

### 4.5a [r3 新增] 受体空间拥挤评估与分步消融实验（回应弱点 2）

**问题回顾**：r2 策略 3 要求基于 DFT Cl–Cl 距离矩阵布置 4–6 个卤键受体位点。r2 引入 squaramide 作为强受体（策略 1），但 squaramide 体积较大（~5 × 4 Å 分子截面），在 PCB-209 扭转腔（~10 Å 直径）内布置 4–6 个可能导致空间拥挤——受体之间范德华接触产生排斥，或受体无法同时达到最优取向。

**策略 1：受体空间拥挤的 DFT 预筛**

- 在 Phase 0 计算中增加**受体拥挤度评估**：
  - 构建含 2 / 3 / 4 / 5 / 6 个 squaramide 受体的扭转互补腔模型
  - DFT 优化每个模型的几何构型
  - 输出：(a) 受体间最近距离（须 >2.5 Å 避免范德华排斥）；(b) 受体取向角分布（C–Cl···B 角偏差）；(c) 拥挤能（受体间范德华排斥能）
- **go 线**：至少一种受体数（n ≤ 6）的构型满足所有受体 C–Cl···B 角 >150° 且受体间距 >2.5 Å
- **no-go 线**：全部受体数均存在 >2 个受体无法满足方向性要求 → 减少受体数至 3 个（最低多价数）

**策略 2：受体数量系列——从 6 到 3 的梯度设计**

| 设计 | 受体数 | 预期单价贡献 | 预期总贡献 | 空间拥挤风险 |
|------|--------|------------|-----------|------------|
| 满配位 | 6 | ~4–8 kJ/mol × 6 = ~24–48 | 高（但拥挤可能降低实际值） | 高 |
| **r3 推荐** | **4** | **~4–8 kJ/mol × 4 = ~16–32** | **中-高** | **中** |
| 最低多价 | 3 | ~4–8 kJ/mol × 3 = ~12–24 | 中 | 低 |
| 单价对照 | 1 | ~4–8 kJ/mol | 低 | 无 |

- **r3 主选 4 受体设计**：平衡多价补偿（总增益 ≥16 kJ/mol）与空间拥挤风险
- 4 个受体布置于 PCB-209 的 4 个邻位 Cl 附近（2,2',6,6' 位 Cl 的 σ 空穴最强——邻位氯空间受阻使 σ 空穴更暴露）

**策略 3：分步消融实验——定量解耦扭转维与卤键维**

r2 继承 r1 的选择性分层 L1–L4，但未给出各层独立量化实验。r3 设计**双维消融对照**：

| 材料 | 扭转匹配 | 卤键受体 | 隔离贡献 |
|------|---------|---------|---------|
| M0：平面疏水腔 | ✗ | ✗ | 疏水基线 |
| M1：扭转匹配腔（无受体） | ✓ | ✗ | 扭转维贡献 |
| M2：非扭转腔 + 受体 | ✗ | ✓ | 卤键维贡献 |
| **M3：完整双维腔** | **✓** | **✓** | **双维加和/协同** |

- **扭转维量化**：ΔlogKd(M1 vs M0) = 扭转匹配贡献
- **卤键维量化**：ΔlogKd(M2 vs M0) = 卤键阵列贡献
- **加和性检验**：logKd(M3) ≥ max(logKd(M1), logKd(M2)) + 0.3 log → 双维正交加和
- **协同性检验**：logKd(M3) > logKd(M1) + logKd(M2) – logKd(M0) → 超加和协同

**M1 合成**（扭转匹配腔，无卤键受体）：
- 间苯二酚[4]芳烃 cavitand + 偶氮桥（锁定扭转角）+ 下缘 –OH 保留（无受体修饰）
- 提供纯扭转几何匹配贡献

**M2 合成**（非扭转腔 + 卤键受体）：
- 非扭转腔：以 β-CD 或 γ-CD 为腔体（圆柱形，无扭转互补性）+ 外壁修饰 squaramide 受体
- 提供纯卤键阵列贡献（无扭转几何匹配）

**关键判决**：
- 若 M3 > M1 ≈ M2 > M0 → 双维正交加和成立 → 正面主张
- 若 M3 ≈ M1 > M2 ≈ M0 → 卤键维贡献可忽略 → 退化为纯扭转维 → 不满足 ODC ≥2 → 终止
- 若 M3 ≈ M2 > M1 ≈ M0 → 扭转维贡献可忽略 → 退化为纯卤键维 → 不满足 ODC ≥2 → 终止

## 六、台架合成 SOP（r3 强化）

### 路径 A 继承 r2（含 §6.1a 扭转预组织细化）

### 6.2a [r3 新增] cavitand 上缘功能化路线细化（回应弱点 3）

**问题回顾**：r2 §6.1a 细化了扭转角控制（偶氮桥优先）与下缘功能化（羟基 → 连接臂 → 受体），但对 cavitand **上缘**（宽口端）如何引入卤键受体的路线不够具体。PCB-209 尺寸 ~10 Å，cavitand 腔深 ~8–10 Å——PCB-209 可能部分嵌入上缘开口区域，上缘受体对跨环 Cl（4,4',5,5' 位）的卤键贡献不可忽视。

**上缘功能化路线**：

**步骤 B1：上缘定向溴化**

- 间苯二酚[4]芳烃 cavitand 上缘芳环的 2-位（朝向腔内）可选择性溴化
- 条件：NBS（N-溴代琥珀酰亚胺），CHCl₃，0°C → RT，12 h
- 选择性：上缘 2-位溴化优先于下缘（上缘位阻更低，更易接近）
- 验证：¹H NMR 确认溴化位点与取代度（目标：2–4 个上缘位点溴化）

**步骤 B2：溴化位点 → squaramide 受体**

- 溴化位点经 Pd 催化 C–N 偶联（Buchwald-Hartwig）引入含 squaramide 的胺基
- 胺基组分：squaramide-单胺（由二乙基 squarate + 单胺合成，继承 r3 DCP26 §7.3c 路线 B）
- 条件：Pd₂(dba)₃ / BINAP / Cs₂CO₃，甲苯，100°C，24 h
- 验证：MALDI-TOF MS 确认分子量增量 + ¹³C NMR squaramide 羰基信号

**步骤 B3：下缘功能化（继承 r2）**

- 下缘 –OH → 烷基化 → 连接臂 → 额外受体位点（可选）
- 上下缘双功能化确保覆盖 PCB-209 的全部 10 个 Cl 原子

**合成可行性评估**：

| 步骤 | 难度 | 关键风险 | 缓解 |
|------|------|---------|------|
| B1 上缘溴化 | 中 | 取代度控制（过度溴化） | 当量控制（2.2 eq NBS → 目标 2 位取代） |
| B2 Buchwald-Hartwig | 中-高 | 大位阻胺偶联效率 | 微波辅助（150°C，30 min）提升效率 |
| B3 下缘功能化 | 中 | 继承 r2 | — |
| 总步骤数 | — | 8–10 步（含 cavitand 合成） | 分阶段验证（每步 NMR/MS 确认） |

**替代路线（保底）：后合成接枝**

- 若上缘定向合成过于复杂，采用后合成接枝：
  - 先合成完整 cavitand（无受体）→ 固定化到 SBA-15 → 气相沉积 squaramide 前体 → 热接枝
  - 优势：避免溶液相多步合成
  - 代价：受体分布可能不均匀（上缘 vs 下缘 vs 外壁）

## 七、实验与因果对照计划（r3 强化）

### 7.1–7.5a 继承 r2

### 7.5b [r3 新增] 双维消融对照执行计划

继承 r3 §4.5a 策略 3 的 M0–M3 设计，执行顺序：

| 阶段 | 材料 | 目的 | go 线 |
|------|------|------|-------|
| Phase-1a | M0 + M1 | 扭转维独立贡献 | ΔlogKd(M1/M0) ≥ 0.3 log |
| Phase-1b | M0 + M2 | 卤键维独立贡献 | ΔlogKd(M2/M0) ≥ 0.3 log |
| Phase-2 | M3 | 双维加和/协同 | logKd(M3) ≥ max(M1, M2) + 0.3 log |

- Phase-1a 与 Phase-1b 可并行执行
- **Phase-1 go 线**：至少一个维度的 ΔlogKd ≥ 0.3 log（否则该维度贡献可忽略 → 退化）
- **Phase-2 go 线**：双维加和成立（否则维度间存在拮抗）
