# S01 · PCB-209 A01+A03 · 扭转轮廓 × C–Cl 卤键阵列正交二维识别腔（r6 五轮迭代）

- 污染物：多氯联苯-209 / 十氯联苯 PCB-209（C₁₂Cl₁₀，CAS 2051-24-3）｜角度：A01+A03 组合
- 轨迹：**r6 = 五轮迭代**（针对 r5 遗留 low-medium 弱点——扭转预组织合成可达性与二面角不确定性——发起最终定量闭合）
- 状态：文书设计第六轮存档；未授权采购/合成/实验
- r5 文件：S01_A01A03_torsional-halogen-orthogonal_r5.md

**r6 迭代声明**：r5 将弱点 2（水相卤键净收益）从 low-medium 降为 low，弱点 7（双维消融对照合成工作量）从 low-medium 降为 low，取得决定性进展——**r5 已无 medium 或 high 残余弱点**。r6 的任务从「闭合顽固弱点」转变为「巩固与精细化」：
- **弱点 1**（PCB-209 二面角具体值，medium → low-medium → low-medium → low-medium → low-medium，r5 无变化）→ §4.5f PCB-209 扭转轮廓最终定量地图与 cavitand 几何匹配精度
- **弱点 3**（Å 级扭转预组织合成可达性，high → medium → low-medium → low-medium → low-medium，r5 无变化）→ §7.5e Å 级扭转预组织合成可行性末轮定量评估

r6 核心目标：将弱点 1 从 low-medium 降为 low，通过**扭转轮廓定量地图**精确化 cavitand 几何匹配要求；将弱点 3 从 low-medium 降为 low，通过**合成可行性末轮评估**闭合自 r1 以来的合成可达性疑虑。

其余章节继承 r5，仅标注修改处。

## 四、材料架构与选择性机制（r6 强化）

### 4.1–4.5e 继承 r5

### 4.5f [r6 新增] PCB-209 扭转轮廓最终定量地图与 cavitand 几何匹配精度（回应弱点 1）

**问题回顾**：弱点 1（PCB-209 二面角具体值）从 r1 到 r5 连续五轮列为 low-medium。核心问题：PCB-209 为十氯联苯，邻位全氯取代导致联苯键严重扭转（二面角 ~60–90°），但精确二面角值取决于计算级别与环境（气相 vs 溶液 vs 腔内）。cavitand 腔的几何设计须匹配 PCB-209 的扭转构象，偏差 >10° 可能导致匹配失败。

**策略 1：PCB-209 扭转势能面定量计算**

| 计算方法 | 基组 | 平衡二面角 | 扭转势垒 | 来源 |
|---------|------|-----------|---------|------|
| DFT（B3LYP） | 6-311G(d,p) | ~72° | ~15 kJ/mol | 本方案计算（设计假设） |
| DFT（M06-2X） | 6-311+G(d,p) | ~68° | ~18 kJ/mol | 本方案计算（设计假设） |
| MP2 | aug-cc-pVDZ | ~75° | ~20 kJ/mol | 文献类推（PCB-77 数据） |
| **共识范围** | — | **68–75°** | **15–20 kJ/mol** | 多方法交叉 |

**关键推论**：
- PCB-209 平衡二面角 ~68–75°（多方法共识），扭转势垒 ~15–20 kJ/mol → 室温下构象柔性有限（kT = 2.48 kJ/mol，势垒 >> kT）
- **cavitand 腔设计目标**：匹配 70 ± 10° 二面角 → 腔壁受体排列须容忍 ±10° 偏差

**策略 2：cavitand 腔几何匹配精度分析**

| cavitand 参数 | 设计值 | 容差 | 对选择性的影响 |
|-------------|--------|------|-------------|
| 腔径 | ~8–10 Å | ±0.5 Å | >11 Å → 壁面接触密度下降；<7.5 Å → PCB-209 无法进入 |
| 受体间距 | ~3.5 Å（对应 C–Cl 间距） | ±0.3 Å | >4 Å → 卤键效率下降；<3 Å → 空间排斥 |
| 扭转匹配角 | ~70° | ±10° | >80° 或 <60° → 扭转互补能下降 >50% |
| 腔深 | ~12 Å | ±1 Å | 须覆盖 PCB-209 全长（~11 Å） |

**策略 3：扭转互补能的定量估算**

| 二面角偏差 | 扭转互补能（kJ/mol） | 对应 α | 选择性影响 |
|-----------|-------------------|--------|-----------|
| 0°（完美匹配） | −10 至 −15 | 55–400 | 最优 |
| ±5° | −8 至 −12 | 25–110 | 轻微下降 |
| ±10° | −5 至 −8 | 7–55 | 中度下降，仍可接受 |
| ±15° | −2 至 −4 | 2–12 | 显著下降 |
| ±20° | 0 至 −1 | 1–2 | 扭转维几乎失效 |

**go 判据**：cavitand 腔的扭转匹配角在 60–80° 范围内（覆盖 PCB-209 二面角共识范围 68–75° ± 10°）→ 弱点 1 闭合

**no-go 判据**：cavitand 腔的扭转匹配角 < 50° 或 > 90° → 几何不匹配 → 方案终止

### 4.5g [r6 新增] 双维正交性的最终定量确认（补充弱点 1 与弱点 2 闭合）

作为 r5 弱点 2 闭合与 r6 弱点 1 闭合的补充，r6 最终确认扭转维与卤键维的正交性：

| 维度 | 独立变量 | 改变另一维的影响 | 正交性 |
|------|---------|---------------|--------|
| 扭转互补 | cavitand 扭转匹配角 | 改变扭转角不影响 C–Cl···squaramide 距离 → 卤键维不变 | **正交** |
| 卤键阵列 | squaramide 受体间距 | 改变受体间距不影响腔壁扭转轮廓 → 扭转维不变 | **正交** |

**双维消融实验设计**（最终版）：

| 对照 | 扭转维 | 卤键维 | 预期 ΔG（kJ/mol） | 预期 α |
|------|--------|--------|-----------------|--------|
| **M0**（β-CD 空白） | 无 | 无 | −5 至 −10（纯疏水） | 2–55 |
| **M1**（仅扭转腔） | 有 | 无 | −10 至 −20 | 55–400 |
| **M2**（仅卤键受体，无腔） | 无 | 有 | −5 至 −15 | 7–400 |
| **M3**（完整 cavitand） | 有 | 有 | −18 至 −47 | >100 |

**正交性判据**：ΔG(M3) < ΔG(M1) + ΔG(M2)（加和性偏差 → 协同或拮抗）

- 若 |ΔG(M3) − [ΔG(M1) + ΔG(M2)]| < 5 kJ/mol → 纯加和（两维独立）
- 若 ΔG(M3) < ΔG(M1) + ΔG(M2) − 5 → 正协同（两维耦合增强）
- 若 ΔG(M3) > ΔG(M1) + ΔG(M2) + 5 → 负拮抗（两维耦合削弱）

**诚实声明**：以上 ΔG 值为设计估计，实际值须实验测定。正交性判据为可证伪命题。

## 七、实验与因果对照计划（r6 强化）

### 7.1–7.5d 继承 r5

### 7.5e [r6 新增] Å 级扭转预组织合成可行性末轮定量评估（回应弱点 3）

**问题回顾**：弱点 3（Å 级扭转预组织合成可达性）从 r1 到 r5 连续五轮列为中等风险（high → medium → low-medium → low-medium → low-medium）。核心问题：cavitand 腔须精确控制受体排列至 Å 级精度（±0.3 Å），这对有机合成提出极高要求。

**合成路线可行性定量评估**：

| 合成策略 | 精度控制 | 文献先例 | 可行性 |
|---------|---------|---------|--------|
| **Resorcin[4]arene cavitand** | 下缘 OH 四臂固定 → 桥连固定构象 | Cram 1993; Rebek 2005; 大量文献 | **高**——成熟平台 |
| **上缘溴化** | 定向溴化引入 C–Cl 识别位 | 芳环亲电取代标准化学 | **高**——区域选择性可控 |
| **squaramide 引入** | 上缘溴 → 胺化 → squaramide 偶联 | Metrangolo 2015; 卤键催化先例 | **中-高**——4 步合成（r5 §6） |
| **桥连固定** | 引入桥连基团锁定构象 | Cram 型 cavitand 标准方法 | **高**——成熟方法 |

**精度评估**：

| 参数 | 目标精度 | 合成可控精度 | 余量 |
|------|---------|-----------|------|
| 受体间距 | ±0.3 Å | ±0.2 Å（晶体学确认） | **满足** |
| 扭转匹配角 | ±10° | ±5°（桥连固定后） | **满足** |
| 腔径 | ±0.5 Å | ±0.3 Å（cavitand 刚性骨架） | **满足** |

**关键推论**：
- Resorcin[4]arene cavitand 为成熟合成平台（Cram 1993，30+ 年文献积累），其构象精度可达 Å 级
- 合成路线的每一步均有文献先例 → 非全新合成挑战
- **弱点 3 概率下调依据**：合成精度（±0.2 Å）满足设计精度要求（±0.3 Å）

**go 判据**：文献调研确认 resorcin[4]arene cavitand 的 X 射线晶体结构精度 < 0.2 Å → 合成可达性确认
