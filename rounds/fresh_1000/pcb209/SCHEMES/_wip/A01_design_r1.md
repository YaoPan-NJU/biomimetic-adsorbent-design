## 1. 科学问题与工程难题

**SP（方案层面）**：PCB-209 中性、无氢键供受体、无解离基团、零 C-H，唯一不可被 logKow 还原的独特维度是四邻位氯锁定的约 85° 扭转螺旋桨构象。该构象使其被 AhR 平面腔几何排斥（非 AhR 配体，Safe 1994；Van den Berg 2006），而被 PXR 大柔性腔容纳（Al-Salman 2012）。能否将这一自然界的"平面腔判别扭转构象"原理反转为人工刚性扭转互补腔：接纳扭转 PCB-209（及同类扭转高氯 PCB），几何排斥共平面竞争物（PCB-77/126/169、TCDD、平面 PAH）？

**靶标合理性论证（回应 A1）**：PCB-209 不是最毒 PCB 同系物（其 TEF=0，非二噁英样），但具有三重科学定位价值：(a) 最高氯代、零 C-H、结构上最不可被好氧降解的极端案例，是"最难捕获 + 最难破坏"双重极端的交汇点；(b) 其扭转构象是区分构象类别的天然探针——若材料能选择性捕获扭转类而排斥共平面类，则证明形状读出超越 logKow 单调；(c) 作为 Aroclor 1260 全氯组分与工业副产物，其环境持久性极高（半衰期年级至十年级），是"终极残留物"示踪。本方案不声称"去除 PCB-209 比去除更毒 dl-PCB 更重要"，而声称"以 PCB-209 为模型证明扭转轮廓作吸附设计维度的可行性"。

**EC（工程难题）**：(1) 水相 PCB-209 溶解态预期 pg/L–亚 ng/L（ΣPCB 推断），传质驱动力极小，Kd≥10⁴ L/kg 为及格线；(2) 第三相竞争（黑碳、颗粒有机碳、NOM）使纯水系分配系数须下调约 16 倍（Werner 2006）；(3) 强疏水吸附（logKAC>7）与温和再生互斥。

**闭环主张（收窄版）**：刚性扭转互补腔在水相对扭转类 PCB（PCB-209、PCB-180、PCB-194）相对共平面类（PCB-77/126/169、TCDD、芘、萘）产生可测滞留差异（α≥3），经刚性平面腔对照材料几何反转（平面腔丧失扭转类摄取/反获共平面类摄取），且全谱 α 与 logKow 非线性（R²<0.8）。**不声称**区分 PCB-209 与九氯/八氯扭转近异构体。

## 4. 材料架构与选择性机制

### 4.1 人工识别单元（非蛋白、非折叠肽）

**主方案：刚性扭转互补间苯二酚芳烃 cavitand 聚合物（Res-Twist）**

设计原理：间苯二酚[4]芳烃（resorcin[4]arene）cavitand 具有刚性碗状骨架，腔径约 5–8 Å、深度约 6–8 Å，可通过上缘（upper rim）取代基调控腔壁几何。本案在 cavitand 上缘引入刚性扭转模板基团（非分子印迹：模板为几何约束而非 PCB-209 本身），使相邻 cavitand 单元在超交联网络中形成约 85° 扭转互补的受限空间。

具体架构：
- **单体**：四(4-乙烯基苯基)间苯二酚[4]芳烃（cavitand 骨架，刚性碗状，BET 贡献）
- **交联剂**：刚性扭转连接基——1,1'-联萘-2,2'-二基双(4-乙烯基苯基)醚（联萘单元锁定约 90° 二面角，提供扭转互补几何）
- **聚合**：Friedel-Crafts 超交联（HCP 路线）或溶剂热 COF 路线
- **腔壁预组织**：联萘连接基的固有扭转角（约 80–90°）与 PCB-209 的约 85° 二面角几何匹配，非模板印迹（规避十氯巨分子模板残留与洗脱困难）

**对照材料系列**：

| 编号 | 材料 | 角色 |
|---|---|---|
| M1（Res-Twist） | 联萘扭转连接基 cavitand HCP | 扭转互补主变体 |
| M2（Res-Planar） | 联苯平面连接基 cavitand HCP（同化学组成，联萘换为联苯，二面角约 0–30°） | 刚性平面腔对照（几何反转） |
| M3（Res-Open） | 无 cavitand 碗状骨架的联萘 HCP（仅交联网络，无受限腔） | 腔体贡献对照 |
| M4（GAC） | 颗粒活性炭 F400 | 工业基准 |
| M5（β-CDP） | β-环糊精聚合物 | 超分子先例对照 |

### 4.2 选择性机制分层

- **L1 疏水预浓缩**（前置、非选择性）：logKow~8.2 驱动 PCB-209 向任何疏水表面分配。本层贡献总容量但不构成选择性来源。诚实声明：在 ng/L 驱动力下，L1 使所有疏水材料对 PCB-209 均有高 uptake，选择性须由 L2 体现为差异保留而非差异摄取。
- **L2 扭转构象互补**（选择性来源，主判据）：扭转互补腔壁与 PCB-209 约 85° 螺旋桨轮廓的范德华接触面积最大化（推断：完全互补时接触面积约 280–320 Å²），而共平面分子（PCB-77、TCDD、芘）在扭转腔中仅能实现边缘接触（推断：约 120–160 Å²），差异约 2–4 kcal/mol（推断，须 DFT/MD 前置验证）。该差异正交于 logKow：共平面 PCB-126（logKow 6.4）与扭转 PCB-209（logKow 8.3）的 α 若仅由 logKow 决定则方向相反（126 疏水性低于 209 但平面腔偏好 126），几何反转对照即检验此点。
- **L3 体积窗口**（使能）：受限腔体积约 1.0 nm 量级，排斥 NOM 大分子（>2 nm），允许 PCB 同系物与 PAH 进入。单独不产生 PCB-209 选择性（九氯近异构体体积相近）。

### 4.3 诚实边界：PCB-170/180/194 问题

PCB-180（2,2',3,4,4',5,5'-七氯）含两个邻位氯，二面角约 70–80°（推断，Andersson 1997）；PCB-194（2,2',3,3',4,4',5,5'-八氯）含两个邻位氯加间位拥挤，二面角约 75–85°；PCB-170 类似。这些同系物亦为扭转构象，体积仅略小于 PCB-209。**本设计诚实声明：扭转互补腔大概率同时捕获 PCB-180/194/170，不能实现 PCB-209 单体特异。** 选择性主张限于"扭转类（含 209/180/194/170）vs 共平面类（77/126/169/TCDD/PAH）"的构象类别判别。

### 4.4 logKow 单调陷阱的直面（回应 A3）

logKow~8.3 意味着 PCB-209 对任何疏水相的分配系数极高（推断 logKAC>9）。在 ng/L 浓度下，热力学驱动力足以使任何疏水材料定量捕获 PCB-209。因此：
- 选择性不能以"PCB-209 被捕获而竞争物不被捕获"体现（所有高 logKow 物都会被捕获）
- 选择性须以"竞争洗脱序"或"平衡分配系数比"体现：在混合体系中，扭转腔对 PCB-209 的 Kd 相对共平面 PCB-77 的 Kd 之比（α），超出二者 logKow 差异所预测的值
- 关键证伪：若全谱 α 与 logKow 线性相关（R²>0.9），则选择性纯由疏水分配驱动，扭转几何非承重，方案终止

### 4.5 报告口径

mg PCB-209/g 总干复合材料 + packed-bed mg/mL + 可及腔密度（探针分子饱和吸附）+ 空白骨架（M3）分配本底 + 脂质/有机碳归一化对照（Koc 对比，区分受限腔与无限分配）。

## 5. 创新性检查清单逐项结论

**A 机制创新：有条件通过。** 将"平面腔排斥非平面"（AhR 自然原理）反转为"扭转腔排斥平面"是明确可验证的机制创新。扭转轮廓作吸附剂设计维度在水相 POP 领域无先例（G3）。条件：须以平面腔对照几何反转 + α-logKow 非线性实验背书。

**B 材料架构创新：有条件通过。** 联萘扭转连接基预组织 cavitand HCP 超越载体替换/孔径调参：腔壁扭转角由连接基固有几何决定（非后修饰），构成"机制驱动空腔设计"（非模板印迹，回应 T2）。条件：合成可达性须由 DFT 预筛 + 小分子模型验证。

**C 仿生转译创新：有条件通过（边界态）。** 从 AhR/PXR 的构象-受体判别原理提取"几何互补反转"设计原则，超越了官能团类比（不是复制 AhR 残基，而是反转其几何逻辑）。但诚实边界：该原理可被表述为通用锁钥/形状互补原则，仿生增量有限。若裁决认为"反转平面腔"仍属通用形状互补，则 C 判不通过（诚实标注）。

**D 选择性策略创新：通过。** 选择性来源为扭转构象互补（非 logKow 单调，D1 通过）；设两个正交维度：扭转几何 × 体积窗口（D2）；竞争物谱含结构近似物：共平面 PCB-77/126/169、九氯扭转近异构体 PCB-206/207、跨类 BDE-209、平面 PAH（D3）。

**E 先例区分：有条件通过。** Weh 2023（E5）为有机相环芳烃对非平面轴手性联苯的手性识别，是扭转识别的最近先例。本案增量：(a) 水相（Weh 为有机溶剂）；(b) 吸附剂格式（Weh 为化学计量受体）；(c) 构象类别判别（Weh 为对映体判别）；(d) 刚性平面腔反转因果系列（Weh 无此对照）。增量真实但须实验量化。PCB-209 水相捕集材料零先例（G1），扭曲螺旋桨轮廓从未被用作吸附剂设计维度（G3）。

## 6. 台架合成 SOP 草图

### 6.1 阶段 −1：DFT/MD 建模前置（go/no-go 门）

- PCB-209 气相 DFT 优化（B3LYP-D3/6-31G*）确认二面角（预期约 85–90°，对标 E4）
- 联萘连接基模型化合物二面角优化（预期约 80–90°）
- PCB-209@扭转腔模型复合物 MD（GAFF 力场，显式水）：计算结合自由能（TI 或 MM/PBSA）
- PCB-77@扭转腔、PCB-209@平面腔对照计算
- **go 判据**：ΔΔG(209-twist vs 77-twist) ≥ 1.5 kcal/mol 且 ΔΔG(209-twist vs 209-planar) ≥ 1.0 kcal/mol
- **no-go**：差异 < 0.5 kcal/mol → 扭转几何非承重，终止本角度

### 6.2 单体合成

**Cavitand 单体（Cav-V）**：间苯二酚 + 4-乙烯基苯甲醛 → 四(4-乙烯基苯基)间苯二酚[4]芳烃（酸催化环化，文献通行条件）。上缘四乙烯基提供聚合把手。

**扭转连接基（Tw-L）**：(R)-1,1'-联萘-2,2'-二醇 + 2 当量 4-乙烯基苄溴 → 联萘-2,2'-二(4-乙烯基苄基)醚（K₂CO₃/DMF，60°C）。联萘单元锁定约 80–90° 二面角。

**平面连接基（Pl-L）**：4,4'-联苯二酚 + 2 当量 4-乙烯基苄溴 → 联苯-4,4'-二(4-乙烯基苄基)醚（同条件）。联苯单元二面角约 0–30°（共平面）。

### 6.3 超交联聚合

**M1（Res-Twist）**：Cav-V + Tw-L（摩尔比 1:2），无水 CH₂Cl₂，FeCl₃ 催化 Friedel-Crafts 超交联（40°C，24 h），索氏提取（MeOH/CH₂Cl₂）除催化剂与低聚物。

**M2（Res-Planar）**：Cav-V + Pl-L（同配比、同条件），仅连接基几何不同。

**M3（Res-Open）**：Tw-L 自聚（无 Cav-V），同条件。

### 6.4 表征

BET（N₂ 77K + CO₂ 273K）、孔径分布（NLDFT）、FTIR、固体 ¹³C NMR、TGA、SEM/TEM、水蒸气吸附、zeta 电位、元素分析。

## 7. 实验与因果对照计划

### 阶段 0：机制预实验（超纯水）

1. **等温线**：M1–M5，PCB-209 初始 0.1 ng/L–1 µg/L（六点），HRGC/HRMS 检测；报 Kd、qmax（Langmuir）、Freundlich n。
2. **构象类别竞争**：等摩尔混合 PCB-209 + PCB-77 + PCB-126 + PCB-180 + PCB-194 + 芘 + TCDD（各 10 ng/L），M1–M5 竞争吸附，报各同系物 Kd 与 α。
3. **平面腔反转对照**：M1 vs M2 对同一混合体系的摄取谱比较。预期：M1 偏好扭转类（209/180/194），M2 偏好共平面类（77/126/TCDD/芘）。
4. **脂质归一化对照**：以正辛醇-水分配（Kow）与有机碳归一化分配（Koc）为基准，检验 M1 的 α 序列是否偏离 logKow 预测。
5. **可饱和性**：高浓（100 ng/L–1 µg/L）等温线验证 Langmuir 饱和（区别于无限分配）。
6. **α-logKow 相关**：全谱（≥8 种竞争物）α 对 logKow 线性回归，R²<0.8 为几何承重判据。

### 阶段 1：真实基质与工程

1. **真实基质**：市政二级出水（DOC 5–15 mg/L）+ 地表水，加标 ΣPCB 混合液（含 209/180/194/77/126/169 + BDE-209 + 芘），M1–M5 竞争。
2. **第三相竞争**：添加腐殖酸（5 mg/L）+ 黑碳颗粒（10 mg/L），测 Kd 衰减。
3. **床层**：M1 微床（50–200 mg），EBCT 10/30 min，进水 ΣPCB 10 ng/L，穿透曲线，报 BV。
4. **再生**：甲苯/正己烷溶剂洗脱（主）；热再生（200°C N₂）备选；5 循环。
5. **泄漏与稳定性**：出水 HRGC/HRMS 检测 cavitand 碎片、联萘单体；BET 前后对比。

### 因果归因

- 扭转几何贡献 = (M1 − M3) − (M2 − M3)，即 M1 − M2（扣除网络本底）
- 腔体贡献 = M3 − M4（HCP 网络 vs GAC）
- 几何反转 = M1 vs M2 的构象类别偏好方向反转
- logKow 解耦 = 全谱 α-logKow R²

## 8. 成功与失败判据

**通过（须全部）**：
- α(PCB-209/PCB-77) ≥ 3 且 α(PCB-209/TCDD) ≥ 3（M1，超纯水）
- M2（平面腔）对 PCB-209 摄取回落 >50% 且对 PCB-77 摄取相对 M1 增加（几何反转成立）
- 全谱 α-logKow R² < 0.8（非线性，几何承重）
- Langmuir 饱和成立（qmax 有限，区别于无限分配）
- 脂质归一化后 M1 对扭转类仍有正偏差（非纯疏水）

**失败（任一）**：
- F1：M1 与 M2 对 PCB-209 摄取等价（几何非承重）→ 终止
- F2：全谱 α-logKow R² > 0.9（纯疏水，命中 T1）→ 终止
- F3：DFT go/no-go 门 ΔΔG < 0.5 kcal/mol → 终止
- F4：M1 在真实基质中 Kd 衰减 >90%（第三相/NOM 主导）→ 收缩或终止
- F5：合成不可达（cavitand 聚合失败或 BET < 100 m²/g）→ 重建

**灰区**：α = 1.5–3 或 R² = 0.8–0.9 → 调连接基扭转角（联萘衍生物）后复测。

## 9. 自识别弱点清单

1. **PCB-170/180/194 不可分**：本设计不能区分 PCB-209 与九氯/八氯扭转近异构体，选择性限于构象类别（扭转 vs 共平面），非单体特异。这是本角度最尖锐的诚实边界。
2. **logKow 极端值使非特异分配主导**：logKow~8.3 意味着 PCB-209 对任何疏水相亲和力极高，扭转互补的 ΔΔG（推断 2–4 kcal/mol）相对于总疏水驱动力（推断 >10 kcal/mol）占比小，表观 α 可能被压缩。
3. **Å 级扭转预组织的合成精度**：联萘连接基给出约 80–90° 扭转，但 HCP 网络的无序性可能使实际腔壁几何分布宽（±15–20°），削弱形状读出精度。COF 路线有序度更高但合成难度更大。
4. **水相验证空白**：Weh 2023 在有机相验证了非平面联苯识别，水相外推无先例。水分子对疏水腔的竞争、水化壳对 PCB-209 进入的能垒均为未知。
5. **Al-Salman 面板不含 209**：PXR 容纳非平面 PCB 的实证限于 PCB-99/138/153/180/194，PCB-209（四邻位全取代）为外推。
6. **Pedersen 1975 具体数值待全文核验**：二面角约 85–90° 为通行引用，精确值（如 88.4° vs 82.1°）影响腔壁设计精度。
7. **ng/L 工况 Kd≥10⁴ 可行性未验证**：全部水相 PCB 吸附先例为 mg/L 批次，向 ng/L 外推无先例（G6）。
8. **再生困难**：logKAC>9 的强吸附使温和再生极困难，溶剂洗脱产生浓缩二次废物。
9. **环境意义张力**：PCB-209 水相无实测浓度、TEF=0、非最毒同系物，"专门捕获 PCB-209"的环境价值论证本身即弱点。本方案以科学价值（证明新设计维度）而非处理价值为主要正当性。
