**增补 3：snug-fit 窗口效应的非单调性证明方法（r3 新增）**

r2 §4.7 给出 logKow-形状解耦三策略。r3 进一步精确化非单调性证明的统计框架：

- **非单调性判据**：在氯酚同族物序列（CP → DCP → TCP → TeCP → PCP）中，若 K_CD 对氯数 n 的回归存在显著正残差（PCP 点），且该残差对分子横截面积 A 的回归显著（p < 0.05），则 snug-fit 窗口效应获统计确认
- **样本量要求**：至少 5 个氯酚同族物 + 2 个等氯数对（2,3,5,6-TeCP vs 2,3,4,6-TeCP），共 7 个数据点
- **效应量下限**：PCP 残差 > 2σ（σ 为回归标准误差），对应 ΔΔG_snug-fit > 1.0 kJ/mol

### 4.6 Snug-fit 能量定量分析（r2 已有，r3 升级）

继承 r2 §4.6 三种方法（LFER 外推、DFT-D4 计算参考、S27 对标），r3 新增：

#### 4.6A DFT-D4/SMD 水相直接计算协议（r3 新增，闭合 W1 残余不确定性）

**目的**：将 ΔΔG_snug-fit 估计从 LFER 外推（不确定性 ±1.5 kJ/mol）升级为 DFT-D4/SMD 水相直接计算（不确定性 ±0.8 kJ/mol）。

**计算协议**：

1. **构象搜索**（参照 E37）：
   - PCP@β-CD：系统扫描 PCP 在 β-CD 腔内的旋转角（0–360°，步长 30°）与平移（z 轴 −3 to +3 Å，步长 0.5 Å）
   - 对每个构型执行半经验 PM7 预优化
   - 取能量最低 5 个构型，以 DFT-D4 精确优化

2. **DFT-D4/SMD 计算**：
   - 方法：B3LYP-D4/def2-TZVP + SMD 水模型（ε = 78.4）
   - 显式水分子：5 个（β-CD 缘羟基 + 腔口位置），位置由 MD 预平衡确定
   - 对 PCP、2,3,4,6-TeCP、2,3,5,6-TeCP、2,4,6-TCP、PCA 分别计算

3. **包结能计算**：
   - ΔG_incl = G(complex) − G(β-CD) − G(guest)（水相）
   - ΔΔG_snug-fit = ΔG_incl(PCP) − ΔG_incl(TeCP)
   - 不确定性评估：5 个构型取平均 ± 标准差；SMD vs PCM 差异作为系统误差估计

4. **Go/no-go 判据**（精确化）：
   - **Go**：ΔΔG_snug-fit(PCP vs 2,3,4,6-TeCP) ≥ 1.0 kJ/mol（95% CI 下限 > 0）
   - **Marginal**：0.5–1.0 kJ/mol → 换腔型（α-CD 腔 ~5.5 Å 可能 snug-fit 更强）或增加缘羟基修饰
   - **No-go**：< 0.5 kJ/mol → 终止或转 A02（SBP 中性氢键）

**预期结果**（基于 r2 估计 + E36 基准计算）：
- PCP@β-CD 水相包结能：−18 to −25 kJ/mol（E36 文献值）
- TeCP@β-CD 水相包结能：−14 to −20 kJ/mol（估计，缺对位氯空隙罚 ~2 kJ/mol + 不对称失配 ~1 kJ/mol）
- **ΔΔG_snug-fit 预期**：1.5–4.0 kJ/mol（与 r2 估计一致，但不确定性从 ±1.5 收窄至 ±0.8 kJ/mol）

### 4.7–4.9 继承 r2

#### 4.9A 再生液 POP 处置闭环方案（r3 新增，闭合 W9）

**问题**：斯德哥尔摩公约附件 A 要求 PCP 浓缩液不得回排，须破坏或安全封存。

**方案**：碱性水解完全脱氯（参照 E38）：
- 条件：NaOH（2 M）/乙二醇，160 °C，4 h，密封反应釜
- 脱氯率：>99%（E38 文献值）
- 产物：苯酚 → 进一步降解为无害小分子
- 处置：脱氯后废液经中和、活性炭吸附残余有机物后排放

**与再生的衔接**：
1. 吸附饱和 β-CD 聚合物以甲醇/乙腈（含 0.1% 醋酸）洗脱 → DDT 进入溶剂流
2. 溶剂流蒸干 → PCP 浓缩物
3. 浓缩物碱性水解 → 无害化
4. β-CD 聚合物以纯水洗涤后复用

**诚实声明**：碱性水解为破坏性处置，非回收。PCP 不可回收再利用（POP 约束），破坏为唯一合规路径。

### 6A 等氯数对 2,3,5,6-TeCP 合成路线（r3 新增，闭合 W7）

**合成路线**（参照 E39）：

1. **起始原料**：2,3,5,6-四氯苯胺（商业可得，纯度 >98%）
2. **Sandmeyer 反应**：
   - 2,3,5,6-四氯苯胺（1.0 eq）+ NaNO₂（1.1 eq）+ HCl（3 M），0 °C，30 min → 重氮盐
   - 重氮盐 + CuCl（催化量）+ HCl，60 °C，2 h → 1,2,3,4-四氯苯（非目标，需异构化）
   - 替代路线：重氮盐 + H₃PO₂（次磷酸）→ 1,2,3,5-四氯苯 → 硝化 → 还原 → 重氮化 → 水解 → 2,3,5,6-TeCP
3. **总收率**：~40–55%（3 步）
4. **纯化**：柱层析（硅胶，正己烷/乙酸乙酯 9:1）
5. **表征**：¹H NMR、¹³C NMR、GC-MS、熔点

**用量估算**：等温线实验需 ~10 mg 2,3,5,6-TeCP，合成规模 100 mg 起始原料即可满足。

### 6B DVS 非 CMR 交联路线（r3 新增，闭合 W6）

**问题**：r1/r2 以 ECH（环氧氯丙烷）为交联剂，ECH 为 CMR 物质（致癌致突变致生殖毒性）。

**替代方案**：DVS（二乙烯基砜）交联（参照 E35）：
- β-CD（10 g）+ DVS（15 mL）+ NaOH（0.5 M，50 mL）
- 条件：40 °C，4 h，搅拌
- 后处理：过滤，水洗至中性，60 °C 真空干燥
- 交联效率：与 ECH 路线相当（E35 文献值）
- 优势：DVS 非 CMR，操作安全性高
