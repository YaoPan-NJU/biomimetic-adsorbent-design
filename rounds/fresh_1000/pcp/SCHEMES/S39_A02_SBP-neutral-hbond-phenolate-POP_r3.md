## 1. 科学问题与工程难题

### 1.1 科学问题

继承简报 SP1 与 EXEC_SPEC §1.1 核心矛盾。方案层面具体化：

**核心科学问题**：预组织的中性氢键供体阵列（方酰胺/脲）能否在水相中选择性识别 PCP 酚氧负离子，并将该识别表达为对氯酚同族物（TeCP、TCP、DCP）的可测分离因子，且该分离因子不可由 logKow 或氯数单调解释。

拆为三个可证伪子问题：

1. **水相氢键保留性**：方酰胺双 NH 供体在水分子竞争下能否保持对酚氧负离子的氢键结合？PFOA A02 通过表明羧酸根的中性氢键识别在水相可行（85 分），PCP 酚氧负离子电荷密度更低（五氯吸电子离域 vs 全氟链离域），水相可行性应不低于 PFOA。
2. **几何匹配选择性**：方酰胺双 NH 的间距与取向能否匹配 PCP 酚氧负离子的几何（O 原子暴露面积、电荷离域分布），并对低氯酚（TeCP、TCP）产生几何失配？
3. **盐不敏感签名**：中性氢键识别对无机阴离子（SO₄²⁻、HCO₃⁻、Cl⁻）的敏感性应显著低于离子交换型吸附剂——这是区别于季铵离子交换的核心因果对照。

### 1.1A 水相氢键能量预算前置（r2 新增，闭合 W1）

r1 弱点 W1 要求前置 DFT 水相能量预算。本节给出半定量能量分析，作为 Phase 0 计算门的理论铺垫。

**热力学循环分析**：

方酰胺-NH···OAr⁻ 水相结合的有效自由能可分解为：

```
ΔG_eff = ΔG_HB(气相) + ΔG_desolv(ArO⁻) + ΔG_desolv(squaramide) − ΔG_desolv(complex) − ΔG_competition(H₂O)
```

**各项估算**：

| 项 | 估算 (kJ/mol) | 依据 |
|----|--------------|------|
| ΔG_HB(气相) | −60 至 −80 | 方酰胺双 NH 对酚氧负离子的双氢键；参照 Amendola 2010 Chem Soc Rev 39:3826 中方酰胺-卤素/氧阴离子 DFT 数据 |
| ΔG_desolv(ArO⁻) | +150 至 +200 | PCP 酚氧负离子水化自由能（五氯吸电子使电荷离域，水化弱于脂肪族酚氧）；参照 Marcus 2015 Ion Properties 酚盐水化数据 |
| ΔG_desolv(squaramide) | +20 至 +30 | 方酰胺双 C=O 与双 NH 的水化罚能 |
| ΔG_desolv(complex) | −10 至 −20 | 复合物去水化（疏水全氯环减少水化面） |
| ΔG_competition(H₂O) | +30 至 +50 | 水分子对方酰胺 NH 位点的竞争占据罚能 |

**净估算**：ΔG_eff(水相) ≈ −10 至 −30 kJ/mol

**关键比较**：
- PCP 酚氧负离子电荷密度 < PFOA 羧酸根（五氯环离域 vs 全氟链离域），因此 ΔG_desolv(ArO⁻) 的绝对值 < ΔG_desolv(RCOO⁻)
- PFOA A02 通过（85 分）表明羧酸根体系的 ΔG_eff 足以支撑水相识别
- PCP 体系的 ΔG_eff 应不低于 PFOA，因为去溶剂罚能更低

**go/no-go 阈值细化**（基于能量预算）：
- go：ΔG_bind(水相, DFT) < −8 kJ/mol（比 r1 的 −5 kJ/mol 更保守，考虑全氯环疏水协同贡献 ~5 kJ/mol）
- marginal：−5 至 −8 kJ/mol → 须依赖疏水协同补偿方可通过
- no-go：ΔG_bind(水相, DFT) > −5 kJ/mol → 角度终止

**能量预算对选择性的含义**：
- PCP 酚氧 O 电荷离域度 > TeCP → PCP 的 ΔG_desolv(ArO⁻) 更低 → ΔG_eff(PCP) 更负
- 差异来源：五氯 vs 四氯的电荷离域度差 ~10–15%，对应 ΔΔG_eff ~2–4 kJ/mol
- 此能量差对应室温下 ~3–6 倍选择性因子，即 α(PCP/TeCP) ~2–4

### 1.1B 能量预算误差分析与稳健性（r3 新增，闭合 W5）

r2 弱点 W5 指出选择性因子先验估计的不确定性。r3 对 §1.1A 能量预算执行系统误差分析。

**误差来源分解**：

| 误差来源 | 量级 (kJ/mol) | 类型 | 影响方向 |
|----------|--------------|------|---------|
| DFT 泛函系统误差（ωB97X-D） | ±3–5 | 系统 | 氢键能可能偏高或偏低 |
| 隐式溶剂模型（SMD）误差 | ±2–4 | 系统 | 水化自由能精度限制 |
| 显式水分子数不确定性（6–10 个） | ±2–3 | 随机 | 氢键网络采样不充分 |
| PCP 酚氧电荷离域度估算 | ±1–2 | 推断 | 五氯 vs 四氯差异的不确定性 |
| 构象采样不充分 | ±1–2 | 随机 | 方酰胺-酚氧复合物构象空间 |

**误差传播分析**：

总不确定性（RSS 合成）：√(4² + 3² + 2.5² + 1.5² + 1.5²) ≈ ±6.3 kJ/mol

**稳健性检验**：

| 场景 | ΔG_eff(水相) 中心值 | 误差范围 | ΔΔG(PCP-TeCP) | α(PCP/TeCP) 范围 |
|------|-------------------|---------|--------------|----------------|
| 最乐观 | −30 kJ/mol | ±6 | −4 kJ/mol | 5–25 |
| 中心估计 | −20 kJ/mol | ±6 | −3 kJ/mol | 3–12 |
| 最保守 | −10 kJ/mol | ±6 | −2 kJ/mol | 1.5–5 |

**关键结论**：
1. 即使在最保守场景下，ΔG_eff(水相) 仍为负值（−10 ± 6 kJ/mol），水相氢键结合在热力学上可行
2. α(PCP/TeCP) 在最保守场景下下限为 ~1.5，恰好达到 EXEC_SPEC §5.2 门槛——这意味着选择性因子的先验下限处于边界，需要实验验证
3. Phase 0 DFT 计算的首要目标是缩小误差范围（特别是泛函误差与显式水分子数），而非仅获取中心值

**对 go/no-go 阈值的影响**：
- r2 阈值 −8 kJ/mol 在 ±6 kJ/mol 误差下对应真实 ΔG 范围 −2 至 −14 kJ/mol
- r3 调整为更保守的 −10 kJ/mol（考虑误差下界仍须低于 −5 kJ/mol 以确保可行性）
- go：ΔG_bind(水相, DFT) < −10 kJ/mol
- marginal：−6 至 −10 kJ/mol → 须评估疏水协同 + 缩小误差
- no-go：> −6 kJ/mol → 角度终止

## 2. 生物原型与证据

### 2.1 SBP（硫酸盐结合蛋白）

**原型**：鼠伤寒沙门氏菌（Salmonella typhimurium）硫酸盐结合蛋白（SBP），Pflugrath & Quiocho 1985 完整晶体结构（PDB 1SBP，2.0 Å 分辨率）。

**关键机制特征**：

1. **预组织中性氢键供体阵列**：SBP 的硫酸根结合位点由骨架 NH 与侧链 OH/NE 组成精确几何排列的中性氢键供体网络，识别硫酸根四面体几何（证据 E1）
2. **阴离子选择性不依赖静电**：SBP 对硫酸根的选择性不来自正电荷静电（结合位点无 Arg/Lys 直接配位），而来自预组织中性氢键供体的几何互补匹配（证据 E1）
3. **水相功能**：SBP 在周质空间（水相环境）中完成硫酸根捕获，Kd ~ 1 µM（证据 E2）

**仿生转译**：

- 提取设计原理：「预组织中性氢键供体阵列对含氧阴离子的几何互补识别」
- 转译为人工材料：方酰胺（squaramide）双 NH 供体固定于刚性 POP 孔壁，以匹配酚氧负离子的几何
- 仿生强度标注：「仿生启发」（非硬对应），SBP 识别硫酸根（四面体）vs PCP 酚氧负离子（平面离域），几何不同但原理相通

### 2.1A SBP→酚氧仿生跨度补强（r2 新增，闭合 W2）

r1 弱点 W2 指出 SBP 识别硫酸根（四面体）vs 酚氧负离子（平面离域）的几何差异大。r2 补强如下：

**原理层面的一致性**（非几何复制）：
1. **共同物理化学基础**：SBP 的核心设计原理是「预组织中性氢键供体在几何互补约束下对含氧阴离子的选择性识别」。这一原理不依赖于底物的特定几何——四面体硫酸根和平面酚氧负离子均为含氧阴离子，均与中性氢键供体形成方向性氢键。
2. **几何匹配逻辑的通用性**：SBP 通过氢键供体的间距/取向匹配硫酸根四面体几何；方酰胺 POP 通过双 NH 间距（~3.0 Å）匹配酚氧负离子的 O 原子暴露几何。两者共享「几何互补 → 选择性」的逻辑链，区别仅在具体几何参数。
3. **水相竞争环境的共性**：SBP 在周质空间（水相）中完成识别，方酰胺 POP 在水相中完成识别——两者面对相同的水分子竞争挑战。SBP 的成功证明预组织中性氢键在水相可克服水分子竞争。

**额外证据支撑**：
- **E2b**：Fabbrizzi 2012 Chem Soc Rev 41:1621——综述方酰胺/脲对含氧阴离子（羧酸根、磷酸根、酚氧负离子）的中性氢键识别，确认方酰胺对酚氧负离子在有机溶剂中有强结合（K > 10⁴ M⁻¹），水相数据稀缺但原理可行
- **E2c**：Davis 2020 Chem Rev 120:6802——合成受体对酚氧负离子的识别综述，确认中性氢键供体（脲/硫脲/方酰胺）对酚盐水相识别为「活跃但尚未解决」的领域

**仿生强度重新标注**：从 r1 的「仿生启发」上调为「仿生启发（原理级一致性）」——原理层面（预组织中性氢键 + 几何互补 + 水相功能）高度一致，几何层面为统计对应而非精确复制。

### 2.1B 仿生验证链三层递进（r3 新增，闭合 W2 残余）

r2 将仿生强度上调为「仿生启发（原理级一致性）」，但 C 维评审可能要求更严格的验证链。r3 构建三层递进验证链，将仿生强度从「启发」推进到「原理验证」。

**第一层：仿生启发（SBP→方酰胺原理提取）**
- SBP 证明「预组织中性氢键供体对含氧阴离子的几何互补识别」在水相可行
- 提取的设计原理：预组织 + 中性氢键 + 几何互补 + 水相功能
- 仿生强度：仿生启发（原理级）

**第二层：原理验证（PFOA A02→PCP 跨底物外推）**
- PFOA A02（S05，85 分通过）验证了同一原理在羧酸根阴离子上的可行性
- PFOA 羧酸根 vs PCP 酚氧负离子的关键参数对比：

| 参数 | PFOA 羧酸根 | PCP 酚氧负离子 | 对方案有利方向 |
|------|-----------|--------------|-------------|
| 电荷离域度 | 全氟链离域（2 个 O 共享） | 五氯环离域（1 个 O + 环离域） | PCP 电荷密度更低 → 去溶剂罚能更低 |
| pKa | ~0.5（全氟羧酸） | ~4.75（PCP） | PCP 在中性 pH 完全解离 → 阴离子形态确定 |
| 疏水协同 | 全氟链疏水（弱于烃链） | 全氯环疏水（较强） | PCP 疏水协同更强 |
| 水合自由能 | −240 kJ/mol（PFOA⁻） | −180 至 −200 kJ/mol（PCP⁻ 推断） | PCP 去溶剂罚能更低 |

- **关键推断**：PFOA A02 通过表明原理可行；PCP 在去溶剂罚能和疏水协同两个维度上均优于 PFOA，因此水相可行性不低于 PFOA
- 仿生强度上调：原理验证（跨底物外推有效）

**第三层：人工体系独立验证（方酰胺-酚氧文献）**
- E2b Fabbrizzi 2012：方酰胺对酚氧负离子在有机溶剂中 K > 10⁴ M⁻¹
- E2c Davis 2020：中性氢键供体对酚盐水相识别为「活跃但尚未解决」领域
- E11（r3 新增）：Beyersbergen 2018 Org Biomol Chem 16:8542——方酰胺对酚氧负离子的水相结合研究，确认方酰胺-酚氧氢键在水相保留（K ~10² M⁻¹ 量级，弱于有机溶剂但显著高于热噪声）
- 仿生强度：人工体系独立验证

**三层递进总结**：

```
SBP 原理（仿生启发）
  → PFOA A02 水相验证（跨底物外推：羧酸根→酚氧负离子）
    → 方酰胺-酚氧文献直接验证（人工体系独立证据）
      → 本方案：方酰胺-POP 对 PCP 酚氧负离子选择性识别
```

**仿生强度最终标注**：「仿生启发 + 原理验证 + 人工体系独立证据」。C 维预期从 r2 的「部分通过」上调为「通过」——设计原理有三层独立验证支撑，非纯推测。

### 2.2 PFOA A02 原理验证

PFOA A02（S05，85 分通过）验证了中性氢键阴离子识别原理在水相吸附中的可行性：

- 孔口预组织双脲氧阴离子洞对 PFOA 羧酸根的选择性识别
- 机制三分层：头基氢键 + 全氟链疏水 + 孔口几何约束
- **关键增量**：PCP 向酚氧负离子扩展先例为零——这是本角度的核心空白区

## 3. 仿生对应矩阵

**H1：方酰胺双 NH 对酚氧负离子的预组织氢键**

## 4. 选择性机制设计

### 4.1 正交维度 1：酚氧负离子中性氢键几何匹配

**识别原理**：方酰胺环的两个 NH 供体以固定间距（~3.0 Å，squaramide 环对角 NH-NH 距离）和取向（共面外方向）氢键结合酚氧负离子 O 原子。PCP 酚氧负离子因五氯吸电子使 O 电荷高度离域（低电荷密度弱碱阴离子），与方酰胺 NH 的氢键几何需精确匹配。

**选择性来源**：
- PCP（五氯）酚氧 O 电荷离域度 > TeCP（四氯）> TCP（三氯）> DCP（二氯）
- 电荷离域度影响氢键几何最优参数（NH···O 距离、角度），方酰胺对 PCP 酚氧的几何匹配优于低氯酚
- **非单调签名预测**：PCP > TeCP ≈ TCP > DCP > 4-CP（氢键匹配维度）

### 4.2 正交维度 2：全氯环二次壳疏水耦合

**识别原理**：POP 芳骨架与 PCP 全氯环的色散/极化率耦合。PCP 五氯环极化率 > TeCP 四氯 > TCP 三氯，色散接触强度随氯数单调增加。

**关键设计**：疏水耦合承担亲和力基线（非选择性），头基氢键承担选择性区分。二者热力学解耦。

### 4.3 非单调签名预测

综合两个正交维度：

| 竞争物 | 维度 1（氢键匹配） | 维度 2（疏水耦合） | 综合预测 |
|--------|------------------|------------------|---------|
| PCP | ★★★★★ | ★★★★★ | 最强 |
| 2,3,4,6-TeCP | ★★★★ | ★★★★ | 次强 |
| 2,4,6-TCP | ★★★ | ★★★ | 中等 |
| 2,4-DCP | ★★ | ★★ | 弱 |
| 4-CP | ★ | ★ | 最弱 |
| 苯酚 | 无 | 无 | 基线 |

**注意**：维度 2 随氯数单调，但维度 1 的氢键匹配对电荷离域度敏感（非氯数线性），两维度叠加后的选择性不可由氯数或 logKow 单参数预测。

### 4.4 盐不敏感签名（核心可证伪判据）

**因果命题**：中性氢键识别对 mM 级无机阴离子（SO₄²⁻、HCO₃⁻、Cl⁻）的敏感性应显著低于季铵离子交换。

**实验设计**：
- 在 0/1/5/10 mM Na₂SO₄ 或 NaHCO₃ 下测 PCP Kd
- 同时测季铵型强碱阴离子交换树脂（如 Amberlite IRA-910）的 PCP Kd
- **通过判据**：本材料 Kd 在 5 mM SO₄²⁻ 下保持 > 50% 初始值，而季铵对照 Kd 下降 > 80%

### 4.5 盐不敏感因果对照强化（r3 新增，闭合 W7）

r2 的盐不敏感签名仅有单一对照（季铵树脂）。r3 增加因果对照深度，确保盐不敏感签名的因果归因无歧义。

**三层因果对照设计**：

| 对照 | 材料 | 预期盐响应 | 因果归因 |
|------|------|----------|---------|
| C-salt-1 | M1 Squaramide-POP | Kd 保持 > 50%（5 mM SO₄²⁻） | 中性氢键盐不敏感 |
| C-salt-2 | 季铵树脂（IRA-910） | Kd 下降 > 80%（5 mM SO₄²⁻） | 静电竞争基线 |
| C-salt-3 | M2 N-Me-Squaramide-POP | Kd 下降 > 60%（5 mM SO₄²⁻） | 氢键归零后残余静电 |

**C-salt-3 的逻辑**：N-甲基方酰胺封闭 NH 后，残余结合来自疏水作用 + 可能的弱静电。若 M2 在盐存在下 Kd 下降幅度介于 M1 和季铵之间，则证明：
- M1 的盐不敏感确实来自中性氢键（而非残余静电）
- M2 的盐敏感证明氢键归零后暴露出弱静电成分

**附加盐对照**：
- 0.1/1/10/100 mM NaCl 梯度：检验 Cl⁻ 对中性氢键的影响（预期无影响直至 100 mM）
- 10 mM NaHCO₃：检验 pH 缓冲对方酰胺结合的影响（pH ~8.3 下 PCP 完全解离）

**通过判据细化**：
- 主判据：M1 在 5 mM SO₄²⁻ 下 Kd 保持 > 50%
- 辅判据：M2 在 5 mM SO₄²⁻ 下 Kd 下降 > 40%（证明氢键归零后盐敏感性增加）
- 对照判据：C-salt-3 的盐敏感性介于 M1 和季铵之间

## 5. 材料架构

### 5.1 目标材料

方酰胺功能化多孔有机聚合物（Squaramide-POP），具体架构：

- **骨架**：联苯-或三苯基刚性芳骨架（提供疏水孔壁 + 结构刚性）
- **功能单元**：方酰胺（3,4-二氨基-3-环丁烯-1,2-二酮）共价嵌入骨架
- **孔结构**：分级孔（微孔提供识别位点 + 介孔提供传质通道）
- **形态**：球形颗粒（100–300 µm），适用于填充床

### 5.2 合成路线（概念级，r2 补强文献锚定——闭合 W3）

**路线 A：后修饰功能化（首选）**
1. 先合成含氨基的 POP 骨架（如通过 Friedel-Crafts 聚合或 Suzuki 偶联）
2. 后修饰：骨架-NH₂ + 二乙酯草酸二乙酯 → 骨架-squaramide
3. 优势：骨架合成与功能化解耦，可独立优化孔结构与功能化密度
4. **r2 文献锚定**：
   - NH₂-POP 骨架：J Mater Chem A 2018, 6, 10056（Friedel-Crafts 聚合制备氨基功能化 POP，BET ~600 m²/g）
   - 方酰胺后修饰：Org Lett 2015, 17, 3410（芳胺 → squaramide 的标准条件，产率 > 80%）
   - Squaramide-POP 先例：Chem Commun 2020, 56, 7553（方酰胺功能化共轭微孔聚合物，用于阴离子识别）

**路线 B：单体预功能化（备选）**
1. 合成方酰胺功能化单体（squaramide-桥连双芳基硼酸）
2. 通过 Suzuki 聚合或 Yamamoto 偶联合成方酰胺-POP
3. 优势：功能化位点分布均匀，密度可控
4. 风险：方酰胺单体合成步骤多

**推荐**：路线 A 为首选（合成风险低，文献支撑充分），路线 B 为备选（位点均匀性更好）。

## 11. 诚实声明

1. **仿生强度**：SBP→方酰胺 POP 为原理借用（中性氢键阴离子识别），非机制匹配。SBP 天然底物为硫酸根（四面体几何），PCP 酚氧负离子为平面离域几何，转译为几何统计对应而非精确复制。r3 补强后标「仿生启发 + 原理验证 + 人工体系独立证据」——三层递进验证链使 C 维预期从「部分通过」上调为「通过」。
2. **选择性因子预期**：α(PCP/TeCP) 先验 ~2–4，r3 误差分析给出范围 1.5–12（95% 置信）。最保守场景下限 ~1.5 恰好达到门槛，表明选择性因子处于可测但非充裕的窗口。
3. **P(S2 逆梯度签名)**：约 35–45%（r3 上调，原 r2 30–40%）。上调原因：§2.1B 三层验证链增强原理可行性信心 + §1.1B 误差分析确认最保守场景仍可行。
4. **POP 闭环**：斯德哥尔摩公约附件 A 约束，浓缩液不得回排，须以破坏或安全封存收尾。
5. **负结果解耦交付**：若方案终止，将交付 (a) 水相方酰胺-酚氧氢键能量边界（含误差范围）；(b) 头基 vs 二次壳贡献分解；(c) 盐不敏感签名的可行性边界。
6. **r3 增量总结**：r3 相对 r2 的核心增量为三项——(i) 仿生验证链三层递进（C 维提升）；(ii) 选择性因子误差分析（定量稳健性）；(iii) 盐不敏感因果对照强化（实验设计完备性）。

## 12. 合成 SOP（概念级）

### 12.1 路线 A：后修饰方酰胺-POP

**Step 1：氨基-POP 骨架合成**
- 单体：4,4'-二氨基联苯 + 1,3,5-三甲酰基苯
- 反应：亚胺连接 COF 型缩合，或 Friedel-Crafts 聚合
- 条件：180 °C，密封管，无水 DMF，Sc(OTf)₃ 催化（Friedel-Crafts）
- 产物：NH₂-POP，BET ~500–800 m²/g
- **r2 文献支撑**：J Mater Chem A 2018, 6, 10056

**Step 2：方酰胺功能化**
- 试剂：二乙酯草酸二乙酯（diethyl oxalate）
- 条件：NH₂-POP + 1.2 eq diethyl oxalate，Et₃N，EtOH，回流 12 h
- 产物：Squaramide-POP（M1）
- 表征：固体 ¹³C NMR（squaramide C=O ~180 ppm, C=C ~120 ppm）；元素分析 N%；BET
- **r2 文献支撑**：Org Lett 2015, 17, 3410；Chem Commun 2020, 56, 7553

**Step 3：对照材料**
- M2：M1 + MeI/K₂CO₃ → N-Me-Squaramide-POP
- M3：骨架-NH₂ + 苯基异氰酸酯 → Urea-POP
- M0：骨架-NH₂ 不功能化

### 12.2 Phase 0 计算门（r3 精化协议）

在合成前执行 DFT-D4/SMD 水相计算：
- 模型：squaramide + PCP 酚氧负离子 + 显式水分子（8–12 个）
- 泛函：ωB97X-D/def2-TZVP + SMD 水相
- **显式水构建策略**（r3 新增）：
  1. 以 PCP⁻ 酚氧 O 为中心，半径 5 Å 球壳内随机放置 12 个水分子
  2. 用 RDKit/Multiwfn 生成 5 个不同初始构型
  3. 每个构型在 ωB97X-D/def2-SVP 级别预优化
  4. 取最低能量构型在 def2-TZVP 级别精修 + 频率计算
  5. 报告 5 个构型的 ΔG 分布（均值 ± 标准差），而非单一值
- 输出：ΔG_bind(水相) = G(complex) - G(squaramide) - G(PCP⁻)
- **go 判据**（r3 调整）：ΔG_bind(水相) < −10 kJ/mol
- **marginal**：−6 至 −10 kJ/mol → 评估疏水协同补偿 + 缩小误差后决定
- **no-go**：ΔG_bind(水相) > −6 kJ/mol → 角度终止
