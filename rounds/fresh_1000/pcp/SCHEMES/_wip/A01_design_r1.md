# S-PCP-A01 TTR 反向模式卤代酚识别通道刚性 COF（隔离设计者第 1 轮）

污染物：五氯苯酚（PCP，CAS 87-86-5，C6HCl5O，MW 266.3 g/mol，pKa 4.70）。
仿生强度：仿生启发（陷阱 T5 全文遵守：TTR 结合 PCP 属 T4 脱靶模拟/甲状腺内分泌干扰，不构成自然界对 PCP 的进化解决方案；借用依据仅为卤代酚识别机制的化学同构）。

---

## 0. 前置诚实声明（承前轮终止教训）

本角度此前经历 4 轮迭代（r1=74→r2=64→r3=76→r4=76）后终止，核心终止依据为：

**几何不可能性**：PCP 氯位 {2,3,4,5,6}，2,3,4,6-TeCP 氯位 {2,3,4,6} 为其真子集。在酚氧锚定注册位姿下，任何 PCP 互补受体图案都给 TeCP 四个注册接触、给 2,4,6-TCP 三个接触，故接触数读数 PCP5>TeCP4>TCP3 **严格单调**。反转型非单调预测（2,4,6-TCP ≥ 2,3,4,6-TeCP）在此架构下几何不可实现。

**水相卤键极弱**：Herbst 等 2026（JACS 148:19331，doi:10.1021/jacs.6c04848）直接实验证据：水溶液中 I/Br 中心弱卤键 <20 kJ/mol；C-Cl σ 空穴更浅（Cl 电负性高于 Br/I），水相净卤键贡献预期 <5 kJ/mol/接触。

**本轮重设计策略**：放弃氯酚同族物间非单调选择性声称（几何不可能），将创新重心重述为：
1. **符合门（coincidence gate）识别**：头基锚 + 卤素接触壁必须被配体以单一位姿同时满足→区分 PCP 与异头基阴离子（苯甲酸类、磺酸类）及无机阴离子；
2. **接触数主导单调 + LFER 残差**：氯酚序列单调但不可由 logKow-LFER 定量解释→残差为符合门贡献的可测证据；
3. **盐不敏感中性锚**：区别于离子交换/静电机制。

诚实先验：本方案通过 85 分的概率低。氯酚水相定量选择性因子先验 <2（同项目 dcp26 前三槽全终止同族教训），水相卤键能量裕度不足是内禀科学风险。本设计以负结果解耦交付为预设。

## 1. 科学问题与工程难题

### 1.1 科学问题

SP-A01（重述）：是否存在一种刚性直孔道周期识别位点，其同一堆叠周期内共列的中性酚氧头基锚与卤素接触壁须被配体以单一位姿同时满足（符合门），使：
- (a) PCP 对异头基两亲阴离子（苯甲酸类、磺酸类）和无机阴离子具有头基几何滤器选择性；
- (b) 氯酚同族物 Kd 序列虽单调（PCP > TeCP > TCP > DCP > 苯酚），但存在不可由 XLogP-LFER 定量解释的显著残差（符合门贡献）；
- (c) 该识别在离子强度 0→100 mM 与腐殖酸共存下稳健（盐不敏感签名）。

**可证伪假设分层**：
- h1（水相卤键能量裕度，硬停门槛）：五 C-Cl→N 接触净水相 σ 空穴定向分量 >5 kJ/mol（总）且具方向性。前置 DFT/MD 能量预算硬停：不达标即判负。
- h2（符合门）：全设计（锚+接触壁）对最佳单维删除变体有协同（单位点 ΔG 超额 >2 kJ/mol），且该协同对异头基阴离子消失。
- h3（头基锚）：共列中性供体对酚氧负离子贡献 4–15 kJ/mol，盐不敏感。
- h4（LFER 残差）：氯酚 Kd 序列对 XLogP 线性回归残差非常数（Δ 图案分析），PCP 残差显著正偏。

**预注册总体否证**：形态校正离子型 Kd 序列被 XLogP-LFER 定量解释（残差落拟合不确定度带内），判 D 维不通过，按负结果归档。

### 1.2 工程难题

EC-1（形态与疏水矛盾）：pH 7 时 PCP >99% 为酚氧负离子，中性 logKow 5.1 无法利用。
EC-2（周期共列预组织合成）：锚位与接触位须在单一堆叠周期内共存且角向注册由结晶学决定。
EC-3（NOM 竞争）：有效孔径 ~1.0–1.3 nm 与富里酸亚单元重叠，尺寸排斥不成立；抗污为待测。
EC-4（POP 闭环）：再生液为浓缩 POP 流，不得回排。
EC-5（成本）：COF 单体昂贵，定位痕量精处理。

## 4. 材料架构

### 4.1 结构设计

**骨架**：二维 β-酮烯胺 COF（E7 稳定性依据），AA 堆叠直孔道。

**单体设计**：
- 节点单体：C3 对称三醛（如 1,3,5-三甲酰基间苯三酚衍生物），提供 β-酮烯胺连接；
- 连接体单体：C2 对称二胺，主链并入：
  - 一个方酰胺（squaramide）单元→酚氧头基锚（双 NH 氢键供体，预组织平面几何）；
  - 两个吡啶基→卤素接触受体（N 孤对电子定向指向孔腔）。

**孔径几何账**：
- PCP 分子尺寸：环平面内 C-Cl 核距 ~0.174 nm，Cl vdW 半径 1.75 Å（E6）→五氯环外径（含 vdW）~0.94 nm（对位轴）×~0.88 nm（邻位轴）；
- 目标有效孔径：1.0–1.3 nm（容纳 PCP 氯鞘 + 壁受体 N 接触距离 ~0.29–0.33 nm，即 Cl vdW + N vdW）；
- 堆叠周期：~0.34–0.38 nm（β-酮烯胺 COF 典型值）；
- 酚氧 O 至对位 Cl 核距 ~0.590 nm ≈ 1.6× 堆叠周期→锚（层 n）与对位 Cl 接触（层 n+1）跨约两个周期。

**诚实标注**：跨周期共列意味着堆叠注册（AA vs 滑移/扭转）是主要结构变量，非次要不确定项。

### 4.2 前置门槛（硬停）

| 门槛 | 内容 | 不通过处置 |
|------|------|-----------|
| M-1 水相能量预算 | DFT-D3(BJ)/COSMO-RS 或 MD-FEP：PCP 五 C-Cl→吡啶 N 水相净结合能 >5 kJ/mol（总）| 判负，终止 |
| M-2 锚强度 | 方酰胺-酚氧负离子水相 H-bond ΔG 4–15 kJ/mol；若方酰胺 NH 表观 pKa <6.5（去质子）则切脲路线 | 切路线或判负 |
| M-3 堆叠注册 | PXRD + 建模：层间滑移 <0.05 nm，扭转 <5°；否则接触几何失配 | 降级为无序接触，声称收窄 |
| M-4 结晶度 | BET >500 m²/g，PXRD 主峰可指认 | 终止 |

### 4.3 能量预算诚实估算

| 贡献项 | 估算值（水相） | 依据 |
|--------|---------------|------|
| 方酰胺双 NH→酚氧 H-bond | 6–12 kJ/mol | 脲/方酰胺-阴离子水相文献通识（推断） |
| 5× C-Cl→N 卤键（水相净） | 2–5 kJ/mol（总） | E5 上限外推至 Cl（更弱），设计估算 |
| 疏水/色散（五氯环脱水） | 15–25 kJ/mol | logKow 5.1 折算（~RT·lnKow·2.303 ≈ 29 kJ/mol 上限，脱水不完全） |
| 静电（中性锚，无） | ~0 | 设计排除 |
| **总估算** | **23–42 kJ/mol** | 对应 Kd ~10⁴–10⁷ L/kg（理想） |

**诚实判断**：卤键贡献（2–5 kJ/mol）仅占总预算 ~10%，选择性增量极小。主驱动力为疏水/色散 + 头基锚。卤键的角色是提供方向性（几何约束）而非能量。

## 5. 创新性检查清单（A–E 五维）

### A. 机制创新：条件通过（边缘）
- 超越疏水/静电/尺寸：是（符合门双读出 + 中性锚盐不敏感）；
- 可被因果对照推翻：是（删除变体包 + LFER 残差）；
- 独特适用性：有限（头基锚对一切酚氧负离子通用，选择性增量落在符合门协同）。

### B. 材料架构创新：不通过
- 周期共列方酰胺+吡啶 COF 属功能化 COF 常规策略；
- 无新空间组织方式（前轮轴向分区已撤回）；
- 合成路线无方法学贡献。

### C. 仿生转译创新：不通过边缘
- TTR 反向模式蛋白特异拓扑不转译（已撤回）；
- 保留的"卤素接触主导 + 头基环境"为化学通识，非蛋白特有设计原则；
- 仿生内容实质为启发式类比。

### D. 选择性策略创新：条件通过（核心承重）
- 非单参数单调：氯酚序列单调（接触数），但 LFER 残差为第二维度；
- 正交维度：头基几何滤器（区分异头基）× 接触数/符合门（区分氯酚梯度）；
- 竞争物含结构近似物：2,3,4,6-TeCP、2,4,6-TCP、2,4-DCP、苯甲酸、苯磺酸。
- **诚实标注**：氯酚间选择性为单调（陷阱 T1 边缘），D 维通过完全依赖 LFER 残差非常数 + 异头基滤器。

### E. 先例区分：条件通过
- 系统检索：简报 59 条 Crossref 核验；COF-PCP 零命中（E9 分析向酰胺 COF 最近）；
- 与最近先例距离：E9（酰胺 COF 氯酚 SPE）→本方案增量为水相痕量 + 符合门 + 盐不敏感；
- 增量可量化：以六氯苯中性基准 + 2,3,5,6-TeCP/2,3,4,6-TeCP 注册探针判别。

## 6. 台架合成 SOP 草图

1. 单体合成：方酰胺二酰胺单体（3,4-双[(4-氨基苯基)氨基]环丁-3-烯-1,2-二酮）+ 二吡啶二胺连接体 + C3 三醛节点；

### 7.1 探针分子谱

| 探针 | 角色 | XLogP |
|------|------|-------|
| PCP | 目标物 | 5.1 |
| 2,3,4,6-TeCP | 最近似物（PCP 去 5-Cl） | 4.5 |
| 2,3,5,6-TeCP | 等氯数镜像对称探针 | 3.9 |
| 2,4,6-TCP | 三氯对称 | 3.7 |
| 2,4-DCP | 二氯不对称 | 3.1 |
| 苯酚 | 无氯基准 | 1.5 |
| 六氯苯 | 中性全氯鞘（无头基） | 5.7 |
| 五氯苯甲醚 | 中性全氯鞘 + 甲氧基 | 5.4 |
| 苯甲酸 | 异头基（羧酸根） | 1.9 |
| 苯磺酸 | 异头基（磺酸根） | — |

### 7.2 实验矩阵

- 单溶质等温线（pH 7.0 磷酸盐缓冲，10 mM）：Langmuir/Freundlich 拟合→Kd；
- 竞争实验：PCP + TeCP + TCP + DCP 四元等摩尔（1 µg/L each）；
- 盐敏性：NaCl/Na₂SO₄ 0→100 mM，PCP Kd 变化；
- 头基置换：PCP vs 苯甲酸 vs 苯磺酸（等浓度）；
- NOM 耐受：腐殖酸 5 mg-C/L 共存容量保持率；
- 再生：pH 12 NaOH 脱附→5 循环容量保持；
- 对照材料：V0（无功能空白 COF）、V1（有锚无吡啶）、V2（有吡啶无锚）、亲水离子交换树脂、疏水季铵树脂、GAC。

### 7.3 因果分解协议

1. **LFER 残差分析**：log Kd vs XLogP 线性回归，残差 Δ = log Kd(obs) - log Kd(pred)。若 Δ 对全部氯酚为常数→符合门贡献不存在→D 维判负。
2. **删除变体协同**：ΔG(全设计) - max[ΔG(V1), ΔG(V2)] > 2 kJ/mol→协同存在。
3. **中性探针分解**：六氯苯 Kd（纯疏水 + 卤键，无头基）vs PCP Kd→差值 = 头基锚贡献。
4. **2,3,5,6-TeCP vs 2,3,4,6-TeCP**（等氯数对）：若 Kd 比值 ≈1→无图案读出；若 2,3,5,6 > 2,3,4,6→镜像对称注册存在（但先验极低，需克服 ΔXLogP 0.6 ≈ 3.4 kJ/mol 疏水梯度）。

## 8. 成功与失败判据

### 成功（通过 85 分）：
- h1 通过（水相卤键 >5 kJ/mol 总）；
- h2 通过（协同 >2 kJ/mol）；
- h4 通过（LFER 残差非常数，PCP 正偏 >0.3 log 单位）；
- 异头基选择性因子 PCP/苯甲酸 >5；
- 盐不敏感签名（100 mM 容量保持 >80%）；
- Kd(PCP) ≥ 10⁴ L/kg at 1 µg/L。

### 失败（终止）：
- h1 不通过→首轮判负（水相卤键能量不足）；
- LFER 残差为常数→D 维不通过；
- 协同 <2 kJ/mol→符合门不存在；
- Kd(PCP) < 10³ L/kg→环境场景不适用。

### 负结果解耦交付（预设）：
即使方案终止，交付：(1) 头基锚/疏水/卤键三项因果分解与上限；(2) 水相 C-Cl 卤键能量实验约束；(3) 氯酚 LFER 基线数据。

## 11. 结论与建议

**推荐：TERMINATE（终止）**

理由：
1. 承重科学假设（水相 C-Cl 卤键提供方向性选择）的先验概率极低（E5 直接证据 + Cl σ 空穴浅于 Br/I）；
2. 氯酚间非单调选择性已被几何证明不可能（前轮终止核心依据，本轮无新机制绕过）；
3. 去除卤键方向性后，方案退化为"方酰胺锚 + 疏水孔壁"→与 A02（硫酸盐结合蛋白中性氢键 POP）机制家族重叠，增量不足以支撑独立角度；
4. 仿生内容（TTR 反向模式）在撤回蛋白拓扑后实质为空，C 维不通过；
5. 自评分 64，远低于 85 线，且无可见的修订路径能弥补 h1 能量不足的内禀科学风险。

**残余价值**：
- 符合门概念（头基 × 接触同时满足）可作为 A02/A03 的补充维度并入，不独立成角度；
- 水相 C-Cl 卤键能量预算的负结果对全项目卤键类角度（A03、A08）有校准价值；
- 前轮终止的子集结构几何不可实现性核算方法学可复用。
