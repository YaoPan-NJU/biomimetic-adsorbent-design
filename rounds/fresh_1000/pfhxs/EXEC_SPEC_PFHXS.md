## 1 两槽终止失败原因深度分析

### 1.1 S31/A01 终止分析（轨迹 r1=69→r2=70→r3=81→r4=70，终止）

**角度**：A01 四面体磺酸头中性氢键笼几何识别
**原型**：Sbp/ModA/TauA/SsuA 周质含氧阴离子结合蛋白
**核心主张**：全 pH 中性硫脲供体阵列在刚性多孔框架中几何匹配 R-SO₃⁻ 四面体头基，实现头基差分识别

**失败根因（结构性，非执行缺陷）**：

1. **FM3-PFAS 命中：中性氢键对强水合磺酸头水相本质弱**
   - 硫脲/脲中性供体对裸阴离子在 ≥90% 水中结合常数常低于 10–50 M⁻¹（E7 Gale 2015 Chem Rev 旁证）
   - S31 方案自身承认：绝对亲和力主自 C6 全氟尾链疏水基线，头基氢键项仅提供选择性方向而非绝对亲和主驱动
   - 头基差分机制含三个方向相反成分（氢键受体强度项偏好 PFHxA 羧酸根、差分脱水项与几何项偏好 PFHxS 磺酸根），净符号为实验问题
   - **命中 GLOBAL_SPEC 附录 FM3 历史反例**（PFHxS A01 已被点名）

2. **单维角度（P1）无法建立正交多维度**
   - A01 仅覆盖头基维（P1 单维角度），无链长维独立贡献
   - 对 PFOS/PFHxS 共享 SO₃⁻ 头基的情况，头基维完全无区分贡献
   - 不满足创新性 D 维（≥2 正交维度）要求

3. **四面体对平面几何识别为材料设计假设而非生物先例**
   - ModA 仅支持同一折叠内尺寸决定特异性原则层（R3-L6 收窄）
   - "四面体 SO₃⁻ 对平面 COO⁻ 判别"无生物直接先例
   - 创新 C 维（仿生转译创新）处于边界态

**终止核心教训**：
> **对 PFHxS（强水合永久阴离子），任何仅依赖中性氢键阵列的头基识别方案均面临 FM3 命中。头基维对 PFHxS/PFOS 无区分贡献（共享 SO₃⁻ 头基），单维头基策略结构性不可行。**

### 1.2 S28/A07 终止分析（轨迹 r1=65→r2=75→r3=78，终止）

**角度**：A07 C6 链长窗口刚性孔道深度匹配
**原型**：OAT4/ASBT 链长指纹
**核心主张**：刚性盲腔深度匹配 C6 全氟链伸展长度，PFOS 因尾链超出孔道深度产生伸出罚分，实现长链受挫置换

**失败根因（结构性，非执行缺陷）**：

1. **承重反转臂（M1）在设计几何下近于必然成立，无机制区分力**
   - PFOS 低于单调外推基线——该预测对一切长链不全埋体系（含平凡浅孔填充）近于必然成立
   - M1 降为必要条件后，机制裁决实际依赖 M2（ΔH 饱和转折随 D 移动）交 M3（去锚对照塌缩），二者确立难度高

2. **Å 级定深 D 系列 cavitand 合成与腔口取向表征可达性差**
   - 溶液相游离深腔 cavitand 以多聚胶囊封顶长链客体消解伸出罚分——机制测量须全在接枝真盲腔材料
   - 腔口朝外取向单层接枝为承重假设，常规表征不能直接证明孔内取向

3. **结构性分数天花板**
   - 轨迹 65→75→78 趋缓，裁决者判结构性天花板
   - 两档价值主张分层（第一档长链受挫置换/再释放抑制为稳健交付，第二档 C6 逆向富集为拉伸目标）虽为方法学贡献，但核心科学赌注（第二档）先验概率低

**终止核心教训**：
> **盲腔深度窗口路线在 PFHxS 上面临结构性天花板：反转臂必然成立无区分力、Å 级合成与取向表征可达性差、溶液相胶囊消解伸出罚分。该路线的核心科学命题（伸出罚分存在性）本身有价值，但作为方案通过路径不可行。**

### 1.3 两槽终止的共性失败模式提取

| 维度 | S31/A01 | S28/A07 | 共性 |
|------|---------|---------|------|
| 核心机制 | 中性氢键头基识别 | 盲腔深度窗口 | 均为单轴机制 |
| FM 命中 | FM3（氢键不可行） | FM2 变体（单调退化/必然反转臂） | 单轴 → 退化或天花板 |
| 正交维度 | 1（仅头基维） | 1（仅链长维） | 均不满足 ODC ≥2 |
| 对 PFOS 区分 | 无（共享头基） | 伸出罚分（必然但无区分力） | 均无法有效区分 PFHxS/PFOS |
| 仿生原型支持 | Sbp/ModA 原则层 | OAT4/ASBT 截止指纹 | 均为设计原理层，非功能同源 |
| 核心教训 | 中性氢键对强水合阴离子不可行 | 盲腔深度天花板 | **PFHxS 需要 ≥2 正交维度 + 非氢键/非盲腔路线** |

## 2 PFBS A17 通过方案可迁移模式提取

### 2.1 A17 核心成功机制回顾

**PFBS A17**（S17，r1=77→r4=85 通过）：孔口几何双位点头基类型反差捕获

- **T 位点**：三足硫脲汇聚匹配四面体磺酸根（PFBS，C4F9SO₃⁻）三氧排布
- **P 位点**：squaramide 平面双给体匹配平面羧酸根（PFBA，C3F7COO⁻）双氧排布
- **反差签名**：R = α_T(PFBS/PFBA) / α_P(PFBS/PFBA)，R >> 1 即头基几何做功耗能成立
- **双分支交付**：S_B 正面底盘（T/P 反差）+ S_deconvolution 阴性交付（机制解耦实测）

### 2.2 A17 可迁移要素清单

| A17 要素 | 迁移到 PFHxS 的适用性 | 迁移约束 |
|---------|---------------------|---------|
| T 位点三足硫脲磺酸锚定 | **高**——PFHxS 同为磺酸根，T 位点可直接复用为磺酸头锚定 | 锚定非选择性（PFOS 同为磺酸根），仅作为注册/锚定组件 |
| PAF-1 载体 + 孔口疏水遮蔽 | **高**——提供低介电孔口环境与 C_nF_{2n+1} 容纳腔 | 继承 A17 合成路线与表征体系 |
| 2×2 因子对照设计 | **高**——分离给体计数/几何/预组织各贡献的方法学可直接复用 | 需适配 PFHxS 特异竞争物谱 |
| S_deconvolution 阴性交付承载 | **极高**——PFHxS 2 槽终止后，机制解耦实测本身即为可发表贡献 | 正面主张先验低时，阴性交付为真贡献承载形式 |
| 同碳全氟配对双向判决 | **高**——PFHxS(PFHxS)/PFHxA(PFHxA) 为 C6 同碳配对，PFOS/PFOA 为 C8 同碳配对 | 用于验证头基维与链长维正交性 |
| 机制三分层（A 脱溶剂化/B 识别/C 疏水） | **高**——可直接采用 PFOA A02 验证的三分层解耦框架 | 每层独立验证、独立失败 |
| 诚实标注 + 可证伪判据前置 | **必须**——PFHxS 2 槽终止后，任何新方案须诚实标注先验概率 | 基线预测为"不工作"时，采用机制确证型研究框架 |

### 2.3 A17 不可迁移要素

| A17 要素 | 不可迁移原因 |
|---------|------------|
| P 位点 squaramide 羧酸匹配 | PFHxS 的竞争物谱中羧酸根（PFHxA）为头基维近似物而非主靶标，P 位点不直接适用于 PFHxS/PFOS 区分 |
| T/P 反差签名 R | PFHxS 与 PFOS 共享 SO₃⁻ 头基，T/P 反差在 PFHxS/PFOS 对上无区分贡献 |
| 头基类型分流工艺动机 | PFHxS 的核心痛点是链长中段两端夹击，非头基类型分流 |

### 2.4 PFHxS 特异约束（A17 未面对）

1. **同头基困境**：PFHxS 与 PFOS 共享 SO₃⁻ 头基，头基维对二者完全无区分
2. **两端夹击**：PFOS 热力学置换（长链优先单调）+ 自身色谱再释放（logDow 高再释放带）
3. **转运体指纹矛盾**：OAT4(+) 接受 PFHxS 排除 PFBS，ASBT(−) 接受 PFOS 排除 PFHxS——生物系统存在 C6 窗口但方向相反
4. **2 槽终止先例压力**：A01（头基氢键）与 A07（盲腔深度）均已终止，剩余角度须避免重复失败模式

## 4 首槽策略：S35 · A03 双轴加和方案

### 4.1 角度选择理由

**选择 A03（A 级）作为首槽**，理由如下：

1. **形式上双轴、对 PFHxS/PFOS 有效单轴**：头基维（T 位点）对 PFHxS/PFOS 核心竞争物贡献为零（同头基困境，共享 SO₃⁻ 头基），有效选择性仅链长维。但链腔实现方式（水平沟槽 + 终端极性墙阶跃函数）区别于已终止的 A07（盲腔深度 D 系列），且双轴对照体系可定量解耦注册/选择性贡献
2. **A17 迁移性最强**：T 位点三足硫脲磺酸锚定可直接从 A17 迁移，载体/合成/表征体系高度复用
3. **S_deconvolution 阴性交付承载**：即使链腔阶跃函数不成立，双轴加和性的机制解耦实测本身构成可发表贡献
4. **先例密度最低（PADS=18）**：PFHxS 特异双轴方案无直接先例
5. **降级声明**：因同头基困境，A03 从 S 级降为 A 级。核心赌注为链腔阶跃函数（极性墙）能否产生非单调选择性——先验概率中等（约 50%）。若失败，收缩为 S_deconvolution 机制解耦交付

### 4.2 PFHxS 特异核心挑战与应对

**核心挑战：同头基困境**

PFHxS 与 PFOS 共享 SO₃⁻ 头基 → 头基几何锚定对二者完全等价 → 选择性必须来自链长维

**应对策略**：
- 头基锚定（T 位点硫脲）定位为**注册组件**（锚定所有磺酸根，使链长维效应最大化），而非选择性来源
- 链长限域腔提供**阶跃函数**（非单调渐变）：C6 全嵌入 vs C8 部分暴露的自由能差为选择性来源
- 通过单轴突变对照证明：头基锚定失效 → 全部亲和力下降但链长序不变（头基项为注册）；链腔失效 → 链长序塌缩为单调（链腔项为选择性来源）

**核心挑战：两端夹击**

PFOS 热力学置换 + 自身色谱再释放

**应对策略**：
- C6 链腔对 PFOS 产生伸出罚分（PFOS C8 超出腔长 ~2 CF₂），直接对抗长链优先单调
- PFHxS 在 C6 腔中实现全长埋藏的强结合，抑制 Nakazawa 型色谱再释放
- 第一档稳健交付：抗长链置换 + 再释放抑制（继承 A07 第一档价值主张）
- 第二档拉伸目标：C6 逆向富集（Kd PFHxS/PFOS ≥ 5）

### 4.3 与已终止方案的区别声明

| 维度 | S31/A01（终止） | S28/A07（终止） | S35/A03（本方案） |
|------|----------------|----------------|-----------------|
| 识别轴数 | 1（头基维） | 1（链长维） | **2（头基维 + 链长维正交）** |
| 头基机制 | 中性氢键笼（FM3 命中） | 注册锚（脲） | T 位点硫脲锚定（复用 A17，不作选择性来源） |
| 链长机制 | 无 | 盲腔深度 D 系列 | C6 限域腔（非盲腔深度，而是水平沟槽 + 终端化学墙） |
| 对 PFOS 区分 | 无 | 伸出罚分（必然但无区分力） | 阶跃函数：C6 全嵌入 vs C8 超出腔长 |
| 选择性签名 | 头基差分（三方向相反） | M1 反转臂（必然）/M2 ΔH 转折 | **双轴加和性：头基项 + 链腔项可被单轴突变对照定量解耦** |

### 4.4 科学问题（方案层面）

**SQ1（双轴加和性，核心）。** 四面体磺酸头 T 位点锚定（三足硫脲，复用 A17）与 C6 链长限域腔（疏水沟槽 + 终端化学墙）的两轴亲和力贡献是否热力学加和？加和性签名：PFHxS 在双轴材料上的 logKd 超过单轴材料（仅头基锚定 / 仅链腔）的较大值，超出量 ≥ 0.5 log 单位（约 2.9 kJ/mol）。可证伪：若双轴材料 logKd ≤ max(单轴) + 0.3 log，则加和性不成立，两轴存在拮抗或独立。

**SQ2（C6 阶跃函数 vs 单调渐变）。** C6 限域腔对 PFHxS/PFOS 的选择性是否来自阶跃函数（C6 全嵌入 vs C8 部分暴露）而非单调渐变（每 CF₂ 贡献递减）？阶跃函数签名：PFHxS/PFOS 分离因子在 C6 腔材料上显著高于 C8 腔材料（对照），且 PFHxS/PFBS 分离因子在 C6 腔材料上显著低于 C8 腔材料（两端不对称）。可证伪：若 C6/C8 腔材料对 PFHxS/PFOS 分离因子无显著差异，则阶跃函数不成立，选择性仍为单调。

**SQ3（头基维与链长维正交性）。** 头基锚定项是否独立于链长维？验证：在 C4（PFBS/PFBA）、C6（PFHxS/PFHxA）、C8（PFOS/PFOA）三组同碳配对上测量 T 位点贡献（T 材料 vs 无 T 对照的 ΔlogKd），若 ΔlogKd 在三组间无显著差异（方向一致、幅度相近），则头基维独立于链长维。

**SQ4（抗硫酸根与基质耐受性）。** 继承 A17 的硫酸根耐受框架：T 位点中性硫脲 + 孔口疏水遮蔽提供两性阴离子脱溶剂化门控。硫酸根耐受定位为独立未决子问题（继承 A17 诚实标注）。

### 4.5 选择性机制三分层（复用 PFOA A02 框架）

| 层 | 机制 | 角色 | 创新贡献 |
|----|------|------|---------|
| A | 两性阴离子脱溶剂化门控 | 物理基底（必要非创新） | 无——中性疏水孔共有 |
| B | T 位点硫脲磺酸头锚定 + C6 链腔限域 | 创新核心（双轴加和） | **有——双轴正交加和性** |
| C | 全氟链疏水腔单调分量 | 容量贡献（随链长单调） | 无——继承单调先验 |

选择性来自 B 层的双轴加和性，A 层为物理基底，C 层为容量贡献。B 层可被单轴突变对照独立验证。

### 4.6 因果对照体系（先于材料设计确定）

| 对照编号 | 对照类型 | 材料 | 预测 | 隔离贡献 |
|---------|---------|------|------|---------|
| M0 | 空白载体 | PAF-1 裸载体 | 疏水基线（链长单调） | 机制 A+C |
| T-only | 头基锚定单轴 | T 位点接枝 PAF-1（无链腔） | 头基锚定增益（对所有磺酸根等价） | 机制 B 头基项 |
| C6-only | 链腔单轴 | C6 链腔接枝 PAF-1（无 T 位点） | 链腔增益（随链长渐变至 C6 阶跃） | 机制 B 链腔项 |
| T+C6 | 双轴 | T 位点 + C6 链腔 | 加和性检验：logKd > max(T-only, C6-only) + 0.5 log | 机制 B 全项 |
| T-Me | 等立体 N-甲基阻断 | N-甲基硫脲 T 位点 | 头基锚定塌缩 | 隔离供体贡献 |
| C8 | 链腔对照 | C8 链腔（无终端墙或终端位置移至 C8） | PFOS 阶跃消失，单调恢复 | 隔离阶跃函数 |
| C4 | 链腔对照 | C4 链腔 | PFBS 全嵌入，PFHxS 开始超出 | 阶跃位置验证 |
| M2a | 阳离子电荷体 | NDMB 复刻（E11） | 静电捕获基准（硫酸根敏感） | 隔离电荷贡献 |

**核心判决**：
- 双轴加和性成立：T+C6 的 logKd(PFHxS) ≥ max(T-only, C6-only) + 0.5 log → SQ1 通过
- C6 阶跃函数成立：T+C6 材料上 α(PFHxS/PFOS) > C8 材料上 α(PFHxS/PFOS) → SQ2 通过
- 正交性成立：ΔlogKd(T-only vs M0) 在 C4/C6/C8 同碳配对上方向一致 → SQ3 通过

### 4.7 两档价值主张（继承 A07 分层方法学）

**第一档（中心稳健交付）**：双轴加和性机制事实 + 抗长链置换 + 再释放抑制
- 双轴加和性本身即为机制贡献（无论绝对选择性大小）
- C6 链腔使 PFOS 超出腔长产生伸出罚分，PFOS 不再具备热力学置换 PFHxS 的优势
- PFHxS 在 C6 腔全长埋藏，脱附驱动力被抑制，色谱再释放尾部收窄
- 该档几乎由几何强制保证，稳健性高

**第二档（拉伸目标）**：C6 逆向富集（α(PFHxS/PFOS) ≥ 5）
- 仅当伸出罚分中的附加项显著超出纯接触平台时成立
- 先验概率低，为可证伪的拉伸主张
- 不成立则交付 S_deconvolution（双轴加和性机制解耦实测）

### 4.8 失败收缩与 S_deconvolution 承载

若双轴加和性不成立（T+C6 ≤ max(T-only, C6-only) + 0.3 log）：
- 交付机制解耦论文：水相 T 位点硫脲 + C6 链腔的 PFHxS 结合序与头基/链长分解实测
- 该交付本身构成独立机制贡献（类似 A17 的 S_deconvolution）
- 诚实标注：双轴加和性为设计假设，实验证伪后收缩为机制解耦实测

若 C6 阶跃函数不成立（C6/C8 腔材料分离因子无差异）：
- 交付链长限域腔的机制对照研究：阶跃函数 vs 单调渐变在 PFAS 吸附中的实验区分
- 诚实标注：链长限域腔未产生阶跃函数，选择性仍为单调

### 4.9 报告口径

继承 GLOBAL_SPEC G6 + A 组 Spec §1.5 约束：
- 主口径：动态床容量（穿透 BV 与 µg/mL 床），报实测湿沉降堆密度
- 批次口径：总干复合体 mg/g（扣 M0 空白载体贡献）
- 可及位点密度：mmol 受体/g 复合体
- ng/L 段 q_eq = Kd × C_eq 仅作诊断，标高浓参照
- PFHxS 特异：报告 PFHxS/PFOS 分离因子与 PFHxS/PFBS 分离因子，双方向

## 5 角度耗尽预案

若 S 级（A03）终止，按以下顺序执行 A 级角度：

| 优先级 | 角度 | 理由 |
|--------|------|------|
| A 级第 1 | A05 | 刚性定距 vs A03 柔性接枝，构象熵差异可比较 |
| A 级第 2 | A12 | 最 PFHxS 特异失效路径（色谱再释放）的直接应对 |
| A 级第 3 | A04 | 柔性刷双基序，与 A05 刚性定距构成熵-焓权衡对比 |
| A 级第 4 | A11 | 两性离子界面，独立于头基/链长机制 |
| B 级第 1 | A13 | 再生维，须与识别维配对 |
| B 级第 2 | A02 | MIP 平台先例密集但 C6 模板未见 |
| B 级第 3 | A09 | 探索性，预设失败判据 |

若 S + 全部 A 级终止，诚实记录 N < 50，附角度耗尽清单与终止原因汇总。

## 6 本执行 Spec 硬约束清单

以下约束不可降级，所有后续 PFHxS 方案须继承：

1. **禁止单维中性氢键方案**：FM3 已命中 A01，对 PFHxS 强水合磺酸头不可行
2. **禁止盲腔深度 D 系列路线**：结构性天花板已确认（A07 终止）
3. **禁止纯亲氟分配方案**：先例饱和（PADS > 50）
4. **禁止 α-C-H 依赖方案**：PFHxS 全氟 α-碳无氢，机制阻断
5. **须满足 ODC ≥2**：任何方案须有 ≥2 个正交选择性维度
6. **须诚实标注先验概率**：PFHxS 2 槽终止后，核心主张先验低时须采用机制确证型研究框架
7. **须包含 S_deconvolution 承载**：任何方案须有阴性交付路径
8. **须复用 A17 因果对照体系**：等立体阻断体、给体计数匹配、柔性对照、阳离子电荷体
9. **归因限定于转运体层级**：不得归因于 FABP 肝结合（简报三条硬约束）
10. **硫酸根耐受为独立未决子问题**：不与核心选择性主张绑定（继承 A17）
