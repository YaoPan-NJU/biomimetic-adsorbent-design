## 0. 方案定位与已通过方案正交性声明

**已通过方案 S32（A01）机制概述**：刚性凹形裂缝半笼碗单元预组织核苷酸碱基模拟氢键站位阵列，读取大环内酯类级共有特征（糖基装饰、内酯羟基/羰基），C9 肟醚臂为类内增量目标。识别机制为可逆吸附（氢键阵列 + 受限微环境）。

**本方案（A06）机制概述**：大环内酯酯酶 EreA/EreB 启发的限域亲核位点，在吸附捕获后水解罗红霉素内酯环使抑菌活性失活，水解产物极性升高易脱附实现再生。识别机制为反应性捕获（捕获即失活），区别于 S32 的可逆吸附。

**正交性矩阵**（不变）：

| 维度 | S32（A01） | S56（A06） | 正交性 |
|------|-----------|-----------|--------|
| 识别机制 | 可逆吸附（氢键阵列 + 受限腔） | 反应性捕获（内酯环水解失活） | 机制正交：可逆 vs 不可逆 |
| 选择性来源 | 核苷酸碱基阵列几何 + C9 肟醚增量 | 内酯环水解（大环内酯类级标志反应） | 选择性逻辑正交 |
| 闭合判据 | 吸附分离因子 α_H(ROX/Ery) | 抗菌活性下降（直击 T4） | 判据正交 |
| 再生 | pH 摆 + 溶剂辅助 | 水解产物易脱附（极性升高） | 再生路径正交 |
| 原型 | 核糖体 NPET（RNA 核苷酸阵列） | 大环内酯酯酶 EreA/EreB（水解酶） | 原型正交 |
| 材料平台 | 介孔有机聚合物 + COF | 多孔吸附载体 + 亲核/氧阴离子洞模拟 | 平台正交 |

## 1. 科学问题与工程难题

### 1.1 科学问题

罗红霉素为 14 元大环内酯，内酯环（14 元环酯键）是大环内酯类级的共有结构标志。大环内酯酯酶 EreA/EreB 家族可水解内酯环使抑菌活性失活（Morar 2012），但该酶底物为红霉素，罗红霉素 C9 肟醚取代对腔体容纳的影响无直接文献。

本方案的机制问题是：**能否在多孔吸附载体上预组织非蛋白限域亲核位点（受限胺/咪唑 + 氧阴离子洞模拟），在捕获罗红霉素后催化内酯环水解使其抑菌活性失活。**

核心科学赌注（r2 量化加强）：
1. 非蛋白体系中内酯环水解的速率是否足够——**r2 补充**：模型底物（红霉素）内酯环水解表观半衰期须 < 24 h（材料表面），ROX 水解半衰期须 < 72 h（C9 肟醚可能降低可及性）
2. ROX C9 肟醚取代是否影响内酯环在限域亲核位点中的可及性——**r2 补充**：MD 模拟确认 C9 肟醚臂在 14 元环构象空间中不遮蔽内酯环羰基碳
3. 水解产物（开环羟基酸）是否确实极性升高、易脱附——**r2 补充**：开环产物 TPSA 预期增加 ~20 Å²（新增 -COOH + -OH），logKow 下降 > 1 单位

### 1.2 工程难题

- **EC1 ng/L 传质**：主目标场景 ng/L 级（二级出水最高 3847 ng/L），837 Da 大分子传质慢
- **EC2 温和再生**：水解产物脱附后位点须再生（亲核基团恢复）
- **EC3 抗菌活性闭合**：闭合判据为抗菌活性下降而非母体去除（T4 去除-失活错位）
- **EC4 NOM 竞争**：mg/L 级 NOM 与 ng/L 级罗红霉素竞争

### 1.3 设计假设（r2 修订）

多孔吸附载体（**r2 首选介孔活性炭**）表面预组织限域亲核位点：
- **亲核基元**：咪唑/叔胺（广义碱催化）+ 邻近硫脲（r2 从脲升级为硫脲，增强氧阴离子洞模拟能力）
- **限域微环境**：疏水孔道预浓缩大环内酯至亲核位点附近
- **r2 新增——预组织策略**：通过分子印迹在碳表面创建尺寸匹配 ROX 的腔体（~12 Å 深穴），使亲核位点位于穴底，内酯环羰基碳正对亲核基元

**两步机制**：(1) 疏水孔道 + 分子印迹腔预浓缩 ROX；(2) 限域亲核位点催化内酯环水解（失活）

## 3. 材料架构（r2 重大修订）

### 3.1 主平台：介孔活性炭 + 分子印迹（r2 修订）

**首选（r2 修订）**：介孔活性炭（框架优先载体）+ 表面分子印迹 ROX 腔体
- 比表面积 > 1000 m²/g，介孔为主（4–8 nm）
- **r2 新增——分子印迹策略**：
  1. ROX 模板分子 + 功能单体（咪唑 + 硫脲基元）在碳表面自组装
  2. 交联聚合固定（低交联度，保持位点柔性以适应底物）
  3. 模板洗脱（甲醇/乙酸混合）留下 ROX 形状腔体
  4. 腔体深度 ~12 Å（匹配 ROX 分子尺寸），亲核位点位于穴底

**r2 修订理由**：分子印迹提供三重增益——(1) 尺寸选择性预过滤（仅 ROX 级分子可进入腔体）；(2) 亲核位点空间预组织（印迹腔底定向排列）；(3) 局部疏水微环境（降低水活度，增强水解速率）

### 3.2 亲核位点构筑（r2 修订）

- **广义碱**：咪唑通过氯甲基化 + 胺化接枝于碳表面印迹腔底部
- **氧阴离子洞模拟（r2 升级）**：**硫脲**替代脲（r1）
  - 硫脲 N-H 氢键供体强度 > 脲（C=S 极化率 > C=O）
  - 硫脲对四面体中间体的羰基氧稳定化能力更强
  - 间距：咪唑与硫脲间距 ~3–4 Å（匹配酯键水解过渡态几何）
- **r2 新增——位点密度目标**：0.05–0.2 mmol/g（印迹腔密度，非总官能团密度）

### 3.3 NOM 耐受性设计（r2 新增，回应 M2）

1. **尺寸排阻外层**：介孔活性炭外表面包覆 500 Da MWCO 亲水凝胶层，阻挡腐殖酸大分子（>500 Da）进入印迹腔
2. **疏水预浓缩域保护**：印迹腔入口为疏水孔道，优先分配 logKow 高的分子（ROX logKow ~3.5），排斥亲水性 NOM 组分
3. **NOM 耐受性定量目标**：腐殖酸 10 mg/L C 存在下水解速率下降 < 40%

## 4. 选择性机制分层

### 4.1 三层架构

| 层 | 机制 | 角色 | 选择性贡献 |
|---|------|------|-----------|
| 第一层 | 疏水预浓缩 + 分子印迹腔（碳表面） | 使能层 + 尺寸预过滤 | 分子印迹腔提供尺寸选择性（ROX 级分子可进入） |
| 第二层 | 内酯环水解（亲核位点 + 氧阴离子洞） | **选择性来源**（大环内酯类级标志） | 内酯环为大环内酯类级共有结构 |
| 第三层 | 水解产物脱附再生 | 使能层 | 极性升高 → 易脱附 |

### 4.2 选择性逻辑

- **类级选择性**：内酯环为大环内酯类级共有 → 捕获全谱大环内酯
- **类内区分**：ROX C9 肟醚对水解速率的影响为设计假设
- **闭合判据**：抗菌活性下降（非母体去除），直击 T4

### 4.3 竞争物谱

| 层级 | 竞争物 | 预期行为 |
|------|--------|---------|
| 第一层 | 红霉素、克拉霉素、螺旋霉素 | 同类大环内酯，均含内酯环，均被水解 |

## 5. 可证伪实验设计（r2 强化）

### 5.1 Stage 0 模型水解实验门（r2 重校准）

**模型底物**：红霉素（MW 734，与 ROX 相近但无 C9 肟醚，内酯环可及性更高）

**r2 门判据（重校准）**：

| 条件 | 判定 |
|------|------|
| 红霉素内酯环水解 t₁/₂ < 24 h（材料表面） | **GO**（进入 ROX 验证） |
| 24 h < t₁/₂ < 7 天 | **CONDITIONAL**（优化位点密度/间距后重测） |
| t₁/₂ > 7 天 | **TERMINATE**（非蛋白水解速率不可行） |

**r2 新增——ROX 平行 Stage 0**：
- 在红霉素 GO 后，立即以 ROX 为底物平行测试
- ROX t₁/₂ < 72 h 为 GO（C9 肟醚可能降低可及性，容忍 3× 减慢）
- ROX t₁/₂ > 7 天为 TERMINATE

### 5.2 C9 肟醚可及性验证（r2 新增，回应 M1）

1. **MD 模拟**：ROX 在印迹腔内的构象动力学（100 ns），确认内酯环羰基碳朝向亲核位点的概率 > 60%
2. **¹³C NMR 化学位移**：ROX 内酯环羰基碳在印迹腔内 vs 自由溶液的化学位移差异（> 0.5 ppm 表示直接相互作用）
3. **红霉素/ROX 平行比较**：若 ROX 水解速率 < 红霉素的 1/10，C9 肟醚遮蔽效应为承重风险

### 5.3 关键实验（r2 修订）

| 实验 | 目的 | 通过判据 |
|------|------|---------|
| E-1 抗菌活性时间序列 | 水解导致活性下降 | 24 h 内活性下降 ≥ 80%（ROX） |
| E-2 LC-MS/MS 产物鉴定 | 确认内酯环水解产物 | 开环羟基酸产物检出 |
| E-3 因果对照系列 | 无亲核位点/无氧阴离子洞/阿奇霉素 | C1 活性不下降；C3 阿奇霉素不水解 |
| E-4 再生测试 | 水解产物脱附 + 位点再生 | 5 循环水解活性保持 ≥ 70% |
| E-5 NOM 竞争（r2 强化） | 二级出水基质 + 腐殖酸 10 mg/L C | 水解速率下降 < 40% |
| E-6 ng/L 床层 | 低驱动力工况 | 穿透曲线示床层寿命可接受 |
| **E-7（r2 新增）水解产物毒性评估** | 开环羟基酸产物毒性 | TEST/EPI Suite 预测 + 文献数据（E15 Wang 2020：红霉素开环产物毒性 < 母体） |

### 5.4 失败判据

- Stage 0 红霉素水解 t₁/₂ > 7 天 → 非蛋白水解不可行，终止
- ROX 水解 t₁/₂ > 7 天（即使红霉素 GO）→ C9 肟醚遮蔽效应致命
- 抗菌活性不下降（即使母体被吸附）→ 去除-失活错位未解决
- 亲核位点不可逆失活（5 循环后活性 < 30%）→ 再生不可行
- 阿奇霉素也被水解 → 选择性声称失败

## 9. 与 S32 的互补性声明

S32（A01）以可逆吸附 + 类内分离因子为闭合判据，本方案（A06）以反应性水解 + 抗菌活性下降为闭合判据。两方案：
- **机制正交**：可逆吸附 vs 反应性水解
- **判据正交**：分离因子 vs 抗菌活性下降
- **选择性互补**：S32 追求类内区分（ROX vs Ery）；A06 追求类级去除 + 活性消除
- **场景互补**：S32 适合需要选择性保留的场景；A06 适合需要消除抗菌活性的场景
