### 0.1 首槽选择理由

## 1. 科学问题与工程难题

### 1.1 科学问题（继承简报 SP1，按 A02 角度收窄）

TCDD 为中性无解离平面刚性三环芳醚，静电、酸碱、氢键三类常规识别把手全部不可用。本方案的机制问题是：**能否以层状 COF 的定域层间距狭缝（~0.35–0.45 nm）与芳壁连续静电场，在水相中读取 2,3,7,8-TCDD 侧位四氯图式的分子四极矩差异，并结合平面性形状排除，实现对同分异构体（1,2,3,4-TCDD）与非平面竞争物（ortho-PCB）的选择性捕获。**

核心热力学图像：2,3,7,8-TCDD 的四个侧位氯产生特征分子四极矩张量（沿分子长轴与短轴方向性不同），与 1,2,3,4-TCDD（氯位型不同、四极矩张量不同）及 OCDD（八氯、四极矩更大但 TEF 低三个数量级）存在可计算的静电差异。COF 芳壁（如萘基、蒽基、六氟苯基等电子密度可调壁）的 π 电子云与该四极矩产生静电互补——连续场匹配而非方向性卤键，水相削弱程度低于单点氢键/卤键（Dieldrin S27 教训：单点水相氢键净收益仅 1–3 kJ/mol；连续静电场匹配对溶剂竞争的鲁棒性更高但须实测验证）。

### 1.2 工程难题（继承简报 E1/E2/E3）

- **pg/L 超痕量**：1 pg/L TCDD ≈ 3.1 pM，表观 Kd 需 ~10⁵ L/kg 量级；同位素稀释 HRGC-HRMS 或 ¹³C/¹⁴C 示踪为硬性分析要求
- **真实基质三重干扰**：NOM/EfOM 孔容预占 + 表观增溶 + 位点竞争
- **再生安全**：含氯平面分子热再生 250–450 °C 可经铜催化 de novo 再合成 PCDD/F，温和再生为硬性要求

### 1.3 闭环主张

层状 COF 狭缝以**连续静电场匹配（氯图式四极矩差异）+ 层间距平面性形状排除**双维度，在含 17 种 PCDD/F 同系物、非邻位 dl-PCB 与 NOM 的真实基质中对 2,3,7,8-TCDD 给出对 1,2,3,4-TCDD 与 PCB-126 的同系物级分离，经脂质/有机碳归一化对照排除普通疏水分配。

### 2.1 原型家族声明

本角度原型家族为**还原脱氯谱系的氯图式读取**叠加 **AhR 口袋几何约束**（后者为标定靶，非原型）。

- **还原脱氯谱系**（P1）：微生物还原脱卤酶对 PCDD/F 氯位型呈位点偏好（peri > lateral），证明氯图式的空间/静电差异可被生物系统读取（Barkovskii & Adriaens 1996；Bunge 2003 CBDB1 区域选择性脱卤；Broderick 1991 氯儿茶酚双加氧酶读氯位，PDB 3TH1）

## 3. 仿生对应矩阵（两条硬对应，六列完整）

### 硬对应 HC1（平面受限疏水狭缝腔：形状读平面性 + 疏水预浓缩）

- **生物特征**：AhR PAS-B 为严格平面刚性疏水腔，仅接纳平面配体（2,3,7,8-TCDD 因严格平面性获高亲和；非平面 ortho-PCB 被排除）
- **来源支持**：E4（氚标 TCDD 高亲和结合）、E5/E6（AhR 结构 PDB，待复核）；T7（AhR 配体混杂性证明单一腔几何不足）
- **材料实现**：层状 COF 的定域层间距狭缝（层间距约 0.35–0.45 nm，匹配 TCDD 分子厚度 ~3.4 Å），壁电子密度通过单体选择可调（萘基/蒽基/六氟苯基等）；层间距防溶胀固定为合成关键
- **预期功能**：接纳严格平面分子（TCDD、PCDF、非邻位 dl-PCB），排除非平面竞争物（ortho-PCB、部分 PAH）；疏水芳壁提供 pg/L 级预浓缩驱动力
- **测量**：单组分等温线（TCDD、1,2,3,4-TCDD、PCDF、OCDD）；层间距对照系列（0.35/0.38/0.42/0.45 nm）；非平面 PCB 排除率
- **因果对照**：层间距放宽对照（>0.5 nm，丧失平面性筛分）；层间距过窄对照（<0.33 nm，TCDD 不可入）；无芳壁对照（脂肪族孔壁，丧失静电互补维）

### 硬对应 HC2（氯图式四极矩静电互补：连续场匹配读氯位型）

- **生物特征**：还原脱氯酶对 PCDD/F 氯位型呈位点偏好（peri > lateral），证明氯图式的空间/静电差异可被微环境读取；AhR 选择性残基（Ile319/Phe318，E4 语境）接触侧位氯
- **来源支持**：E1/E2/E3（还原脱氯谱系氯位型读取）；E12（TCDD 分子四极矩计算）
- **材料实现**：COF 芳壁 π 电子云与 TCDD 侧位四氯图式的分子四极矩产生静电互补——区别 A01 的方向性卤键（σ-空穴），本维度为连续静电场匹配（π-π 静电），水相削弱程度预期低于单点氢键/卤键；壁电子密度通过单体选择（富电子萘/蒽 vs 缺电子六氟苯/四氟苯）调制静电互补方向
- **预期功能**：2,3,7,8-TCDD（侧位四氯，特征四极矩）与 1,2,3,4-TCDD（peri 位氯，四极矩不同）在芳壁间产生差分静电结合能；OCDD（八氯、四极矩更大）与 TCDD 的差分由层间距形状维 + 四极矩标度协同区分
- **测量**：α(2,3,7,8-TCDD / 1,2,3,4-TCDD)；α(TCDD / PCB-126)；α(TCDD / OCDD)；壁电子密度系列（富电子 vs 缺电子）的 α 响应
- **因果对照**：壁电子密度调制系列（改变静电互补强度）；无氯母核 DD（二苯并-p-二噁英，无侧位氯）对照分解静电维贡献；同分异构体对（2,3,7,8 vs 1,2,3,4）为强制核心对照

## 4. 材料架构与选择性机制

### 4.1 载体与构筑

**主载体**：层状共价有机框架（COF），目标层间距 0.35–0.45 nm，壁电子密度可调。

候选 COF 体系（按层间距控制成熟度排序）：
1. **COF-LZU1 类**（硼酸酯键，层间距 ~0.34 nm，可通过单体扩展调至 ~0.40 nm）：合成成熟、层间距表征完善
2. **TpPa 类**（β-酮烯胺键，层间距 ~0.36 nm）：水稳定性优于硼酸酯，键能更高
3. **亚胺键 COF**（如 TpBD-Me，层间距 ~0.38 nm）：水稳定性好，单体选择范围广
4. **氟化 COF**（如含六氟苯基单体，层间距可调）：缺电子壁调制静电互补方向

**架构变体**：
- 壁电子密度系列：富电子（萘基/蒽基单体）→ 中性（苯基单体）→ 缺电子（六氟苯基/四氟苯基单体）
- 层间距系列：0.35 / 0.38 / 0.42 / 0.45 nm（通过单体长度/角度调制）
- 交联度变体：层间共价支柱（pillaring）防溶胀

### 4.2 选择性机制（分层）

**第一层：疏水预浓缩层（非选择性来源）**
- COF 芳壁对超疏水平面分子（logKow ~6.8）的疏水分配驱动 pg/L 捕获
- 该层提供驱动力但不构成选择性（OCDD logKow 更高，疏水本底偏好 OCDD）
- 诚实声明：疏水本底本身不可区分 TCDD 与 OCDD/PeCDD

**第二层：平面性形状排除层（第一正交维度）**
- 层间距 ~0.35–0.40 nm 严格排除非平面分子（ortho-PCB 扭转角 >30°，分子厚度 >4 Å）
- 对平面分子（TCDD、PCDF、非邻位 dl-PCB、PAH）不产生区分——此维度为"使能"而非"选择性"
- 因果对照：层间距放宽至 >0.5 nm 应丧失平面性筛分

**第三层：四极矩静电互补层（选择性来源，核心赌注）**
- 2,3,7,8-TCDD 侧位四氯图式产生特征分子四极矩张量，与 COF 芳壁 π 电子云产生静电互补
- 1,2,3,4-TCDD 氯位型不同（peri 位 vs lateral 位），四极矩张量不同，静电互补差分预期 >1 kJ/mol
- OCDD 八氯四极矩更大但层间距形状维可部分区分（分子厚度略增 + 层间距固定）
- 壁电子密度调制可改变静电互补方向与强度：富电子壁偏好缺电子区域（氯取代区），缺电子壁偏好富电子区域（无氯角位区）
- **核心赌注**：连续静电场匹配在水相中的净收益是否足以产生可测分离因子（α ≥ 2）

### 4.3 亲和力预算（吸收 SL04 教训）

SL04/A10 指出 pg/L 工况需 K_a ~10⁸–10⁹ M⁻¹（近抗体级），为非蛋白腔结构性天花板。本槽 A02 的策略差异：
- **不追求单点高亲和**：走连续静电场 + 疏水协同（多位点弱作用加和），非单点结合
- **亲和力来源分解**：疏水预浓缩（logKow ~6.8 贡献 ~10³–10⁴ L/kg）+ 静电互补（预期增量 ~10¹–10²）+ 形状匹配（熵增益）
- **诚实上限**：总 Kd ~10⁵ L/kg 量级为 C 组 Spec 目标，本方案能否达到取决于静电互补增量；Stage-0 门控前置验证

### 4.4 报告口径（继承 GLOBAL_SPEC G6）

- 总干复合体 mg/g（TCDD 分子量 322.0）
- 床层口径 mg/mL（COF 粉末压片或颗粒填充床堆积密度约 0.3–0.5 g/mL）
- 可及位点密度（mmol/g，由层间距与比表面积估算）
- 空白载体贡献（无静电互补壁的对照）
- **脂质/有机碳归一化对照**（EXEC_SPEC §5.3 GC1 强制）：K_d,材料/K_d,脂质 与 K_d,材料/K_OC 比值
- **分离因子 α 为主指标**（非容量）：α(2,3,7,8-TCDD / 1,2,3,4-TCDD)、α(TCDD / PCB-126)、α(TCDD / OCDD)

### 4.5 再生机制（避 de novo 窗口，EXEC_SPEC §8.3）

- **禁止热再生**：250–450 °C 窗口铜催化 de novo 再合成 PCDD/F
- **主路线**：低温溶剂洗脱（超临界 CO₂ 或温和有机溶剂），不破坏客体骨架
- **备选**：电化学切换（若 COF 导电性允许）
- 再生液全程 TEQ 核算（EXEC_SPEC T8）

## 5. 创新性清单 A-E 逐项自判

### A 机制创新：通过（附核心保留）

- 选择性机制为连续静电场匹配（四极矩静电互补），超越普通疏水分配/静电吸附/尺寸筛分
- 对 logKow 相近（~6.6–7.0）、电荷为零、骨架相似的 TCDD 同系物产生非单调区分
- "层状 COF 芳壁对侧位氯图式四极矩的水相静电互补读取"可被 Stage-0 DFT 计算与壁电子密度系列因果对照直接证伪
- **核心保留**：水相连续静电场匹配的净收益为未证赌注；若静电互补增量 <1 kJ/mol，则机制退化为纯疏水 + 形状筛分（丧失同分异构体区分）

### B 材料架构创新：部分通过

- COF 为成熟平台（弱点），但 COF-二噁英零命中（机会）
- 增量：(a) 壁电子密度可调的静电互补系列设计；(b) 层间距防溶胀固定用于平面性筛分；(c) 四极矩静电匹配机制主张
- 合成路线方法学贡献：中等（COF 合成化学成熟，创新在应用组合）
- 改进方向：若 COF 水稳定性不足，可转 HCP（超交联聚合物）或孔径调制碳

### C 仿生转译创新：通过（附 T6/T7 硬约束）

- 提取"还原脱氯谱系氯位型读取"的架构原理（氯图式空间/静电差异可被微环境读取），非官能团拷贝
- AhR 几何约束仅用于标定靶（平面腔尺寸参考），标注仿生启发，不写为"模仿 AhR"
- 立论建于 approach-2 工程难题（pg/L 级选择性捕获），非 approach-1 原型模仿
- 仿生转译内容中等：氯图式读取原理为提取层级，非结构拷贝

### D 选择性策略创新：通过（最强维度）

- 单一 logKow 单调解释在 TCDD 体系失效（OCDD logKow 更高而 TEF 低三个数量级，EXEC_SPEC T2）
- 两正交维度协同：平面性形状排除 + 四极矩静电互补
- 三层竞争物谱含最严格同分异构体对（1,2,3,4-TCDD）与结构近似物（PCB-126、PCDF）
- 对 OCDD 的区分由层间距形状维 + 四极矩标度协同（非 logKow 单调）

### E 先例区分：有条件通过

- COF-二噁英零命中（EXEC_SPEC U1/U2/U5 交集）
- 与最近先例（高硅沸石 Beta 形状筛分，E7）的区别：本方案增加四极矩静电维（沸石仅形状筛分，单维度）
- 增量足否取决于静电互补增量是否可测；若 <1 kJ/mol 则增量塌陷为纯形状筛分（与 E7 区别消失）

**总判定**：A、C、D 三维展示可验证的创新性（D 最强），B/E 部分或有条件通过已标注原因与改进方向，满足清单"至少一维明确创新"门槛。

## 6. 台架合成 SOP 草图

### 步骤一：COF 单体选择与系列设计

**壁电子密度系列**（主系列，固定层间距 ~0.38 nm）：
- 富电子壁：2,6-二氨基蒽 + 1,3,5-三甲酰基苯（TFB）→ 亚胺键 COF，蒽基壁
- 中性壁：对苯二胺 + TFB → 亚胺键 COF，苯基壁
- 缺电子壁：2,3,5,6-四氟对苯二胺 + TFB → 亚胺键 COF，四氟苯基壁
- 强缺电子壁：2,3,5,6-四氟对苯二胺 + 1,3,5-三(五氟苯甲酰基)苯 → 全氟化 COF

**层间距系列**（固定壁化学，调层间距）：
- 0.35 nm：对苯二胺 + TFB（短单体）
- 0.38 nm：4,4'-二氨基联苯 + TFB（中联体）
- 0.42 nm：4,4''-二氨基三联苯 + TFB（长联体）
- 0.45 nm：引入支柱单体（如 1,4-苯二硼酸支柱）

### 步骤二：COF 合成

标准溶剂热法：
1. 单体按化学计量比溶于均相溶剂（1,4-二噁烷/均三甲苯 1:1 v/v，含 6 M 醋酸水溶液为催化剂）
2. 封管，120 °C 溶剂热 72 h
3. 离心收集固体，依次用 1,4-二噁烷、丙酮、甲醇各洗涤 3 次
4. 活化：80 °C 真空干燥 12 h
5. 表征：PXRD（层间距确认）、N₂ 吸脱附（BET 比表面积与孔径分布）、FT-IR（键合确认）、TGA（热稳定性）、元素分析（组成确认）

### 步骤三：层间距防溶胀固定

**关键合成难点**（EXEC_SPEC §7.1 前置风险）：
- 共价支柱法：在层间引入二醛/二胺交联支柱（如 1,4-苯二甲醛），固定层间距
- 后合成固化：合成后以二醛蒸汽处理，层间亚胺键锁定
- 验证：水汽吸附等温线 + 高压水侵入-挤出（参照 Dieldrin S27 E15 方法），层间距偏差 <0.5 Å 为 go 线

### 步骤四：颗粒成型与床层制备

- COF 粉末与粘结剂（PVDF 或 PTFE，≤5 wt%）混合
- 造粒/压片/涂覆于惰性载体（硅胶或石英砂）
- 填充柱制备（内径 4.6 mm 分析柱或 10 mm 制备柱）
- 床层表征：堆积密度、孔隙率、渗透性

### 步骤五：表征清单

| 表征 | 方法 | 目的 |
|------|------|------|
| 层间距 | PXRD（干态 + 湿态） | 确认层间距与溶胀稳定性 |
| 比表面积/孔径 | N₂ 吸脱附（BET） | 孔结构确认 |
| 壁电子密度 | XPS、接触角、zeta 电位 | 壁化学确认 |
| 水稳定性 | 水汽吸附、浸泡实验（7 d, pH 5–9） | 水相适用性 |
| 热稳定性 | TGA | 确认无热再生风险 |
| 润湿态 | 水汽吸附 + 高压侵入-挤出 | 孔内润湿行为 |

## 7. 实验与因果对照计划

### 7.1 阶段 0：三道前置门（不经此关不合成材料）

**Stage-0a：DFT/MD 计算差分结合能**
- 内容：DFT（ωB97X-D/def2-TZVP 或同等级）计算 TCDD vs 1,2,3,4-TCDD 在芳壁狭缝间的差分结合能
- 模型：两片芳烃（苯/萘/蒽/六氟苯）夹 TCDD 或 1,2,3,4-TCDD，间距 0.35–0.45 nm
- 水相校正：隐式溶剂模型（SMD）+ 显式水分子竞争（3–6 个水分子）
- go 线：|ΔΔG| ≥ 1.0 kJ/mol（298 K 对应 α ≥ 1.5）
- 终止线：|ΔΔG| < 0.5 kJ/mol（静电互补维不可区分，退化为纯形状筛分）
- caution 带：0.5–1.0 kJ/mol 进入合成但效应下限下压

**Stage-0b：层间距溶胀稳定性预筛**
- 内容：候选 COF 的水汽吸附等温线与高压水侵入-挤出
- go 线：层间距偏差 <0.5 Å（水汽饱和 vs 干态）
- 终止线：层间距偏差 >1.0 Å（溶胀不可控，平面性筛分失效）

**Stage-0c：模型化合物吸附 go/no-go**
- 模型客体：1,2-二氯苯（1,2-DCB，EXEC_SPEC §8.4 第二级代用物，沸石 Beta 先例代用物）
- 方法：批次吸附等温线（超纯水，GC-MS/MS 检测）
- go 线：K ≥ 10³ M⁻¹（疏水预浓缩 + 静电互补加和可测）
- 终止线：K < 10² M⁻¹（亲和力不足，pg/L 工况不可达）

### 7.2 材料级等温线与竞争实验

**竞争物谱（三层，继承 EXEC_SPEC §5）**：

| 层级 | 竞争物 | 威胁机制 | 强制优先级 |
|------|--------|---------|-----------|
| L1 | 1,2,3,4-TCDD | 分子式/MW/logKow 全同，仅氯位型不同 | **必须首位** |
| L1 | PCB-126 | 平面性相似、氯数相同、无醚氧 | **必须** |
| L1 | PCDF（2,3,7,8-TCDF） | 呋喃骨架，少一氧 | **必须** |
| L2 | OCDD | logKow 更高但 TEF 低 10³ | **必须** |
| L2 | 1,2,3,7,8-PeCDD | TEQ 竞争主对手 | **必须** |
| L2 | 2,3,7,8-TCDF | 骨架差异 + 氯数相同 | 推荐 |
| L2 | 非邻位 dl-PCB（77/126/169） | 平面性相似 | 推荐 |
| L3 | NOM/DOC/EfOM | 孔容预占 + 位点竞争 + 增溶 | **必须** |
| L3 | 颗粒有机碳 | 无限分配相 | **必须** |

**浓度与基质**：
- 超纯水（规约）：三点浓度 0.1 pg/L（低，~0.3 pM）、1 pg/L（中，~3 pM）、10 pg/L（高，~30 pM）
- 二级出水/真实地表水加标：检验选择性保持
- 分析：同位素稀释 HRGC-HRMS（¹³C₁₂-TCDD）或 ¹³C/¹⁴C 示踪

**器壁对照（EXEC_SPEC T3 强制）**：
- 玻璃器壁硅烷化回收率对照
- 0.7 µm 过滤口径声明
- 全程 TEQ 核算

### 7.3 因果对照（解耦静电维与形状维）

**其一，壁电子密度系列（解耦静电维）**：
- 富电子/中性/缺电子壁三组同层间距 COF
- α(2,3,7,8/1,2,3,4) 随壁电子密度单调变化则静电互补维得解耦
- 不单调则静电互补维失效或水相竞争淹没

**其二，层间距系列（解耦形状维）**：
- 0.35/0.38/0.42/0.45 nm 四组同壁化学 COF
- 非平面 PCB 排除率随层间距放宽而下降则形状维得解耦
- TCDD 对同分异构体 α 在层间距 ~0.38 nm 附近应达峰

**其三，无氯母核 DD 对照（分解静电维贡献）**：
- DD（二苯并-p-二噁英，无侧位氯）与 TCDD 分测 Kd
- ΔKd(TCDD-DD) 为侧位氯贡献（静电互补 + 卤键 + 极化率增量）
- 若 ΔKd ≈ 0 则侧位氯不可读，静电互补维失效

**其四，脂质/有机碳归一化对照（GC1 强制）**：
- 测各单体三油酸甘油酯/水与正辛醇/水分配（Kow 代理）
- 材料单体选择性谱与 Kow 谱一致则为普通分配
- TCDD 被特异增强超出 Kow 预测则为静电互补识别

**其五，NOM 竞争预占对照**：
- 腐殖酸（HA）/富里酸（FA）预加载实验
- 报 NOM 预占后 Kd 与 α 保留率
- 二级出水真实基质验证

**其六，再生安全性验证**：
- 超临界 CO₂ 或温和溶剂洗脱再生
- 5 循环以上，测 Kd 与 α 保留率
- 再生液 TEQ 全程核算
- 确认无 de novo 再合成（不进入 250–450 °C 窗口）

## 8. 成功与失败判据

### 8.1 必要条件层

- Kd(2,3,7,8-TCDD) ≥ 10⁴ L/kg（pg/L 驱动力门槛，不计入选择性证据）
- Stage-0 三道门全部通过（或 caution 带附条件进入）

### 8.2 成功（通过）判据

须同时满足以下全部：

1. **L1 同分异构体对（主声称）**：超纯水 α(2,3,7,8-TCDD / 1,2,3,4-TCDD) ≥ 3（EXEC_SPEC §5.2 要求 ≥ 3）
2. **L1 结构近似物**：α(TCDD / PCB-126) ≥ 3
3. **静电互补维解耦**：壁电子密度系列 α 随壁电子密度单调变化（富电子壁偏好侧位氯区）
4. **形状维解耦**：非平面 PCB 排除率 >90%（层间距 ~0.38 nm COF）
5. **L2 同系物**：α(TCDD / OCDD) ≥ 2（TCDD 优先于 OCDD 须由非 logKow 维度解释）
6. **脂质归一化**：材料选择性谱显著偏离 Kow 谱（GC1）
7. **真实基质**：二级出水 α(2,3,7,8/1,2,3,4) ≥ 2（允许衰减）
8. **再生与稳定性**：5 循环以上再生后 Kd 与 α 保留 ≥ 80%，再生液 TEQ 无升高

### 8.3 失败（终止或重建）判据

1. Stage-0a DFT |ΔΔG| < 0.5 kJ/mol（静电互补维不可区分，终止或转纯形状筛分基线角度）
2. Stage-0b 层间距偏差 >1.0 Å（溶胀不可控）
3. Stage-0c K(1,2-DCB) < 10² M⁻¹（亲和力不足）
4. 材料级 α(2,3,7,8/1,2,3,4) < 1.5（静电互补维无贡献）
5. 壁电子密度系列 α 不随壁电子密度变化（静电维失效）
6. 全谱 α 与 logKow 线性（纯疏水分配，命中 T2）
7. 脂质归一化后选择性消失（纯疏水分配）
8. COF 水相不稳定（浸泡 7 d 结构崩塌）

### 8.4 灰区条款

- α(2,3,7,8/1,2,3,4) 落于 1.5–3.0：有贡献但不足，须重建（壁化学精化、层间距优化）或终止
- 单槽至多 3 次重建（最多 5 轮总计），EXEC_SPEC §7.3 迭代预算

## 9. 自识别弱点

**弱点一（中心风险）：水相连续静电场匹配的净收益不确定**。连续静电场匹配对溶剂竞争的鲁棒性预期高于单点氢键/卤键，但水相中 π-π 静电互补的净自由能贡献仍可能被水竞争大幅削弱。Stage-0a DFT 计算为第一道门，但隐式溶剂模型对狭缝内水行为的描述精度有限。整个设计系于此赌注。

**弱点二：COF 层间距防溶胀固定为合成难点**。层状 COF 在水相中易溶胀，层间距偏差 >0.5 Å 即削弱平面性筛分维度。共价支柱法与后合成固化为候选方案但均增加合成复杂度。Stage-0b 为前置门。

**弱点三：pg/L 亲和力预算仍为结构性约束**。本槽走多位点弱作用加和（非单点高亲和），但总 Kd ~10⁵ L/kg 能否在竞争条件下实现仍取决于 Stage-0c 模型化合物结果。若 K(1,2-DCB) < 10² M⁻¹，则 pg/L 工况不可达。

**弱点四：COF 水稳定性**。硼酸酯键 COF 水稳定性差，亚胺键/β-酮烯胺键 COF 水稳定性较好但长期浸泡（>7 d）数据有限。水稳定性为进入判据，非可优化参数。

**弱点五：代用物外推间隙**。Stage-0c 以 1,2-DCB 为代用物（EXEC_SPEC §8.4 第二级），但 1,2-DCB 无四极矩差异维（仅疏水 + 形状），对静电互补维无诊断力。无氯母核 DD 对照（§7.3 其三）部分弥补，但 DD 水溶度极低（~0.5 µg/L），批次实验浓度受限。

**弱点六：COF-二噁英零先例的双刃性**。零先例意味着增量明确（E 维机会），但也意味着无一手实验数据可参考，所有性能预期均为外推。

**弱点七：真实基质 NOM 竞争**。NOM 含大量芳环结构（EfOM），与 COF 芳壁竞争 π-π 相互作用，可能预占静电互补位点。NOM 预占后 α 保留率为真实基质验证的关键指标。

**弱点八：同位素稀释 HRGC-HRMS 为唯一可靠分析手段**。pg/L 级 TCDD 实验受高等级防护许可约束，代用物阶梯向真实 TCDD 的外推须逐环排除替代解释（EXEC_SPEC §8.4）。

**弱点九：再生为脱附回收而非破坏**。温和溶剂洗脱将 TCDD 转入溶剂流需二次处置，本方案不矿化，仅为捕获-浓缩-移交。

**弱点十：证据完整性低**。全部文献为摘要级/题录级，无一经全文 verified；AhR 结构 PDB 待复核；COF 层间距控制与平面芳烃吸附为领域常识级，具体一手文献待补。
