## 4. 材料架构与选择性机制（r4 强化）

### 4.1–4.8 继承 r3

### 4.9a [r4 新增] pg/L 亲和力定量预算与 Stage-0 计算门（回应弱点三）

**问题回顾**：弱点三（pg/L 亲和力预算）从 r1 到 r3 连续三轮列为 medium。EXEC_SPEC §6 诚实上限指出"pg/L 亲和力预算为结构性约束；需 Stage-0 门控方可突破"。r1–r3 均未给出定量能量预算——仅以"连续静电场匹配"定性描述，缺乏 ΔG 收支明细。

**策略 1：pg/L 工况亲和力收支明细**

目标工况：TCDD ~1 pg/L ≈ 3.1 pM，需表观 Kd ~10⁵ L/kg 方能在竞争条件下实现显著捕获。

| 贡献项 | 估算值（kJ/mol） | 来源 | 不确定性 |
|--------|-----------------|------|---------|
| **疏水分配基线** | | | |
| 平板芳壁-平面芳烃 π-π 堆积（水相） | −15 至 −25 | Hunter & Sanders 1990；Meot-Ner 2005 水相芳烃堆积 | 中（壁面电子密度依赖） |
| **静电互补增量** | | | |
| 四极矩匹配（TCDD 四极矩 vs COF 壁面四极矩） | −2 至 −5 | DFT 估算（B3LYP-D3/def2-TZVP，PCM 水模型） | 高（需计算验证） |
| 氯图式-壁面卤键弱贡献（侧位 Cl 作为弱 Lewis 碱） | −1 至 −3 | Cavallo 2016 水相卤键上界 | 高 |
| **去溶剂化罚能** | | | |
| TCDD 脱水（从水相进入疏水狭缝） | +3 至 +6 | 基于 logKow ~6.8 反推；TCDD 水合自由能极小 | 低 |
| COF 壁面去溶剂化（狭缝内残留水排出） | +1 至 +2 | 基于沸石 Beta 水汽吸附焓 | 中 |
| **构象约束罚能** | | | |
| TCDD 刚性平面（无构象罚） | 0 | TCDD 为刚性三环，无旋转自由度损失 | 低 |
| **净结合自由能估算** | **−14 至 −25** | 上述加和 | — |

**Kd 换算**：ΔG = −20 kJ/mol → K ≈ 3 × 10³ M⁻¹（25°C）；ΔG = −25 kJ/mol → K ≈ 2.4 × 10⁴ M⁻¹。

**关键诚实标注**：
- 净结合能 −14 至 −25 kJ/mol 对应的 K 值（3 × 10³–2.4 × 10⁴ M⁻¹）**远低于** pg/L 工况所需的 ~10⁸–10⁹ M⁻¹（Kd ~10⁵ L/kg）
- **绝对亲和力缺口**：约 30–45 kJ/mol，需由多价协同（多个芳壁接触面）+ 孔道限域效应（一维狭缝内多次反弹接触）补偿
- **多价补偿上限估算**：若 TCDD 在狭缝内经历 n 次有效壁面接触，总结合能 ≈ n × (−20) kJ/mol；n = 5–8 可达 −100 至 −160 kJ/mol → K > 10¹⁷ M⁻¹（远超所需）
- **但**：多价接触的有效性取决于狭缝长度与 TCDD 分子尺寸的匹配——狭缝过短则 n 小，狭缝过长则传质受限

**策略 2：Stage-0 计算门（go/no-go）**

| 门控 | 计算内容 | 方法 | go 线 | no-go 后果 |
|------|---------|------|-------|-----------|
| **S0a** | TCDD vs 1,2,3,4-TCDD 在 COF 芳壁狭缝中的差分结合能 | DFT-D4/ωB97X-D + def2-TZVP + PCM 水模型；构建 3–5 层芳壁狭缝模型 | \|ΔΔG\| ≥ 1.0 kJ/mol（对同分异构体有区分力） | 静电互补维无区分力 → 退化为纯疏水 → 终止 |
| **S0b** | TCDD 在狭缝内的多价接触有效次数 n | MD 模拟（GROMACS，OPLS-AA 力场，水相，300 K，100 ns） | n ≥ 3（有效壁面接触 ≥ 3 次） | 多价补偿不足 → 亲和力缺口不可闭合 → 收窄主张为"选择性验证"而非"绝对容量" |
| **S0c** | 模型化合物（1,2-DCB）在 COF 狭缝中的结合常数 | DFT + MD 自由能微扰（FEP） | K ≥ 10² M⁻¹（模型化合物可测下界） | 连模型化合物都无法结合 → 狭缝设计根本失败 → 终止 |

**策略 3：亲和力缺口的实验补偿路线**

若 Stage-0 计算显示绝对亲和力不足（S0a go 但 S0b no-go），采用以下补偿路线：

- **路线 A（优先）：狭缝长度优化**——增加 COF 层数（3–7 层堆叠）以增加有效接触次数 n；但以传质受限为上限（层数 >7 时分子扩散进入狭缝内部的时间 >实验可接受范围）
- **路线 B：孔径收窄至 snug-fit**——将层间距从 7.5 Å（宽松）收窄至 6.0–6.5 Å（snug-fit TCDD 截面 5.8 × 8.6 Å），增加壁面-分子接触密度
- **路线 C：诚实收窄主张**——若绝对亲和力确实无法达到 pg/L 工况要求，将方案主张从"pg/L 捕获"收窄为"µg/L 选择性验证 + pg/L 机制确证型研究"——选择性因子 α 为主口径，绝对 Kd 为次口径

### 4.9b [r4 新增] 水相静电互补能量预算与代用物实验验证（回应弱点一）

**问题回顾**：弱点一（水相连续静电场净收益不确定）从 r1 到 r3 连续三轮列为 medium。核心问题：COF 壁面与 TCDD 之间的静电互补（四极矩匹配 + 氯图式读取）在水相中是否产生**净正**结合能增量？水的高介电常数（ε = 78.4）可能将静电互补效应屏蔽至可忽略水平。

**策略 1：水相 vs 气相静电互补能量对比计算**

| 条件 | 计算方法 | 预期结果 | 判决意义 |
|------|---------|---------|---------|
| 气相 | DFT-D4（无溶剂模型） | ΔG_elec ~ −5 至 −10 kJ/mol | 静电互补上界（无屏蔽） |
| 水相（PCM） | DFT-D4 + PCM 水模型 | ΔG_elec ~ −1 至 −4 kJ/mol | 水相静电互补实际值 |
| 水相（显式水 MD） | FEP + 显式水分子 | ΔG_elec ~ −0.5 至 −3 kJ/mol | 最可靠水相估算 |

**关键预测**：水相静电互补效应预计衰减至气相值的 30–50%（基于文献中水相 π-π 静电互补的衰减比例，Hunter & Sanders 1990）。即使衰减 50%，ΔG_elec ~ −2.5 至 −5 kJ/mol 仍可提供对同分异构体的差分选择性（1,2,3,4-TCDD 的四极矩张量与 2,3,7,8-TCDD 不同 → 静电互补增量不同）。

**策略 2：代用物阶梯实验验证（与 EXEC_SPEC §8.4 对齐）**

| 代用物级别 | 代用物 | 实验 | 测量 | go 线 |
|-----------|--------|------|------|-------|
| 第一级 | 二苯并-p-二噁英（DD，无氯） | 吸附等温线（超纯水，25°C） | K(DD) | K ≥ 10² M⁻¹ |
| 第二级 | 1,2-二氯苯（1,2-DCB） | 吸附等温线 + 竞争实验（DD vs 1,2-DCB） | K(1,2-DCB)，α(1,2-DCB/DD) | K ≥ 10² M⁻¹，α ≥ 1.5 |
| 第三级 | 咔唑 | 吸附等温线 + 竞争实验 | K(carbazole) | K ≥ 10² M⁻¹ |
| 第四级 | 1,2,3,4-TCDD 代用物（1,2,4-TCB + 氯代二苯并-p-二噁英类似物） | 选择性验证 | α(目标/类似物) | α ≥ 2 |

**关键判决**：
- 若 K(1,2-DCB) < 10 M⁻¹ → 狭缝对模型化合物无有效结合 → 静电互补在水相可忽略 → 弱点一确认不可闭合 → 终止
- 若 K(1,2-DCB) ≥ 10² M⁻¹ 且 α(1,2-DCB/DD) ≥ 1.5 → 静电互补在水相提供净正增量且对氯图式有区分力 → 弱点一降为 low-medium

## 8b. [r4 新增] Stage-0 门控执行计划（整合弱点三与弱点一）

**门控执行顺序**（串行，前门通过后进入下一门）：

| 阶段 | 门控 | 内容 | go 线 | 时间预算 |
|------|------|------|-------|---------|
| Stage-0a | 计算门 | DFT-D4 差分结合能（TCDD vs 1,2,3,4-TCDD） | \|ΔΔG\| ≥ 1.0 kJ/mol | 2 周 |
| Stage-0b | 计算门 | MD 多价接触次数 + 层间距溶胀稳定性 | n ≥ 3；层间距偏差 <0.5 Å | 2 周 |
| Stage-0c | 实验门 | 模型化合物（1,2-DCB）吸附等温线 | K ≥ 10² M⁻¹ | 4 周 |
| Stage-0d | 实验门 | 代用物阶梯选择性验证 | α(1,2-DCB/DD) ≥ 1.5 | 4 周 |

**总时间预算**：Stage-0 合计 ~12 周（计算 4 周 + 实验 8 周，可部分并行）

**no-go 收缩路径**：
- S0a no-go → 静电互补维无区分力 → 退化为纯疏水 → 终止（A02 结构性不可行）
- S0b no-go → 多价补偿不足 → 收窄主张为选择性验证（α 为主口径）
- S0c no-go → 狭缝设计根本失败 → 终止
- S0d no-go → 氯图式无区分力 → 终止或收窄为类级捕获
