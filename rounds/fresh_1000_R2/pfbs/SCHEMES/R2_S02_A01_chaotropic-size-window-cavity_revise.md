## 监督者摘要

PFBS R2 广度优先首槽。角度地图（`angle_maps/pfbs_ANGLES.yaml`）4 个正交候选仅 R2_A01（趋液）为 A 级；anion-π（R2_A02）经 PFOA 槽记录的可传递负知识直接判 X（anion-π 偏好高电荷密度硫酸根，对全 PFAS 组磺酸/羧酸头基均为选择性反转），卤键、穿套亦 X。

方案核心：以 **趋液（chaotropic/Hofmeister）水合热力学** 为识别物理——高能水释放型受限腔按 Hofmeister 位次优先结合弱水化 PFBS 并 **内禀排斥强水化二价硫酸根**，叠加 C4 尺寸窗口。这是与 R1 全部通过方案（A17 头基几何反差、A01 头基氢键、A05 单调链疏水）正交的第六类机制轴（水合热力学），原型取生物阴离子通道的 Hofmeister 序选择性（Gurnev 2017；Kang 2020）。

**相对 anion-π 与 R1 静电路线的关键优势（方向正确）**：趋液效应内禀排斥 kosmotrope 硫酸根——正面解决 PFBS 头号竞争陷阱（陷阱 4，1 mM 硫酸盐去除率 94%→38%）。这与 PFOA R2 anion-π 的硫酸根反转负债 **方向相反**，构成 PFAS 组头基-水合识别方向的一对互补知识（anion-π=负债 / 趋液=资产）。

**角度内禀硬约束（诚实核心）**：(1) C4 为 PFSA 最短链、趋液性/疏水驱动力最弱，ng/L 绝对亲和力边缘（SETAC 2026 直接示短链 PFAS 对 CD 疏水腔亲和力低）；(2) 趋液轴偏好更趋液的 PFOS（C8）> PFBS（C4），逆向尺寸窗口排 PFOS 为硬约束，故主选择性主张收窄为 **PFBS vs 无机含氧阴离子**（放弃 PFAS 类内分离）。r1 判 2 critical，r2 将 C1 转前置量热/Phase 0 go/no-go、C2 转适用范围声明消解，落 revise_with_phase0_prerequisite ~72，天花板 78–82，**未达 85**。

**去向**：量热（ITC）+ Phase 0 计算门（C4 趋液绝对 Ka + α(PFBS/SO₄²⁻)）为仓库外动作，挂起。基线预测：C4 绝对亲和力不足倾向 NO-GO。PFBS R2 正交空间同 PFOA 接近诚实耗尽，建议挂起后轮转 PFHxS。

## 1. 科学问题与工程难题

**科学问题。** C4 疏水驱动力降至 PFSA 同系物最低（BRIEF 收紧一），吸附被迫依赖静电/头基作用，而这对无机含氧阴离子先天非选择（陷阱 4）。能否用一个 **内禀排斥强水化硫酸根** 的识别物理（非 A17 头基几何、非 A01 氢键、非静电）为弱水化 PFBS 提供选择性？

**工程难题。** 构建趋液选择型受限腔（高能水释放腔），按 Hofmeister 位次优先纳弱水化 PFBS、排斥强水化二价硫酸根，并叠加 C4 尺寸约束。

## 2. 生物原型与证据

**原型：生物阴离子通道的 Hofmeister/趋液序选择性。** 阴离子通道电导随阴离子趋液性升高（KH₂PO₄→KSCN），与 Hofmeister 位次良好相关（Gurnev 2017 PMC5518747）；Hofmeister/lyotropic 序为大量生物与物化过程的关键（Kang 2020，514 引）。**转译距离诚实声明**：生物功能为离子通透/电导调制，非水相竞争基质选择捕获；趋液效应为 Nau/Assaf 成熟超分子物化原理。故 C 维**诚实不通过**（同 anion-π/氧阴离子洞）。

## 4. 材料架构与三层机制

**人工识别单元（非蛋白）。** 竹环（bambusuril）/葫芦脲（cucurbituril）型高能水释放腔或深疏水限尺寸有机笼，接枝水稳定多孔载体；腔形按 C4F9 契合 + 高能水释放优化。区别于 A17 POP 接枝活性炭。

**三层机制。**
- **层 A（趋液水合门，创新+承重）**：高能水释放腔优先纳弱水化 PFBS、内禀排斥强水化二价 SO₄²⁻（−1080 kJ/mol 强 kosmotrope，E5）。**正面解决陷阱 4**——与 anion-π 方向相反（资产而非负债）。
- **层 B（C4 尺寸窗口，承重待验）**：限尺寸腔口调 C4 契合；逆向排 PFOS 为硬约束（见 §5），主张收窄为 vs 无机阴离子。
- **层 C（弱疏水基线，单调）**：C4 弱疏水分配，容量分量。

**等结构因子系列。** M0 敞口/大腔（趋液门弱化对照）；M1 竹环型高能水释放腔（主变体）；M2 葫芦脲型（第二独立格式）；M1-depth 腔深/腔形系列（C4 契合度）；Blank 空白载体。

## 5. 选择性判决、主张收窄与外部门（决定性前置）

**主选择性主张（收窄，诚实）**：**PFBS vs 无机含氧阴离子（硫酸根/磷酸根/碳酸氢根/氯离子/硝酸根）**，承重于趋液水合轴（方向有利）。**放弃** PFBS/PFOS 类内分离主张——趋液轴偏好更趋液的 PFOS，逆向尺寸窗口排 PFOS 为硬约束（C8 前段可部分插入限尺寸腔获强结合，色谱置换）。若 PFOS 共存则本材料为 PFAS 共捕获，类内分离交下游。

**外部门（合成前强制，量热 + Phase 0，GO/NO-GO）**：ITC 测 C4 PFBS 在趋液腔的绝对 Ka 与焓-熵分解（验高能水释放熵驱动）；计算 + 实测 α(PFBS/SO₄²⁻)。
- **GO**：Ka(C4) 达 ng/L 占位阈值（约需 ≥10⁶–10⁸ L/kg 分布，或按动态床占位模型）且 α(PFBS/SO₄²⁻)≥10²。
- **NO-GO（基线预测倾向）**：C4 绝对亲和力不足 → 不合成，交付清洁负结果（趋液识别对最短链 PFSA 存在绝对亲和力下限，界定趋液路线链长适用边界）。

**四结果框架。** M1 趋液腔对 C4 达 ng/L 选择捕获（vs 硫酸根 α≥10²）/ M2 温和 / F1 C4 亲和力不足如期证伪（清洁负结果）/ F3 选择性存在但源自疏水非趋液（Hofmeister 序错向证明）。
