# PFBS R2_A01 — 隔离角色循环（设计-攻击-裁决 × 2 轮）

> 角色隔离持久化。每节为独立角色 pass，输入边界见各节。趋液（chaotropic）× C4 尺寸窗口识别。

---

## 设计者 r1

**有界输入**：`rounds/fresh_1000/pfbs/BRIEF.md`、`angle_maps/pfbs_ANGLES.yaml`（R2_A01）、`GLOBAL_SPEC.md`、`INNOVATION_CHECKLIST.md`、`R1_OCCUPIED_SPACE.yaml`。

**科学问题**：C4 疏水驱动力降至同系物最低（收紧一），静电/头基捕获对无机含氧阴离子先天非选择（陷阱 4，PFBS 1 mM 硫酸盐去除 94%→38%）。能否用一个**内禀排斥强水化硫酸根**的识别物理（而非 A17 头基几何、A01 氢键）为弱水化 PFBS 提供选择性？

**工程难题**：构建趋液选择型受限腔——高能水释放腔按 Hofmeister 位次优先结合弱水化 PFBS，内禀排斥强水化二价硫酸根；叠加 C4 尺寸窗口排除更长 PFOS。

**生物原型（诚实转译距离）**：生物阴离子通道选择性遵循 Hofmeister/趋液序（通道电导 KH₂PO₄→KSCN 递增，Gurnev 2017 PMC5518747；Hofmeister 效应为生物过程关键，Kang 2020 综述 514 引）。转译距离：生物功能为离子通透/电导调制，非水相选择捕获；C 维诚实类比级（同 anion-π/氧阴离子洞）。

**三层机制**：层 A 趋液水合门（**创新+承重**）——高能水释放腔优先纳弱水化 PFBS、排斥强水化 SO₄²⁻（正面解决陷阱 4，相对 anion-π 方向相反=资产）；层 B C4 尺寸窗口（**承重**）——限尺寸腔口排除 PFOS/PFHxS（逆向链长，硬）；层 C 弱疏水基线（单调）。

**材料**：竹环（bambusuril）/葫芦脲（cucurbituril）型高能水释放腔或深疏水限尺寸笼，接枝多孔载体；区别于 A17 POP 接枝炭。

**因果对照**：Hofmeister 序滴定（选择性是否随阴离子趋液性单调、随电荷密度反相关——证趋液轴）；C4/C6/C8 排除系列（证尺寸窗口）；SO₄²⁻/PO₄³⁻/Cl⁻/NO₃⁻ 竞争；PFBA（同 C4 羧酸）对照。

**创新自评**：A 通过（趋液水合识别超越普通疏水/静电/尺寸筛，Hofmeister 序可证伪）；B 条件性（趋液腔平台 CD/竹环已存）；C 不通过（诚实，通道功能非吸附）；D 通过（趋液水合 × 尺寸窗口 2 正交维）；E 条件性（趋液归因+C4 窗口为空白，平台拥挤）。

**弱点自报**：(1) C4 最短链趋液性/绝对亲和力最弱，ng/L 捕获边缘（SETAC 2026 短链对 CD 腔亲和力低）；(2) 逆向尺寸窗口排 PFOS 难（PFOS 更趋液，部分插入即强结合，色谱置换）；(3) 趋液单轴有单参数风险，须尺寸窗口承重第二维。

---

## 攻击者 r1

**C1（critical）——C4 短链趋液绝对亲和力不足以支撑 ng/L 捕获**。趋液效应/疏水腔结合随链长（趋液性、疏水表面积）单调，C4 为 PFSA 最短、趋液性最弱；SETAC 2026 直接示短链 PFAS 对 CD 疏水腔亲和力低、DOM 几乎不抑制（因结合本就弱）。ng/L（约 33 pM）工况需 Ka≥10⁸–10⁹ 量级方能有效占位，而趋液主客体对短链结合常数通常 ≤10³–10⁴ M⁻¹。绝对亲和力缺口为存亡级。

**C2（critical，降 high 待回应）——逆向尺寸窗口排 PFOS 不成立**。趋液轴偏好更趋液的 PFOS（C8）> PFBS（C4），方向与目标相反；尺寸窗口须靠腔口限尺寸排 C8，但 C8 前段 C4F9 可插入限尺寸腔获部分强结合（PFOS 更趋液），色谱置换（Zhang 2023）持续。逆向链长窗口在 R1（NTCP/OAT4 窗口、PFHxS A07 盲腔深度）反复受阻。

**H1（high）——趋液单轴单参数（FM2）**。若尺寸窗口不成立（C2），选择性退化为单一趋液性/水合参数单调，命中 FM2；且趋液性与 logKow/链长强相关，正交性存疑。

**H2（high）——先例平台密度**。CD/葫芦脲/竹环趋液阴离子结合密集（Nau/Assaf）；Verma 2022 β-CD-PFBS 主客体已存。趋液归因增量须实验量化。

**M（medium）**：C 维原型类比（通道功能非吸附）；大环腔可及性/再生；ng/L 传质。

**攻击结论**：2 critical（C4 绝对亲和力 + 逆向尺寸窗口）。趋液轴正面解决硫酸根竞争（真优势），但短链绝对亲和力 + PFOS 排除为存亡级。须降为前置 Phase 0/量热 go/no-go + 清洁负结果，否则终止。

## 裁决者 r1

| 攻击项 | 裁决 |
|---|---|
| C1 C4 绝对亲和力 | critical 成立。短链趋液结合弱为硬物理（SETAC 2026 佐证）。 |
| C2 逆向尺寸窗口 | critical 成立（趋液偏好 PFOS 方向反 + 部分插入）。 |
| H1 单参数 | 成立（尺寸窗口不成立则趋液单轴单调）。 |
| H2 先例 | medium（平台拥挤，趋液归因空白）。 |

**评分 r1**：因果闭环 13 / 选择性机制 12 / 转译 14 / 原创 8 / 可证伪 8 / 证据 7 = **62/100**。**verdict：revise，2 critical + 2 high。**

诚实预判：趋液轴对硫酸根竞争的正面解决是相对 R1 与 anion-π 的实质优势（方向正确），但 C4 绝对亲和力 + PFOS 排除为角度内禀硬约束；即便 r2 转 Phase 0 go/no-go 消解 critical，天花板约 78-82，难达 85。

## 设计者 r2（回应台账）

**C1（→ 前置量热/Phase 0 go/no-go）**：不主张 C4 绝对亲和力充分为通过前置，改为决定性检验——量热（ITC）+ 计算测 C4 PFBS 在趋液腔的绝对 Ka 与 SO₄²⁻/PFBS 选择性。GO：Ka(C4)≥阈值（按 ng/L 占位模型）且 α(PFBS/SO₄²⁻)≥10²。NO-GO（基线预测倾向）：C4 亲和力不足 → 清洁负结果（趋液识别对最短链 PFSA 存在绝对亲和力下限，界定趋液路线的链长适用边界，可发表机制边界）。

**C2（→ 尺寸窗口降为承重待验 + 诚实边界）**：承认逆向尺寸窗口排 PFOS 为硬约束；改为"若 PFOS 共存则本材料为 PFBS+PFOS 共捕获（趋液轴），PFBS/PFOS 分离交由下游或不作主张"，主选择性主张收窄为 **PFBS vs 无机含氧阴离子（趋液轴，方向有利）**。此收窄使 C2 从"致命"降为"适用范围声明"，但也削弱链长维承重（原创性受压）。

**H1（→ 正交维重定义）**：主承重维为趋液水合轴（vs 无机阴离子），第二维改为**高能水释放腔的腔形/深度**（调 C4 契合度），以 Hofmeister 序滴定 × 腔深系列双因子解耦。

**H2/M**：趋液归因 + Hofmeister 序因果对照为空白；C 维诚实不通过；水稳定大环 + 分级孔传质。

**四结果框架**：M1 趋液腔对 C4 达 ng/L 选择捕获（vs 硫酸根 α≥10²）/ M2 温和 / F1 C4 绝对亲和力不足如期证伪（清洁负结果，界定趋液链长下限）/ F3 选择性存在但源自疏水非趋液（Hofmeister 序错向）。

- 天花板诚实评估 78-82：趋液轴正面解决硫酸根竞争（方向优于 anion-π 与 R1 静电路线）为真价值，但 C4 短链绝对亲和力（ng/L）+ 放弃 PFAS 类内分离（收窄主张）为角度内禀，非文本可闭合。
- 外部前置：量热（ITC）+ Phase 0 计算 go/no-go（C4 趋液绝对 Ka + α(PFBS/SO₄²⁻)）。
- 残余价值：趋液（Hofmeister 序）识别正面解决 PFAS/硫酸根竞争的因果对照方法学（**可传递正知识**，与 anion-π 负知识互补：anion-π 偏好硫酸根=负债，趋液偏好弱水化 PFAS=资产，两者界定 PFAS 组头基-水合识别的方向）；趋液识别的链长绝对亲和力下限（负知识，界定趋液路线对最短链 PFBS 的适用边界）。
