## 监督者摘要

PFOA R2 广度优先首槽。角度地图预筛（`angle_maps/pfoa_ANGLES.yaml`）中 4 个正交候选仅 R2_A01（anion-π）为 A 级（其余 3 个命中 TFG 门或生物原型门 G2），本槽执行之。方案核心：以缺电子芳香 π 面（三嗪/NDI）经 **anion-π 相互作用**识别全氟羧酸头基——这是与 R1 全部通过方案（A02 中性氢键、A01 阳离子静电、A05 配位、OC A01 π-π 供体受体 CT）**正交的第三类识别物理**，原型取黄素蛋白天然 anion-π（Lucas 2015 PDB 统计；Yurenko 2017 黄素蛋白 anion-π 电荷转移）。

**存亡级科学张力（诚实核心）**：anion-π 结合能随阴离子电荷密度升高而增强，二价 SO₄²⁻ 先验上比单价全氟羧酸根 anion-π **更强**——方案唯一正交创新层（层 B）对头号竞争物**方向反转**。第 1 轮裁决判此为 critical。第 2 轮设计者将其重构为**前置 Phase 0 计算决定性检验 + 清洁负结果交付**（同 Endosulfan A01/OC A04/TCDD A01 范式），critical 解除、降为 1 个角度内禀 high（NO-GO 分支剩余选择性落入 A02 已占据空间 + 正向选择性先验低）。裁决 ~74，天花板诚实评估 76–80，**难达 85**。

**去向**：Phase 0 门（DFT-SAPT + SMD 隐式溶剂，算受限 π 孔内 ΔΔG_net(PFOA−SO₄²⁻)）为仓库外计算动作，挂起。基线预测倾向 NO-GO（硫酸根胜出）。若 NO-GO，本槽终止并交付 anion-π 负债机制边界负结果。PFOA R2 正交空间接近诚实耗尽，建议 Phase 0 挂起后轮转 PFBS。

## 1. 科学问题与工程难题

**科学问题。** mM 硫酸根/碳酸氢根 + mg/L DOC 背景、ng/L PFOA 目标（摩尔比 10⁻⁶–10⁻⁹）下，能否以**不含阳离子中心、且不依赖中性氢键供体阵列**的第三类识别物理，为单价全氟羧酸根提供可与背景阴离子区分的正贡献结合？（R1 证据：阳离子位点对二价硫酸根过补偿=AT3；中性氢键对强水合永久阴离子水相本质弱=FM3，且 A02 已占据。）

**工程难题。** 在同一受限疏水通道内正交叠加"缺电子 π 面电子识别（anion-π）"与"脱溶剂化几何门（排斥二价硫酸根）"，传统合成难以实现。

## 2. 生物原型与证据

**原型：黄素蛋白 anion-π 相互作用。** anion-π 在蛋白质/核酸中广泛自然存在（Lucas 2015 大规模 PDB 分析）；黄素蛋白以缺电子芳香面经 anion-π（含电荷转移分量）结合阴离子辅因子并调制黄素氧化还原电位（Yurenko 2017）。**转译距离诚实声明**：生物功能为氧化还原调制/辅因子结合，非水相竞争基质中的选择性阴离子捕获；故 anion-π 为机制类比层转译，创新性 C 维**诚实不通过**（同 A02 氧阴离子洞、OC A01 光合反应中心）。

## 4. 材料架构与三层机制

**人工识别单元（非蛋白）。** 缺电子三嗪节点或 NDI 芳核晶态 COF/CTF，孔径 0.7–1.1 nm，π 面正四极矩朝向通道；水稳定 sp²-碳或 β-酮烯胺连接（替代水解敏感亚胺），全氮/全烃**不含氟**（守 AT5；疏水驱动力源自靶标全氟尾）。

**三层机制（承重解耦，继承 A02 三分层方法学，识别阵列置换为 anion-π）。**
- **层 A（脱溶剂化门，物理基底，非创新）**：受限低介电疏水孔以脱溶剂化罚能排斥二价 SO₄²⁻（水合自由能 −1080 vs 乙酸根 −365 kJ/mol，约 3×，E5）。一切中性疏水孔共性（含 A02 层 A），不构成创新。
- **层 B（anion-π 正贡献，创新锚点，正交轴）**：缺电子 π 面对进腔全氟羧酸头的 anion-π 稳定。与 R1 全部通过方案正交的识别物理。**核心风险：bulk anion-π 偏好高电荷密度硫酸根（P4），层 B 可能为选择性负债。**
- **层 C（全氟尾疏水分配，单调容量）**：全氟尾进缺电子芳孔的疏水分配，贡献容量随链长单调，非头基选择性来源。

**等骨架因子系列。** M0 富电子/中性芳孔（anion-π 关闭 + 疏水基线）；M1 缺电子三嗪 CTF（主变体）；M2 NDI 核 COF（第二独立格式，排除平台假象）；M1-grad 电子梯度系列（苯→吡啶→三嗪→氰基三嗪）；Blank-AC 纯疏水基线。

## 5. 选择性判决与 Phase 0 计算门（决定性前置）

**核心科学赌注（诚实低先验）。** 方案不将选择性作通过前置，而作**决定性机制检验**：受限低介电 π 孔内，全氟尾进腔疏水驱动（ΔG_tail≈−20 至 −35 kJ/mol，推断待核）+ 硫酸根进孔脱溶剂化罚能（约 3×）之净转移自由能差，能否反转 bulk anion-π 硫酸根偏好。

**Phase 0 门（合成前强制，GO/NO-GO）。** DFT+SMD 隐式溶剂 + DFT-SAPT 分项，算 ΔΔG_net(PFOA−SO₄²⁻)@受限 π 孔，并做孔径(0.7/0.9/1.1 nm)×电子度二维扫描定"anion-π 可及窗口"。
- **GO**：净偏好 PFOA 且幅度足抵 10⁶–10⁹ 摩尔过量（有效选择性 ΔΔG≥~34 kJ/mol 或分级 Regime）→ 推进合成。
- **NO-GO（基线预测）**：硫酸根胜出/窗口不存在 → 不合成，交付清洁负结果。

**四结果框架（均可独立发表，继承 ROX/OC S5）。** M1 anion-π+门确立 / M2 温和 / F1 硫酸根如期胜出（假设证伪，清洁负结果）/ F3 选择性存在但源自疏水非 anion-π（电子梯度错向证明）。

**竞争物谱。** 硫酸根（关键）、碳酸氢根、硝酸根、氯离子、富里酸/HON、短链 PFCA、PFOS（同碳磺酸对照）。
