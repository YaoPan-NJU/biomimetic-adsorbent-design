# PFOA R2_A01 — 设计者第 1 轮（隔离）

- 角色：隔离设计者（R2 slot 1）
- 有界输入：`rounds/fresh_1000/pfoa/BRIEF.md`、`rounds/fresh_1000_R2/angle_maps/pfoa_ANGLES.yaml`（R2_A01 条目）、`rounds/fresh_1000/GLOBAL_SPEC.md`、`INNOVATION_CHECKLIST.md`、`R1_OCCUPIED_SPACE.yaml`
- 角度：R2_A01「缺电子芳香 π 面 anion-π 识别全氟羧酸头基 + 疏水受限腔脱溶剂化门」
- 定位：机制确证型研究（继承 E 组成功模式 S5）+ Phase 0 计算门前置

## 1. 科学问题与工程难题

**科学问题（SQ）。** 在 mM 级硫酸根/碳酸氢根与 mg/L DOC 背景、ng/L 目标浓度下，能否用一个**不含阳离子中心、且不依赖中性氢键供体阵列**的识别机制，为单价全氟羧酸根提供可与背景阴离子区分的正贡献结合？R1 已证明：阳离子位点对二价硫酸根过补偿（陷阱 AT3）；中性氢键供体阵列对强水合永久阴离子水相本质弱（FM3，且 A02 已占据该机制）。故需要第三类识别物理。

**工程难题。** 构建一个孔壁呈缺电子 π 面（正四极矩）的受限疏水通道，使 (i) 全氟羧酸头基获得 anion-π 定向稳定，(ii) 全氟尾获得进腔疏水驱动力，(iii) 二价强水合硫酸根被低介电受限腔的脱溶剂化罚能排斥于腔外。传统合成难以在同一受限腔内正交叠加"缺电子 π 面电子识别"与"脱溶剂化几何门"。

## 2. 生物原型与证据（诚实转译距离）

**原型：黄素蛋白 anion-π 相互作用。** 大规模 PDB 分析证实 anion-π 相互作用在蛋白质与核酸中广泛自然存在（Lucas 2015，RSC Adv，PMC5967298，PDB 统计层）；黄素蛋白中缺电子异咯嗪/芳香残基以 anion-π 结合阴离子辅因子并调制黄素氧化还原电位，含显著电荷转移分量（Chem Eur J 2017, 23:3246, Yurenko 等）。

**转译距离诚实声明。** 黄素蛋白 anion-π 的生物功能是**辅因子结合与氧化还原电位调制**，不是从竞争水基质中选择性捕获阴离子。因此本方案 anion-π 为**机制类比层**转译（与 PFOA A02 氧阴离子洞、OC A01 光合反应中心同类诚实定位），创新性清单 C 维预判**不通过**（anion-π 为 Schneider/Matile 以降的通用超分子原则，非黄素蛋白特异提取）。承重创新置于 A 维（新识别物理）与 D 维（正交维度）。

## 4. 材料架构与三层机制

**人工识别单元（非蛋白）。** 缺电子三嗪节点或 NDI 芳核构筑的晶态 COF/CTF，孔径约 0.7–1.1 nm，孔壁 π 面朝向通道。全氮/全烃骨架，**不含氟**（守 AT5 含氟材料环境风险；疏水驱动力来自靶标全氟尾而非材料）。

**三层机制（承重解耦，继承 A02 三分层方法学并置换识别阵列为 anion-π）。**
- **层 A（脱溶剂化门，物理基底，非创新）**：受限低介电疏水孔对二价 SO₄²⁻（水合自由能约 −1080 kJ/mol，约乙酸根 −365 的 3 倍，Marcus 1991 doi:10.1039/ft9918702995）的脱溶剂化罚能排斥。此为一切中性疏水孔共性（含 A02 层 A），**不构成创新主张**。
- **层 B（anion-π 正贡献，创新锚点，正交轴）**：缺电子 π 面对进腔全氟羧酸头的 anion-π 稳定。此为与 R1 全部通过方案正交的识别物理（非氢键、非阳离子、非配位）。
- **层 C（全氟尾疏水分配，单调容量）**：全氟尾进缺电子芳孔的疏水分配，贡献总容量但随链长单调，非头基选择性来源。

**等骨架因子系列（因果对照先于材料设计）。**

| 编号 | π 面电子性 / 结构 | 角色 |
|---|---|---|
| M0 | 富电子/中性芳孔（咔唑或苯核 COF，孔几何匹配） | anion-π 关闭对照 + 疏水基线 |
| M1 | 缺电子三嗪 CTF（强正四极矩） | anion-π 主变体 |
| M2 | NDI 核 COF（强缺电子，可调核取代） | 第二独立格式（不同化学家族，排除平台假象） |
| M1-grad | 电子梯度系列（苯→吡啶→三嗪→氰基三嗪，缺电子度递增） | anion-π 承重的单调判据（错向即证负债） |
| Blank-AC | 空白活性炭 | 纯疏水基线容量 |

## 5. 选择性判决与 Phase 0 计算门（前置）

**核心科学赌注（诚实低先验）。** anion-π 结合能随阴离子电荷密度升高而增强，二价 SO₄²⁻ 先验上比单价全氟羧酸根 anion-π 更强 → **选择性反转风险**。本方案不将选择性作为通过前置，而作为**待决定性检验的中心假设**。

**Phase 0 计算门（合成前强制）。** DFT + 隐式溶剂（或 DFT-SAPT）计算受限 π 孔内 PFOA 羧酸头 vs SO₄²⁻ 的**净转移自由能**（含脱溶剂化 + anion-π + 全氟尾疏水驱动）。
- **GO 判据**：净 ΔΔG(PFOA − 硫酸根) 偏好 PFOA，且幅度足以抵消 10⁶–10⁹ 摩尔过量（需 ≥ ~34 kJ/mol 有效选择性，或按占据模型分级）。
- **NO-GO/TERMINATE**：若硫酸根 anion-π 偏好 + 浓度过量胜出（基线预测），交付**清洁负结果**：anion-π 对单价全氟羧酸根不能克服硫酸根——一个可发表的机制边界。

**四结果框架（均可独立发表，继承 ROX/OC S5 模式）。** M1 anion-π+门确立选择性 / M2 温和 / F1 硫酸根如期胜出（假设证伪，清洁负结果）/ F3 选择性存在但源自疏水非 anion-π（电子梯度错向证明）。

**竞争物谱。** 硫酸根（关键）、碳酸氢根、硝酸根、氯离子、富里酸/HON 组分、短链 PFCA、PFOS（同碳磺酸对照）。

## 6. 报告口径（G6）

动态床容量为主口径（4 ng/L 穿透 BV、µg/mL 床、µg/g 总干换算）；批次 qmax 仅作高浓参照（守陷阱 6）；报可及 π 位点密度、空白骨架 uptake、受体质量分数。材料不含氟，规避含氟吸附剂生命周期风险（E17 doi:10.1038/s41467-025-67596-6）。

## 7. 创新性清单自评

- A 机制创新：**通过**——anion-π 识别全氟羧酸根超越普通疏水/静电/尺寸，提出可被电子梯度错向对照推翻的新识别原理。
- B 材料架构：**条件性**——缺电子 π 面朝向受限腔为特定空间组织，但三嗪/NDI COF 平台已存，增量在 anion-π 定向孔 + 电子梯度系列。
- C 仿生转译：**不通过（诚实标注）**——黄素蛋白 anion-π 功能为氧化还原调制非吸附；anion-π 为通用超分子原则。
- D 选择性策略：**通过**——anion-π 电子维 + 脱溶剂化门几何维正交（改变 π 面电子密度不改变腔疏水性），非 logKow/链长单调。
- E 先例区分：**条件性**——三嗪/CTF 平台对 PFOA 已被 fluorophilic/疏水归因占据；anion-π 机制归因为空白，增量须由电子梯度系列实验量化。

## 8. 弱点自报

1. 层 B（anion-π，唯一正交创新层）先验上偏好硫酸根，可能为选择性负债——本方案的存亡赌注。
2. 层 A（脱溶剂化门）与层 C（全氟尾）与 A02 的机制 A/C 同构（已占据空间），若层 B 为负债则剩余贡献落入 A02 空间。
3. anion-π 与疏水/π-π 在芳壁上实验解耦困难（电子梯度系列 + 富电子壁对照缓解）。
4. CTF/亚胺 COF 水解稳定性；ng/L 传质。
