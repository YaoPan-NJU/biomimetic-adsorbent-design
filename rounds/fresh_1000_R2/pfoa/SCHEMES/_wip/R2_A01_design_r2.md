# PFOA R2_A01 — 设计者第 2 轮（隔离，回应 r1 台账）

- 有界输入：设计者 r1 方案 + 裁决 r1 未决台账（C1/C2/H1/H2 + medium）
- 本轮关键动作：将 C1 从隐含选择性主张转为**前置 Phase 0 决定性检验 + 清洁负结果交付**；量化几何窗口；给出解耦协议；明确负结果骨架。

## 逐条回应

**C1（critical → 转为前置决定性检验）。** 承认 anion-π 对二价硫酸根的 bulk 偏好为硬物理（不辩驳）。重构方案定位：**本方案不主张 anion-π 净选择捕获 PFOA 为通过前置**，而主张一个**决定性机制检验**——受限低介电 π 孔内，全氟尾疏水进腔驱动力（ΔG_tail，随 C8 尾约 −20 至 −35 kJ/mol 量级，推断待 Phase 0 核）+ 二价硫酸根进低介电孔的脱溶剂化罚能（约 3× 单价，Marcus 1991）之**净转移自由能差**，能否反转 bulk anion-π 的硫酸根偏好。
- **Phase 0 计算门（合成前强制，GO/NO-GO）**：DFT+隐式溶剂（SMD）+ DFT-SAPT 分项，计算 ΔΔG_net(PFOA−SO₄²⁻)@受限 π 孔。GO：净偏好 PFOA 且 ≥ 有效阈值（按 mM 硫酸根 vs ng/L PFOA 占据模型，需有效选择性 ΔΔG ≥ ~34 kJ/mol 或分级 Regime）。NO-GO：硫酸根胜出 → **不合成**，交付负结果。
- 该重构使 C1 由"致命缺陷"变为"中心可证伪假设 + 前置计算裁定"，与 Endosulfan A01（Phase 0 GO 通过）、OC A04/TCDD A01（revise_with_phase0_prerequisite）同范式。**诚实声明：基线预测倾向 NO-GO（硫酸根胜出），GO 为低先验假设。**

**C2（剩余层落入 A02 空间）。** 若 Phase 0 GO，则层 B（anion-π）为正贡献，方案与 A02 在识别物理（anion-π vs 氢键）、材料（缺电子 π 骨架 vs 全烃 PAF-1）、原型（黄素蛋白 vs 氧阴离子洞）三重正交，不落入 A02。若 Phase 0 NO-GO，则如实承认剩余选择性来源（脱溶剂化门 + 全氟尾）与 A02 重叠，此时方案**不作为独立 PFOA 吸附方案交付**，而作为**anion-π 对全氟羧酸根为选择性负债的机制边界报告**（负知识，独立价值：明确 anion-π 分支对 PFOA 不可行，收窄 R2 及后续设计空间）。

**H1（几何两难 → 量化窗口）。** 定义"anion-π 可及窗口"：孔径 d 须同时满足 (i) 容纳部分脱水的全氟羧酸头触及 π 面（头基-π 面距 3.0–3.5 Å），(ii) 对二价硫酸根水合簇（有效直径含首层水约 7–8 Å）几何+去溶剂化双重排斥。以孔径系列（0.7/0.9/1.1 nm）× π 面缺电子度系列做二维扫描，Phase 0 预测窗口是否存在；窗口不存在亦为清洁负结果。

**H2（解耦可达性 → DFT-SAPT 协议）。** 承重对照升级为 OC A01 力度：DFT-SAPT 将结合能分解为静电/诱导/色散/交换，anion-π 静电+诱导分量须与色散（疏水/π-π）分项分离；实测电子学描述符（π 面静电势 V_s,max、四极矩 Q_zz）替代跨语境类比；电子梯度系列（苯/吡啶/三嗪/氰基三嗪，孔几何 PXRD 匹配）+ 富电子咔唑壁对照隔离 anion-π。**错向判据**：PFOA/硫酸根选择性随 V_s,max 缺电子度升高而下降 → 证 anion-π 为负债（清洁证伪）。

**H3（medium）+ M1/M2。** anion-π 机制归因为检索确认的空白（0 直接先例）；C 维维持诚实不通过；材料改用水解稳定的 sp²-碳连接或 β-酮烯胺连接 COF 替代亚胺以保水稳定性；分级孔道解 ng/L 传质。

## 负结果交付骨架（S_anion-π-boundary）
无论 Phase 0 GO/NO-GO，本方案产出一个可发表的机制边界研究：*"anion-π 相互作用能否为受限孔内的全氟羧酸根提供克服硫酸根竞争的选择性？"* 四结果（GO 确立/温和/NO-GO 如期证伪/选择性源自疏水非 anion-π）均定量回答该开放问题，附电子梯度因果系列。
