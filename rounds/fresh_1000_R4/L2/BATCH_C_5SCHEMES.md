# L2 批次 C：5 方案深度闭环

**日期：** 2026-08-02
**范围：** NP A35 / BPA A07 / DDT A05 / Dieldrin A04 / PFBS A08

---

## 1. NP A35 — Bayram+P450+ER 三原型（L1: 79 → L2: 81）

**原型：** Bayram（α-四级碳拓扑）+ P450（链末端读取）+ ER（酚锚几何）
**材料：** 深腔笼（Bayram 形状）+ 腔底萘基（P450 末端锚）+ 腔口吡啶 N（ER 酚锚）
**与 A01/A09/A49 关系：** A35 与 A49 本质相同（三原型叠加），仅原型组合顺序不同。

**攻击要点：**
- (medium) 与 A49 完全重叠（同材料同对照），应合并
- (medium) ER 毒性靶标降级
- (low) 边际收益递减

**裁决：** 81 pass（0c/0h/2m）。**建议与 A49 合并为同一方案**，不独立占 L2 名额。归入 A01 谱系作为三原型对照变体。

---

## 2. BPA A07 — DmpR 门+漆酶酚锚（L1: 78 → L2: 80）

**原型：** DmpR（酚锚+门交换）+ 漆酶（酚氧化酶，酚羟基特异配位）
**材料：** β-酮烯胺 COF（DmpR 门系列）+ 孔壁吡啶二甲酰胺（漆酶型酚 H 键供体）
**与 A01 区别：** A07 增加漆酶型酚锚作为第二识别维（A01 仅有 DmpR 吡啶 N 锚）。

**攻击要点：**
- (medium) 漆酶是催化氧化酶（非吸附），转译为"酚 H 键供体"是外推
- (medium) 吡啶二甲酰胺对酚的水相 H 键极弱（<2 kJ/mol）
- (low) 与 A01 重叠度高（仅增加孔壁功能化）

**裁决：** 80 pass（0c/0h/2m）。漆酶酚识别是真实酶功能但转译为吸附锚的增量有限。建议作为 A01 的孔壁增强变体。

---

## 3. DDT A05 — 脱氯化氢酶+膜分配（L1: 78 → L2: 80）

**原型：** 脱氯化氢酶（DDT/DDE 二元开关）+ 膜分配（链有序度）
**材料：** 介孔 PMO 孔壁碱位（脱氯化氢酶攫氢碱）+ C12 烷基壁（膜分配）
**与 A09 区别：** A05 是 A09 的简化版（去掉 SCP-2 深腔），仅保留碱位+链有序度双机制。

**攻击要点：**
- (medium) 碱位在水相质子化（同 A09 问题）
- (medium) 与 DDT50-01（LPO-SIP，膜分配）部分重叠
- (low) 碱位+链有序度是否真正交

**裁决：** 80 pass（0c/0h/2m）。A05 是 A09 的简化版，建议合并。脱氯化氢酶 DDT/DDE 开关 + 膜分配链有序度是互补机制。

---

## 4. Dieldrin A04 — Rdl+环氧化物水解酶（L1: 78 → L2: 81）

**原型：** Rdl（刚性疏水腔+极性调制）+ 环氧化物水解酶（环氧氧特异识别）
**材料：** SBA-15 苯基疏水壁（Rdl）+ 方酰胺双 NH 腔口（EH 环氧识别）
**与 A01/A08 关系：** A04 是 A01（仅 Rdl）和 A08（Rdl+EH+P450）的中间版。

**攻击要点：**
- (medium) Rdl 毒性靶标降级
- (medium) 与 A01 材料相同（仅叙事增加 EH 原型）
- (low) 水相环氧 H 键弱

**裁决：** 81 pass（0c/0h/2m）。A04 与 A01 材料相同但仿生叙事更完整（增加 EH 原型强化环氧读出的仿生基础）。建议：A04 替代 A01 作为 Dieldrin 主方案叙事（原型更丰富），材料不变。

---

## 5. PFBS A08 — SsuA+SBP 双原型四面体夹口（L1: 77 → L2: 80）

**原型：** SsuA（烷基磺酸盐营养捕获）+ SBP（四面体纯氢键，1.7 Å 晶体）
**材料：** 三(脲丙基)胺硅烷接枝 SBA-15（C3 对称三脲，四面体供体阵列匹配磺酸根）
**核心逻辑：** SsuA 提供"磺酸根是天然底物"的功能证据 + SBP 提供"四面体纯氢键几何"的结构证据 → 中性多齿四面体夹口

**攻击要点：**
- (medium) 三脲对 SO₄²⁻ 也匹配四面体 → PFBS/SO₄²⁻ 选择性核心风险
- (medium) PFBS C4 链太短，疏水驱动力不足（与 PFHxS 相比劣势明显）
- (low) 与 PFHxS A04 高度重叠（同材料，仅目标污染物不同）

**裁决：** 80 pass（0c/0h/2m）。PFBS 的核心困难是 C4 链太短（疏水驱动力不足），即使头基识别完美，总亲和力可能不够 ng/L 工况。建议：PFBS 方案定位为"类级 PFAS 捕获"（PFBS+PFHxS+PFOS 共捕获）而非 PFBS 特异。

## L2 阶段性发现

经过 20 个方案的 L2 深度闭环，发现以下模式：

1. **多原型叠加方案高度重叠**：NP A09/A35/A49 本质是同一材料的三种叙事；PFHxS A01/A02/A04/A46/A48 共享核心材料。建议合并为 3-5 个独立材料实体 + 多个对照变体。

2. **L2 校准普遍降分**：已有方案（R1 通过）在 L2 校准中降 5-10 分（毒性靶标降级、材料悬空、工程化缺失）。

3. **水相弱相互作用是系统性瓶颈**：脲-阴离子 H 键（<5 M⁻¹）、环氧 H 键（<3 kJ/mol）、C-H···π（<1 kJ/mol）在 ng/L 工况下几乎不贡献选择性。

4. **真正有区分力的机制**：链长阈值（OAT4，PFHxS）、α-四级碳拓扑（Bayram，NP）、DDT/DDE 桥 H 开关（脱氯化氢酶，DDT）、酚锚+门交换（DmpR，BPA）。这四个是项目中最强的选择性机制。
