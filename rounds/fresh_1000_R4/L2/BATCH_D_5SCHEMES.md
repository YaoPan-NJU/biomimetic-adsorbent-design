# L2 批次 D：真正新颖的材料实体（GenX A01 + OC A09 + GenX A19 + ROX A48 + BPA A35）

**日期：** 2026-08-02
**说明：** 批次 D 聚焦于与已完成 L2 方案材料实体不同的新方案。

---

## 1. GenX A01 — Bug/TRAP 羧酸夹钳+支链占位（L1: 77 → L2: 80）

**原型：** Bug/TRAP 羧酸夹钳（结构级，PDB）
**核心机制：** 羧酸头双模体夹钳（直接+水桥 H 键）+ 第二结构域检验尾部支链占位 → GenX 支链醚羧酸特异识别
**材料：** PMO 孔口双脲夹口（羧酸根锚）+ 孔内 Y 形支链腔（匹配 GenX -OCF(CF₃)CF₂CF₃ 支链拓扑）
**合成：** BTEB/BTPU PMO + GenX 甲酯假模板辅助 Y 形腔成型 + 模板洗脱

**攻击要点：**
- (medium) GenX 极亲水（logKow ~0.5-1.5），疏水腔驱动力几乎为零 → 支链腔可能不结合
- (medium) Y 形腔精度难控（GenX 甲酯模板洗脱后腔是否保持）
- (medium) Bug/TRAP 天然底物是 C4 二羧酸/酮酸，GenX 是 C6 支链醚单羧酸 → 底物匹配度中等
- (low) 与 main GX50-01（BGE-SIP，84 分）部分重叠

**裁决：** 80 pass（0c/0h/3m）。GenX 的核心困难是极亲水（疏水机制失效），Bug/TRAP 羧酸夹钳是最直接的仿生原型但水相羧酸根 H 键极弱。建议：结合 main GX50-01 的假模板印迹策略，以支链形状互补（非疏水）为主选择性机制。

## 2. OC A09 — 光合 RC+迈克尔+HSA 三原型（L1: 76 → L2: 78）

**原型：** 光合反应中心（CT 电子预组织）+ GST 迈克尔加成（共价捕获）+ HSA（疏水腔）
**核心机制：** CT 预富集（电子亏缺腔吸引 OC 供体-受体体系）+ 迈克尔共价锁定（亲核体攻击 OC β-碳）+ 疏水腔容纳二苯基
**材料：** 萘二酰亚胺（NDI）壁离散笼（CT 受体）+ 哌嗪亲核体（迈克尔供体）+ 疏水腔

**攻击要点：**
- (medium) 水相 CT 极弱（OC 的 CT 跃迁在有机溶剂/蛋白中强，水相被水竞争淬灭）
- (medium) 迈克尔共价不可逆 → 再生问题（OC 加合物无法脱附）
- (medium) β,β-Ph₂ 位阻使迈克尔速率极慢（DFT 门控 ΔG‡ 待验证）
- (low) 三原型叠加是否真正交

**裁决：** 78 pass（0c/0h/3m）。OC 的核心挑战是水相 CT 极弱 + 迈克尔位阻。建议：迈克尔共价是最有希望的方向（绕过水相弱相互作用），但需 DFT 验证 ΔG‡ ≤ 55 kJ/mol。CT 预富集降为辅助机制。

## 3. GenX A19 — Bug/TRAP+支链 AA BP+OxlT 三原型（L1: 76 → L2: 79）

**原型：** Bug/TRAP（羧酸夹钳）+ 支链 AA BP（Y 形腔）+ OxlT（短链羧酸转运）
**核心机制：** 三原型收敛于"短链支链醚羧酸"的特异识别：Bug/TRAP 羧酸锚 + 支链 AA BP Y 形腔 + OxlT 短链窗口
**材料：** 同 A01 但增加 OxlT 短链窗口逻辑（腔深限制，排除长链 PFCA）

**攻击要点：**
- (medium) 与 A01 高度重叠（仅增加腔深限制）
- (medium) GenX 极亲水问题同 A01
- (low) 三原型叙事是否增加真实设计信息

**裁决：** 79 pass（0c/0h/2m）。建议归入 A01 谱系作为腔深变体。

---

## 4. ROX A48 — NPET+FcRn+CYP3A4 三原型（L1: 77 → L2: 79）

**原型：** NPET（核苷酸碱基阵列类级读取）+ FcRn（pH 门控释放）+ CYP3A4（叔胺 N-脱甲基识别）
**核心机制：** 核苷酸碱基站位（类级捕获）+ PVI 咪唑 pH 门控（酸性释放）+ 阳离子-π 叔胺锚
**材料：** 碗单元 + 核苷酸碱基站位 + PVI 刷 + 芳烃壁（阳离子-π）

**攻击要点：**
- (medium) 材料极复杂（碗+站位+PVI+芳烃壁，四功能化），合成不可行
- (medium) 与 ROX A01（NPET 碗）和 ROX PVI 刷（FcRn pH 门控）重叠
- (low) CYP3A4 叔胺识别转译为阳离子-π 是外推

**裁决：** 79 pass（0c/0h/2m）。建议：拆分为两个独立方案——(1) NPET 碗（类级捕获）和 (2) PVI 刷（pH 释放），不叠加为单一材料。

---

## 5. BPA A35 — DmpR+ERRγ+漆酶三原型（L1: 77 → L2: 79）

**原型：** DmpR（酚锚+门交换）+ ERRγ（非对称腔几何）+ 漆酶（酚 H 键供体）
**核心机制：** 吡啶 N 酚锚（DmpR）+ 非对称腔壁约束异丙叉桥（ERRγ）+ 孔壁酚 H 键供体（漆酶）
**材料：** 同 A01/A07 但增加非对称腔壁（ERRγ 几何）

**攻击要点：**
- (medium) 与 A01/A07 高度重叠（同 COF 骨架）
- (medium) ERRγ 是毒性靶标（降级为几何参考）
- (low) 非对称腔壁在周期 COF 中难以实现（COF 是对称晶格）

**裁决：** 79 pass（0c/0h/2m）。ERRγ 非对称几何在周期 COF 中不可实现（COF 是对称晶格），建议放弃 ERRγ 维度，保留 DmpR+漆酶双原型（即 A07）。
