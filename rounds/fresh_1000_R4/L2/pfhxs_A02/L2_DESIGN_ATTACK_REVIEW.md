# L2 完整设计：PFHxS A02 — OAT4+SsuA 双机制（链长阈值 + 磺酸根夹口）

**L1 诊断分：** 81/100（PFHxS 第 2，全局第 5）
**原型：** OAT4（链长阈值）+ SsuA（磺酸根夹口）
**核心机制：** 孔口磺酸根中性夹口（SsuA 逻辑）+ 孔深 C6 阈值（OAT4 逻辑）→ 双正交门

---

## 设计者方案（摘要）

**与 A01 的区别：** A01 用离散 cavitand 盲腔；A02 用 PMO 孔道（连续孔壁功能化），孔口脲桥夹口 + 孔底 C6 烷基封底控制有效深度。

**材料：** BTEB/BTPU 共缩合 PMO（苯桥疏水壁 + 脲桥孔口夹口），孔底以 C6 烷基硅烷后封底（控制有效孔深 ~10 Å）。

**合成：** 溶胶-凝胶（BTEB 先 → BTPU 延迟 20 min）→ C6 三甲基硅烷气相封底（控制封底深度）→ 表征。

**对照：** M0 裸 PMO / M1 完整（脲口+C6 底）/ M2 无封底（全深孔）/ M3 无脲口（纯苯桥）/ M4 C4 封底（浅）/ M5 C8 封底（深）。

**成功判据：** α(PFHxS/PFBS) ≥ 3 且 M1/M3 ≥ 2（脲口贡献）且 M1/M2 ≥ 2（封底贡献）。

## 攻击意见

| # | 严重度 | 问题 |

| ATK-01 | medium | C6 封底深度控制：气相硅烷封底是统计过程，封底深度分布宽（±3-5 Å），C6/C4 阈值可能被模糊 |
