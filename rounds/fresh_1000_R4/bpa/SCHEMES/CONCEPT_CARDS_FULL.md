# BPA 仿生原型注册表 + 50 概念卡（L1 全量）

**污染物：** 双酚 A（CAS 80-05-7，(CH₃)₂C(C₆H₄OH)₂，MW 228.29）
**核心难点：** 中性 pH 下为中性分子（pKa ~10.2，静电无效）+ logKow ~3.4（中等疏水，几乎所有材料都能吸附）+ 真正难题是从 BPF/BPS/BPAF 类似物中选择性区分 BPA + 逆 logKow 选择性（BPA 优先于更疏水的 BPAF）是金标准
**与 PFAS 的关键差异：** 非离子型 + 酚羟基（H 键供体/受体）+ 异丙叉桥（形状特征）+ 类内选择是核心（非去除）
**生成日期：** 2026-08-02

## 原型注册表（联网验证）

### PROTO_BPA_001: DmpR/PoxR 酚感应调节蛋白（核心原型）

- **自然功能：** Pseudomonas sp. CF600 酚降解操纵子的 AAA+ 转录激活蛋白，N 端 A 域在水相特异识别酚类效应物并调控下游降解通路
- **与 BPA 的关系：** Park 2020（Nature Communications，PDB 6IY8）报道 DmpR 酚结合结构：His100 咪唑 ND1 锚定酚羟基（O···ND1 ~2.42-2.54 Å），壁身份改变效应物谱（His100 在酚响应 PoxR/MopR 保守，在甲苯响应 XylR 中被 Tyr 替换）；酚 Kd ~16 µM
- **证据层级：** 结构级（PDB 6IY8，直接复合物）
- **可转译原则：** 固定单酚锚定姿态（His100→吡啶 N）+ 可更换邻位门身份决定底物谱（壁→COF 门系列）
- **先例密度：** 中（fresh_1000 BPA A01 和 main BPA20-01 已用）
- **BPA 特异优势：** 唯一有直接结构证据的水相酚识别蛋白，且功能就是"识别酚→调控降解"（非毒性靶标）

### PROTO_BPA_002: ERRγ（雌激素相关受体 γ）

- **自然功能：** 组成型活性核受体，调控代谢基因表达
- **与 BPA 的关系：** Matsushima 2007（被引 309，PDB 2E2R）报道 BPA 与 ERRγ 高亲和结合（KD = 5.5 nM），BPA 酚-A 基团在结合腔中采取特定取向；Liu 2014 发现"背靠支撑结构"是 BPA 结合特征
- **证据层级：** 结构级（PDB 2E2R，5.5 nM 亲和力）
- **可转译原则：** 非对称单酚锚（BPA 一个酚端深入，另一个朝外）+ 异丙叉桥区域空间约束 + 腔壁形状互补
- **先例密度：** 中（fresh_1000 R3 ERRγ 方案 revise ~79）
- **诚实限制：** ERRγ 是毒性靶标（核受体），按项目纪律不作主干仿生本体；但结构信息可约束几何

### PROTO_BPA_003: PXR（孕烷 X 受体）定向混杂

- **自然功能：** 肝脏/肠道核受体，感应多种外源物（药物、毒素）并激活解毒通路（CYP3A4 等）
- **与 BPA 的关系：** PXR 以超大疏水腔（~1400 Å³）容纳多种配体，BPA 是 PXR 配体之一；"定向混杂"（promiscuity with purpose）是 PXR 的天然功能
- **证据层级：** 结构级（PXR 多个配体复合物 PDB）
- **可转译原则：** 大腔 + 多位点弱接触 → 类级捕获（双酚类家族）而非单分子特异
- **先例密度：** 低（fresh_1000 R2 BPA PXR 方案 ~82 revise）

### PROTO_BPA_004: 漆酶/酪氨酸酶（酚氧化酶）

- **自然功能：** 真菌/细菌酚类降解酶，以铜活性中心氧化酚为醌
- **与 BPA 的关系：** 漆酶可氧化 BPA（生成醌/二聚体），活性位点对酚羟基有特异配位；白腐真菌漆酶是 BPA 生物降解的主要酶
- **证据层级：** 结构级（多个漆酶 PDB）+ 机制级（BPA 降解）
- **可转译原则：** 酚羟基的铜配位识别 → 转译为酚羟基 H 键/配位锚（不复制氧化功能）
- **先例密度：** 低
- **诚实限制：** 酶功能是催化氧化（非吸附），转译限于酚识别几何

### PROTO_BPA_005: 苯酚羟化酶 DmpKLMNOP（DmpR 下游）

- **自然功能：** DmpR 调控的下游降解酶，执行苯酚→儿茶酚的羟化
- **与 BPA 的关系：** Dmp 系统完整通路：DmpR 感应酚→激活 DmpKLMNOP 降解；DmpR 识别 + Dmp 酶降解是同一生物系统的两步
- **证据层级：** 机制级（通路）+ 部分结构级
- **可转译原则：** 感应-降解耦合 → 材料"捕获-转化"双功能（先吸附后催化降解）
- **先例密度：** 零（从未用于 BPA 吸附材料）

### PROTO_BPA_006: 转甲状腺素蛋白 TTR

- **自然功能：** 血浆甲状腺素（T4）转运蛋白，四聚体，以卤代酚通道结合 T4
- **与 BPA 的关系：** BPA 是 TTR 配体（与 T4 竞争结合），BPA 酚羟基模拟 T4 酚端；卤代酚通道对酚类有广谱结合
- **证据层级：** 结构级（TTR-T4 复合物 PDB）+ 机制级（BPA 竞争结合）
- **可转译原则：** 卤代酚通道 → 酚通道（酚羟基锚 + 芳环疏水腔）
- **先例密度：** 低（fresh_1000 PCP A01 用过 TTR）

### PROTO_BPA_007: HSA BPA 结合

- **自然功能：** 血浆广谱转运
- **与 BPA 的关系：** BPA 与 HSA 结合（Sudlow site I/II），亲和力中等（~10⁴-10⁵ M⁻¹）
- **证据层级：** 机制级（结合测定）
- **先例密度：** 高

### PROTO_BPA_008: EPS/活性污泥 BPA 分配

- **自然功能：** 生物膜/污泥基质
- **与 BPA 的关系：** 活性污泥对 BPA 有部分吸附（logKd ~2-3），EPS 蛋白组分参与
- **证据层级：** 现象级
- **诚实限制：** 非特异疏水分配为主

### PROTO_BPA_009: 脂ocalin 型前列腺素 D 合成酶（L-PGDS）

- **自然功能：** 脑脊液中前列腺素 D₂ 合成与转运，lipocalin 家族疏水腔结合多种小分子
- **与 BPA 的关系：** Lipocalin 家族以 β-桶疏水腔结合双酚类（有文献报道 BPA 与 lipocalin 结合）
- **证据层级：** 机制级 + 部分结构级
- **可转译原则：** β-桶疏水腔 + 腔口极性锚 → 深腔主体化学
- **先例密度：** 零

### PROTO_BPA_010: 酚类植物受体（水杨酸受体 NPR1）

- **自然功能：** 植物免疫受体 NPR1 感应水杨酸（邻羟基苯甲酸），激活系统获得性抗性
- **与 BPA 的关系：** 水杨酸是酚酸，NPR1 对酚羟基 + 羧基的双功能识别；BPA 有双酚但无羧基
- **证据层级：** 机制级 + 部分结构级
- **可转译原则：** 酚羟基特异感应（非广谱疏水）→ 酚锚设计
- **先例密度：** 零
- **诚实限制：** 水杨酸是单酚+羧酸，BPA 是双酚无羧酸，结构差异大

## 50 概念卡

### A01 — DmpR 固定酚锚 + 门交换 COF（核心设计，已有方案）

- **原型：** PROTO_BPA_001（DmpR，结构级）
- **转译原则：** His100 酚锚→吡啶 N + 壁身份→同晶格门系列
- **材料概念：** β-酮烯胺 COF，G0/G1/G2/G3 门系列，C1 去锚体
- **合成概要：** Tp + 2,6-双(4-氨基-3,5-R₂-苯基)吡啶缩合
- **致命风险：** 水相酚-吡啶 H 键可能趋零；同晶格精度制造难
- **六维诊断分：** 因果 17/选择性 22/可转译 16/原创 12/可证伪 9/证据 9 = **85**
- **谱系状态：** SP-retained / BP-retained / TR-retained / ME-advance / SR-revise / ER-concept_valid
- **仿生真实性快检：** DmpR 天然功能就是水相酚识别 → functional_biomimicry（最强）

### A02 — ERRγ 非对称单酚锚 + 异丙叉桥约束

- **原型：** PROTO_BPA_002（ERRγ，结构级，毒性靶标降级）
- **转译原则：** ERRγ 腔中 BPA 一个酚端深入（Asp346 H 键）+ 异丙叉桥被腔壁约束 → 非对称腔
- **材料概念：** 非对称深腔笼（一端极性锚，另一端疏水壁约束异丙叉），BPA 单端深入
- **合成概要：** 非对称 resorcinarene 或 calixarene 笼
- **致命风险：** ERRγ 是毒性靶标（项目纪律降级）；非对称笼合成难
- **六维诊断分：** 因果 14/选择性 19/可转译 11/原创 13/可证伪 8/证据 9 = **74**
- **谱系状态：** SP-retained / BP-conditional（毒性靶标）/ TR-retained / ME-repairable / SR-revise / ER-lead_only
- **仿生真实性快检：** ERRγ 是毒性靶标 → 仅作几何约束参考，不作主干仿生

### A03 — PXR 定向混杂大腔（类级双酚捕获）

- **原型：** PROTO_BPA_003（PXR，结构级）
- **转译原则：** PXR 超大腔 + 多位点弱接触 → 类级捕获（BPA/BPF/BPS/BPAF 全捕获）
- **材料概念：** 大孔 POP（~3 nm）+ 多脲/多芳烃壁，双酚类家族广谱捕获
- **合成概要：** 大孔 POP 或 COF（3 nm 级孔道）
- **致命风险：** 类级捕获不是 BPA 选择性（BPAF 也捕获）；先例多
- **六维诊断分：** 因果 12/选择性 13/可转译 15/原创 9/可证伪 7/证据 8 = **64**
- **谱系状态：** SP-retained / BP-conditional（毒性靶标）/ TR-retained / ME-advance / SR-bench_ready / ER-lead_only
- **仿生真实性快检：** PXR 定向混杂是真实功能 → functional_biomimicry（但非 BPA 特异）

### A04 — 漆酶酚识别铜位转译为酚锚

- **原型：** PROTO_BPA_004（漆酶，结构级）
- **转译原则：** 漆酶 T1 铜位对酚羟基的特异配位 → 材料设酚羟基 H 键/配位锚（不复制氧化）
- **材料概念：** 吡啶-2,6-二甲酰胺孔壁（模拟漆酶 His/Cys 配位几何）+ 疏水腔（芳环容纳）
- **合成概要：** COF 或 POP 含吡啶二甲酰胺壁
- **致命风险：** 漆酶功能是氧化（非吸附）；酚 H 键在水相弱
- **六维诊断分：** 因果 12/选择性 16/可转译 13/原创 12/可证伪 7/证据 8 = **68**
- **谱系状态：** SP-retained / BP-retained / TR-retained / ME-advance / SR-bench_ready / ER-lead_only
- **仿生真实性快检：** 漆酶酚识别是真实酶功能 → functional_biomimicry（但转译限于识别几何）

### A05 — DmpR + Dmp 酶感应-降解耦合

- **原型：** PROTO_BPA_005（Dmp 通路，机制级，零先例）
- **转译原则：** DmpR 感应酚→DmpKLMNOP 降解 → 材料"捕获-催化"双功能
- **材料概念：** 双层颗粒：外层酚锚捕获（DmpR 逻辑）+ 内层负载漆酶/仿生催化剂（降解）
- **合成概要：** 核壳：COF 壳（酚锚）+ 漆酶固定化核（或 Mn-卟啉仿生催化核）
- **致命风险：** 酶固定化超出项目范围（蛋白）；仿生催化剂（Mn-卟啉）对 BPA 降解效率未知

- **谱系状态：** SP-retained / BP-retained / TR-conditional / ME-repairable / SR-revise / ER-lead_only
- **仿生真实性快检：** Dmp 通路感应-降解是真实生物系统 → functional_biomimicry（但降解超出吸附范围）

### A06 — TTR 卤代酚通道转译为酚通道
