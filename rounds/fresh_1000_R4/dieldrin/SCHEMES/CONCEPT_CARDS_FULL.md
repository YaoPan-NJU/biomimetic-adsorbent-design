# Dieldrin 仿生原型注册表 + 50 概念卡（L1 全量）

**污染物：** 狄氏剂（CAS 60-57-1，C₁₂H₈Cl₆O，MW 380.91，logKow 5.40）
**核心难点：** 笼状含氧有机氯（中性、无解离、无氢键供体）+ 唯一弱极性把手为 6,7-环氧桥氧 + 与异狄氏剂（endo-环氧）仅 exo/endo 构型不同 + 与艾氏剂（无环氧）仅差一个氧 + Koc ~5×10⁶ L/kg 极强疏水本底 + 监管基准 ng/L 级
**独特挑战：** 从极强疏水本底中解耦环氧几何信息（exo vs endo vs 无环氧）
**生成日期：** 2026-08-02

## 原型注册表（联网验证）

### PROTO_DLD_001: GABA/Rdl 受体（环二烯类靶标）

- **自然功能：** 果蝇/昆虫 GABA 门控氯通道，环二烯类杀虫剂（狄氏剂、异狄氏剂）的作用靶标
- **与狄氏剂的关系：** ffrench-Constant 1993（Nature 363:449）A302S 单点突变赋予狄氏剂抗性；Cole 1995 [³H]EBOB 结合位点改变；Abalis 1985 立体专一性结合；Casida 2015 综述
- **证据层级：** 机制级（突变+结合）+ 立体化学级
- **可转译原则：** 刚性疏水腔内单一极性接触的开关式调制（A302 位）→ 腔口极性供体对环氧几何读出
- **先例密度：** 低（fresh_1000 A01 已用，89 分）
- **诚实限制：** 毒性靶标（不作主干仿生本体）；A302S 方向为削弱（非增强）

### PROTO_DLD_002: 环氧化物水解酶（Epoxide Hydrolase）

- **自然功能：** 水解环氧化物为反式二醇（解毒/代谢）
- **与狄氏剂的关系：** 狄氏剂环氧桥可被环氧化物水解酶攻击（但狄氏剂笼状结构使环氧极难接近）
- **证据层级：** 机制级（酶学）
- **可转译原则：** 环氧化物水解酶对环氧氧的亲核攻击几何 → 转译为环氧氧 H 键供体识别
- **先例密度：** 零

### PROTO_DLD_003: 细胞色素 P450 环氧化/脱氯

- **自然功能：** P450 氧化有机氯农药（艾氏剂→狄氏剂的环氧化就是 P450 催化）
- **与狄氏剂的关系：** 艾氏剂经 P450 环氧化生成狄氏剂（6,7-环氧桥形成）；P450 也可进一步氧化狄氏剂
- **证据层级：** 机制级（代谢通路）
- **可转译原则：** P450 对艾氏剂/狄氏剂的区分（有/无环氧）→ 环氧识别
- **先例密度：** 零

### PROTO_DLD_004: 脂质膜分配（笼状疏水分子跨膜）

- **自然功能：** 被动扩散跨膜
- **与狄氏剂的关系：** 狄氏剂 logKow 5.40，强烈分配入脂质膜；Koc ~5×10⁶
- **证据层级：** 物化原理
- **可转译原则：** 疏水分配 → 疏水腔材料

### PROTO_DLD_005: 血清白蛋白有机氯结合

- **证据层级：** 机制级
- **可转译原则：** 疏水腔 + 极性入口

## 50 概念卡（Top 10 + 速览）

### A01 — Rdl 刚性疏水腔 + 方酰胺环氧读出（已有方案，89 分）

- **原型：** PROTO_DLD_001（Rdl，机制级，毒性靶标降级）
- **转译原则：** 刚性疏水腔 + 单一极性接触调制 → SBA-15 苯基疏水壁 + 方酰胺双 NH 环氧读出
- **材料概念：** SBA-15 孔壁苯基疏水化 + 腔口方酰胺双 NH 双齿供体
- **致命风险：** Rdl 是毒性靶标（降级）；水相环氧 H 键净收益 <2-3 kJ/mol
- **六维诊断分：** 因果 16/选择性 21/可转译 17/原创 12/可证伪 9/证据 8 = **83**（降分：毒性靶标+水相弱 H 键）
- **仿生真实性快检：** Rdl 是毒性靶标 → 改称"受 Rdl 启发的理性受体设计"

### A02 — 环氧化物水解酶环氧识别

- **原型：** PROTO_DLD_002（环氧化物水解酶，机制级，零先例）
- **转译原则：** 环氧化物水解酶对环氧氧的亲核攻击几何 → 材料设环氧氧 H 键供体（不复制水解）
- **材料概念：** 方酰胺/硫脲功能化介孔（环氧氧双 H 键）+ 疏水腔（笼状骨架容纳）
- **合成概要：** SBA-15 + 方酰胺硅烷接枝（同 A01 但原型叙事不同）
- **致命风险：** 与 A01 材料相同（仅原型叙事不同）；水相环氧 H 键弱
- **六维诊断分：** 因果 14/选择性 19/可转译 16/原创 11/可证伪 8/证据 7 = **75**
- **谱系状态：** SP-retained / BP-retained / TR-retained / ME-advance / SR-bench_ready / ER-lead_only
- **仿生真实性快检：** 环氧化物水解酶是真实酶功能 → functional_biomimicry（非毒性靶标，优于 Rdl）

### A03 — P450 艾氏剂/狄氏剂区分（有/无环氧）

- **原型：** PROTO_DLD_003（P450，机制级，零先例）
- **转译原则：** P450 催化艾氏剂→狄氏剂环氧化 → 材料区分有/无环氧（狄氏剂 vs 艾氏剂）
- **材料概念：** 环氧氧 H 键供体（区分有/无环氧）+ 疏水腔（笼状骨架）
- **六维诊断分：** 因果 13/选择性 18/可转译 15/原创 12/可证伪 7/证据 7 = **72**
- **仿生真实性快检：** P450 环氧化是真实代谢 → functional_biomimicry（零先例）
