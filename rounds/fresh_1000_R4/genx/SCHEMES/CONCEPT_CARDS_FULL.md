# GenX (HFPO-DA) 仿生原型注册表 + 50 概念卡（L1 全量）

**污染物：** 六氟环氧丙烷二聚酸 GenX / HFPO-DA（CAS 13252-13-6，CF₃CF₂CF₂OCF(CF₃)COOH，MW 316.05）
**核心难点：** 极亲水（logKow ~0.5-1.5，疏水机制近乎失效）+ 支链醚结构（区别于线性 PFCA）+ 强水合壳 + 羧酸根头基 + US MCL 10 ng/L + 醚氧弱 H 键受体
**与 PFOA 的关键差异：** 支链（非线性）+ 醚氧（C-O-C）+ 极短有效疏水链 + 强亲水
**生成日期：** 2026-08-02

## 原型注册表（联网验证）

### PROTO_GENX_001: HSA 四位点结合（直接 GenX 证据）

- **自然功能：** 血浆广谱转运
- **与 GenX 的关系：** Delva-Wiley 2021（ACS Omega，被引 34）计算报道 GenX 在 HSA 上有 4 个结合位点；Moro 2022（PMC9682524，被引 61）实验研究 HSA 与支链短链 PFAS（HPFO-DA/C6O4）相互作用
- **证据层级：** 计算级（对接+MD）+ 实验级（Moro 2022 光谱/量热）
- **可转译原则：** 支链醚羧酸在蛋白多亚腔中的多点弱结合 → 材料设多位点协同
- **先例密度：** 低（main GX50 系列未直接用 HSA 四位点逻辑）

### PROTO_GENX_002: Bug/TRAP 羧酸夹钳（支链醚羧酸直接相关）

- **自然功能：** 细菌 C4-二羧酸/酮酸转运，以"羧酸夹钳"（两个保守模体经直接+水桥氢键锚定羧酸头）识别
- **与 GenX 的关系：** GenX 是醚羧酸（R-O-CF(CF₃)-COO⁻），Bug/TRAP 天然识别含氧取代的短链羧酸；第二结构域检验尾部是否形成生产性占位
- **证据层级：** 结构级（PDB）+ 机制级
- **可转译原则：** 羧酸头双模体夹钳 + 尾部占位检验（支链 vs 线性区分）
- **先例密度：** 低（main SC-P02 引用为支持原型）
- **GenX 特异优势：** Bug/TRAP 天然识别含氧短链羧酸，与 GenX 醚羧酸结构最接近

### PROTO_GENX_003: 支链氨基酸结合蛋白（Branched-chain AA BP）

- **自然功能：** 细菌/古菌亮氨酸/异亮氨酸/缬氨酸（支链疏水氨基酸）的周质结合与转运
- **与 GenX 的关系：** GenX 的支链全氟异丙氧基（-OCF(CF₃)CF₂CF₃）在拓扑上类似支链氨基酸的异丙基/仲丁基侧链；支链 AA BP 的腔专门容纳分支点
- **证据层级：** 结构级（PDB，多个支链 AA BP 结构）
- **可转译原则：** 分支点几何互补（Y 形腔匹配支链）+ 主链极性锚（氨基/羧基 → 转译为醚氧/羧酸根锚）
- **先例密度：** 零（从未用于 PFAS 设计）
- **GenX 特异优势：** 支链拓扑是 GenX 区别于线性 PFOA/PFBS 的核心结构特征

### PROTO_GENX_004: 聚醚离子载体（Monensin/Nigericin）

- **自然功能：** 链霉菌产生的聚醚抗生素，以醚氧阵列包裹阳离子实现跨膜转运
- **与 GenX 的关系：** GenX 含醚氧（C-O-C），聚醚离子载体的醚氧-阳离子配位原理可反转为"醚氧作为 H 键受体被材料识别"
- **证据层级：** 结构级（多个聚醚-阳离子复合物晶体）
- **可转译原则：** 醚氧的弱 H 键受体性质 → 材料设强 H 键供体（方酰胺/硫脲）定向对醚氧
- **先例密度：** 低（fresh_1000 GenX A03 用过多酚醚离子载体角度，终止）
- **诚实限制：** 醚氧在水相中 H 键碱度极弱（β₂H ~0.2），净贡献可能 <1 kJ/mol

### PROTO_GENX_005: OAT1/OAT3 有机阴离子分泌

- **自然功能：** 肾近曲小管基底膜有机阴离子分泌（药物/代谢物排泄）
- **与 GenX 的关系：** GenX 是 OAT 底物（Zhao 2023 综述确认 PFAS 包括 GenX 与 OAT 相互作用）；OAT 对有机阴离子的识别依赖羧酸根 + 疏水骨架
- **证据层级：** 机制级（转运测定）
- **可转译原则：** 有机阴离子头基识别 + 疏水/氟碳骨架辅助
- **先例密度：** 低

### PROTO_GENX_006: 主要乳胶蛋白 MLP（pH 依赖污染物结合）

- **自然功能：** 植物防御蛋白，以疏水腔结合多种有机分子，pH 依赖（酸性高亲和）
- **与 GenX 的关系：** Fujita 2023（PMC10513956）报道 MLP 在酸性条件下对疏水有机污染物亲和力升高 → pH 门控结合/释放
- **证据层级：** 机制级（结合测定 + pH 依赖）
- **可转译原则：** 疏水腔 + pH 门控（酸性结合/中性释放）→ 但 GenX 极亲水，疏水腔可能不适用
- **先例密度：** 零
- **诚实限制：** MLP 结合疏水污染物（芘），GenX 极亲水，转译可能不成立

### PROTO_GENX_007: SsuA/TauA（同 PFAS 系列）

- **与 GenX 的关系：** GenX 是羧酸（非磺酸），SsuA 天然底物为磺酸盐 → 头基不匹配
- **诚实限制：** SsuA 对 GenX 的适用性弱于对 PFBS/PFHxS（头基不同）

### PROTO_GENX_008: EPS/生物膜（GenX 分配）

- **与 GenX 的关系：** GenX 极亲水，在 EPS 中分配弱于长链 PFAS；但生物膜增强人工湿地对 GenX 有部分去除（Zhang 2025）
- **证据层级：** 现象级
- **诚实限制：** GenX 在 EPS 中结合极弱，仿生价值有限

### PROTO_GENX_009: 草酸转运体 OxlT（二羧酸/醚酸反向转运）

- **自然功能：** 产甲酸草酸杆菌（Oxalobacter formigenes）的草酸/甲酸反向转运体，以草酸（二羧酸）为底物
- **与 GenX 的关系：** 草酸（HOOC-COOH）与 GenX（R-O-CF(CF₃)-COOH）共享羧酸根基团；OxlT 对短链二羧酸/单羧酸有特异识别
- **证据层级：** 结构级（PDB）+ 机制级
- **可转译原则：** 短链羧酸的特异识别（不依赖长疏水链）+ 电荷不对称反向转运
- **先例密度：** 零
- **GenX 特异优势：** 天然识别短链羧酸（不需要长疏水链），适合极亲水 GenX

### PROTO_GENX_010: 氟柠檬酸/氟乙酸代谢酶（氟代有机酸识别）

- **自然功能：** 某些细菌可代谢氟乙酸/氟柠檬酸（氟代有机酸），相关酶对 C-F 键有特异识别
- **与 GenX 的关系：** GenX 含多个 C-F 键 + 羧酸根，与氟乙酸（FCH₂COO⁻）共享"氟代+羧酸"特征
- **证据层级：** 机制级（酶学）
- **可转译原则：** 氟代有机酸的特异识别（C-F 键极化 + 羧酸根配位）
- **先例密度：** 零
- **诚实限制：** 氟乙酸是 C2，GenX 是 C6 支链醚，结构差异大

## 50 概念卡

### A01 — Bug/TRAP 羧酸夹钳 + 支链占位检验（核心设计）

- **原型：** PROTO_GENX_002（Bug/TRAP，结构级，直接相关）
- **转译原则：** 羧酸头双模体夹钳（直接+水桥 H 键）+ 第二结构域检验尾部支链占位 → 材料设双 H 键供体夹口 + 支链形状互补腔
- **材料概念：** PMO 孔口双脲夹口（羧酸根锚）+ 孔内 Y 形支链腔（匹配 GenX -OCF(CF₃)CF₂CF₃ 支链拓扑）
- **合成概要：** BTEB/BTPU PMO + 支链模板辅助腔成型（GenX 甲酯假模板）
- **致命风险：** GenX 极亲水，疏水腔驱动力不足；支链腔精度难控
- **六维诊断分：** 因果 15/选择性 19/可转译 14/原创 13/可证伪 8/证据 8 = **77**
- **谱系状态：** SP-retained / BP-retained / TR-retained / ME-advance / SR-revise / ER-lead_only
- **仿生真实性快检：** Bug/TRAP 天然识别含氧短链羧酸 → functional_biomimicry

### A02 — 支链氨基酸 BP Y 形腔（支链拓扑选择）

- **原型：** PROTO_GENX_003（支链 AA BP，结构级，零先例）
- **转译原则：** 亮氨酸/异亮氨酸 BP 的 Y 形疏水腔匹配分支点 → 材料设 Y 形腔匹配 GenX 支链醚
- **材料概念：** 三叉形分子笼（三臂芳烃，中心空腔呈 Y 形），GenX 支链插入 Y 形腔，线性 PFCA 不匹配
- **合成概要：** 1,3,5-三取代苯基笼合成（多步）
- **致命风险：** 三叉笼合成极难；水相支链/线性区分可能 <2 倍
- **六维诊断分：** 因果 13/选择性 20/可转译 9/原创 15/可证伪 7/证据 7 = **71**
- **谱系状态：** SP-retained / BP-retained / TR-retained / ME-repairable / SR-revise / ER-lead_only
- **仿生真实性快检：** 支链 AA BP Y 形腔是真实结构 → functional_biomimicry（零先例，高创新）

### A03 — HSA 四位点协同（多位点弱结合叠加）

- **原型：** PROTO_GENX_001（HSA，计算+实验级）
- **转译原则：** GenX 在 HSA 上 4 个位点各弱结合 → 材料设多位点协同（单位点弱但 4 位点叠加）
- **材料概念：** 高密度多功能孔壁（脲+芳烃+醚氧+氟碳四位点），GenX 同时接触多位点
- **合成概要：** 四功能化 PMO（BTEB + BTPU + 醚桥 + 氟碳硅烷共缩合）
- **致命风险：** 四组分共缩合相分离；多位点协同在 ng/L 下不生效（占据率极低）
- **六维诊断分：** 因果 12/选择性 15/可转译 14/原创 11/可证伪 7/证据 8 = **67**
- **谱系状态：** SP-retained / BP-retained / TR-conditional / ME-advance / SR-revise / ER-lead_only
- **仿生真实性快检：** HSA 四位点是计算预测（非实验验证）→ mechanism_informed

### A04 — 聚醚离子载体反转（醚氧 H 键受体识别）

- **原型：** PROTO_GENX_004（Monensin，结构级）
- **转译原则：** 聚醚以醚氧配位阳离子 → 反转为材料以强 H 键供体识别 GenX 醚氧
- **材料概念：** 方酰胺/硫脲功能化孔壁，定向 H 键供体对 GenX 醚氧（C-O-C）
- **合成概要：** SBA-15 + 方酰胺硅烷接枝
- **致命风险：** 醚氧在水相 H 键碱度极弱（β₂H ~0.2），净贡献 <1 kJ/mol；水竞争
- **六维诊断分：** 因果 10/选择性 14/可转译 13/原创 12/可证伪 7/证据 7 = **63**
- **谱系状态：** SP-retained / BP-retained / TR-conditional / ME-advance / SR-bench_ready / ER-lead_only
- **仿生真实性快检：** 聚醚醚氧配位是真实化学 → functional_biomimicry（但水相极弱）

### A05 — OxlT 短链羧酸特异识别（不依赖疏水链）

- **原型：** PROTO_GENX_009（OxlT，结构级，零先例）
- **转译原则：** OxlT 识别草酸（C2 二羧酸）不依赖长疏水链 → 材料设短链羧酸特异夹口（不需要疏水腔）
- **材料概念：** 双胍基/双脲基孔口（匹配 GenX 羧酸根 + 邻近醚氧），不依赖疏水腔
- **合成概要：** SBA-15 + 双胍基硅烷（或双脲硅烷）高覆盖接枝
- **致命风险：** 双胍基带正电→硫酸盐陷阱；对所有羧酸根无选择性
- **六维诊断分：** 因果 12/选择性 14/可转译 15/原创 13/可证伪 7/证据 7 = **68**

- **仿生真实性快检：** OxlT 短链羧酸识别是真实功能 → functional_biomimicry（零先例）

### A06 — 氟乙酸代谢酶 C-F 极化识别

- **原型：** PROTO_GENX_010（氟代有机酸酶，机制级，零先例）

- **材料概念：** Zr-MOF 开放金属位点（Lewis 酸，极化 C-F）+ 脲基（羧酸根锚）
- **合成概要：** UiO-66-Zr + 后接枝脲基硅烷
- **致命风险：** Zr 开放位点对所有阴离子配位；MOF 水稳定性；金属溶出
- **六维诊断分：** 因果 10/选择性 13/可转译 12/原创 14/可证伪 6/证据 6 = **61**
