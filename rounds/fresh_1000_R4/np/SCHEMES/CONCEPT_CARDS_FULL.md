# NP 仿生原型注册表 + 50 概念卡（L1 全量）

**污染物：** 壬基酚 NP（CAS 25154-52-3，技术品 ~20 种异构体混合物，C₁₅H₂₄O，MW 220.35）
**核心难点：** 中性 pH 下为中性分子（酚 pKa ~10.2，静电无效）+ logKow 4.5-5.2（强疏水）+ ~20 种异构体 logKow 近简并（差异 <0.3）+ 活性污泥处理后残留的恰是雌激素活性最高的 α-四级碳支链异构体 + 异构体分离分析本身极难
**独特挑战：** 不是"去除 NP"（GAC 即可），而是"从异构体混合物中选择性捕获高风险支链异构体"
**生成日期：** 2026-08-02

## 原型注册表（联网验证）

### PROTO_NP_001: Bayram/TTNP3 ipso 羟基化途径（核心原型）

- **自然功能：** Sphingobium xenophagum Bayram 和 Sphingomonas TTNP3 对 α-四级碳对位烷基酚的 ipso 碳羟化 + 1,2-烷基迁移降解
- **与 NP 的关系：** Gabriel 2007（AEM，被引 55）证实 α-四级碳 NP 异构体进入 ipso 途径，线性 4-n-NP 不进入；Lu 2015（Water Res，PMID 25462736，被引 25）报 19 种异构体出水残留与立体效应指数正相关 R²=0.76；PDB 5M22（TTNP3 氢醌 1,2-双加氧酶）
- **证据层级：** 机制级（代谢物鉴定 + 异构体选择性）+ 部分结构级（下游酶 PDB，非底物复合物）
- **可转译原则：** α-四级碳拓扑的几何读取（生物侧为电子效应稳定碳正离子，材料侧为形状互补）+ 酚羟基对位锚定
- **先例密度：** 低（fresh_1000 A01 已用，92 分全项目最高）
- **诚实限制：** 无 NP-酶复合物晶体结构；生物侧判据为电子效应，材料侧为几何统计对应

### PROTO_NP_002: ERα/ERβ 雌激素受体（毒性靶标）

- **自然功能：** 核受体转录因子，结合 17β-雌二醇调控基因表达
- **与 NP 的关系：** NP 异构体以 α-四级碳支链异构体雌激素活性最高（Preuss 2006，Gabriel 2008）；ER 配体结合腔对烷基酚的容纳有结构证据（PDB 多个 ER-烷基酚复合物）
- **证据层级：** 结构级（PDB）+ 机制级（异构体活性差异）
- **可转译原则：** ER 腔对酚羟基 + 对位烷基链的双点识别 + 支链/线性形状区分
- **先例密度：** 中（BPA 方案引用过 ER）
- **诚实限制：** 毒性靶标，按项目纪律不作主干仿生本体

### PROTO_NP_003: 细胞色素 P450 烷基酚代谢

- **自然功能：** 肝脏/微生物 P450 单加氧酶，氧化外源物（药物、污染物）
- **与 NP 的关系：** CYP2C18 等 P450 催化 NP 的 ω-氧化和芳环羟化；不同异构体代谢速率不同（支链慢于线性）
- **证据层级：** 机制级（代谢产物鉴定）
- **可转译原则：** P450 活性位点对烷基链末端/芳环的区域选择性氧化 → 转译为烷基链深度/取向读取
- **先例密度：** 零（从未用于 NP 吸附材料）

### PROTO_NP_004: FABP 烷基酚结合

- **自然功能：** 细胞内脂肪酸/疏水配体转运
- **与 NP 的关系：** FABP 结合烷基酚（疏水腔容纳烷基链 + 极性入口锚定酚羟基）；U Toronto 论文确认 FABP 结合烷基酚和 ERRγ
- **证据层级：** 机制级（结合测定）
- **可转译原则：** 疏水腔 + 酚锚的双区组织
- **先例密度：** 低

### PROTO_NP_005: β-CD 烷基链包结

- **自然功能：** 非生物原型（环糊精为细菌酶产物），但 β-CD 对 NP 烷基链有包结作用
- **与 NP 的关系：** Bonenfant 2009 报道 β-CD 与 NP 包合物（烷基尾入腔、酚羟基不深进腔）；Crini 2022 报道 CD 聚合物对 4-n-NP/4-tert-OP 吸附（紧凑型支链 4-tert-OP 最优）
- **证据层级：** 机制级（包合物表征）
- **可转译原则：** 烷基链入腔 + 支链/线性形状区分（支链紧凑更易入腔）
- **先例密度：** 高（CD-NP 先例多）
- **诚实限制：** 非生物原型（CD 是酶产物非蛋白）；先例饱和

### PROTO_NP_006: AhR 芳烃受体（平面疏水识别）

- **自然功能：** 胞质转录因子，感应平面多环芳烃/卤代芳烃（TCDD 等），激活解毒通路
- **与 NP 的关系：** NP 芳环可进入 AhR 配体腔（但 NP 非典型 AhR 配体，亲和力弱）；AhR 腔对平面芳环 + 疏水取代基有形状选择
- **证据层级：** 结构级（AhR-TCDD 类似物 PDB）
- **可转译原则：** 平面芳环 π-π 堆叠 + 疏水取代基容纳 → 芳烃壁 + 烷基腔
- **先例密度：** 低
- **诚实限制：** NP 非典型 AhR 配体；毒性靶标

### PROTO_NP_007: NPEO 降解酶（烷基酚聚氧乙烯醚降解）

- **自然功能：** 环境中 NPEO（NP 聚氧乙烯醚）的微生物降解，逐步脱乙氧基生成 NP
- **与 NP 的关系：** NPEO 降解菌（如 Pseudomonas putida）的醇脱氢酶/醚酶识别 NP 乙氧基链 → NP 是降解终端产物
- **证据层级：** 机制级（降解通路）
- **可转译原则：** 乙氧基链识别 → 转译为 NP/NPEO 区分（NP 无乙氧基链）
- **先例密度：** 零

### PROTO_NP_008: 石墨碳 NP 异构体色谱分离

- **自然功能：** 非生物原型（石墨化碳黑色谱固定相）
- **与 NP 的关系：** Gundersen 报道石墨碳柱可分离 NP 异构体（基于平面性和支链程度的保留差异）
- **证据层级：** 现象级（色谱分离）
- **可转译原则：** 平面性/支链程度的形状读取 → 石墨化碳壁 + 形状选择
- **先例密度：** 低
- **诚实限制：** 非生物原型

### PROTO_NP_009: EPS/活性污泥 NP 异构体分配

- **自然功能：** 生物膜/污泥基质
- **与 NP 的关系：** 活性污泥对 NP 异构体的分配有差异（支链异构体 logKow 略低但空间位阻影响分配动力学）
- **证据层级：** 现象级
- **诚实限制：** 非特异疏水分配为主

### PROTO_NP_010: 植物根系烷基酚吸收（水通道/脂质体途径）

- **自然功能：** 植物根系从土壤/水中吸收有机污染物
- **与 NP 的关系：** 植物对 NP 的吸收经脂质体途径（跨膜分配）和水通道蛋白途径；支链异构体跨膜速率不同于线性
- **证据层级：** 现象级（吸收测量）
- **可转译原则：** 脂质双层跨膜分配的形状选择性 → 仿生膜材料
- **先例密度：** 零
- **诚实限制：** 膜过程可能超出项目范围

## 50 概念卡

### A01 — Bayram ipso α-四级碳拓扑深腔笼（已有方案，92 分）

- **原型：** PROTO_NP_001（Bayram，机制级）
- **转译原则：** α-四级碳拓扑几何读取 + 酚羟基对位锚定 + "生物留下/材料捕获"逆读标尺
- **材料概念：** 间苯二酚芳烃深腔笼（闭底，腔深匹配 α-四级碳 C9 分支丛）+ 腔口酚锚 + IEDDA 点击成网
- **合成概要：** 间苯二酚[4]芳烃扩壁 → 下缘降冰片烯 → 双四嗪连接体 IEDDA 成网 → HIPE 造粒
- **致命风险：** 无酶-底物复合物结构（几何统计对应）；水相形状区分可能 <2 倍；heroic 合成
- **六维诊断分：** 因果 18/选择性 24/可转译 18/原创 13/可证伪 10/证据 9 = **92**
- **谱系状态：** SP-retained / BP-retained / TR-retained / ME-advance / SR-revise / ER-lead_only
- **仿生真实性快检：** ipso 途径 α-四级碳判据是真实酶学 → functional_biomimicry（几何统计对应）

### A02 — ER 配体腔形状互补（毒性靶标降级）

- **原型：** PROTO_NP_002（ER，结构级，毒性靶标）
- **转译原则：** ER 腔对酚 + 对位烷基链的双点识别 + 支链/线性形状区分
- **材料概念：** 非对称深腔（一端酚锚，另一端烷基链形状腔），模拟 ER 配体腔
- **合成概要：** 非对称 calixarene 或 COF
- **致命风险：** ER 是毒性靶标（降级）；ER 腔对 NP 亲和力弱（µM 级）
- **六维诊断分：** 因果 13/选择性 18/可转译 11/原创 11/可证伪 7/证据 8 = **68**
- **谱系状态：** SP-retained / BP-conditional（毒性靶标）/ TR-retained / ME-repairable / SR-revise / ER-lead_only
- **仿生真实性快检：** ER 是毒性靶标 → 仅作几何参考

### A03 — P450 烷基链末端/芳环区域选择读取

- **原型：** PROTO_NP_003（P450，机制级，零先例）
- **转译原则：** P450 对烷基链末端的 ω-氧化 vs 芳环羟化区域选择 → 材料设烷基链深度读取（末端 vs 芳环端）
- **材料概念：** 梯度功能化孔道：孔口酚锚（芳环端固定）+ 孔底疏水腔（烷基链末端深入）→ 链长/支链读取
- **合成概要：** SBA-15 轴向梯度功能化（孔口氨基/脲基 + 孔底 C18 烷基）
- **致命风险：** 轴向梯度精度难控；P450 是催化氧化非吸附
- **六维诊断分：** 因果 12/选择性 16/可转译 14/原创 13/可证伪 7/证据 7 = **69**
- **谱系状态：** SP-retained / BP-retained / TR-retained / ME-advance / SR-revise / ER-lead_only
- **仿生真实性快检：** P450 区域选择是真实酶学 → functional_biomimicry（但转译为吸附是外推）

### A04 — FABP 疏水腔 + 酚锚双区

### A05 — β-CD 烷基链包结 + 支链/线性形状区分

### A07 — NPEO 降解酶乙氧基链识别（NP/NPEO 区分）

- **原型：** PROTO_NP_007（NPEO 酶，机制级，零先例）

- **致命风险：** 这是"排斥 NP"而非"捕获 NP"（逻辑反转）；PEG 刷对 NP 无选择性捕获
- **六维诊断分：** 因果 8/选择性 11/可转译 12/原创 12/可证伪 6/证据 6 = **55**
- **谱系状态：** SP-retained / BP-conditional / TR-conditional / ME-repairable / SR-revise / ER-lead_only
- **仿生真实性快检：** NPEO 酶识别乙氧基链是真实功能 → mechanism_informed（但逻辑反转）

### A08 — 石墨碳平面性/支链形状读取
