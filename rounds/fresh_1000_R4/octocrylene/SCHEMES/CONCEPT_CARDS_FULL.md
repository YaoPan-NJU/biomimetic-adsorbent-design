# Octocrylene 仿生原型注册表 + 50 概念卡（L1 全量）

**污染物：** 奥克立林 OC（CAS 6197-30-4，C₂₄H₂₇NO₂，MW 361.48，logKow ~6.1）
**核心难点：** 极强疏水中性分子（无离子化基团）+ 氰基丙烯酸酯核（电子亏缺）+ 与同类 UV 过滤剂共存（EHMC/BP-3/4-MBC/avobenzone）+ 强季节性/颗粒分配 + 降解产物二苯甲酮
**独特挑战：** 区分 OC 与结构类似的 EHMC（甲氧基肉桂酸酯）是核心选择性难题
**生成日期：** 2026-08-02

---

## 原型注册表（联网验证）

### PROTO_OC_001: 光合反应中心供体-受体电子预组织

- **自然功能：** 光合细菌/植物反应中心以精确供体-受体空间排列实现光诱导电荷分离
- **与 OC 的关系：** OC 氰基丙烯酸酯核是电子亏缺体（受体），二苯基是电子供体 → 分子内 CT 跃迁（OC 本身就是供体-受体体系）
- **证据层级：** 结构级（反应中心 PDB）+ 光化学原理
- **可转译原则：** 电子亏缺腔（受体壁）对 OC 供体-受体体系的 CT 识别
- **先例密度：** 低（fresh_1000 A01 已用，85 分）
- **诚实限制：** 光合反应中心是泛化电子预组织类比，非 OC 特异识别

### PROTO_OC_002: 珊瑚应激/UV 损伤修复蛋白

- **自然功能：** 珊瑚在 UV 胁迫下产生荧光蛋白/热休克蛋白/抗氧化酶
- **与 OC 的关系：** OC 对珊瑚有毒性（ANSES 2022 法国限制提案）；珊瑚对 UV 过滤剂的应激响应涉及蛋白识别
- **证据层级：** 现象级（毒性/应激）
- **诚实限制：** 毒性响应非识别功能；无结构证据

### PROTO_OC_003: 血清白蛋白疏水腔（UV 过滤剂结合）

- **自然功能：** 血浆疏水配体转运
- **与 OC 的关系：** OC 与 HSA 结合（疏水腔容纳二苯基 + 氰基丙烯酸酯核）；Bury 2023 报道 OC 人体暴露增加
- **证据层级：** 机制级（结合测定）
- **可转译原则：** 疏水腔 + 极性入口（氰基锚）

### PROTO_OC_004: 脂质膜分配（疏水中性分子跨膜）

- **自然功能：** 细胞膜脂质双层对疏水分子的被动分配
- **与 OC 的关系：** OC logKow ~6.1，强烈分配入脂质膜/颗粒/污泥
- **证据层级：** 物化原理
- **可转译原则：** 脂质双层疏水核心 → 疏水腔材料

### PROTO_OC_005: CYP450 UV 过滤剂代谢

- **自然功能：** 肝脏/皮肤 CYP450 代谢外源物
- **与 OC 的关系：** OC 经 CYP 代谢（酯水解→二苯甲酮 + 2-乙基己醇）
- **证据层级：** 机制级
- **可转译原则：** 酯键识别 → 转译为氰基丙烯酸酯核识别

### PROTO_OC_006: 迈克尔加成酶（亲核加成到 α,β-不饱和羰基）

- **自然功能：** 谷胱甘肽 S-转移酶（GST）催化亲核加成到 α,β-不饱和羰基化合物
- **与 OC 的关系：** OC 氰基丙烯酸酯是 α,β-不饱和体系（迈克尔受体）；GST 可催化亲核加成
- **证据层级：** 机制级（酶学）
- **可转译原则：** 迈克尔受体识别 → 亲核功能化材料（共价捕获）
- **先例密度：** 低（fresh_1000 A04 已用，80 分 DFT 门控）

### PROTO_OC_007: 角质层/表皮脂质屏障

- **自然功能：** 皮肤角质层脂质屏障（神经酰胺/胆固醇/脂肪酸）阻止外源物渗透
- **与 OC 的关系：** OC 设计为停留在皮肤表面（不渗透），角质层脂质与 OC 有亲和
- **证据层级：** 现象级
- **可转译原则：** 脂质屏障 → 仿生脂质层材料

### PROTO_OC_008: EPS/生物膜 UV 过滤剂分配

- **证据层级：** 现象级
- **诚实限制：** 非特异疏水分配

### PROTO_OC_009: 植物类黄酮 UV 吸收（天然 UV 防护）

- **自然功能：** 植物产生类黄酮/花青素作为天然 UV 吸收剂
- **与 OC 的关系：** 类黄酮与 OC 同为 UV 吸收剂（功能类似但结构不同）
- **证据层级：** 类比级
- **诚实限制：** 功能类比非识别

### PROTO_OC_010: 视觉色素视黄醛（光异构化识别）

- **自然功能：** 视紫红质中 11-顺-视黄醛光异构化为全反式
- **与 OC 的关系：** OC 也是光活性分子（UV 吸收后激发态弛豫）；视黄醛的共轭多烯与 OC 氰基丙烯酸酯共轭体系有电子结构类似
- **证据层级：** 类比级
- **诚实限制：** 光化学类比，非识别功能

## 50 概念卡（Top 10 + 速览）

### A01 — 光合反应中心供体-受体 CT 腔（已有方案，85 分）

- **原型：** PROTO_OC_001（光合 RC，结构级）
- **转译原则：** 电子亏缺腔对 OC 供体-受体体系的 CT 识别
- **材料概念：** 离散分子笼（电子亏缺萘二酰亚胺/苝二酰亚胺壁）+ OC 二苯基供体插入
- **致命风险：** 水相 CT 极弱；先例有（碘/硝基芳烃 CT 捕获）
- **六维诊断分：** 因果 14/选择性 17/可转译 13/原创 12/可证伪 8/证据 8 = **72**（降分：水相 CT 未验证）
- **仿生真实性快检：** 光合 RC 是泛化类比 → mechanism_informed

### A02 — 迈克尔共价捕获（已有方案，80 分 DFT 门控）

- **原型：** PROTO_OC_006（GST 迈克尔加成，机制级）
- **转译原则：** 亲核加成到 OC 氰基丙烯酸酯 β-碳 → 共价捕获
- **材料概念：** 哌嗪/硫醇功能化孔壁（亲核体）+ OC 迈克尔受体
- **致命风险：** β,β-Ph₂ 位阻速率待 DFT 验证；共价不可逆→再生问题
- **六维诊断分：** 因果 13/选择性 18/可转译 14/原创 13/可证伪 8/证据 7 = **73**
- **仿生真实性快检：** GST 迈克尔加成是真实酶功能 → functional_biomimicry
