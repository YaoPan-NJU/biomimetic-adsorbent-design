# PCP 仿生原型注册表 + 50 概念卡（L1 全量）

**污染物：** 五氯苯酚 PCP（CAS 87-86-5，C₆Cl₅OH，MW 266.34，pKa 4.75，logKow ~5）
**核心难点：** 弱酸（pH 6-9 以五氯酚氧阴离子为主）+ 五氯代芳环（强疏水+卤键供体）+ 与低氯酚同族物共存（2,4-DCP/2,4,6-TCP/2,3,4,6-TeCP）+ 斯德哥尔摩公约附件 A + IARC 1 类致癌
**独特挑战：** 从氯酚同族物中区分五氯取代（氯数/位置选择性）
**生成日期：** 2026-08-02

## 原型注册表（联网验证）

### PROTO_PCP_001: TTR 卤代酚通道（核心原型）

- **自然功能：** 转甲状腺素蛋白（TTR）四聚体转运甲状腺素 T4（四碘酚）
- **与 PCP 的关系：** Sandau 2002（被引 208）证实 PCP 和其他卤代酚结合 TTR；Yang 2013（被引 59）报道阴离子酚与 TTR 结合强于中性酚；TTR 通道对卤代酚有广谱结合
- **证据层级：** 结构级（TTR-T4 PDB）+ 机制级（PCP 竞争结合）
- **可转译原则：** 卤代酚通道（酚氧阴离子锚 + 卤代芳环疏水腔）→ 氯数/位置选择性
- **先例密度：** 低（fresh_1000 PCP A01 已用）

### PROTO_PCP_002: 五氯酚降解菌（Sphingobium chlorophenolicum）

- **自然功能：** 细菌以 PcpB（五氯酚羟化酶）逐步脱氯降解 PCP
- **证据层级：** 机制级（降解通路）+ 部分结构级（PcpB 结构）
- **可转译原则：** 逐步脱氯识别（五氯→四氯→三氯）→ 氯数选择性

### PROTO_PCP_003: β-CD 五氯环 snug-fit 包结

- **证据层级：** 机制级（包合物表征）
- **可转译原则：** β-CD 腔匹配五氯环轮廓（snug-fit）
- **先例密度：** 中（fresh_1000 PCP A04 已用）
