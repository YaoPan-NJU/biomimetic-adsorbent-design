# PFOA 仿生原型注册表（联网验证版）

**生成日期：** 2026-08-02
**验证方式：** WebSearch + 文献核验
**用途：** fresh_1000_R4 PFOA 50 方案的概念基础

---

## PROTO_PFOA_001: FABP4（脂肪酸结合蛋白 4）

- **自然功能：** 细胞内脂肪酸转运/穿梭，在脂肪细胞中结合并递送长链脂肪酸至核受体
- **与 PFOA 的关系：** Birchfield 2025 JACS Au（PMC12188406）报道 FABP4 与 PFOA、PFDA、PFHxDA 的晶体结构，展示三种不同结合模式，蛋白对链长变化具有适应性
- **证据层级：** 结构级（PDB 晶体结构，直接复合物）
- **可转译原则：** 疏水内腔容纳全氟链 + 腔口极性残基锚定羧酸头 + 结合模式可变性（非锁钥，而是诱导适配）
- **先例密度：** 中（fresh_1000 R1 A08 已用但终止；main 分支未用）
- **功能类别：** 识别 + 转运

## PROTO_PFOA_002: hL-FABP（肝脏脂肪酸结合蛋白）

- **自然功能：** 肝细胞内脂肪酸摄取与胞内转运，维护肝脏脂质稳态
- **与 PFOA 的关系：** Zhang 2013 ES&T（被引 302）对 17 种 PFC 与 hL-FABP 的结合进行结构基础研究；Fan 2025 报道 14 种 PFAS 与 rL-FABP 的结合亲和力
- **证据层级：** 结构级 + 结合亲和力定量
- **可转译原则：** 两亲性配体在疏水腔内的取向固定（头基朝向腔口极性区、尾部深入疏水核心）+ 链长依赖性亲和力梯度
- **先例密度：** 中（fresh_1000 R1 S1 历史方案用过）
- **功能类别：** 识别 + 分配

## PROTO_PFOA_003: HSA（人血清白蛋白）Sudlow 位点

- **自然功能：** 血浆中脂肪酸、药物、代谢物的广谱转运载体
- **与 PFOA 的关系：** Maso 2021（PMC7980502）报道 hSA-PFOA 晶体结构，8 个结合位点，Sudlow site I（subdomain IIA）和 II（subdomain IIIA）为主位点；Li 2025 确认 Sudlow I 为 PFAS 主结合位
- **证据层级：** 结构级（晶体结构，多分子复合物）
- **可转译原则：** 多亚腔分级结合（主腔 + 辅腔）+ 疏水腔口 Trp214 芳香壁 + 极性入口 Lys/Arg 锚定头基 + 广谱但非特异
- **先例密度：** 高（历史 S3/S4 用过 HSA 原型）
- **功能类别：** 转运 + 分配

## PROTO_PFOA_004: OAT4（有机阴离子转运体 4）

- **自然功能：** 肾近曲小管有机阴离子重吸收，介导尿酸、雌激素硫酸酯等从管腔回收
- **与 PFOA 的关系：** Louisse 2023（PMC9968691，被引 77）证实 PFAS 是 OAT4 底物，关键发现：**PFBS 不被转运**但 PFHxS/PFOA/PFOS/PFNA 均被转运 → 链长阈值 ≥C6
- **证据层级：** 机制级（转运体功能测定 + 链长选择性）
- **可转译原则：** 链长阈值门控（≥C6 通过，C4 排除）+ 有机阴离子头基识别 + 疏水尾部深度匹配
- **先例密度：** 低（fresh_1000 R2 PFHxS 方案引用过，PFOA 方案未直接用）
- **功能类别：** 选择性转运

## PROTO_PFOA_005: SsuA（烷基磺酸盐结合蛋白）

- **自然功能：** 细菌缺硫条件下捕获多种烷基磺酸盐并向 ABC 转运系统递送（营养摄取）
- **与 PFOA 的关系：** Beale 2010（PMC2852328）报道 SsuA 结构，两球域形成裂缝，磺酸头由多重主链 NH + 侧链极性基团 + 保守水定位；烷基尾进入含疏水残基的宽口袋
- **证据层级：** 结构级（PDB）+ 功能级（营养摄取）
- **可转译原则：** 入口中性多齿含水夹口（头基）+ 相邻低极性受限腔体（尾部）+ 不依赖永久电荷
- **先例密度：** 低（main SC-P02 用过，Ultimate 未用）
- **功能类别：** 识别 + 营养捕获

## PROTO_PFOA_006: TauA（牛磺酸/烷基磺酸盐结合蛋白）

- **自然功能：** 与 SsuA 同族，结合牛磺酸和短链烷基磺酸盐
- **与 PFOA 的关系：** Qu 2019（PMC6906117，被引 25）关键发现：**底物脱溶剂化代价决定选择性**——即使头基配位几何相同，不同链长的去溶剂化罚能差异造成数量级亲和差异
- **证据层级：** 机制级 + 结构级
- **可转译原则：** 脱溶剂化门控（头基进入疏水孔前必须脱水，二价离子脱水代价远高于单价）+ 链长-脱溶剂化耦合
- **先例密度：** 低（main SC-P02 引用为支持原型）
- **功能类别：** 选择性识别（脱溶剂化机制）

## PROTO_PFOA_007: 氟化物核糖开关（crcB/Fluoride riboswitch）

- **自然功能：** 细菌/古菌中感应氟离子毒性，激活下游氟化物外排泵（CrcB/EriC）表达
- **与 PFOA 的关系：** Baker 2011（PMC4140402，被引 577）发现广泛存在的氟化物核糖开关；2025 ACS Synth Biol 报道基于该核糖开关的氟化物生物传感器。注意：识别的是 F⁻ 离子而非全氟链，但"氟特异感应"原理可启发
- **证据层级：** 机制级 + 结构级（RNA 结构已解析）
- **可转译原则：** 氟离子特异配位几何（三配位平面，H 键供体环绕）+ 毒性感应→外排（捕获-隔离逻辑）
- **先例密度：** 零（从未用于 PFAS 吸附材料设计）
- **功能类别：** 特异感应 + 解毒外排
- **诚实限制：** 识别对象是 F⁻ 而非全氟烷基链，转译为 PFAS 吸附需要额外论证

## PROTO_PFOA_008: EPS（胞外聚合物）PFAS 分配

- **自然功能：** 生物膜结构基质，由多糖/蛋白/核酸/脂质组成，提供保护性屏障和污染物分配相
- **与 PFOA 的关系：** Yan 2020（被引 144）研究 PFOA 与三类污泥 EPS 的相互作用，证实 EPS 蛋白组分（疏水域）是 PFOA 主要结合位点；Zhang 2025 报道生物膜增强人工湿地 PFAS 去除
- **证据层级：** 现象级（吸附测量 + 组分分离）
- **可转译原则：** 多组分协同（亲水多糖屏障 + 疏水蛋白域结合）+ 分级孔道传质 + 非特异但有效的分配
- **先例密度：** 低（main DCP20-01 用过 EPS 屏障概念）
- **功能类别：** 屏障 + 分配

## PROTO_PFOA_009: SP-A/SP-D（肺表面活性蛋白，收集素家族）

- **自然功能：** 肺泡气-液界面的先天免疫识别，通过疏水颈域插入脂质膜 + 糖识别域（CRD）识别病原体表面糖图案
- **与 PFOA 的关系：** 无直接 PFAS 结合证据。但 SP-A 的"疏水颈域插入两亲界面 + 亲水头部在水相识别"的双域组织与 PFAS 的两亲性（疏水氟碳尾 + 亲水羧酸头）在界面行为上结构类似
- **证据层级：** 类比级（无直接 PFAS 证据，功能组织原理可迁移）
- **可转译原则：** 双域组织（疏水插入域 + 水相识别域）+ 界面定位 + 多聚体 avidity
- **先例密度：** 零
- **功能类别：** 界面识别 + 免疫防御
- **诚实限制：** 转译为 PFAS 吸附是原理类比，非功能同源

## PROTO_PFOA_010: 胆汁酸转运体 NTCP/ASBT

- **自然功能：** 肝肠循环中胆汁酸（两亲性甾体阴离子）的回肠重吸收和肝摄取
- **与 PFOA 的关系：** 胆汁酸与 PFAS 共享"疏水骨架 + 阴离子头基"的两亲性阴离子特征；NTCP 已被证实转运 PFOS（fresh_1000 PFBS 简报引用）。ASBT 回肠顶端钠依赖胆汁酸转运体对两亲性阴离子有高度选择性
- **证据层级：** 机制级（转运测定）+ 部分结构级（ASBT 有晶体结构）
- **可转译原则：** 两亲性阴离子的"疏水面 + 离子头"双特征读取 + 钠梯度驱动（可转译为 pH 梯度或浓度梯度）+ 甾体骨架形状互补
- **先例密度：** 低（PFBS 方案引用过 NTCP）
- **功能类别：** 选择性转运
