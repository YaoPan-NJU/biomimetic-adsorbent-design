# PFOA 50 概念卡（L1 全量）

**污染物：** 全氟辛酸 PFOA（CAS 335-67-1，C₇F₁₅COOH，MW 414.07）
**核心难点：** pKa≈0 全 pH 阴离子 + 两亲性（疏水全氟尾 + 亲水羧酸头）+ MCL 4 ng/L + 硫酸根 10⁷-10⁸ 摩尔过量 + 短链 PFAS 更难
**生成日期：** 2026-08-02
**原型来源：** PROTOTYPE_REGISTRY.md（10 个经联网验证原型）

## A01 — FABP4 诱导适配疏水腔 PMO

- **原型：** PROTO_PFOA_001（FABP4，结构级）
- **转译原则：** 疏水内腔容纳全氟链 + 腔口极性残基锚定羧酸头 + 结合模式可变性
- **材料概念：** BTEB 苯桥 PMO 孔壁（疏水腔）+ 孔口延迟共缩合 BTPU 脲桥（极性夹口），2.5-4.5 nm 孔径匹配 PFOA 全长 ~1.3 nm
- **合成概要：** 溶胶-凝胶，BTEB 先成核 → BTPU 延迟 20 min，P123/CTAB 模板，酸催化，80°C/130°C 水热
- **致命风险：** 脲桥孔口富集无法在分子尺度证明（仅外层元素比）；中性脲对全氟羧酸根水相净结合可能 <10 M⁻¹

## A02 — FABP4 三模式自适应笼

- **原型：** PROTO_PFOA_001（FABP4，结构级）
- **转译原则：** FABP4 对 PFOA/PFDA/PFHxDA 展示三种不同结合模式 → 材料应有多个亚位点而非单一锁钥
- **材料概念：** 间苯二酚[4]芳烃深腔笼，腔壁三段不同功能化（上缘脲/中段芳烃/下缘氟碳），允许不同链长 PFAS 以不同深度/取向结合
- **合成概要：** 间苯二酚[4]芳烃合成 → 上缘硝化/还原/脲化 → 下缘氟碳硅烷化 → 多步，产率中等
- **致命风险：** 离散笼合成 heroic（5+ 步），固定化路线未给出；水相笼-客体结合常数可能极低
- **六维诊断分：** 因果 12/选择性 18/可转译 10/原创 13/可证伪 7/证据 8 = **68**
- **谱系状态：** SP-retained / BP-retained / TR-retained / ME-repairable / SR-revise / ER-lead_only
- **仿生真实性快检：** 三模式自适应是 FABP4 真实特征 → functional_biomimicry（但材料能否复现待验证）

## A03 — FABP4 腔口门控 COF 通道

## A04 — hL-FABP 取向固定双区介孔
